# 英语空战实现结构

[返回总览](../README.md)

## 入口与模块

入口 `index.html`，原生 JavaScript ES Modules + Three.js，无编译步骤。 import map 后预加载 `three.module.js` 与 `three.core.js`，`scene.js` 导入和 `prepareAssets()` 并行；场景构造仍等待两者成功。`npm ci` 后以独立 `PORT` 运行 `npm start`，通过 HTTP 加载。程序版本 `v1.2.1`，日常修改不创建发布 tag。

战斗不显示年级、重点练习或操作提示。普通题使用上颚、下颚咬住题面，整个怪兽范围接弹；Boss 出现时保留已有普通飞机继续下降接弹，只停止新生成，不叠加面数／名称提示。题面 DOM 和点阵节点、怪兽材质及几何、弹体实例、幸运箱与收藏 DOM 池均在开局前准备，游玩仅更新既有对象。点阵采用字位的规范大小写，满格在 receive 中立即切换待定真字母并设置一秒输入锁，不依赖 keyup；同格同字母重复按键复用输入段并持续累加在途弹，只有实际换字母或重做才切换输入段、清理旧弹；退格删除清理旧弹并恢复可编辑状态。幸运箱仅与玩家做双向相对移动扫掠碰触，所有弹体忽略箱子；箱满时奖励排队。

普通题型使用独立种子流和二十题洗牌袋，十四拼写、三释义选择、三挖空选择；释义选择方向每两题各一次。选择题唯一正确、干扰项文本去重，命中时以弹体横坐标划分三个等宽区；首个满 20 发的选项锁定答案，清理在途目标弹、停止下降并复用验证状态。学习明细保存 `questionType`／`choiceMode`，身份映射由 accountId、libraryId 与 wordId 校验。八爪鱼头部和三根主触手分别使用共享 Worker 顶点色几何，四个目标槽在初始化预建，瞄准时仅切换预备高亮材质；UI 选项节点、16 个幸运箱与收藏节点在初始化阶段预建。

## 状态与时间

资源入口为 preparing／prepareFailed；界面包括 menu、instructions、tutorial、preview、playing、paused、review、recap、won。活动飞行与首页星空沿用 requestAnimationFrame；战斗逐帧提交，菜单在高画质最高 60 帧、标准／省电最高 30 帧，背景累计显示间隔推进时间。覆盖式弹窗（含预习）、暂停和结算按状态、尺寸或设置变化重绘，隐藏页面停止帧调度。复习仍独立按秒唤醒更新界面。复习仅在前台且聚焦时按下一秒边界唤醒，使用实际有效时间推进并保存余时，失焦前结清有效片段，恢复不补算后台时间。只有 playing 推进有效时间。桌面首关随机选空战或碎片，随后交替，碎片关使用 AssemblyRound 四轮有效计时；触屏碎片关使用 AssemblyRound，点选关使用同一 Game 判题，普通题与 Boss 均直接点选。UI 根据 pointer: coarse 更新设备属性，Game.prepareLevel 固定当前局模式，缩放及游玩中设备属性变化不切换当前局；Game 先分流碎片更新，避免生成射击、Boss 或补给，学习与结算复用现有流程。四轮完整规则见[交替关卡与碎片模式](../design/english-air-combat/09-交替关卡与碎片模式.md)。`victoryRemaining` 为 null 时运行常规倒计时；大 Boss 所有面结果为 correct 后清场、发五箱并设为 5，仍使用 playing／paused，暂停与失焦沿用既有冻结。此阶段只处理四方向移动、箱子和收藏动画，停止射击及新生成，完整五秒后以 boss-defeated 原因结算；可超过本词库的常规时限，不回退有效时间。重开及切账号清空此阶段并恢复玩家底部位置。暂停冻结移动、验证、转面与收藏动画，失焦清空输入。review 单独推进，页面隐藏或失焦时停止；每秒及 pagehide 保存余时。结束后 review 在错题回顾中推进，结束进入 recap 等待用户继续，再进入 won。无错题直接 recap。result.recapPending 标记尚未查看完的回顾，与剩余复习时间一起保存，零秒仍保留；继续后清除。恢复时按剩余时间进入 review 或 recap，不开放可绕过复习的菜单入口。

登录先等待旧保存完成，关闭旧学习库后载入目标账号及其上次词库，设置对象原地更新供场景复用。每关预习先读取未完成／重玩的十二词，或新建并同步保存词池，再完整浏览后开局；新抽词池限定当前词库，小六沿用分组随机整数配额，其他库按本库权重抽取；已保存的十二词继续原样恢复，不因比例调整重抽。本关用同一洗牌袋分配普通题和 Boss 面。Boss 期限与关卡时钟独立；结束统计所有已出现实体，未出现词不计入正确率。普通出题按整局剩余时间及逐格锁定预留完整作答预算。正常飞机最多 2 个可编辑、3 个题面槽；敌机活动池 16，溢出规则事件排队，不能丢失。普通颗粒 64、撤销弹 4、战斗炮弹 8、敌弹 64，幸运箱／收藏飞行槽各 16。容量修改须重新核对最大需求。

星座星位、点径及连线以 TypedArray 随 Worker 结果持久保存，新增五套几何共 1728 字节；场景槽位共享几何和材质，预热完成后游玩只切换资源。生成器及缓存格式为 8，包含 `constellations`、航母 `carrier` 及两档球体数据；球体新增 `Uint16Array` 索引与飞机专用 `aircraftSphere`，移除未引用的旧 `monster`。星空组按新指纹重新准备，独立 Boss 和箱子位图缓存继续复用，程序版本保持 `v1.0.9`。

## 数据与兼容性

每个账号每个词库的学习库含 words、attempts、runs 三个 store。学习库采用版本 2，attempts 包含 wordTime 复合索引；明细按时间倒序、每页 100 条，仅游标读取当前页，异步回写核对账号、词库、单词、页码及面板状态。每次飞机／Boss 面对应唯一明细标识，kind 为 correct、wrong、incomplete；同词多次出现保存多行。局末在同一个事务中更新汇总、写明细与局标记，重复局不累加。事务按队列串行执行，开下一局前等待上局保存，界面异步回写检查当前面板和结果标识。

账号目录使用 english-air-combat:accounts。账号级前缀 english-air-combat:account:<id>: 保存 settings 和 active-library；词库级前缀追加 library:<libraryId>:，保存成绩、关卡、复习、待入库及 level-state。调试账号使用独立 debug:<testId>:。学习库名称为 english-air-combat-learning-<accountId>-library-<libraryId>，不读取原来未分词库的学习库或快照，不做旧记录迁移。

Storage.login 恢复账号上次词库，switchLibrary 在当前复习锁清零后才允许切换。二者复用 finishPending 等待旧保存及数据库队列、缓存原映射再关闭旧连接；profileCache 键包含账号和词库。Game 的 session、record、result 均保存 accountId、libraryId；存储层校验词条属于当前词库，拒绝外来写入。例子随结果保存，并可按规范词条恢复。设置对象身份保持不变，Scene 和 Audio 复用同一对象；模型缓存仍为游戏级，不因切库重新生成。

词库在 vocabulary-data.js 注册，getVocabulary 遇到非法 ID 抛错；恢复保存的选择时回退小六。每词含 example.text、example.meaning、example.kind；多义词的首例及 example.additional 中的补充例句另含 sense 和 partOfSpeech，按义项配对并共用卡片渲染；卡片按 WORD_CARDS 中的例子数量、释义长度及英中加权文本量选择普通／紧凑／密集排版，两组例子起收紧间距，四组或特别长的内容采用更紧凑的字体与义项侧栏；矮窗口进一步缩减预习头部间距。预习卡片内容独立滚动、导航和开始按钮固定可见；过关回顾按词合并显示作答快照和正确词义，相同错误写法标注次数，小模型与对错文字直接摆在星空上；根据宽度使用二至四列，长词适应列宽，内容超出时使用最右侧滚动条，标题和底部按钮固定；最终弹窗仅保留操作按钮。选择题干扰项限定当前库，字位在 Scene 初始化时按 VOCAB.maxWordLength 预建；长词题面宽度不超过逻辑可用宽度，显示压缩字母行但保留完整字位。学习重置二次确认后仅清当前账号当前库的 words、attempts、runs 及学习快照、待入库；其他库、设置、成绩、关卡、词池及复习锁保留。

历史正确率严格超过 50%、75%、85% 时选词权重分别为 0.5、0.25、0.01，非累计相乘；只影响下局词池。本局词池仍全部用完后再重复。

朗读使用系统 SpeechSynthesis，页面初始化不调用getVoices，首次点击在同一调用栈内以通用en语言直接播放，不以声音枚举成功为前提。播放开始后才优选Samantha等自然英语声音用于后续点击；英语声音不限制国家地区，兼容en_US与eng-US等标签。默认rate 0.75、pitch 1.08、volume 0.85；未启动或语音／语言失败时依次尝试标准语速音调、至多两种可用英语声音、自动en-US、自动en-GB及完全交由系统默认语言与声音。总共最多七次尝试，并保留最后的系统默认路径；每次启动等待1.4秒，取消队列后间隔80ms再尝试，不等待voiceschanged；若引擎报告正在播放则停止启动超时回退，避免重复读词。参数集中在AUDIO。播放已开始后不自动重读；系统禁止播放时提示再次点击，音频设备忙或不可用时单独提示。复用pendingCancel清理计时器和旧事件，重复点击、切词、离开列表、开局或失焦取消整条回退链。应用不生成或下载音频文件。

## 资源、版本与发布范围

GENERATOR_VERSION 与 CACHE_FORMAT_VERSION 均为 8，包含星座、航母及两档索引球体几何。缓存按源码、生成所需配置与固定种子指纹校验，速度、蒙版及未参与生成的参数变化不重算几何／像素；同格式兼容的旧完整配置指纹可直接读取并登记新键。新资源校验并成功写入后才清理本游戏旧生成缓存，设置和学习数据保留。只在非游玩阶段生成，队列与 Worker 停止后恢复 GPU 对象并预热，目标准备不超过 6 秒。游玩和同页重开复用，不产生新模型。首页尾气、驾驶舱、发动机和尾焰共用飞机专用 24×12 球体，星球与大气层使用原 48×24 球体；二者按完整位置／法线／UV 网格保留接缝，缓存及 Worker 传输均保留索引。无 Worker 时，星点按有界块、纹理按行、球体按网格行推进同一生成器，约每 4 毫秒让出主线程；游玩阶段继续只复用资源。

星空包含 1200 星点、6000 银河点、十七项背景表、十一张 512×256 纹理。月球／地球／太阳／银河参考半径 22／64／180／400，大型天体外缘限制宽 72%、高 60%。每 15 秒无放回出场，十七种用完再洗牌，跨轮避免连续同项。背景速度缩减取整，星球每秒 21，蒙版透明度战斗 0.52、菜单 0.28。

npm run prepare:pages 整理英语空战运行依赖与 Three.js 到忽略目录 .pages-output，资源指纹清单与缓存不入 Git。发布文件目标小于 10 MB。当前支持桌面实体键盘空战与手机点选／碎片交替练习，均为单人本地游戏，提供无密码本地账号，无联网同步或屏幕字母键盘。四阶段词库及词语例子随静态包发布，保留 third-party 许可与来源，不声明完整教材或官方考试大纲覆盖。

账号选择、随机创建及登录确认使用 home-accounts，直接替代 home-launch-controls，不复用 dialog 遮罩。accountMode 管理列表和原位登录确认；首页开局区提供当前账号切换入口，页脚只保留靠右的音量、减少闪烁和版本。账号名仅在创建表单编辑，存储层不提供改名方法。

首页右侧展示使用 makeHomePreview，在 Scene 初始化时随机选择红色小怪、四面小 Boss 或五面大 Boss，本次页面生命周期内复用。makeMonster 共用战斗怪兽的几何、顶点色材质与构造，实例矩阵独立；缩放、横向位置及页面高度比例集中在 HOME。展示模型在开局前预热，游玩期间隐藏，仅更新既有对象变换。挖空单词顶部为页面高度的 65%，模型中心为 46%，两者水平对齐，长单词保持单行。

幸运箱沿用原 SVG 图案与串联双重阴影，在准备期按至少二倍像素密度一次栅格化、解码并持久缓存，箱子池共享图片；位图指纹独立包含图案、尺寸、阴影、留白和像素密度。不可用时保留原 SVG 与相同阴影作为降级。活动箱子、收藏、题面及敌机文字只更新 transform，内容和可见性变化才写入；HUD 显示值变化才刷新。游玩中不生成位图或新建节点。普通答对箱复用相同箱子池，通过有效时间先慢晃两秒，再按到 HUD 的逻辑距离计算飞行时长（0.65–3.2 秒）；Scene 仅提供 HUD 坐标和绘制，Game 在抵达时入账。局末逐箱补齐未抵达的已发奖励，不重复入账。

`word-blanks.js` 对任意字母生成随机挖空，数量从2到词长一半（向下取整），二至三个字母词也挖2个；`background-layout.js` 负责有界事件元数据及外观边界避让，不修改生成资源配方或持久缓存。

敌机九个部件在准备期按两种材质烘焙位置与法线，合并时保留索引，使用两个有界 InstancedMesh。每架 2,958 三角形、两个合批原型合计 1,823 个顶点和 61,500 字节；机身外沿、部件尺寸、材质与警戒缩放保持。矩阵变化才上传，空池隐藏；实例化着色器在开放操作前预热。首页预览复用同一飞机模型。

页脚画质按账号保存为 `renderQuality`，旧设置缺失或非法值使用高画质。高／标准／省电的 DPR 上限为 2／1.5／1，高／标准／省电分别限制 4,500,000／3,686,400／2,073,600 绘制像素。仅调整三维画布，DOM 题面保持清晰；尺寸、画质或显示器 DPR 改变时同步绘制尺寸、相机和点径 uniform，未变不重建 buffer。调参集中 `MODEL_GEOMETRY` 与 `RENDERING`。

## 紫色恶魔 Boss

小／大 Boss 保留双角圆脸与四角头冠、宝石和蝙蝠翼造型。主体单Mesh、触手单InstancedMesh，另有当前表情Mesh与轻微外光壳；表情细节及格式见下方“模型细节与逐面情绪”。左右、上下摆动及答题后触手收起只更新实例矩阵，不生成几何，不改变面数、转面时间、题面命中区、判题或奖励。

顶点、法线、线性顶点色与索引在独立Worker中生成并转移，使用Boss源码指纹、独立格式2及生成配置。动作速度、外光、缩放和位置不进入几何配方。主资源格式／生成器仍为8，程序版本保持v1.2.1；无Worker时按小批次让出主线程。开放操作前停止Worker，所有主体、触手及四种表情均离屏预热。

## 资源并行与题面更新

打开缓存连接后，星空／飞机／航母、Boss 和补给位图三条链独立读取、校验、生成和写入。进度按已完成权重累计，不因完成顺序回退。用 `Promise.allSettled` 等待全部任务；任一必要资源失败仍等待其余 Worker 停止，最后关闭数据库，保留旧成功记录。缓存键、生成器与格式不因并行调度变化而递增。

纹理在场景构造阶段通过 `initTexture` 上传。预热复用背景槽，同时显示五套星座的点／线几何及 Standard／太阳 Basic 贴图材质变体，使用与页面相同输出色彩空间的 1×1 临时离屏目标，先异步编译，再用两次整场景绘制覆盖全部缓冲；两次绘制间只让出一次主线程。预热结束或异常时恢复原渲染目标、释放临时目标并还原槽位状态，临时居中的八爪鱼、Boss 和天体不提交到页面画布。启动期间仅先绘制一次正常首页，资源及回顾缩略图准备完成后才开放普通帧调度，避免失焦／恢复事件在预热期间插入绘制。首次正常场景绘制另计，不把上传延迟到游玩。

题面 `font-size` 和 `line-height` 改为 CSS 根据 `#word-layer` 的 `--word-scale` 计算；仅窗口缩放变化时更新该变量。卡片宽度随实际 `word.width` 变化才写入，题面使用自然高度，换题或缩放时读取一次实际边界并写入 word.height；接弹、目标排序和模型上下颚／触手读取同一高度。`will-change` 使用实际运动的 `transform`。粗指针媒体查询在 UI 初始化时保存，监听 change 后刷新界面，帧循环只读现有结果。

启动日志补充 `spaceMilliseconds`、`sceneImportMilliseconds`、`sceneConstructionMilliseconds` 和 `warmupMilliseconds`。资源链耗时可能重叠，不能相加作为总准备时间；`navigationMilliseconds` 从启动模块执行开始计时，不包含此前的 HTML 和模块下载。

词库导入由官方分级清单与内容配对模块驱动：`scripts/extract-cet-wordlist.py` 恢复大纲词形，`scripts/import-vocabulary.mjs` 负责同库去重、字段校验和统一写出前的完整内容检查。六级为新增进阶库；主词、派生词和合法变体按独立拼写计数。词义、词性及英中例子以 `src/vocabulary-*.js` 为准，导入保留已有词条内容，仅为新增词形补充内容；内容缺项不写出词库，`--check` 可核对词形清单、字段和写出格式。

## 通关回顾资源

Scene 在初始化预热阶段复用同一 WebGLRenderer、现有咬题怪兽／八爪鱼／两种 Boss 几何和材质，依次渲染四张透明缩略图。图像只作为本页 DOM 展示快照，同页重开复用；不新增模型配方、Worker、持久资源组或渲染器，不改变已有资源缓存版本。临时渲染目标生成后释放，借用的模型变换、父节点及渲染器目标／清屏状态全部恢复。游玩中不生成缩略图。recap.js 按 wordId 分组，按结果、答案和字位快照合并相同写法并计数，保留不同写法及对应题型模型；原始学习明细不合并。review／recap／won 的场景提交统一隐藏全部天体和战斗对象，只画星点；回顾和最后弹窗沿用按需绘制。

## Shift 跟踪弹

Game 只对场内存活红色小怪选目标，成功取得弹体后扣库存和登记冷却。弧线以发射点、侧向控制点和实时敌机位置计算；目标失效时重新从当前弹位起弧，无目标回收。二维相对扫掠与曲线终点共同保证移动目标的命中，击杀只入账一次。Projectiles 初始化时为每枚跟踪弹分配固定环形尾迹，发射复用时清零计数；Scene 沿用同一颗粒 InstancedMesh，容量包含八枚跟踪弹各十二个尾迹，不增加渲染器、几何配方或游玩阶段资源生成。

## 点阵与横向边界

letterShotCount 统一按字形亮点数的 70% 取最近偶数，Game 的作答预算、接弹、完成判定及答案文本共用该值；letterDotCount 把子弹进度映射为完整字形亮点。Scene 与错题回顾共用该映射。新回顾快照保存完成状态与实际点亮数量，旧快照仍按当时的原亮点阈值解释，不因调参重写已保存的样子。

Scene.resize 将可视逻辑宽度交给 Game.setPlayWidth，活动宽度以原 960 的 1.25 倍为上限，窄屏不超出可视区域。坐标原点和背景投影保持，玩家、出题、Boss、敌机、箱子及跟踪弧线读取同一左右界限；收窄时把现存对象收回界内，不重新生成资源。Boss 仍沿用原速度参数，只调整振幅与面数；模型与字形缓存继续兼容。

## 触屏布局与预览

UI 初始化匹配主指针 coarse 并设置 Game.touchMode 与 body 的 data-touch；媒体查询变化只影响后续 prepareLevel，当前 mode 保持。resetAccount 保留设备属性，设备不参与存储键。首页、预习及模式说明读取同一 levelMode(level,touchMode)，已保存结果保留原模式。bootstrap 的 debug=1&touch=1 仅用于桌面验证触屏布局，正式手机无需调试参数。

触屏样式独立按 data-touch 覆盖，避免窄窗口桌面被误判为手机。使用 100dvh 和 safe-area-inset，手机首页隐藏已有飞机装饰的可见性，不改模型与缓存配方。触屏滚动使用原生滚动，不拦截 pointermove；预习只在水平主导的 pointerup 翻卡，pointercancel 清除起点。SVG 连线仍读取同一重排坐标，在 ResizeObserver 中更新；布局调整不生成三维资源。

## 空战词库时序

config.js 的 combatTiming(libraryId) 统一计算小六／初中／四级／六级的 270／285／300／315 秒总时长、小 Boss 和大 Boss 出场时机及普通出题间隔。Game 在创建、切账号、预习及恢复回顾时读取该词库配置；start、剩余作答预算、普通出题调度、Boss 出场和截止共用本局 timing。UI 首页和玩法介绍读取同一函数，碎片模式保持独立的 每轮 90 秒计时。

每个 Boss 仍保留 60 秒，普通阶段时长为总时长减 120 秒，出题间隔相对四级的 180 秒普通预算同比缩放；不修改飞机下降及键盘输入节奏。新结果保存 durationSeconds，恢复时读取记录自身时长，旧结果缺失字段按原 300 秒兼容，避免用当前词库时长改写旧回顾。程序及模型缓存版本保持不变。

## 随机首关与交替顺序

Storage.modeForLevel 统一供首页和 Game.prepareLevel 调用。首次桌面访问当前账号＋词库时等概率选 combat／assembly，写入现有 progress.firstMode；后续用同一首关模式及关号推导交替序列。触屏直接返回 assembly，不消耗桌面随机选择，也不覆盖已保存首关。账号和词库的现有存储隔离、缓存与异步等待保持。

旧进度缺少 firstMode 时，优先从本账号、本词库最早的有效空战 session 或成绩反推桌面顺序；没有可用桌面记录才随机。随机结果即使持久写入失败也留在当前进度对象，本页重开不会重复抽取。已保存结果的 mode 继续用于回顾，存档与缓存格式版本不变。

## 模型细节与逐面情绪

怪兽主体保持原有分类与判题轮廓。咬题怪兽和红色小怪增加斜眉、侧边獠牙、双层额角与皮肤斑点；八爪鱼增加卷角、坏笑与小獠牙，保留圆润身体和八根触手。玩家飞机增加座舱玻璃、进气口、尾喷口、翼面灯条和通风栅；补给箱使用同一张预备位图表达倒角、铆钉、锁扣和灯带。八类行星增加坐标驱动的条带、风暴或岩面细纹，随机序列不变；地球、月球、太阳、银河、星座保留原有完整表现与同源布局。

两种Boss主体轮廓保持，眉毛和嘴部拆为四份表情：初始坏笑、微怒、咬牙发怒、强怒。按已记录面数选取预建表情，第二面后出现淡紫红外光，第三面进一步加强；不改变判题、面数或奖励。小Boss剩最后一面为发怒加微光，大Boss剩最后一面为强怒加深微光。所有表情在准备期逐份离屏提交；暂停时有效时间与表情冻结，重开恢复初始。

全部五类怪兽几何按position／normal／color完整属性合并顶点，保留颜色与硬法线边界；Uint16索引与必要时Uint32索引随Worker转移。旧无索引、空索引和越界索引缓存拒绝恢复。索引整理按小批次让出；缓存采用Boss独立格式2及源码指纹，星空纹理按自身源码指纹更新，补给位图按SVG配方更新，账号与学习记录保持独立。最终几何总数据1,563,864字节，包含新增表情；不等同Pages发布体积或显存峰值。

# 潮汐渔场

Godot 4.5.1 原生离线捕鱼游戏，使用类型化 GDScript 与 Compatibility 渲染。当前实现 macOS 与 Android 共用玩法；macOS 提供独立 Universal 应用，Android 提供触摸适配与导出预设。iOS、Windows 仅保留共享代码可复用性。

## 启动

- 安装版位于 `/Applications/潮汐渔场.app`；构建包位于 `exports/macos/潮汐渔场.app`，压缩包为同目录下的 `潮汐渔场-macOS.zip`。导出目录不提交版本控制。
- 开发运行：双击 `tools/run-macos.command`，或在 Godot 4.5.1 中导入 `project.godot`。
- 重新签名打包：运行 `tools/export-macos.command`；打包并安装使用 `tools/install-macos.command`，已有最新签名构建时可追加 `--skip-build`。项目使用同版本官方 `macos.zip` 模板，下载脚本及校验信息见 [运行与平台.md](docs/技术/运行与平台.md)。

首次从其他机器检出时，需将官方 Godot 4.5.1 macOS 编辑器解压到 `.tools/Godot.app`，也可设置 `GODOT_BIN` 指向该版本可执行文件。本工程没有第三方 Godot 插件或联网依赖。

## 操作

- macOS：左右方向键转炮，按住任一 Shift 连发；鼠标只操作界面。Esc 暂停／继续，失焦自动暂停，继续后重新按键。
- Android：点击有效海面，炮弹从炮口发射；多指、UI 点击及冷却期点击不额外发射。横屏，后台暂停，返回键控制鱼篓／暂停。
- 六档渔网从破网逐步提升到龙绡网，全部可选，切换免费；每炮消耗一发弹药和卡片显示的金币。没有瞄准线或范围预览。
- 普通渔获进入鱼篓，支持按鱼种出售和全部出售；鱼篓打开时海面继续游动。
- 免费补给每次提供 1,000 弹药与 5,000 金币，可以反复领取。

## 已实现玩法

- 十种普通鱼、四种小鱼编队、单体巡游与普通大鱼；鱼身后躯、尾鳍和胸鳍局部变形，独立影子、受击与网兜捕获动画。
- 深海巨鲨稀有穿场，概率极低但可捕获，仍需手动出售。
- 星翼宝鲂完整三秒预警；预警前已开鱼篓时延后，预警开始后不因鱼篓开关重置。有效渔网实际覆盖即必捕，炮弹遵守首次阻挡，3,600 金币一次提交，十二批金币连续喷出并飞入金币袋。
- 六档真实网具独立配置、扫掠弹道、一次张网逐鱼独立概率判定、在途配置冻结；普通鱼没有累计必捕。
- 新档 50,000 金币、10,000 弹药；钱包、渔获冻结单价、设置、随机状态、在途炮弹、刷新与事件时钟持久化。正式档、备份、临时档校验，保存失败暂停交易并可重试；损坏档不静默清空。
- 主音量、音效开关、减少闪光、画质选择、暂停、补给、鱼篓、中文字体和原创合成音效。

数值仍为首轮调参基线，平台与验证范围见 [运行与平台.md](docs/技术/运行与平台.md)。Android 暂未进行构建及设备验证。macOS 沿用 SimplePaint 的固定 `PasteHub Local Signing` 本机证书，由 `.local-signing.json` 固定证书指纹，不退回 ad-hoc 签名；当前未配置 Apple 公证。

## macOS 运行与导出

开发运行使用 `tools/run-macos.command`；`GODOT_BIN` 可覆盖编辑器路径。重新生成签名应用与 ZIP 使用 `tools/export-macos.command`；构建并安装使用 `tools/install-macos.command`，已有最新签名包时可追加 `--skip-build`。缺少模板时，脚本从官方压缩包按字节区段提取 macOS 模板，并验证 ZIP CRC。

独立应用路径为 `exports/macos/潮汐渔场.app`，包含 Intel 与 Apple Silicon 可执行架构；ZIP 为 `exports/macos/潮汐渔场-macOS.zip`，安装位置为 `/Applications/潮汐渔场.app`。打包、签名、安装只处理 macOS。

签名流程与 SimplePaint 一致：使用固定的 `PasteHub Local Signing` 本机证书，SHA-1 指纹为 `48DD95F4C2AED23D2BD3119352C50951CB532931`，开启 hardened runtime、不请求时间戳；designated requirement 绑定 `com.allan.tidalfishing` 与该证书。通过 `codesign --verify --deep --strict -R` 校验，拒绝证书缺失时退回 ad-hoc。此本机证书不是 Apple Developer ID，当前未配置 Apple 公证或 App Store 发布；平台发布要求参考 [Godot macOS 导出文档](https://docs.godotengine.org/en/4.5/tutorials/export/exporting_for_macos.html)。

`tools/package_macos.py` 先在 `.tools/` 临时目录完成 Godot 导出、固定证书签名与校验，再整包切换到输出目录，旧包保留在 `.tools/retired-apps/`。安装时先在 `/Applications` 同卷临时目录复制并校验整包，再替换安装目标，失败恢复旧包；不原地覆盖运行中的二进制，不重签运行中的应用，不自动启动游戏。

`.local-signing.json` 仅保存在本机并被忽略，包含 `identity`、`certificate_name`、`bundle_id`，不包含私钥或密码。首次在其他机器使用打包脚本前，需配置可用证书的准确指纹与游戏 bundle ID。核对已有构建和安装版可运行 `python3 -I tools/package_macos.py --verify --install`。

桌面操作：左右方向键转炮，任一 Shift 开炮，Esc 暂停；鼠标只操作 UI。两枚 Shift 共用同一射速预算，左右同时按下不转向。暂停、失焦和鱼篓开关清空按住状态。

macOS 默认窗口为 1920×1080，界面随窗口等比放大；世界逻辑仍为 1600×900，放大窗口不会改变网的判定范围或射速。

## Android 实现范围

`export_presets.cfg` 的 Android 预设使用 `com.allan.tidalfishing`、arm64、横屏、沉浸显示、无网络权限，使用 Godot 标准 APK 导出路径。玩法、资源与存档和 macOS 共用。InputRouter 以平台特性区分触摸与桌面输入；只接收首个有效触点，点击 UI 或冷却期间不扣资源。

画面采用 1600×900 固定逻辑空间与等比边饰，网的世界尺寸不随设备比例改变。移动 UI 六档采用 2×3 排列；通过 DisplayServer 安全区域缩放和偏移 HUD，射击同时过滤安全区域。返回键控制鱼篓或暂停，切后台保存并暂停；竖屏显示旋转提示。

后续导出需安装匹配模板、JDK 17 和对应 Android SDK，再在 Godot 中配置 SDK 路径与签名。具体依赖以 [Godot 4.5 Android 导出文档](https://docs.godotengine.org/en/4.5/tutorials/export/exporting_for_android.html) 为准。本轮只编写共用实现与预设，未进行 Android 构建、安装或真机验证。

## 实现边界与存档兼容

已接入阶段一及阶段二的玩法循环、十种普通鱼、巨鲨、星翼宝鲂、四种编队、六档真实绳网、设置、音效和持久化。首轮资源、概率、价格与刷新间隔均按设计基线配置，不表示已经完成长期平衡或性能验收。

存档 schema 为 1。NetDefinition 的 ID 稳定，六档名称和数值可调整；已经发射的炮弹保存发射时的范围、概率系数和价格。新增的 `texture_path` 是可选视觉字段，旧炮弹缺少该字段时使用基础真实绳网，不重算旧炮弹或已有渔获价值。随机状态以十进制字符串保存，避免 JSON 浮点数损失 64 位随机状态精度。

运动每两秒保存；交易在同一物理步结束后合并同步保存，UI 交易、失焦与退出立即保存。保存失败冻结交易，保留当前完整状态和待播放反馈供重试。当前同步保存便于保证结算边界；后续若实测写盘影响低端设备帧耗时，再改为明确有序的保存队列。

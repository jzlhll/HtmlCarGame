# 美术、动画与音效

## 视觉方向

精致海底街机风格：深蓝与青绿水体、暖金色炮台和金币、少量珊瑚红／紫色点缀。背景偏低对比，鱼具有清晰轮廓和体积明暗，金币和捕获特效承担短时视觉高点。保持统一的略俯视视角、上方主光和柔和投影。

立体感由分层海床、鱼体体积绘制、远近缩放、阴影和局部动态光组成，不要求首版建立实时 3D 海底。鱼和界面采用不同的阅读优先级，不能让复杂背景淹没目标。

## 资源生产选择

- 使用 imagegen 内置工具生成原创海底、鱼类与炮台的光栅素材；提示词明确用途、视角、朝向、留白、光照及透明背景。
- 生成素材需检查轮廓、透明边缘、鳍数量、光源和同角色一致性；未经检查不得直接入图集。
- 鱼体、尾鳍和胸鳍根据动画需求分层或使用网格变形。关键鱼需要专门的尾部与鳍动作，不能只通过整张图缩放、旋转伪装游动。
- 使用 Godot 内置工具制作程序化网纹、图形 UI、Shader 和粒子；不以临时几何占位替代最终主角鱼或海底美术。
- 首版不依赖付费 Spine 工具链。需要连续变形时优先 Polygon2D／Skeleton2D；适合短爆发的效果使用帧动画。
- 音效使用原创合成或明确允许商用的资源；字体使用许可明确、能覆盖中文的字体。引擎免费不等同于所有资源免费。

## 动画规则

### 鱼

- 鱼头和躯干保持体积稳定，摆动幅度从躯干后段向尾鳍增加；胸鳍使用更轻微、不同频率的动作。
- 根据路径切线平滑朝向，转弯有身体弧度；不在一次显示帧内翻面 180°。
- 鱼体 Shader 可做小幅周期形变与受击染色，UV 边缘不能撕裂；较大弯曲交给细分网格或骨骼。
- 受击有 0.1～0.2 秒局部高光与短挣扎；各次受击表现独立，所有鱼均不使用累积疲惫或濒死提示，避免暗示必捕。
- 捕获约 0.7～1.0 秒，依次张网、包拢、轻旋和缩入鱼篓；判定已经提交，动画不是二次判定机会。
- 不通过无目的全身缩放制造呼吸感；嘴和鳃可作克制的细节动画。

### 炮台与网

- 炮管角度与实际弹道相同，发射点始终为炮口；后坐只影响炮管视觉偏移，不改变本发弹道。
- 网从命中点向外展开，网结沿圆周受力、随后收拢或消散；颜色与所选渔网一致。
- 没有命中时也正常张网、短暂停留并淡出，不能用捕获特效误导成功。
- 未发射前不展示虚线轨迹、范围圆或预测落点。

### 海底材质

- 海床使用缓慢移动的焦散光纹，叠加不超过少量透明层；避免全屏强烈波纹引起不适。
- 前景海草轻摆、远景低饱和、气泡稀疏上升；鱼影随鱼移动并与鱼体保持一致。
- 发光特效通过局部纹理和 Shader 实现，慎用全屏后处理。

### 金币雨

- 星翼宝鲂触发后采用“蓄光 → 连续向外喷币 → 金币弧线汇入袋口 → 最后收束”的节奏。
- 金币拥有不同初速度、旋转相位和路径，但最终汇入真实金币袋位置；适配屏幕变化后重新计算终点。
- 喷发持续约 4.8 秒，12 批，每批约 8 枚主金币。控制同屏数量，使用复用对象，不为每枚金币创建钱包交易。
- 袋口轻微弹性开合、金币数滚动与音高递进协同。低画质保留多批节奏，减少每批数量。
- 减少闪光模式降低白闪与金光面积，保留完整奖励与持续飞币过程。

## 声音

- 发射短而干净，网展开带轻水声；普通捕获与巨鲨捕获使用不同层次。
- Bonus 出现前有 3 秒可见预警，提示覆盖在鱼篓之上；入场使用可辨认的轻铃，喷币音每批触发，不能每枚金币同时播放导致爆音。
- 建立 Master、Music、SFX、UI 总线；高频发射限制并发，金币声按批次节流。
- 首版环境声可用轻水流底噪，音乐不是首个小场景的交付前提；所有声音支持独立关闭或主音量控制。

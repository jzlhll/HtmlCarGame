# 素材来源

所有游戏画面均为本项目现场生成或代码绘制，没有使用现成游戏的图片、角色或音效。

| 文件 | 来源与用途 | 处理与许可说明 |
| --- | --- | --- |
| `assets/art/seabed.png` | OpenAI 内置 imagegen，原创海底背景 | 保留原始像素；运行时统一缩放、调色，叠加独立焦散、气泡与海草 |
| `assets/art/golden_grouper.png` | 同上，金纹石斑透明精灵 | 保留生成 alpha，细分网格进行后躯、尾鳍与胸鳍局部变形 |
| `assets/art/cannon.png` | 同上，炮管透明精灵 | 运行时设置旋转轴和炮口，基座由程序绘制 |
| `assets/art/fish_atlas.png` | 同上，九种普通鱼透明图集 | 按逐鱼检查的像素边界建立 AtlasTexture，排除相邻鳍条，不重绘、不覆盖源图 |
| `assets/art/great_shark.png` | 同上，巨鲨透明精灵 | 网格变形，独立碰撞体，影子程序绘制 |
| `assets/art/starwing_bonus.png` | 同上，星翼宝鲂透明精灵 | 宽鳍网格变形，金色边缘辉光保留原始 alpha |
| `assets/art/cast_net*.png` | 同上，六档真实网具 | 基础网及五档独立编辑变体，保留 alpha，绳网张开与包裹使用对应档位的纹理 |
| `assets/art/net_*.svg`、`icon.svg` | 本项目代码原创 | 可随本项目使用；生成代码见 `tools/create_resources.py` |
| `assets/audio/*.wav` | 本项目 Python 数学合成，固定随机种子 | 无采样录音或第三方音乐；生成代码见同上 |
| `assets/fonts/NotoSansSC.ttf` | Google Fonts 的 Noto Sans SC | SIL Open Font License 1.1，原始许可见 `assets/fonts/OFL.txt`；未修改字体文件 |

生成工具：内置 `image_gen.imagegen`。生成时间：2026-10-29。未使用外部参考图；提示词由项目的美术要求组织。生成图按所用 OpenAI 服务条款使用，不将其描述为第三方开源授权或独占版权保证。原始文件复制进入工程后再引用；透明素材保留实际 alpha，无手工抠图。所有尺寸和透明通道见 `assets/art/manifest.json`。

字体来源：[Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)。引擎许可见工程根目录 `THIRD_PARTY_NOTICES.txt`。

# 渔网与经济系统

## 玩家可见规则

- 六档渔网从破网逐步升级到龙绡网；列表只显示档位、名称、真实网具图标、每发金币价格及选中状态。
- 渔网开局全部可选。选中不收费；有效发射才扣一发弹药和金币。
- 普通鱼捕获进入鱼篓，点击出售才能获得金币。星翼宝鲂是直接奖励金币的特殊事件。
- 不公开捕获概率、范围尺寸和效果排序；文档中的数值只供开发调参。

## 一次发射与一次张网

1. 确认游戏处于可操作状态、冷却结束且资源足够。
2. 固定本发 `net_id`、配置数值、发射方向及随机种子，同时扣除金币和弹药，形成唯一 `shot_id`。
3. 炮弹从炮口出发。碰到第一条有效鱼的碰撞体，或达到射程／水面边界后，产生一次张网。
4. 在张网生效的一个固定模拟步内收集相交鱼体，每条鱼只判定一次。网的后续扩散和淡出仅作视觉表现，不持续每帧抽奖。
5. 对范围内的每条鱼独立计算；一次张网可以捕获多条鱼，不能把总概率平均分摊。鱼尾透明区域不算碰撞体。
6. 同步提交本次捕获结果，再播放动画。对已捕获、逃离、奖励触发中的鱼不重复判定。

同一条普通鱼可被不同炮弹重复命中，每次独立抽取，不累积捕获进度。新选择的渔网不能改变在途炮弹。同一模拟步多网命中按发射序号稳定处理。

## 普通鱼与鲨鱼捕获

`FishDefinition` 定义基础概率 `p_base`，六种渔网使用概率系数 `K`。普通鱼与鲨鱼每次有效命中均按 `p = clamp(p_base × K, 0, 0.95)` 独立抽取一次。

- 以标准体型对应的 `p_base` 调参：同一渔网下，体型越大基础捕获率越低；不把摆尾、透视缩放或临时动画变形当成体型变化。
- 不设置血量、累积进度、必捕次数、连续失败补偿或暗中递增概率。高概率小鱼也可能逃过，极低概率大鱼也可能一发成功。
- 相同渔网、相同鱼种的每次判定概率保持一致，未捕获只产生受击表现，不逐渐显示濒死。
- 大鲨鱼基础概率为 `0.00002`，六种渔网对应单次有效命中概率为 0.002%～0.0064%。鲨鱼有有限停留时间，成功捕获后进入鱼篓，出售才得金币。
- 体型与概率基线见鱼种名录；概率封顶可能让部分小鱼在高系数渔网下达到相同上限，但大鱼不得反向获得高于小鱼的概率。

## Bonus 捕获例外与阻挡

星翼宝鲂不受体型概率规则限制：第一次实际被有效渔网覆盖便必定捕获并触发金币雨，不进入普通鱼篓、不再二次出售。所有渔网均可捕获它。

炮弹遵守首次碰撞规则。若其他鱼在弹道上挡住炮弹，网会在那条鱼处展开；只有展开范围仍与 Bonus 鱼的有效碰撞体相交，才会捕获 Bonus。网覆盖不到时不触发，不能穿鱼、自动追踪或以点击目标为由远程判定成功。

同一张网可以同时对普通鱼抽取概率并捕获覆盖到的 Bonus。已触发奖励的 Bonus 不再阻挡或接受后续炮弹；同一鱼只发一次奖励。被鱼的美术贴图遮住不等于无敌，是否命中依据真实弹道、碰撞体与网范围。

## 金币、弹药与出售

| 项目 | 首轮规则 |
| --- | --- |
| 新档弹药 | 10,000 发，仅初始化新档时发放 |
| 新档金币 | 50,000 金币，仅初始化新档时发放 |
| 发射开销 | 一发弹药 + 所选渔网对应金币；空枪和未捕获也消耗 |
| 普通收益 | 捕获后暂存鱼篓；玩家出售时一次结算 |
| 出售价 | 由鱼种与捕获时冻结的出售价值决定，与当前渔网和后续价格配置无关 |
| 免费补给 | 主动点击补给箱，每次增加 1,000 发弹药与 5,000 金币，无广告和每日次数限制 |
| Bonus 收益 | 每条星翼宝鲂一次固定 3,600 金币，视觉分批飞入金币袋 |

免费补给是自玩模式的正式功能，让玩家可以持续探索渔网；金币作为开炮消费和收集反馈，不通过短缺逼迫重复劳动。补给不是重置存档，不影响渔获和累计记录。

鱼篓按鱼种合并显示但保留每批实际数量与价值；单项出售按钮显示明确的数量与收入，另提供“全部出售”。禁止自动定时出售。空鱼篓按钮禁用。连续点击、重复动画回调不能重复入账。

## 金币雨结算

星翼宝鲂被有效渔网覆盖后，先将该鱼标为已触发，并把 3,600 金币作为一笔奖励持久化，再进行表现。视觉上用连续喷发和金币袋滚动数字表现逐批到账，真实钱包与视觉计数分离。

金币粒子只是奖励的表示，不是一枚一个结算回调。切后台、跳过动画、画质降级、丢帧和退出均不能改变实际收益。播放期间可显示“+3,600”本次奖励，动画结束将展示余额对齐真实钱包。恢复存档直接展示已提交余额，不重放发奖。

## 调参目标

- 验证六档渔网的真实材质、完整度、范围与捕获能力逐步提升，不能只是更换颜色和金币价格。
- 普通小鱼应频繁被捕获，普通大鱼的单次概率低于中小鱼；鲨鱼概率极低，所有普通鱼与鲨鱼均没有必捕保障。
- Bonus 是实际覆盖即可必捕的惊喜，必须遵守弹道阻挡和网覆盖范围，不能继承普通鱼与鲨鱼的概率判定。
- 测量实际捕获速度、鱼群收入和每分钟金币消费后再定最终价格；不宣称当前表已经实现经济平衡。

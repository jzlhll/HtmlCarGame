# 游戏设计

## 定位

- 暂定名称：潮汐渔场。
- 类型：单人、离线、横屏街机捕鱼，精致 2D／2.5D 海底美术。
- 当前平台：Android、macOS 独立应用，共用玩法和资源；iOS、Windows 保留后续复用能力。
- 体验：自己的休闲游乐场，弹药充裕，通过试用不同渔网探索效果，捕获普通鱼、积攒渔获并出售，等待偶发的金币雨。
- 不设计真实货币交易、广告门槛、联网房间或竞争排行榜。金币是本地游戏资源。

## 游玩循环

选择渔网 → 调整炮台方向 → 发射并消耗一发弹药与对应金币 → 炮弹命中或到达终点张网 → 对范围内的目标分别判定 → 普通渔获进入鱼篓 → 玩家点击出售 → 金币进入金币袋 → 继续尝试渔网。

普通鱼、大鲨鱼和 Bonus 各有职责：普通鱼提供持续捕获反馈；鲨鱼带来稀有挑战；Bonus 提供短时追逐和大量金币动画。大鲨鱼不能成为推进玩法的必需门槛。

## 输入规则

### Windows / macOS

- 只通过键盘左、右方向键转动炮台；按住持续转动，松开停止。左右同时按下时不转动。
- 左 Shift、右 Shift 均可开炮；单次按下发射一炮，按住按武器射速持续发射。两个 Shift 同时按住也只产生一条发射流。
- 炮台默认朝上，以竖直方向为 0°，活动角度为左右各 75°。转动速度首轮设为 100°/秒，射速为每秒 4 发，均与显示帧率无关。
- 鼠标只操作渔网列表、鱼篓、出售、设置和补给等界面，不改变炮台方向，不发射。
- 不显示瞄准虚线、预测轨迹、落点标记或渔网半径预览。玩家通过炮管方向和真实弹道判断。
- Esc 打开／关闭暂停。窗口失焦立即暂停并清空按住状态；重新激活后需要重新按键。

### Android / iOS

- 点击可游玩水面：炮台朝点击方向转动，从炮口向该方向发射一炮；炮弹不能在点击位置直接出现。
- 方向由炮口和点击位置决定，遵守与桌面相同的炮台角度限制；炮台下方、界面覆盖区和安全区外点击不发射。
- 首版每次有效点击只发一炮，不默认长按连发或拖拽连射。冷却中的点击不扣费，也不积压延迟发射。
- 第一个有效触点控制水面操作；其他同时触点不产生额外炮弹。点击渔网、出售等 UI 必须被 UI 消费。
- 不显示瞄准辅助线或范围预览。

### 共同行为

- 暂停、设置或补给弹层打开时停止世界模拟、发射与事件计时，清空输入状态。鱼篓详情打开不暂停海面：鱼、在途炮弹、现有特效及普通刷新继续运行；鱼篓面板消费输入，打开时停止新发射并清空按住状态，关闭后需要重新按键或点击才能射击。
- Bonus 出现前有 3 秒预警。只有鱼篓关闭才能开始预警；鱼篓已打开时到期的 Bonus 延后，关闭后才开始完整 3 秒预警。预警已经开始时打开鱼篓，倒计时仍继续，Bonus 照常入场，错过后正常离场。
- 渔网列表使用常驻紧凑面板，切换不暂停；新选择在下一发有效射击时生效。
- 桌面炮弹沿当前炮管方向前进，触屏炮弹沿点击方向前进；统一由碰撞或射程终点触发张网，触屏不获得遥控引爆优势。
- 炮弹达到水面边界时在边界内张网；不穿越操作栏，也不反弹。真实飞行时间是提前量操作的一部分。

## 界面结构

| 区域 | 内容与交互 |
| --- | --- |
| 顶部左侧 | 渔场名称、暂停和声音开关 |
| 顶部右侧 | 金币袋及余额；金币雨和出售动画汇入这里 |
| 水面主体 | 鱼群、大鱼、炮弹和真实展开的渔网；保持清晰可辨 |
| 底部中央 | 炮台、当前渔网名称、剩余弹药 |
| 底部侧边 | 六种渔网选择列表，名称、图标、每发金币价、选中边框 |
| 鱼篓入口 | 待出售数量；点击查看渔获列表 |
| 鱼篓详情 | 鱼的图片、名字、数量、单价和出售按钮；可逐项出售或出售全部 |

渔网列表显示Ⅰ～Ⅵ档位，由破网逐步升级到龙绡网；范围与捕获能力随档位提升，但不公开成功率、半径、强度条或具体效果说明。体验差异通过真实网具材质、张网和捕获自然呈现。六档开局全部可选，不要求解锁。

手机紧凑横屏采用 2×3 渔网卡片布局，确保六种可发现且触控目标不小于 48 个逻辑像素；桌面可横排。UI 适配安全区域，渔网列表不能遮挡主要鱼道。竖屏显示旋转提示并暂停。

## 反馈与节奏

- 发射：炮口短闪、炮管后坐、紧凑音效；连续射击不造成持续强震屏。
- 命中未捕获：渔网收紧、鱼体短闪、尾部挣扎，只表现本次受击，不显示概率，不暗示持续削弱或即将必捕。
- 捕获：网收拢、短时聚光、鱼缩入鱼篓；加入渔获后给出小型提示，继续游玩。
- 出售：明确点击触发，显示本次收入，金币弧线飞向金币袋。
- 鲨鱼经过：鱼群让行、低频音效与更深阴影；偶尔经过，不让长期低成功率主导整场体验。
- 星翼宝鲂：提前 3 秒预警，独特展翼和色彩；被有效渔网实际覆盖即进入金币喷发，每次经过只触发一次。其他鱼可以提前挡住炮弹，覆盖不到它的网不能远程触发。

## 边界情况

- 弹药不足或金币不足时不发射、不扣费，给一次温和提示和补给入口，不连续刷提示。
- 开局赠送及补给详见经济文档。玩家随时可暂停，后台时间不扣资源、不继续刷鱼、不消耗 Bonus 窗口。
- 存档异常时提示恢复或重试，不能静默清空已有金币和渔获。
- 设置至少包含主音量、音效开关、减少闪光、画质档位；调整画质不能改变捕获判定或金币收益。

# 鱼种与事件系统

## 设计原则与参考

采用街机捕鱼中“多样鱼群、稀有大目标、特殊奖励事件”的场面组织方式，使用原创名称、造型与数值。参考来源为开发者公开产品介绍，不将宣传中的爆率或收益当成真实参数。

- [牛仔捕鱼 App Store 产品介绍](https://apps.apple.com/cn/app/id1611466948)：参考花样鱼群与渔场的内容层次。
- [姚记捕鱼 App Store 产品介绍](https://apps.apple.com/cn/app/id1480655849)：参考常规捕鱼与限时事件的节奏组合、金币爆发的视觉反馈。
- 不复制现成游戏的贴图、音效、角色、界面或经济系统；本项目采用自己的金币与手动出售规则。

## 鱼群行为

- 编队使用一条共享主路径，成员具有固定队形偏移、轻微速度差与摆尾相位差。
- 提供流线、弧线、错列和松散群四种队形，避免高频全对全邻居搜索。
- 个体捕获后从编队移除，其余成员自然通过短时偏移填补视觉空隙，不整体瞬移。
- 单体使用弧形巡游或缓弯穿场路径；转弯有身体弯曲和速度过渡，禁止每帧随机变向。
- 鱼群可与单体同时出现，路径错层，避免所有鱼从同一侧、同一高度、相同速度进入。
- 只开放水面内的鱼体命中；鱼尚未完整入场或已经离开有效区域时不提供屏外捕获。
- 普通鱼短时受击可以减速，但累计减速有下限和恢复时间；不能通过网永久定身。

## 刷新调度

以下为完整场景的首轮目标；最小场景阶段使用单条金纹石斑反复入场。

| 内容 | 间隔／持续时间 | 限制 |
| --- | --- | --- |
| 小鱼群 | 每 7～12 秒尝试一组；通过水面约 12～20 秒 | 同时最多 3 组 |
| 单独中鱼 | 每 5～9 秒尝试一条；停留约 18～30 秒 | 同时最多 6 条 |
| 普通大鱼 | 每 25～40 秒尝试一条；停留约 30～40 秒 | 同时最多 2 条 |
| 巨鲨 | 每 120～180 秒尝试一次；穿场约 20～25 秒 | 同时最多 1 条 |
| 星翼宝鲂 | 首次在有效游玩 35～55 秒出现，此后离场或奖励结束后 75～120 秒 | 同时最多 1 条事件鱼 |

有效游玩时间不含暂停、后台和暂停型菜单；鱼篓不是暂停型菜单。暂停恢复不补发一批过期事件。总在场鱼先限制为 60 条，满额时延后普通刷新；稀有事件通过预留名额进入，不能突然删除现有鱼。Bonus 与巨鲨不同时新入场，避免争抢注意力。出场计划属于当前存档，不通过反复重进刷新事件时机。

## Bonus 三秒预警与鱼篓规则

采用 `waiting` → `warning` → `active` → `rewarding`／离场 → `waiting` 状态机，预警长度为 3 秒有效游玩时间。

- `waiting`：到期且鱼篓关闭、场内有预留容量、无巨鲨入场冲突时才开始 `warning`。鱼篓打开时不启动预警、不刷新 Bonus；到期事件只保留一项待出现机会，不能积压多个。
- `warning`：屏幕给出清晰的 Bonus 提示、3 秒倒计时和提示音；预警不被鱼篓遮挡。即使此时打开鱼篓，倒计时仍继续，到零照常入场。
- `active`：鱼篓开关不改变 Bonus 的位置、速度、剩余停留时间；错过便正常离场，不自动捕获或补发奖励。
- `rewarding`：鱼篓开关不影响金币雨及已确认奖励。
- 如果玩家在预警开始前已打开鱼篓，则关闭鱼篓后从完整 3 秒预警开始，不能立即刷到水面。反复开关只影响尚未开始的预警，不能重置既有倒计时。
- 同一模拟步中先处理鱼篓开关输入，再判断是否启动预警；预警状态已经生效后打开鱼篓，不再获得延后保护。
- 开始预警时预留事件名额和入场路径，倒计时到零不能因后续普通刷新或巨鲨刷新再次延期。
- Esc、设置、后台等真正的暂停仍冻结预警及世界时间；恢复继续剩余时间，不重新给 3 秒。

## 深海巨鲨

- 宽大身体、坚硬背鳍、慢摆尾、大阴影，出现时具有明显压迫感。
- 与普通鱼使用同一概率公式，通过极低的 `p_base` 实现难捕获，不设累计必捕。
- 受击只产生短暂鳞光和网绳弹开，不显示虚假的濒死状态或即将必捕提示。
- 不能购买、用某网保证捕获或靠重复进出场刷新结果。
- 成功捕获时使用独立庆祝特效与鱼篓卡片；仍由玩家点击出售，金币不在捕获瞬间自动发放。
- 鲨鱼经过不吃掉玩家已捕获的鱼，不扣额外金币，不强制玩家开火。

## 星翼宝鲂：Bonus 原型与表现

原型选择东方飞角鱼（Dactyloptena orientalis），其辨识特征是可展开的宽大胸鳍。游戏采用中等体型，保留宽鳍轮廓，加入原创的深蓝翼面、金色脉络、星点及琥珀色腹部。游戏名称“星翼宝鲂”和发光设定为艺术创作。

生物资料：[台湾鱼类数据库](https://fishdb.sinica.edu.tw/taxon/382799-fishdb)、[台湾生物多样性网络](https://www.tbn.org.tw/taxa/d0c93322-cd31-43cc-8179-ccc1b4b24b69)。这里的“飞过”指水下展开胸鳍滑行，不把原型描述成真正空中飞行的鱼；公开图片只供形态研究，不直接作为游戏资产。

### 经过与命中

1. 出现前先进行完整 3 秒预警；倒计时结束以轻铃和侧边短光入场，约 1 秒展翼。
2. 沿一条易观察的弧线滑过炮台前方可射区域，目标穿场时间 9～12 秒；不经过 UI 背后。
3. 第一张有效渔网实际覆盖鱼体时立即触发奖励，身体短暂停留并卷起双翼，状态切换为 `rewarding`。
4. 奖励提交成功后，开启约 4.8 秒金币雨：12 次连续喷发，约每 0.4 秒一批，金币先向外跃起，再沿弧线飞向金币袋。
5. 金币袋轻微鼓动、数字滚动和递进叮当声形成持续收获感；最后一批收束后，鱼展翼化成光点离场。

实际覆盖即必捕，不要求再击杀，不进鱼篓，不需要出售。炮弹可被其他鱼提前阻挡；若阻挡处展开的网覆盖不到它，则不触发。未命中则正常离场，按下次事件时间重新出现；不扣额外资源。奖励期间其他炮弹可以继续命中普通鱼，但不能在同一 Bonus 鱼上二次发奖。

### 表现预算

每批约 8 枚主金币，合计约 96 枚可见金币，另配小光点；同时可见主金币上限 64，低画质减少到 24。少量粒子仍需通过分批喷发保持持续感，不能用单个“+金币”数字替代整段动画。所有档位真实奖励均为同一金额。

# 文档导航

1. [游戏设计.md](规划/游戏设计.md)：定位、操作、界面与游玩循环。
2. [渔网与经济系统.md](规划/渔网与经济系统.md)：六种渔网、内部捕获规则、金币和出售。
3. [鱼种与事件系统.md](规划/鱼种与事件系统.md)：鱼类名录、编队、鲨鱼和 Bonus。
4. [技术架构.md](技术/技术架构.md)：Godot 技术选择、模块边界、平台与性能。
5. [美术动画与音效.md](技术/美术动画与音效.md)：资源方案、视觉规范、动画及金币雨。

7. [实施阶段与验收.md](规划/实施阶段与验收.md)：阶段范围、交付要求与人工验收。

## 文档约定

- 本目录记录当前权威设计与首轮配置；实现、平台交付与实际验证范围以 `技术/运行与平台.md` 为准，不能把设计清单等同于全部实测通过。
- 捕获公式和经济数值以 `渔网与经济系统.md` 为准；鱼种、事件和刷新数值以 `鱼种与事件系统.md` 为准。
- 操作方式以 `游戏设计.md` 为准；技术契约以 `技术架构.md`、`数据与存档.md` 为准。
- 初始数值用于制作可玩版本，实施后通过实际游玩调整。调整更新原表，不追加对话记录或历史方案。
- 渔网概率和半径数值仅面向开发者，不进入玩家说明、提示框、商店、图鉴或无障碍描述；Ⅰ～Ⅵ档位与品质递增可见。
- 第一阶段与完整目标分开验收；未进入第一阶段的内容仍需在架构和资源目录中留出清晰扩展边界。

# 撑过20秒开发规则

- 本工程使用原生 JavaScript ES Modules + Three.js，独立维护依赖和脚本；入口与操作见 [README.md](README.md)。
- 回复、文档和注释使用中文，日志使用英文。保留实际文件名和代码标识符。
- 电脑只使用方向键操控飞机；触屏使用虚拟摇杆，不添加鼠标追踪或触摸直接定位。
- 逻辑和渲染分离；游戏有效时间采用固定步长，暂停和后台冻结模拟，恢复须由用户操作。
- 几何、材质和对象池在初始化准备，同页重开复用；游玩时不生成资源。弹幕使用实例化渲染和有界对象池。
- 参数集中在 `src/config.js`；分难度成绩与设置使用独立的 `bullet-survival` 存储命名空间。
- 不主动生成测试或运行 Gradle；执行 `git diff` 直接使用原生命令。
- 不自行发布、提交或改动其他游戏及 Android 容器；文档只保留最终结论。

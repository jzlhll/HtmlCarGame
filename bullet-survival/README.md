# 撑过20秒 · LAST VECTOR

使用原生 JavaScript ES Modules、Three.js 0.186.1 和 Node.js 静态服务实现的弹幕生存游戏，独立于仓库其他游戏。

## 启动

需要 Node.js 18 或更高版本。在本目录运行：

```bash
npm ci
npm start
```

打开 `http://localhost:5176`，或双击 `启动游戏.command`。使用 `PORT=5180 npm start` 可更换端口。必须通过 HTTP 访问，不直接打开 HTML 文件。

## 操作与规则

- 电脑只使用键盘方向键移动，不支持鼠标控制飞机；对角线速度与直线一致。
- 触屏使用场地左下角的固定虚拟摇杆，支持斜向和小幅移动，松手停止；不支持触摸画面直接定位飞机。触屏设备可同时使用方向键。
- 空格开始或重新挑战，Esc 暂停／继续；触屏使用开始和暂停按钮。
- 开局时场地在2.5秒内展开至接近整屏，同时倒数4秒。展开期间锁定移动，最后1.5秒可提前操作飞机，倒数结束才发射子弹并开始生存计时。离开窗口或切至后台时自动暂停，返回后手动继续；展开动画与倒数同步冻结。
- 子弹从四周随机进入，部分瞄准飞机位置，发出后沿直线飞行。随时间增加发射密度和速度，并设上限。
- 飞机中心白点是碰撞判定点；机翼不参与碰撞。以相对运动线段检测，避免子弹穿透。
- 坚持20秒即达成目标，随后可继续挑战；碰撞时立即提示“挑战失败”并停止模拟，同时用2秒收回场地；收回后才开放重新挑战和难度选择，保留生存时间、避开子弹数量和难度。
- 练习、标准、极限各自保存本地最佳时间，音效和难度也保存在 `bullet-survival:settings:v1`。存储不可用时降级为本页记录。
- 生存时间严格超过5秒的对局结束后，保留最后5秒的飞机轨迹和当时的弹幕，保存至 `bullet-survival:replay:v1`，刷新后可继续播放。不超过5秒的对局不覆盖已有记录，没有记录时不播放。
- 首页与失败收回后的待机界面每10秒开始一次5秒回放，播放期间不展开布局、不累计成绩、不响应飞机控制；可随时按空格或点击开始按钮进入新局，Esc 可结束回放。离开窗口或切后台时停止回放并重置待机计时，回到窗口后重新等待10秒。

## 工程结构

| 文件 | 职责 |
| --- | --- |
| `src/config.js` | 版本、尺寸、判定范围、速度和难度参数 |
| `src/game.js` | 固定步长模拟、弹幕对象池、碰撞和计时 |
| `src/input.js` | 键盘方向键与触屏摇杆 |
| `src/scene.js` | Three.js 正交视图、飞机、实例化弹幕和碰撞粒子 |
| `src/audio.js` | Web Audio 合成音效 |
| `src/replay.js` | 最近5秒的有界环形录制、本地回放记录与待机播放 |
| `src/main.js` | 状态切换、界面、存储和初始化 |

480 个弹幕槽位、飞机几何和48个碰撞粒子在初始化时预分配，开局和重开复用；游玩过程中不生成模型、纹理或关卡资源。几何仅由少量基础图元构成，初始化生成，无大规模离线资产；GPU 资源采用会话内复用，不引入成本高于生成的小几何持久缓存。暂停时冻结模拟，静止画面不重复提交渲染。场地随可用窗口比例调整正交相机与逻辑边界，至少保留120×100逻辑单位；宽屏增加横向范围，竖屏增加纵向范围，飞机和子弹不随布局拉伸。首页采用紧凑顶部栏，隐藏介绍、操作手册和页脚，进入游戏后将场地展开至接近整屏。展开与收回仅变换现有界面，复用游戏时钟推进动画，不逐帧重建绘制缓冲；准备和收回期间不发射弹幕。

录制以每秒30帧采样，使用初始化时预分配的152帧环形缓冲，只记录正式飞行有效时间，暂停和开局倒数不录入。回放按原对局场地比例显示，插值飞机与同一颗子弹的位置；弹幕槽位复用后按子弹标识区分，不连接不同子弹的轨迹。录制与回放均复用原场景和对象池，不新增模型或纹理。

## 静态打包

```bash
npm run prepare:pages
```

输出至忽略目录 `.pages-output/`，包含源码、Three.js 必需模块与许可，无外部字体、图片或网络资源依赖，支持部署至静态托管子路径。尚未接入仓库自动发布工作流或 Android 容器。

# 方块时光 · BRICK TIME

使用 Three.js 制作的独立俄罗斯方块网页游戏，包含经典七关和无尽残局。棋盘为 10 列 × 20 行，支持键盘与触屏，暂停时自动保存，再次打开可继续。

## 启动

需要 Node.js 18 或更新版本。在本目录执行：

```bash
npm ci
npm start
```

打开 `http://localhost:5177`。也可双击本目录的 `启动游戏.command`，会检查依赖并打开浏览器。端口冲突时使用 `PORT=5180 npm start`。

依赖只安装到本工程，不需要运行其他游戏。请通过本地服务访问，不能直接双击 `index.html`。不同协议、主机名或端口使用不同的浏览器存储；继续同一存档时使用相同地址。

## 两种玩法

- **经典七关**：使用常规七种四格方块，从第一档开始。每关有效游玩两分钟后升级并提高一档速度，保留堆叠；完成第七关后显示“恭喜通关”。
- **无尽残局**：底部六行随机堆叠，保留常规方块，加入两格短横、三格「7」字形和五格 T。可选 1～7 档初始速度，每累计有效游玩 2.5 分钟提速一次，直到无法放置新方块而失败。
- **五角星 bonus**：仅在残局模式出现，持续闪烁，左右与向下均可穿过堆叠，停在下方最深合法空洞后消除所在整行，不要求满行。每隔随机 2～3 分钟有效游玩时间，保证于下一次出块发放一个。

下落速度和计分基线见 [游戏设计.md](docs/规划/游戏设计.md)，后续可以按手感调整。

## 操作与存档

| 操作 | 键盘 |
| --- | --- |
| 左右移动 | ← / →，可按住 |
| 顺时针旋转 | ↑ / X |
| 逆时针旋转 | Z |
| 加速下落 | 按住 ↓ |
| 直接落底 | Space |
| 暂停 / 继续 | Esc / P |
| 开始 / 继续 | Enter |

窄屏提供触屏按钮，可按住左右移动和加速下落。界面同时提供暂停、继续、模式切换和新局入口；新局需明确确认替换当前模式进度。

两种模式各保存一个独立存档。手动暂停、失焦、切换后台和退出页面时自动暂停保存；落地、提速和结束也写入检查点。刷新后先保持暂停，主动继续才计时。保存包含棋盘、当前方块、后续顺序、随机状态、速度、计时和 bonus 等待进度。

浏览器存储被禁用或写入失败时显示提示；损坏或不兼容的原存档不会自动覆盖。系统强制结束进程不保证触发保存事件，继续时以最近成功写入的检查点为准。没有联网账户或跨设备同步。

```bash
npm run prepare:pages
```

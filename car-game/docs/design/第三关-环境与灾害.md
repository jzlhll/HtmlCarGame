# 第三关：环境与灾害

## 范围与状态

第三关初版已实现：第二关有效运行满 3 分 15 秒后进入通关说明，按空格或触屏按钮进入第三关；第三关从自行车、初始积分、满防御、空氮气、零距离和零有效时间重新开始。只保留涂装和调试选择。首页可勾选“调试 · 直接进入第三关”，调试局不写排行榜。

第三关移除四季场景、四季天气及其相关事件，以火山、海水、冰山替代。第一关和第二关继续使用各自已有的季节与天气规则。“相关事件”指春雾、夏季雷雨与雷击、秋季横风、冬季降雪与天气结冰落点，第三关保留白马、警车、吞吃成长、饥饿、氮气、普通车流、施工与 X 路障；不投放恐龙、装甲坦克、金币火箭炮、天降炮击或横穿奶牛。第三关采用平坦道路，不生成原高架、谷底、河道减速及桥下列车；分叉与道路弯曲保持。

## 环境轮换与路面

固定以火山开场，按 **火山 → 海水 → 冰山 → 火山** 循环，每种环境持续一分钟。按第三关自身有效运行时间计算，与距离和车速无关。

| 第三关有效时间 | 环境 | 路面与路外表现 |
| --- | --- | --- |
| 0:00–0:59… | 火山 | 车道以暗褐岩石为底、保留少量橙色热裂纹，道路两侧随机出现火山 |
| 1:00–1:59… | 海水 | 道路变为海面上的浮桥，海啸从一侧横扫到另一侧 |
| 2:00–2:59… | 冰山 | 道路变为低反光灰蓝冰路，两侧混合大型冰山与小冰峰，路上另有致命冰山障碍 |
| 3:00–3:59… | 火山 | 第二轮火山环境；道路固定为四车道 |
| 4:00–4:59… | 海水 | 第二轮海水环境；四车道浮桥 |
| 5:00–5:59… | 冰山 | 第二轮冰山环境；四车道冰块道路 |
| 满 6:00 | 第三关通关 | 停止本关驾驶和灾害调度，不启动第三轮环境 |

使用现有关卡有效时间口径：停车继续计时；准备、暂停、失焦暂停、答题、被抓、死亡动画及结算期间冻结。每次进入环境都从该环境的局部时间零开始安排周期事件。

火山道路的暗岩与热裂纹是基础路面表现，正常行驶不因此受伤；只有喷发落点岩浆造成命中伤害。冰块道路与崩塌覆盖区也需在外观上区分，长时间横移失控规则作用于崩塌覆盖区。

## 通关时限与车道变化

第三关自身有效运行满 **6 分钟（360 秒）** 通关。六分钟内完整经历两轮火山、海水、冰山，每种环境共出现两次。通关先处理截止时刻以内的碰撞、伤害与救援，只有仍处于正常行驶状态才判定成功；满六分钟不再生成新的火山事件。最后五秒显示顶部倒计时，满六分钟以 `complete` 最终结算，显示“恭喜！全部通关。”。普通局仅记录第三关自身距离、时间与统计，不合并前两关；调试局不记录。

第三关满 **3 分钟（180 秒）** 后，道路只有 **四车道**，主路和副路一致，直至本关通关不再恢复六车道。不生成五车道；三分钟前沿用已有四／六车道布局。该节点同时是第二轮火山环境的开始，环境切换不能撤销车道限制。

第三关使用自身三分钟门槛，不沿用第二关的两分钟收窄门槛。满三分钟时当前道路及后续主副路统一限制为四车道，玩家横向位置夹回可行驶边界，取消外侧车道上的系统车辆、原外侧截止墙与越界危险落点；后续投放仅使用开放车道。收窄本身不默认追加第二关的危险车比例与变道概率加成。

## 火山：三连喷发与岩浆落点

| 项目 | 确定规则 |
| --- | --- |
| 火山位置 | 道路两边随机出现 |
| 喷发周期 | 火山每隔 10 秒开始一轮喷发 |
| 每轮节奏 | 每隔 2 秒喷发一次，一轮共 3 次 |
| 落点距离 | 玩家前方 20–30 米 |
| 落点范围 | 每次形成直径五米的圆形岩浆范围 |
| 自行车命中 | 直接死亡，不先扣防御 |
| 其他车型命中 | 直接降一级，不先扣防御 |

周期按每轮开始时刻间隔 10 秒理解。例如环境进入后第 10、12、14 秒为第一轮三次喷发，第 20、22、24 秒为下一轮；不将第三次喷发后的等待重新算作 10 秒。

每次喷发分别选定落点，玩家前方距离沿当前路线的实际行驶弧长量取；落点选定后固定在道路上，不随玩家继续前进或横移追踪。横向从当前路线开放车道中随机选择，喷发后 0.3 秒落地，落地后存留六秒；空中飞行期间以直径五米圆圈预警。每十秒新增一座路边火山，位于玩家前方 60–90 米、路缘外十米，存续二十秒；存续期间每座火山独立按三连喷发节奏运行。

命中指车身接触已生效的落点岩浆。基础路面颜色、路边火山模型和空中喷发动画本身不承担落点伤害。同一块岩浆对玩家只结算一次，不能持续停留就每帧重复降级；不同喷发各有独立事件标识。

直接降级复用现有车型变更流程，将成长积分设为低一级车型门槛，补满新车型防御并按已有规则限制速度。降级后获得现有两秒保护，期间免疫本关灾害。

## 海水：横扫海啸

| 项目 | 确定规则 |
| --- | --- |
| 道路 | 浮桥 |
| 海啸周期 | 每隔 10 秒出现一次 |
| 方向 | 从左到右或从右到左 |
| 运动速度 | 100 km/h，约 27.78 米/秒 |
| 自行车命中 | 直接死亡 |
| 其他车型命中 | 防御力减少 60% |
| 控制与动作 | 车辆失控 1.5 秒，被海水浸泡并旋转 |

海啸以整片涌上浮桥的宽厚波体表现，左右方向随机选择。速度指波体实际移动速度，不是玩家降速比例。海啸在玩家前方十八米的位置从路缘外半个波宽横向生成，横向覆盖十六米、纵向覆盖十八米、高 7.8 米，起伏水体、浅色浪峰和前沿白沫一起推进；越过对侧路缘后回收。波体不投影、不接收阴影，颜色不受左右方向的光照影响；采用不透明闭合水体减少透明叠绘。海水环境本身不造成伤害，浮桥采用连续桥面。

同一场海啸对玩家只结算一次，波面与车身重叠期间不重复扣防御或刷新失控时长。每次扣除命中时车型满防御的 60%；例如满防御首次命中剩 40%，未补防御再次命中则降一级。防御耗尽时复用现有降级、补满新防御流程，溢出伤害不继续扣新车型。

失控期间复用现有车辆旋转与输入锁定表现，暂时不能主动横移、加速、刹车或喷气；结束恢复驾驶。命中后浸泡视觉持续三秒，以包住车身的半透明水层表现，失控结束后剩余浸泡只作为外观；不额外减速。

## 冰山：崩塌覆盖与致命障碍

冰山环境有两类独立事件：路边冰山崩塌形成覆盖区；道路冰山作为直接致命的实体障碍。两类模型、接触范围及事件标识需明确区分。

### 路边冰山与崩塌覆盖

| 项目 | 确定规则 |
| --- | --- |
| 道路 | 冰块道路 |
| 路边冰山生成 | 每隔 10 秒在道路两边随机出现 |
| 崩塌周期 | 路边冰山每隔 5 秒崩塌一次 |
| 崩塌结果 | 产生路面覆盖效果 |
| 失控条件 | 玩家在覆盖区左右移动，超过 0.8 秒 |
| 命中后果 | 车辆失控 1 秒并旋转 |

路边冰山崩塌不沿用原冬季天气的“三秒减速至零、再停一秒”冻结规则。冰山崩塌覆盖区内的横移才触发本关的失控旋转，不把正常直行或整个冰块道路默认视为命中。

阈值是**超过 0.8 秒**，恰好达到 0.8 秒不触发。按覆盖区内连续主动横移计时，左右换向不断计时；松开横移、离开覆盖区、进入保护或失控时清零。重叠覆盖区按合并接触窗口计时，不倍增；失控结束后必须重新主动横移超过 0.8 秒才可再次触发。仅玩家主动横移参与计时，失控旋转造成的被动位移不继续累计触发新一轮失控。

覆盖区位置生成后固定，不随玩家或镜头移动。路边冰山在玩家前方 170–210 米、路缘外十米生成，存续二十秒，生成五秒后首次崩塌，此后每五秒崩塌一次。每次覆盖当前路线全宽、纵向二十二米，存留十二秒，按路线中心线放置。路边和道路冰山采用不对称双峰、断裂冰面和雪色分层，保持宽底冰峰轮廓；共用不同的低面数模板，路边冰山崩塌时缩动并掉落碎冰。

### 道路上的致命冰山

| 项目 | 确定规则 |
| --- | --- |
| 生成周期 | 每隔 10 秒 |
| 生成位置 | 道路上随机一个车道 |
| 数量 | 每次生成一座 |
| 碰撞结果 | 所有玩家车型撞上均直接死亡 |

道路冰山不走防御扣减或车型降级流程，坦克也直接死亡。生成应使用当前路线可通行车道；障碍在前方 90–130 米的开放车道随机生成，底部宽 3.1 米、长五米、高五米，存留十二秒；实体生成时即可远处看见，不附加倒计时提示。路边装饰冰山不能误用致命障碍碰撞。

## 实现约定与复用范围

逻辑由 `disasters.js` 管理，展示由 `disaster-view.js` 管理；参数入口为 `config.js` 的 `DISASTERS`，通过 `Game.disasters` 接入当前关。

- 第三关单独管理环境时钟与灾害排程，不修改第一、二关共享的季节和天气默认值；主副路采用同一种当前环境，危险接触按路线区分，避免误伤分离路线上的玩家。
- 进入新环境时停止旧环境调度，取消尚未发生的三连喷发、崩塌和障碍生成，清理旧环境危险区与模型；已发生的玩家失控按剩余时间完成，不因换景重新计时。恰好在环境边界的旧环境生成任务取消。
- 事件使用稳定标识记录已命中玩家，距离、速度、最近车辆、换道或画面刷新不重置命中记录。伤害采用车身连续接触检测，不能只检测一帧末的位置。
- 旋转通过 `collision.js` 的 `startDisasterSpin` 接入，复用 `bounceTravel`、`advanceBounce` 及 `render.js` 的车身朝向显示。高级车侧撞的旋转为 1.5 秒，同时带有减速 40%、横向弹开和后车投放；第三关只复用所需动作与控制锁定，按事件传入 1.5 秒或 1 秒，不自动附加侧撞的减速、后车投放等效果。
- 失控期间不因覆盖刷新重新开始旋转；新的有效伤害仍独立结算。重开、切关和复活清理不应继承的横移计时、失控及浸泡状态。
- 时间、距离、尺寸、速度、伤害比例及颜色集中在 `src/config.js`；灾害逻辑与 Three.js 展示分离，模型、粒子及落点按可视范围复用和回收。
- 灾害最多三十二个、路边灾害源最多十二个，按有效时间和驶离距离原地清理。浮桥接缝与远景山体采用八十米区块缓存，最多保留七块；仅区块、道路修订、环境或画质档变化时重写静态实例，其余帧只转换父节点。低画质档减少远景冰峰、火山与装饰碎片，装饰动作使用现有动画频率；实际危险区、道路冰山和海啸不因画质降档减少。
- 喷发、海啸和崩塌音效已按事件接入 `src/audio.js`，使用 Web Audio 合成；暂停、答题与结算静音。临时事件提示单次不超过 3 秒，并按稳定事件标识计时，不持续刷新重弹。

## 保护、救援与系统车辆

白马无敌、降级保护及复活保护均免疫岩浆、海啸、冰雪打滑和致命道路冰山。保护结束后，仍未命中过的危险区继续有效；已结算过的事件不重复命中。直接死亡沿用普通局前两次答题救援与调试复活，不跳过当前游戏的救援规则。

本关灾害只对玩家结算，系统车不因海啸、岩浆或冰山被额外击毁；车流仍按原有避让和车辆碰撞规则运动。原有系统车六车道投放在三分钟后受四车道限制，不增加第二关的变道强度。

配置节奏可通过 URL 白名单 `DISASTERS.environmentSeconds`、`narrowSeconds`、`volcanoInterval`、`waveInterval`、`iceInterval`、`collapseInterval`、`icebergInterval` 及 `LEVELS.thirdSeconds` 缩短验证；不开放尺寸、伤害与速度修改，去除参数并刷新恢复默认，不写存档。

## 后续验收重点

- 开场必为火山，60 秒进入海水，120 秒进入冰山，180 秒回到火山，240 秒进入海水，300 秒进入冰山；满 360 秒通关，不开启第三轮。停车继续计时，暂停与答题冻结，重开恢复火山。
- 三分钟前按原四／六车道布局行驶，满 180 秒后主副路仅四车道并保持至通关；环境切换不恢复六车道，不出现五车道，取消车道不继续投放车流或危险障碍，玩家不被收窄夹住。
- 跨越六分钟的逻辑步准确截断，截止时刻以内的致命事件与救援不能被通关覆盖；通关后驾驶、事件及音效冻结，不重复结算。
- 第三关无春雾、夏雷雨与雷击、秋横风、冬雪及原天气冰冻落点；前两关原有天气继续按所在关规则运行。
- 火山每轮三次、间隔两秒、轮起点间隔十秒；每次落点位于生成时玩家前方 20–30 米，危险范围为直径五米的圆形，后续移动不改变落点；自行车死亡，其他车型降一级，同点不重复伤害。
- 海啸每十秒一次，两种横扫方向可出现，波面速度为 100 km/h；自行车死亡，其他车型扣除车型满防御的 60%，同一海啸不连续扣减，失控旋转恰为 1.5 秒并有浸泡表现。
- 路边冰山每十秒随机生成、每五秒崩塌；覆盖区内横移未超过 0.8 秒不触发，超过后失控旋转一秒，普通直行与被动旋转位移不误触发。
- 道路冰山每十秒在随机一个可通行车道生成一座；自行车至坦克均在无保护时直接死亡，不先扣防御。
- 换景不残留旧灾害生成和碰撞；暂停冻结喷发、海啸位移、崩塌、覆盖、横移计时和旋转；高速、弯道、坡道、分叉及汇流不漏判或跨路线误判，对象数量不随运行时间持续增长。
- 核对静态区块缓存有界、同区块内不重复写入，收窄及换景立即更新缓存；左右来浪颜色一致且无阴影。完整帧性能仍需按常规验证流程在目标设备实测，灾害调度和实例写入统计不能直接推算游戏帧率。


## 灾害模型与表面

火山使用宽山脚、渐变坡度、分叉侵蚀沟壑、破碎岩坡及偏心火山口；山体参考半径 22 米、高 13 米，纵向略拉长，火山口包含独立内壁和下沉熔岩盆地，不再用平面盖住山顶。喷发山体距道路边缘至少 32 米，主副路净空按完整山脚保留；装饰山体默认距路缘 28–46 米并变化朝向，另按 `DISASTERS.volcanoScenery.closeChance`（默认 40%）概率贴近主路，山脚向内压住外侧车道约一半宽度（`encroachLanes` 默认 0.5 条），仅视觉贴近、不参与碰撞，副路仍按完整山脚保留净空，不满足时回退远距摆放；危险落点与伤害尺寸保持原配置。

冰山使用陡直冰壁、错层断面、不规则雪顶及压缩冰层色差，道路冰山底部仍归一化到实际接触宽度和长度。路外装饰混合小冰峰、宽阔台地冰山与高耸冰脊：台地宽 38–68 米、高 22–34 米、长 32–54 米，冰脊宽 26–42 米、高 32–44 米、长 42–64 米；朝向及尺寸由独立固定种子决定，大型山体约占装饰冰山的 78%。按完整山脚外接圆检查弯道、主路及副路净空，未找到安全位置则跳过；装饰不参与碰撞，路边崩塌源与道路致命障碍的尺寸和节奏保持原值。新增两套共享几何，仍使用有界区块与实例池。海浪用连续水体截面形成前翻浪唇、内部空腔和宽厚浪背，浪高与前沿沿纵向不规则变化；细泡沫在片元中采样，并随有效游戏时间漂移，浪尖飞沫独立实例化。波体保留统一水色和不受场景明暗影响的材质，以表面法线产生水面高光，不投射或接收阴影；暂停、答题和结算冻结泡沫与飞沫。

三种环境的地面分别使用岩石、水面与冰层材质；浮桥继续表现板缝。火山车道以暗褐岩石与稀疏橙色热裂纹降低整片红色，并将发光强度降至 0.10；真实岩浆危险区仍保留亮橙色。冰路采用灰蓝底色、较细较淡的裂纹和 0.62 粗糙度，减弱高光并保留车道线对比，崩塌覆盖仍单独显示。

共享纹理及主要几何在版本升级或开局前等非游玩阶段由后台线程分批生成并持久化；第三关开始前编译材质并上传，进入驾驶前等待队列与 Worker 停止，换景与重开复用。灾害资源组按源码及配置指纹增量更新，兼容的其他模型不重建；不新增预制资源或 Git 内生成产物。

# 飞机模拟游戏文档总览

## 项目定位与交付范围

游戏名称为“低空穿越”。游戏面向带键盘的桌面浏览器，使用虚构双发窄体民航客机，保留常见客机的外形、驾驶舱仪表、开关和起飞概念，操作采用便于理解的简化版本。

熟悉键盘字母位置是核心目标之一。通过有明确含义的动作、英文首字母和键帽提示，让使用者在起飞流程中练习找键；后续扩展到逗号、句号和分号等标点位置。首版不以覆盖全部字母为目标，键位学习通过飞机操作自然完成。

已实现四秒入舱、六步准备、手动变速起飞与巡航、广州／长沙／武汉／西安进近、着陆与停机、300／480／600／1080 秒关卡时限、山体／建筑碰撞、瀑布奖励、9900米显示高度硬上限、飞鸟与飞机遭遇、真实轨迹航线图与雷达预警。仪表与底部操作英文为主、中文为辅。倒数、开关、发动机、风、轮胎、收放电机和安全警报均已接入；英文播报使用固定Samantha女声语音库，不依赖浏览器系统语音起播；已接入白云、乌云、能见度、雷达干扰与雷击故障；气流已接入；降水仍为后续范围。

四关航程为78.5／158／206／404.2公里，使用4倍世界水平位移倍率；空速与垂直运动分别推进，深圳至广州为滨海平原及低丘田园，机场近岸为海面并以道路连接沿岸高速；后两关的景点群间保留溪流、草地与低丘。使用有限、虚构、压缩的共用路线；深圳起点相同，后关延长前段。四个目的地机场均为零海拔。开场有计划路线，首次R放行后分别在300／480／600／1080秒内于当前目的地跑道内停妥，准备不计时。完整玩法以[航程专题](design/07-航线与关卡.md)为准。

前三关沿途覆盖13座城市区域，武汉完整航线1085栋普通建筑（扩展前337栋，合计3.22倍），新增22处主题景点及车站、码头、帆船、古建等8415个实体构件。广东段保留深圳、东莞、佛山、广州、韶关；湘鄂段加入郴州、衡阳、岳阳、赤壁、咸宁，并扩充张家界、武汉。每局首次飞入各城市区域，顶部显示3秒中英文城市提示，暂停冻结且不覆盖危险警告。城市与景点选材见[航程专题](design/07-航线与关卡.md)。

第4关在经过武汉后以半径260公里、转角45°的圆弧向西北延伸至西安，18分钟内完成404.2公里航程及停机；新建15座豫陕城市区域、45处主题景点与27424个实体构件，全航线28城、2598栋普通建筑。开封清明上河园／龙亭／铁塔、洛阳龙门石窟／应天门／白马寺、少林塔林和西安大雁塔／城墙／兵马俑等已接入；实际位置、航图、偏航、城市提示、云层、森林和西安45°进近共用弧线数据。

外围地景已使用固定模板槽位池环形回收，单轴跨格只移动边缘7槽、斜向13槽，显示半径约18.67公里（VIEW_DISTANCE.scale=0.7，地形与碰撞范围不变），最外围为不可越过的高山墙体。森林按1.2公里空间块实例化，视野内始终使用同一完整树形，远端在7–8.4公里平滑淡出后才裁剪；地形近中远材质最多6／3／0次岩纹采样，平地跳过零权重方向，变体在准备期预热。脚部小窗在准备期建立真实世界空间索引与大型静态实例子组，地形使用独立细节预算，树木与主视口保持同一模型；跨格按预存节点表单遍更新移动槽位。

景物已升级共享曲面飞檐、廊柱斗拱、格窗、砖石／琉璃瓦材质、石窟窟龛与佛像面部衣褶、古城门券、少林塔林和兵马俑盔甲；现代楼房具备入口、竖框和屋顶设备。第4关旅游及山中古塔共42642个实例构件。固定模型与高成本数值已纳入构建预生成并按内容去重，浏览器完整准备目标4秒；发布总预算50 MB，生成资源不进入Git。完整分类见[模型资源与预算](implementation/model-assets.md)。

后续范围为降水、标点键观察、自动驾驶及更复杂任务，不将当前固定遭遇解释成真实空管或完整机型模拟。

## 文档维护

- 玩法与操作以设计专题为准，README 只概述；实现说明维护模块契约，不重复扩展规则。
- 飞行速度、镜头时长、阈值及音量均为初版可调值，落地时集中到 `src/config.js`。
- 专题明确标注“首版”或“后续规划”；实现完成后再更新项目状态，不能仅凭文档存在标记完成。
- 不把虚构客机的参数写成某个真实机型的飞行手册数据。必要航空概念在专题内附原始资料来源。

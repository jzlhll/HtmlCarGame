# 英语空战设计入口

Three.js 单人英语拼写射击游戏。玩家横移，向白色拼写飞机或 Boss 发射字母颗粒补全单词，或瞄准选择题航母的三个选项；先预习、再战斗、结算复习并记录学习结果。当前实现本地账号、固定十二词续玩、多关卡、Boss、幸运箱、三类学习记录和浏览器朗读。

| 项目 | 最终规则 |
| --- | --- |
| 账号 | 首页内嵌无密码账号，创建时编辑并保存名字、重名校验、原位二次确认登录，保存后不改名，数据按账号隔离 |
| 关卡 | 常规倒计时 300 秒、固定 12 词；大 Boss 全对后切为五秒自由拾箱 |
| 续玩 | 预习前保存词池，未完成及重玩用原词，新关重抽 |
| 预习 | 横滑词卡、圆点、分数页码，全看过才开始 |
| 出题 | 本关词池用完才重复；普通题默认 10–14 秒尝试生成，慢速下落；每十题七拼写、三选择 |
| 输入 | A–Z 连射，大小写跟随规范词形；1–4 选缺字，Shift 炮弹，退格删除、反引号撤销 |
| 点阵 | 26 个大写、26 个小写，0.06 秒一颗；未完成换字母清空重填 |
| Boss | 90 秒四面、240 秒五面，各限时一分钟，期间保留已有普通飞机，只停新生成，去除面数提示 |
| 幸运箱 | 周期箱每 120 秒一个；选择题成功爆 2 箱，小／大 Boss 全对爆 3／5 箱；碰触收藏 |
| 选择题 | 英译中／中译英各三个等宽选项；任意字母射击，按命中区累计 20 发淡出后验证，选错变两架敌机 |
| 拾箱 | 大 Boss 全对后清场，倒数五秒，四方向自由移动；暂停、失焦冻结 |
| 结算 | 恭喜通关；正确率按每架飞机／Boss 面的成功、写错、没写完计算 |
| 复习 | 不同失败词各 10 秒，锁住操作及开局，刷新保留、失焦暂停 |
| 学习库 | 每账号独立 IndexedDB 明细及汇总，100 词每页，失败降序，按需朗读 |
| 选词权重 | 历史正确率严格高于 50%／75%／85%，分别权重 0.5／0.25／0.01 |
| 词库 | 191 个练习词，80% 三至六练习、5% 一至二练习、15% 初中拓展 |
| 星空 | 十七种背景每 15 秒无放回轮换，背景蒙版，不限制总轮换时长 |

沪教新版全册尚未逐册核验，练习分组不作为正式教材归属或完整覆盖声明。数值集中 `src/config.js`，规则修改同步专题。

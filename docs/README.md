# 赛车游戏文档总览

## 项目定位

使用 Three.js 制作在本机浏览器中运行的单人、无限道路赛车游戏。玩家车辆位于屏幕下方，靠左右移动、刹车和加油调整与其他车辆的位置；道路、交通和景物相对玩家移动。通过自身后半部侧撞吞吃车辆并升级，依靠行驶距离获得分数。

当前阶段交付设计与实施规划。所有标为“初版参数”的数值均为可调设计值；车辆长度、交通速度区间和核心碰撞规则采用已确定的设定。

## 一分钟了解玩法

- 空格开始、暂停或继续；暂停时遮罩覆盖游戏，点击“结束游戏”结束本局。
- 左右方向键横向转向，按住 Z 刹车，按住 X 加油。
- 道路随机组合为双向四车道或六车道，左侧对向，右侧同向；玩家从右侧起步，可以越线进入左侧。
- 车辆依次为自行车、小汽车、拖拉机、卡车、加长卡车、坦克。初版从自行车开始。
- 自身后半部侧撞同级或低级车辆可以吞吃；吃三辆同级车升级，低一级需要九辆，低两级需要二十七辆，也可混合累积。
- 直撞同级或高级车辆死亡；直撞低一级降一级；直撞低两级及以下不降级，但速度下降 50%。尾侧撞高级车辆同样死亡。
- 前半部侧擦同级或高级车死亡；侧擦低级车使双方偏离原车道，不吞吃、不降级。
- 对向车辆碰撞直接死亡，低级车也不例外。车辆只从前方出现，不出现后方来车。
- 玩家速度范围为零到原车型交通速度上限加 20 km/h。
- 渐进收窄时刮擦路边、逐渐减速并纠偏；突然截止的车道有实体墙，撞墙死亡。
- 春、夏、秋、冬顺序循环，改变环境表现；初版各季节的道路抓地与规则相同。
- 每行驶一米获得一分。成绩使用 localStorage 保存在当前浏览器。

## 初版边界与设计决策

| 项目 | 初版决策 |
| --- | --- |
| 运行方式 | 固定本机 HTTP 地址，Three.js 与资源随项目提供，可离线运行 |
| 视角 | 俯视斜向跟随，玩家纵向屏幕位置基本固定，横向可移动 |
| 车道数量 | 四或六车道，分别为 2+2、3+3；不使用五车道 |
| 活动范围 | 全部车道可用，越线进入对向车道后仍朝原方向前进 |
| 玩家速度 | 原车型速度上限加 20 km/h，刹车最低到零 |
| 操作 | 空格、左右方向键、Z、X；不加入 A/D、鼠标转向或自动驾驶 |
| 最高等级 | 坦克，满级后继续吞吃与行驶，不追加第七级 |
| 失败 | 爆炸损毁、缩小远离并消失，最后显示结算 |
| 存档 | 保存已完成局的成绩和偏好，不保存可恢复的进行中对局 |
| 范围 | 单人、本机、无账号，无联网竞速或在线排行榜 |

暂停后空格可以继续；点击“结束游戏”才主动结束。巡航速度、擦边减速参数和升级余量等未指定细节在专题中给出初版决策，后续调参集中修改对应专题。升级导致车身变大后的新增重叠处理仍待确认，见碰撞专题。

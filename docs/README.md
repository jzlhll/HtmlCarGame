# 赛车游戏文档总览

## 项目定位

使用 Three.js 制作在本机浏览器中运行的单人、无限道路赛车游戏。玩家车辆位于屏幕下方，靠左右移动、刹车和加油调整与其他车辆的位置；道路、交通和景物相对玩家移动。通过车身侧面撞击吞吃车辆并升级，依靠行驶距离获得分数。

项目已提供本机可玩的初版，运行入口见[项目说明](../README.md)，模块说明见[实现结构](implementation/README.md)。所有标为“初版参数”的数值均为可调设计值；车辆尺寸、交通速度区间和核心碰撞规则采用已确定的设定。

## 一分钟了解玩法

- 空格开始、暂停或继续；暂停时遮罩覆盖游戏，点击“结束游戏”结束本局。
- 左右箭头横向转向，按住下箭头减速；松开后自动缓慢提速至当前车型上限。
- 车辆自动沿弯道前进，左右箭头只调整道路上的横向位置，不按左右键不会因普通弯道自然冲出道路。
- 道路随机组合为双向四车道或六车道，左侧对向，右侧同向；玩家从右侧起步，可以越线进入左侧。
- 车辆依次为自行车、三轮车、小汽车、卡车、加长卡车、坦克。初版从自行车开始。三轮车同时用于玩家与交通车辆；三级交通随机使用小汽车或拖拉机外观，等级、速度、尺寸和碰撞规则相同。
- 整段车身侧面撞击同级或低级车辆可以吞吃；目标固定积分依次为 1、2、6、18、54、216 分。升级门槛依次为 2、6、18、54、216 分，达到下一车型积分值即可升级，扣除门槛并保留余分；界面直接显示当前积分与门槛。
- 首次侧面接触时，我方车头超过对方车头，或位于对方车身后半段，算侧碰；其余按追尾。斜向接触按这两个位置条件判断，纯纵向端面接触仍按追尾。
- 追尾同级或高级车辆死亡；追尾低一级降一级；追尾低两级及以下不降级，但速度下降 50%。侧碰高级车辆同样死亡。
- 左侧对向车道也允许吞吃，接触范围与等级判定同右侧一致；车辆方向只影响相对接近速度。玩家当前车道不生成后方来车，其他车道允许。
- 路上车辆平时保持自己的车道，前后留足空间；前车较慢或车道关闭时，提前减速并确认其他系统车辆的空隙后变道。系统驾驶不考虑玩家，发生接触按玩家碰撞规则处理。
- 玩家速度最低为零，最高速度按车型独立设定：自行车 65、三轮车 75、小汽车、卡车、加长卡车、坦克均为 90 km/h。换车型后超过新上限会自动降速，交通车辆速度不随玩家上限调整。
- 渐进收窄时刮擦路边、逐渐减速并纠偏；突然截止的车道有实体墙，撞墙死亡。
- 路面偶尔出现坑洞和泥巴沼泽洞。踩坑车速减半、弹跳并偏向邻道；踩泥洞车速减半，车身挂泥并限速为车型上限的 50%，持续 8 秒，详见[路面接触规则](design/03-collision-and-growth.md#坑洞与泥巴沼泽洞)。
- 每局随机起始季节，按有效游戏时间每两分钟轮换到下一季；暂停不计时，刹停仍计时。初版各季节的道路抓地与规则相同。
- 每行驶一米获得一分。成绩使用 localStorage 保存在当前浏览器。

## 初版边界与设计决策

| 项目 | 初版决策 |
| --- | --- |
| 运行方式 | 固定本机 HTTP 地址，Three.js 与资源随项目提供，可离线运行 |
| 视角 | 俯视斜向跟随，玩家纵向屏幕位置基本固定，横向可移动 |
| 车道数量 | 四或六车道，分别为 2+2、3+3；不使用五车道 |
| 车流布局 | 平时保持所属车道，慢车超车/车道关闭时合法变道；系统之间留足净距，系统驾驶不避让玩家 |
| 活动范围 | 全部车道可用，越线进入对向车道后仍朝原方向前进 |
| 玩家速度 | 各车型固定上限，刹车最低到零；换车型时超过新上限自动降速，详见车辆专题 |
| 操作 | 空格、左右箭头、下箭头；按住下箭头刹车，松开自动提速 |
| 弯道行驶 | 自动跟随道路曲线，左右键仅横向调整，不承担过弯转向 |
| 最高等级 | 坦克，满级后继续吞吃与行驶，不追加第七级 |
| 失败 | 爆炸损毁、缩小远离并消失，最后显示结算 |
| 存档 | 仅保留本机排行榜前十名，不保存可恢复的进行中对局 |
| 范围 | 单人、本机、无账号，无联网竞速或在线排行榜 |

暂停后空格可以继续；点击“结束游戏”才主动结束。初始速度、加减速参数、擦边减速参数和升级余量等未指定细节在专题中给出初版决策，后续调参集中修改对应专题。降级清空当前升级进度。升级采用正常车型尺寸更新，宽车道与较大前后净距提供空间，不额外加入升级无敌或自动推开车辆的规则。系统车辆的变道决策只考虑其他系统车辆，玩家自行避免接触。

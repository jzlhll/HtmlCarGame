# 赛车游戏文档总览

## 项目定位

使用 Three.js 制作在本机浏览器中运行的单人、无限道路赛车游戏。玩家车辆位于屏幕下方，靠左右移动、刹车和氮气调整与其他车辆的位置；道路、交通和景物相对玩家移动。通过车身侧面撞击吞吃车辆并升级，依靠行驶距离获得分数。

项目已提供本机可玩的初版，运行入口见[项目说明](../README.md)，模块说明见[实现结构](implementation/README.md)。所有标为“初版参数”的数值均为可调设计值；车辆尺寸、交通速度区间和核心碰撞规则采用已确定的设定。

## 一分钟了解玩法

- 空格开始、暂停或继续；暂停时遮罩覆盖游戏，点击“结束游戏”结束本局。开始前可勾选内存中的调试模式，死亡动画结束后恢复当前车辆、闪烁保护两秒并继续，调试局不写排行榜。
- 左右箭头横向转向，按住下箭头减速；松开后自动缓慢提速至当前车型上限。
- 左右箭头横向转向，按住下箭头减速；松开后自动缓慢提速至当前车型上限。吞吃任何车辆都回气半管，同方向持续侧移超过 0.4 秒时吞吃回气翻倍。低于车型正常最高速度的 60% 时按住上箭头普通加速，不消耗气量；达到门槛后按住喷气，松开保留余量，每管可喷 3.5 秒，满两管可连续喷气 7 秒，每秒额外提速 70 km/h、最高速度提高 66%；停喷后用 0.35 秒回落，详见[横移与氮气](design/09-横移与氮气.md)。
- 车辆自动沿弯道前进，左右箭头只调整道路上的横向位置，不按左右键不会因普通弯道自然冲出道路。
- 有效运行满 2 分 30 秒后，前方经过平滑收窄，后续道路及副路保持双向四车道；过渡期间子弹概率增加 10 个百分点；进入后期四车道后，子弹相对基础增加 25 个百分点、火箭增加 20 个百分点，随机变道概率升至 45%–70%、间隔缩至 4–7 秒，危险车比例由 15% 升至 25%。此前道路随机组合为双向四车道或六车道，左侧对向，右侧同向；玩家从右侧起步，可以越线进入左侧。
- 车辆依次为自行车、三轮车、小汽车、卡车、坦克。初版从自行车开始，一级模型采用加宽的摩托车造型。三轮车同时用于玩家与交通车辆；三级交通统一使用小汽车模型，保留随机配色。
- 前方车辆优先提供低一级吞吃目标：基础 60% 低一级、10% 更低级、20% 同级、10% 高级；三轮车前方自行车及坦克前方卡车占 70%，自行车前方同级占 90%。后方车流保持原有分布，已生成车辆不替换。
- 前方普通新车在 160–240 米投放，前后补车失败后重试一次。场内容量从 88 辆起，每 15 秒有效运行增加 3 辆，最多 160 辆；普通系统车距每档缩短初始值的 2%，最低保留 65%，暂停冻结，新局重置。
- 整段车身侧面可吞吃低级车辆，自行车可吞吃同级自行车；氮气喷气期间可侧碰吞吃同级车辆；其他时候同级侧碰各按自身车宽两倍惯性弹开，再缓慢收尾；玩家 1.5 秒内不能左右控制、不加分。吞吃总分增加目标价值 1／2／6／18。总积分用于成长与饥饿储备，车型由 1／2／6／18／54 的门槛决定；吞吃和积分扣减引起的升降级保留积分，防御耗尽则设为低一级门槛，总分封顶 54，满级吞吃仍计数量并重置饥饿计时，左侧显示车型、总积分／门槛和当前防御百分比。
- 连续 10 秒未吞吃按当前车型扣 1／1／2／6／18，吃车重新计时。任何扣分导致降级都闪烁保护两秒；自行车允许到 −2，低于 −2 才死亡，负分吞吃直接累加。暂停冻结，零速继续，详见[成长积分与饥饿](design/10-成长与饥饿.md)。
- 首次接触侧面且纵向重叠足够算侧碰，整段车身可吞吃；明确撞击双方端面中央才按追尾。轻微擦角及已有重叠只横向分离，不吞吃、不降级、不减速。
- 追尾低级车只撞飞目标，不加分、不扣分、不减速；自行车追尾自行车直接死亡；其他同级追尾扣低一级车型价值、减速 50% 并移除目标，低于当前车型下限才降级保护两秒。明确侧碰或追尾高级车直接死亡。
- 左侧对向车道也允许吞吃，接触范围与等级判定同右侧一致；车辆方向只影响相对接近速度。所有同向车道均允许后方来车，刹车时可能被追上；右侧独立显示接近提示。
- 系统车生成后保持固定巡航，不因玩家或系统前车跟车减速。普通车仅在临近系统车辆、路障、坑洞、水流等碰撞或车道关闭时闪灯择邻道避让；保留原有随机变道开关，另有前期 15%、后期 25% 的危险车辆主动随机换道、不检查空隙。系统车之间碰撞时高级车撞毁低级车，同级弹开。
- 玩家速度最低为零，最高速度按车型独立设定：自行车 90、三轮车 110、小汽车、卡车、坦克均为 125 km/h。换车型后超过新上限会自动降速，交通车辆速度不随玩家上限调整。
- 渐进收窄时刮擦路边、逐渐减速并纠偏；突然截止的车道有实体墙，撞墙死亡。
- 路面偶尔出现坑洞和泥巴沼泽洞。踩坑车速减半、弹跳并偏向邻道；踩泥洞车速减半，车身挂泥并限速为车型上限的 50%，持续 8 秒，详见[路面接触规则](design/03-碰撞与成长.md#坑洞与泥巴沼泽洞)。
- 平坦地面道路低概率出现一队 5–7 头横穿奶牛，避开高架、坡道和河谷，并与结构两端保留 20 米缓冲。自行车、三轮车接触立即死亡，氮气不提供保护；小汽车及以上扣低一级车型价值，由剩余总积分决定降级及保护。
- 每局随机起始季节，按有效游戏时间每两分钟轮换到下一季；暂停不计时，刹停仍计时。各季节可随机触发春雾、夏雨雷击、冬雪结冰持续 9 秒，秋风持续 6 秒；分叉副路天气跨季节随机且更频繁；天气影响视野、横移或速度，碰撞与成长规则保持一致。
- 高架桥下随机出现铁路或河道，火车仅在桥下运行，不与公路平交、不设信号灯停车或火车撞击；低沉河道谷底长 20 米，进入时速度减半，干燥低谷不减速。
- 曾达到坦克或运行超过 75 秒后，道路左右外围出现碉堡（火箭）与塔楼（子弹），沿用玩家车型开火概率；车辆均不攻击。射弹耗尽防御时降级、保护两秒，详见[射击与防御](design/08-射击与防御.md)。
- 每满一分钟必定出现一匹 60 km/h 白马，奔跑 6 秒、闪烁 2 秒；任意接触立即保护，1 秒提至车型正常最高速度的两倍，无敌共 10 秒（最后 2 秒闪烁），随后 2 秒回落。保护期间一路撞飞、不吞吃或加分，饥饿倒计时冻结，详见[白马与无敌冲刺](design/11-白马事件.md)。
- 每行驶一米获得一分。成绩使用 localStorage 保存在当前浏览器。

## 初版边界与设计决策

| 项目 | 初版决策 |
| --- | --- |
| 运行方式 | 固定本机 HTTP 地址，Three.js 与资源随项目提供，可离线运行 |
| 视角 | 俯视斜向跟随，玩家纵向屏幕位置基本固定，横向可移动 |
| 车道数量 | 四或六车道，分别为 2+2、3+3；不使用五车道 |
| 车流布局 | 固定巡航、保留随机变道；普通车仅在临近碰撞时闪灯避让，前期 15%、后期 25% 的危险车不检查空隙；系统之间按等级撞毁或弹开，均不主动避让玩家 |
| 活动范围 | 全部车道可用，越线进入对向车道后仍朝原方向前进 |
| 玩家速度 | 各车型固定上限，刹车最低到零；换车型时超过新上限自动降速，详见车辆专题 |
| 操作 | 空格与方向键；下箭头刹车，左右横移，上箭头低速按住上键加速、达到 60% 后喷气、松开留气 |
| 弯道行驶 | 自动跟随道路曲线，左右键仅横向调整，不承担过弯转向 |
| 最高等级 | 坦克，满级后继续吞吃与行驶，不追加第六级 |
| 失败 | 爆炸损毁、缩小远离并消失，最后显示结算 |
| 存档 | 仅保留本机排行榜前十名，不保存可恢复的进行中对局 |
| 范围 | 单人、本机、无账号，无联网竞速或在线排行榜 |

暂停后空格可继续，点击“结束游戏”主动结束。数值集中在专题及配置中。车型由实际总积分决定，升级与降级均保留积分；升级不提供无敌，任何扣分降级保护两秒。已有车身重叠按碰撞专题横向分离。系统车辆驾驶只考虑其他系统车辆，玩家自行避让。

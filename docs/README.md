# 飞机模拟游戏文档总览

[返回项目说明](../README.md)

## 项目定位与交付范围

“云端驾驶舱”为暂定名称。游戏面向带键盘的桌面浏览器，使用虚构双发窄体民航客机，保留常见客机的外形、驾驶舱仪表、开关和起飞概念，操作采用便于理解的简化版本。

熟悉键盘字母位置是核心目标之一。通过有明确含义的动作、英文首字母和键帽提示，让使用者在起飞流程中练习找键；后续扩展到逗号、句号和分号等标点位置。首版不以覆盖全部字母为目标，键位学习通过飞机操作自然完成。

第一阶段已实现三维机场、跑道、静止客机和双窗驾驶舱，仪表台约占屏幕下方四分之一；支持外部／驾驶舱切换、空格暂停／继续、失焦暂停和窗口适配。飞机保持熄火，启动与飞行操作尚未实现。技术选择与模块结构见[实现说明](implementation/README.md)。

| 范围 | 内容 |
| --- | --- |
| 首个可玩版本 | 外部待机、四秒倒数运镜、七步开关、发动机启动、跑道加速、抬轮、离地、收起落架和襟翼、完成初始爬升 |
| 同步规划，后续实现 | 低空、云层、高空三个视觉区域；双窗观察山地、云海与远处地面；持续巡航与区域过渡 |
| 后续键位学习 | 逗号、句号、分号等标点键，优先用于安全、可重复的观察和仪表操作 |
| 暂不开发 | 动态天气、气流颠簸、降雨、雷暴、昼夜变化、降落、航线任务、自动驾驶、复杂故障、空中交通 |

首版的清朗天空与机场地面是起飞的必要背景，不等于已经实现天空巡航。首版终点为完成初始爬升后的结果页，后续再连接巡航阶段。

## 文档维护

- 玩法与操作以设计专题为准，README 只概述；实现说明维护模块契约，不重复扩展规则。
- 飞行速度、镜头时长、阈值及音量均为初版可调值，落地时集中到 `src/config.js`。
- 专题明确标注“首版”或“后续规划”；实现完成后再更新项目状态，不能仅凭文档存在标记完成。
- 不把虚构客机的参数写成某个真实机型的飞行手册数据。必要航空概念在专题内附原始资料来源。

# 飞机模拟游戏文档总览

[返回项目说明](../README.md)

## 项目定位与交付范围

“云端驾驶舱”为暂定名称。游戏面向带键盘的桌面浏览器，使用虚构双发窄体民航客机，保留常见客机的外形、驾驶舱仪表、开关和起飞概念，操作采用便于理解的简化版本。

熟悉键盘字母位置是核心目标之一。通过有明确含义的动作、英文首字母和键帽提示，让使用者在起飞流程中练习找键；后续扩展到逗号、句号和分号等标点位置。首版不以覆盖全部字母为目标，键位学习通过飞机操作自然完成。

已实现四秒入舱、七步准备、受力起飞与巡航、广州／长沙／武汉进近、着陆与停机、200／225／255 秒关卡时限、山体／建筑碰撞、瀑布奖励、10000 米限高故障、飞鸟与飞机遭遇、真实轨迹航线图与雷达预警。仪表与底部操作英文为主、中文为辅。倒数、开关、发动机、风、轮胎、收放电机和安全警报均已接入；本地英文播报随设备语音可用性降级，统一女声音色尚未验收；云层和天气仍未实现。

三关使用有限、虚构、压缩的共用路线；深圳起点相同，后关延长前段。终点广州／长沙／武汉的地面海拔沿途升至300／650／1000米。开场有计划路线，首次R放行后分别在200／225／255秒内于当前目的地圈内停妥，准备不计时。完整玩法以[航程专题](design/07-航线与关卡.md)为准。

后续范围为云层／天气、统一女声音色验收、地形分块、标点键观察、自动驾驶及更复杂任务，不将当前固定遭遇解释成真实空管或完整机型模拟。

## 文档维护

- 玩法与操作以设计专题为准，README 只概述；实现说明维护模块契约，不重复扩展规则。
- 飞行速度、镜头时长、阈值及音量均为初版可调值，落地时集中到 `src/config.js`。
- 专题明确标注“首版”或“后续规划”；实现完成后再更新项目状态，不能仅凭文档存在标记完成。
- 不把虚构客机的参数写成某个真实机型的飞行手册数据。必要航空概念在专题内附原始资料来源。

# 赛车游戏文档总览

## 项目定位

使用 Three.js 制作在本机浏览器中运行的单人、无限道路赛车游戏。玩家车辆位于屏幕下方，靠左右移动、刹车和氮气调整与其他车辆的位置；道路、交通和景物相对玩家移动。通过车身侧面撞击吞吃车辆并升级，依靠行驶距离获得分数。

项目已提供本机可玩的初版，运行入口见[项目说明](../README.md)，模块说明见[实现结构](implementation/README.md)。所有标为“初版参数”的数值均为可调设计值；车辆尺寸、交通速度区间和核心碰撞规则采用已确定的设定。

## 一分钟了解玩法

- 空格开始、暂停或继续，暂停页可结束本局。开局前可开启调试模式，死亡后原地复活并保护两秒，调试局不写排行榜。
- 左右键横移，下键刹车至零，松开自动提速。上键先普通加速至最高速，停按后再按才喷气；吞吃回气，同向持续侧移超过 0.4 秒时翻倍。每管喷气 3.5 秒，上限两管，喷气最高速度提高 66%，停喷平滑回落，见[横移与氮气](design/09-横移与氮气.md)。
- 车辆自动跟弯，可使用同向和对向车道。道路初期随机四/六车道；有效运行满 150 秒后平滑收窄，主副路随后永久四车道，危险车比例和随机变道强度提高，见[道路与车流](design/05-道路与车流.md)。
- 五级车型为自行车、三轮车、小汽车、卡车、坦克，门槛及吞吃价值为 1／2／6／18／54；一级采用加宽摩托车造型。升至三轮车或小汽车时立即在当前路线前方 80–150 米投放同级与低一级各五辆。
- 有效侧碰吞吃低级车，自行车可吃同级，其他同级车仅喷气时可吃，普通侧碰则惯性弹开并锁定左右控制 1.5 秒。追尾同级车必定降级、减速并保护两秒，自行车同级追尾死亡；低级追尾只撞飞，高级车有效接触及截止墙接触致命。擦角和已有重叠只分离，见[碰撞规则](design/03-碰撞与成长.md)。
- 吞吃增加总积分并重置十秒饥饿；到期按实际车型扣分，自行车低于 −2 死亡。换级补满防御，降级保护两秒；闪电、炮弹先消耗防御，耗尽降一级，见[成长与饥饿](design/10-成长与饥饿.md)。
- 前方普通车优先提供低一级目标，运行中在 160–240 米投放；车流容量由 88 逐步增至 160。普通系统车临近碰撞才避让，危险车不检查空隙，均不主动避让玩家。升级补车是近距投放的专用例外。
- 四季随机起始，每 120 秒轮换，天气影响视野、横移与速度。道路包含上下坡、施工、缓行、坑洞、泥洞及随机分叉，副路坑洞和天气更密集。高架桥下火车仅为装饰，河道谷底入口减半车速，铁路不减速。
- 两分钟后开始天降炮击，红圈预警后落地爆炸，区域从 6×6 米起每 30 秒扩大 20%，坦克和卡车按比例消耗防御，其他车型直接命中死亡，见[炮击与防御](design/08-炮击与防御.md)。
- 每分钟出现白马，接触后提至车型正常上限两倍并无敌十秒，撞飞而不吞吃，饥饿冻结，随后平滑回落，见[白马事件](design/11-白马事件.md)。
- 警车在前方保持距离、极速避让并向预判位置撒网，网落地后接触即被抓，动画后按所选年级答题；答对撤离、答错结束，持续 45 秒自动撤离，见[警车追击](design/13-警车追击.md)。
- 每实际前进一米得一分，排行榜保存在当前浏览器。暂停冻结有效时间；零速仍推进饥饿、天气及事件。

## 初版边界与设计决策

| 项目 | 初版决策 |
| --- | --- |
| 运行方式 | 固定本机 HTTP 地址，Three.js 与资源随项目提供，可离线运行 |
| 视角 | 俯视斜向跟随，玩家纵向屏幕位置基本固定，横向可移动 |
| 车道数量 | 四或六车道，分别为 2+2、3+3；不使用五车道 |
| 车流布局 | 固定巡航、保留随机变道；普通车仅在临近碰撞时闪灯避让，前期 15%、后期 25% 的危险车不检查空隙；系统之间按等级撞毁或弹开，均不主动避让玩家 |
| 活动范围 | 全部车道可用，越线进入对向车道后仍朝原方向前进 |
| 玩家速度 | 各车型固定上限，刹车最低到零；换车型时超过新上限自动降速，详见车辆专题 |
| 操作 | 空格与方向键；下箭头刹车，左右横移，上箭头按住加速到最高车速、停按后再按喷气、松开留气 |
| 弯道行驶 | 自动跟随道路曲线，左右键仅横向调整，不承担过弯转向 |
| 最高等级 | 坦克，满级后继续吞吃与行驶，不追加第六级 |
| 失败 | 爆炸损毁、缩小远离并消失，最后显示结算 |
| 存档 | 仅保留本机排行榜前十名，不保存可恢复的进行中对局 |
| 范围 | 单人、本机、无账号，无联网竞速或在线排行榜 |

暂停后空格可继续，点击“结束游戏”主动结束。数值集中在专题及配置中。车型由实际总积分决定，升级与降级均保留积分；升级不提供无敌，任何扣分降级保护两秒。已有车身重叠按碰撞专题横向分离。系统车辆驾驶只考虑其他系统车辆，玩家自行避让。

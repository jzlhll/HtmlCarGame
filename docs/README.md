# 英语空战设计入口

Three.js 单人英语拼写射击游戏。玩家横移，向咬题怪兽或 Boss 发射字母颗粒补全单词，或瞄准选择题八爪鱼的三个选项；先预习、再战斗、结算复习并记录学习结果。当前实现本地账号、固定十二词续玩、多关卡、Boss、幸运箱、三类学习记录和浏览器朗读；桌面首关随机选择空战或碎片，之后交替，手机点选挑战与四轮碎片模式逐关交替。

| 项目 | 最终规则 |
| --- | --- |
| 账号 | 首页内嵌无密码账号，创建时编辑并保存名字、重名校验、原位二次确认登录，保存后不改名，设置按账号、学习与进度按账号＋词库隔离 |
| 关卡 | 固定 12 词，桌面首关随机、随后交替；空战按小六／初中／四级／六级为 270／285／300／315 秒（大 Boss 全对后五秒拾箱），两轮碎片组装＋两轮护航编队，拼接各六词、护航各九词，每轮90秒，总计 360 秒；手机点选挑战与碎片模式逐关交替 |
| 碎片模式 | 前两轮各六词互不重复，恰好覆盖十二词，每词最多三块；后两轮九架单词战机与九个释义航标配对、建立待定连线，两轮轮空三词互不相同、合计覆盖十二词；每轮完整分配后提交，最多三次验证，正确消除、错误释放 |
| 续玩 | 预习前保存词池，未完成及重玩用原词，新关重抽 |
| 预习 | 单词、中文与英中短语／例句，横滑词卡、圆点、分数页码，全看过才开始 |
| 出题 | 任意字母随机挖空，至少两个、最多一半；二至三个字母词也挖两个；本关词池用完才重复；普通题间隔按词库普通出题时间缩放，小六约 8.33–11.67 秒尝试生成，慢速下落；每二十题十四拼写、三释义选择、三挖空选择 |
| 输入 | A–Z 连射，大小写跟随规范词形；1–4 选前四个缺字格，Shift 单发弧线跟踪弹（无敌机不耗弹），退格删除、反引号撤销 |
| 点阵 | 26 个大写、26 个小写，子弹需求约七成并取最近偶数；0.06 秒一颗、填完锁定 0.75 秒 |
| Boss | 三面小 Boss、四面大 Boss 各限时一分钟，普通预算一半／结束前 60 秒出场，期间保留已有普通飞机，只停新生成，去除面数提示 |
| 幸运箱 | 普通拼写／选择答对各 2 箱，慢晃两秒再按距离自动飞入收藏；桌面周期箱及 Boss 3／5 箱碰触收藏，手机均自动收藏 |
| 选择题 | 挖空片段或双向释义，各三个等宽选项；桌面射击累计 20 发后验证，手机直接点选；手机普通题与 Boss 两类选择各半，不生成敌机，补给自动收藏 |
| 拾箱 | 大 Boss 全对后清场，倒数五秒，四方向自由移动；暂停、失焦冻结 |
| 结算 | 星光上按词合并展示小模型及对错答案，超出一屏时在最右侧滚动，复习完成后只显示重玩与下一关按钮；成绩独立保存 |
| 复习 | 不同失败词各 10 秒，锁住操作及开局，刷新保留、失焦暂停 |
| 学习库 | 每账号每词库独立 IndexedDB 明细及汇总，100 词每页，失败降序，按需朗读 |
| 选词权重 | 历史正确率严格高于 50%／75%／85%，分别权重 0.5／0.25／0.01 |
| 词库 | 小六 1000、初中进阶 2200、英语四级 6259、英语六级 1718；每词有英中短语或例句 |
| 星空 | 十七种背景每 15 秒无放回轮换，背景蒙版，不限制总轮换时长 |

四阶段词库按分级课标及阶段资料选编，来源和范围见词库专题，不作为某版教材或官方考试大纲的完整覆盖声明。玩法数值集中 `src/config.js`，词库元数据统一注册，规则修改同步专题。

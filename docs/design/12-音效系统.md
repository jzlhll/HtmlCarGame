# 音效系统

音效全部由 `src/audio.js` 用 Web Audio 实时合成，不加载任何音频文件；数值集中在 `src/config.js` 的 `AUDIO`，事件触发点跟随对应游戏逻辑（散布在 `game.js`、`ui.js`）。本文档描述声音构成、空间模型、触发点与静音规则；调参流程见[开发与验证效率](../implementation/development-workflow.md)，试听验证要求见[常规验证流程](../implementation/validation.md)。

## 设计原则

- 全部声音代码生成：持续声由循环模式拼装，事件声由振荡器与噪声即时合成，无资源加载与解码等待。
- `AudioContext` 依赖用户手势，在开始一局（`Game.start` 调用 `audio.ensure`）时创建；页面刷新后需重新开始才会出声。
- 主总线增益 `AUDIO.master` 0.55 统一控制，玩家自身发动机与喷气音量刻意低于环境声。
- 音效细化不阻塞玩法：新增声音优先复用既有合成模式，只加参数不加机制。

## 合成方式

| 方式 | 组成 | 用途 |
| --- | --- | --- |
| `tone` | 振荡器 + 指数频率滑动 + 快起慢落包络 | 事件声的音高成分 |
| `burst` | 循环白噪声 + 双二次滤波器频率滑动 | 事件声的噪声成分 |
| 循环声 | 噪声源、LFO、滤波、增益、声像常驻节点 | 六类持续环境声 |

## 空间模型

- 环境声按与玩家的实际距离衰减：河道流水 70 米、火车 170 米、坦克 55 米、掠过车流 7 米，超出范围完全静音，进入范围按 `1−距离/范围` 淡入。
- 声像按声源横方位偏置：横风随风向 ±0.75，火车随横穿位置 ±0.75，坦克随所在侧 ±0.6，掠过呼啸 ±0.65。
- 火车与坦克循环声按接近速率实时计算多普勒：音高系数 `1+接近速度/60`，限制在 0.82–1.3，作用于哐当节奏、隆隆与履带滤波频率；掠过呼啸用固有下滑频率近似多普勒，不实时计算。

## 循环环境声

| 声音 | 触发条件 | 表现 |
| --- | --- | --- |
| 发动机 | 行驶中常驻 | 音高随车速从 44 Hz 升至 96 Hz 区间，增益随速度比例抬升 |
| 喷气 | 氮气 `boost>0` | 叠加 1400 Hz 气流噪声，停喷即收 |
| 横风 | 秋季风场开启且玩家在对应路线 | 持续风噪，声像随风向往复 |
| 河道流水 | 玩家 70 米内存在河道段 | 距离平方淡入的持续水声 |
| 火车 | 桥下火车 170 米内 | 哐当节奏 + 低频隆隆，声像随横穿方向移动并带多普勒 |
| 坦克 | 系统坦克 55 米内 | 履带低频轰隆，声像随所在侧并带多普勒 |
| 掠过车流 | 车辆前进方向越过玩家的瞬间 | 相对速度 ≥ 29 km/h 且横向距离 7 米内时播放一次呼啸，音量按横向距离与相对速度平方衰减 |
| 路边刮蹭 | 持续刮擦路边 | 每 0.13 秒一次短噪声，直至脱离 |

## 事件声

事件声按次触发、自然衰减，无距离模型（触发即发生在玩家身上或极近处）。碰撞类由同刻事件组统一分发（`collision(group)`），每种动作只响一次：

| 声音 | 触发点 |
| --- | --- |
| 开始一局 `start` | `Game.start`，低频上扬 + 噪声铺底 |
| 吞吃 `eat` | 碰撞事件 `eat`，低沉吸入感 |
| 同级弹开 `side` | 碰撞事件 `bounce` 与奶牛降级 `cowDowngrade` |
| 擦角 `graze` | 碰撞事件 `graze` |
| 撞毁 `crash` | 碰撞事件 `knockaway`、`downgrade`、`wall`、`roadwork` |
| 玩家死亡 `explosion` | `Game.die` 进入 `DYING` |
| 追尾警示 `rear` | 右侧后方接近提示出现时（UI 层触发） |
| 提示音 `beep` | 临时提示与道路文字预告弹出时（UI 层触发） |
| 射弹命中 `impact` | 防御吸收射弹伤害（`hurtProjectile`），死亡走 `explosion` 不重复 |
| 升级／降级 `upgrade`／`downgrade` | 车型变化（升三音阶、降两音下行） |
| 踩泥洞 `mud` | 接触泥巴沼泽洞 |
| 撞坑弹跳 `bump` | 接触坑洞 |
| 入水 `splash` | 谷底河道触水减速 |
| 结冰 `freeze` | 冬季冰面打滑 |
| 雷击 `thunder` | 夏季闪电 |
| 白马 `horse` | 收集白马进入保护 |
| 结算 `result` | 本局结束时两音收尾 |

## 静音与状态规则

- 暂停、结算、返回首页（`state≠RUNNING`）时 `setState` 立即把六类循环声增益压到零，事件声自然衰减；恢复运行后环境声按各自条件重新淡入。
- 循环声计算由运行状态门控：暂停后火车、坦克等数据数组冻结滞留，若不门控会在静音后被重新拉高。
- 结算界面只保留 `result` 事件声；死亡动画期间循环声已静音，`explosion` 自然衰减。

## 配置入口

全部数值集中在 `config.js` 的 `AUDIO`：`master` 主音量；`engine`（怠速/最高频率、增益、喷气增益与频率）；`wind`、`water`、`train`、`tank`（增益、可闻距离、声像幅度）；`pass`（可闻横向距离、最低相对速度、增益）；`beep`（提示音频率与增益）。调整后刷新页面即可对比试听，不引入资源文件。

# 音效系统

音效由 `src/audio.js` 用 Web Audio 实时合成，不加载音频文件；数值集中在 `src/config.js` 的 `AUDIO`，触发点跟随游戏逻辑（散布在 `game.js`、`ui.js`）。调参流程见[开发与验证效率](../implementation/development-workflow.md)，试听验证见[常规验证流程](../implementation/validation.md)。

## 设计原则

- `AudioContext` 依赖用户手势，开始一局时创建（`Game.start` 调用 `audio.ensure`）。
- 主总线 `AUDIO.master` 0.55 统一控制；玩家发动机与喷气音量低于环境声。
- 新增声音优先复用既有合成模式，只加参数不加机制。

## 合成方式

| 方式 | 组成 | 用途 |
| --- | --- | --- |
| `tone` | 振荡器 + 指数频率滑动 + 快起慢落包络 | 事件声的音高成分 |
| `burst` | 循环白噪声 + 双二次滤波器频率滑动 | 事件声的噪声成分 |
| 循环声 | 噪声源、LFO、滤波、增益、声像常驻节点 | 七类持续环境声 |

## 空间模型

- 环境声按距离衰减，超出即静音，水声、火车、坦克与警笛在范围内按 `(1−距离/范围)²` 淡入（可闻距离见下表）。
- 声像按横方位偏置：横风随风向 ±0.75，火车随横穿位置 ±0.75，警笛 ±0.7，坦克 ±0.6，掠过呼啸 ±0.65。
- 火车与坦克按接近速率实时计算多普勒：音高系数 `1+接近速度/60`，限制在 0.82–1.3，作用于哐当节奏、隆隆与履带滤波频率；掠过呼啸用固有下滑频率近似多普勒。

## 循环环境声

| 声音 | 触发条件 | 表现 |
| --- | --- | --- |
| 发动机 | 行驶中常驻 | 音高从 44 Hz 起每单位车速比例提升 96 Hz（上限 1.7，约至 207 Hz），增益随速度抬升 |
| 喷气 | 氮气 `boost>0` | 叠加 1400 Hz 气流噪声，停喷即收 |
| 横风 | 秋季风场开启且玩家在对应路线 | 持续风噪，声像随风往复 |
| 河道流水 | 玩家 70 米内存在河道段 | 距离平方淡入的持续水声 |
| 火车 | 桥下火车 170 米内 | 哐当节奏 + 低频隆隆，声像随横穿移动并带多普勒 |
| 坦克 | 系统坦克 55 米内 | 履带低频轰隆，声像随所在侧带多普勒 |
| 警笛 | 警车存在且 170 米内 | 低频单音按约 3.1 Hz 通断的“嗯、嗯、嗯”脉冲，内频率轻微下滑，声像随所在侧 |
| 掠过车流 | 车辆前进方向越过玩家瞬间 | 达到配置的相对速度门槛 且横向距离 7 米内播放一次呼啸，音量按横向距离与相对速度平方衰减 |
| 路边刮蹭 | 持续刮擦路边 | 每 0.13 秒一次短噪声直至脱离 |

## 事件声

事件声按次触发、自然衰减，无距离模型；碰撞类由同刻事件组分发（`collision(group)`），逐事件分发；擦角声另按最小间隔节流，不改变接触判定：

| 声音 | 触发点 |
| --- | --- |
| 开始一局 `start` | `Game.start` |
| 吞吃 `eat` | 碰撞事件 `eat` |
| 同级弹开 `side` | 碰撞事件 `bounce` 与奶牛降级 `cowDowngrade` |
| 擦角 `graze` | 碰撞事件 `graze`，相邻触发至少间隔 0.16 秒，新局重置 |
| 撞毁 `crash` | 碰撞事件 `knockaway`、`downgrade`、`wall`、`roadwork` |
| 玩家死亡 `explosion` | `Game.die` 进入 `DYING` |
| 追尾警示 `rear` | 右后方接近提示出现（UI 层） |
| 提示音 `beep` | 临时提示弹出（UI 层） |
| 防御吸收 `impact` | `Game.hurt` 防御分支吸收炮弹/闪电伤害，死亡走 `explosion` 不重复 |
| 炮弹啸声 `shellWhistle` | 炮弹落点生成时按下落时长播放啸声 |
| 炮弹爆炸 `shellBoom` | 炮弹落地爆炸（区域摧毁） |
| 撒网 `netThrow` / 被抓 `netCatch` | 警车撒网、渔网罩住玩家 |
| 升级／降级 `upgrade`／`downgrade` | 车型变化（升三音阶、降两音下行） |
| 踩泥洞 `mud` | 接触泥巴沼泽洞 |
| 撞坑弹跳 `bump` | 接触坑洞 |
| 入水 `splash` | 谷底河道触水减速 |
| 结冰 `freeze` | 冬季冰面打滑 |
| 雷击 `thunder` | 夏季闪电 |
| 白马 `horse` | 收集白马进入保护 |
| 结算 `result` | 本局结束 |

## 静音与状态规则

- 暂停、结算、返回首页（`state≠RUNNING`）时 `setState` 在 0.05 秒内将循环声增益压到零，事件声自然衰减；恢复后按各自条件重新淡入。
- 循环声计算由运行状态门控，避免暂停后冻结滞留的数据在静音后被重新拉高。
- 结算界面只保留 `result` 事件声。

## 配置入口

全部数值集中在 `config.js` 的 `AUDIO`：`master` 主音量；`engine`（怠速/最高频率、增益、喷气增益与频率）；`wind`、`water`、`train`、`tank`（增益、可闻距离、声像幅度）；`police`（警笛频率、通断、可闻距离与声像）；`shell`（啸声与爆炸参数）；`pass`（可闻横向距离、最低相对速度、增益）；`beep`（提示音频率与增益）；`graze.intervalSeconds`（擦角声最小间隔）。刷新页面即可对比试听。

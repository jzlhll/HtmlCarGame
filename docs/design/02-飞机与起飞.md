# 飞机与起飞

[返回总览](../README.md)

## 飞机定位与真实概念

采用虚构的双发窄体喷气客机，外形尺度参考常见单通道客机：机长约 38 米、翼展约 35 米，前三点式可收放起落架，机翼带起飞襟翼。驾驶舱抽象为两扇主要前窗，不追求某架真实客机的窗框或按钮复刻。

机翼始终展开；W 调整的是机翼后缘的襟翼，起飞位提供额外升力并增加阻力。首版使用 CLEAN／TAKEOFF 两个稳定位置及 RETRACTING 过渡状态，具体襟翼角度不套用真实机型档位。

真实客机的 VR 是开始抬轮的速度，不是达到就自动离地的速度；V2 是起飞安全速度。实际数值取决于飞机与起飞配置，不能把一个固定速度当成所有客机的标准。[Airbus 起飞速度说明](https://safetyfirst.airbus.com/control-your-speed-at-take-off/)

本游戏不设置可变重量系统，不计算机场性能条件；质量、机翼面积、动力和起飞提示速度采用固定预设，升力与阻力随实时状态计算。首版只保留玩家可感知的开关、滑跑、抬轮和爬升过程，后续通过天气、湿滑或碎石路面等改变操纵表现。

## 首版场景与参数

以下全部是虚构飞机的游戏初始值，后续通过体验调整；不作为真实 A320、737 等机型性能数据。

| 项目 | 初版值 | 用途 |
| --- | --- | --- |
| 跑道 | 长 3,000 米、宽 60 米；飞机从距入口约 100 米处开始 | 有足够的滑跑与中止空间 |
| 初始状态 | 速度 0，油门 0，两台发动机熄火，驻车刹车开启 | 禁止开场自行滑行 |
| 自动点火时长 | 约 3 秒 | 一次 F 完成两台发动机启动 |
| VR 抬轮标记 | 145 kt，约 269 km/h | 达到后提示 ↑ 抬头；不自动起飞 |
| 推荐爬升速度 | 180–220 kt，约 333–407 km/h | 收襟翼后的稳定爬升范围 |
| 推荐抬轮／爬升姿态 | 机头上仰约 8–12°，俯仰变化上限约 3°/s | 有客机的重量感，避免瞬间拉起 |
| 滑跑节奏 | 从静止持续加油门约 20 秒达到 145 kt | 由推力、发动机响应、阻力和轮胎摩擦共同产生，不按计时器强行设置速度 |
| 收起落架条件 | 离地高度 ≥ 30 米，且正在正爬升 | G 不能在地面生效 |
| 收起襟翼条件 | 离地高度 ≥ 200 米且空速 ≥ 180 kt | W 不提前清除起飞升力配置 |
| 初始爬升完成 | 离地高度 ≥ 500 米、空速在 180–220 kt、爬升率 > 0、坡度绝对值 ≤ 10°、起落架与襟翼已收，连续保持 3 秒 | 冻结飞行，成功反馈 1.5 秒后进入结果页；任一条件失效则重新累计 |
| 低速警告 | 空速 < 130 kt；恢复到 > 140 kt 并保持 0.8 秒后解除 | 低速降低动压，失速仍根据迎角判定 |
| 姿态警告 | 俯仰 > 15° 或 < −10°；低于 120 米且下降航迹 < −6° 也警告 | 中央单次 2.5 秒；底部和气动读数常驻危险状态 |
| 超速警告 | 空速 > 250 kt；低于 240 kt 解除 | 提示收油和平缓改出俯冲，不直接截断速度 |

内部使用米、秒、米每秒、弧度；HUD 主显示 kt，旁列 km/h，`1 kt = 1.852 km/h`。高度主显示米，初始阶段明确为离地高度 AGL；未来巡航另加海拔高度 MSL，两者不能混用。

## 地面到空中的行为

1. 熄火和驻车状态下位置保持不变。发动机达到怠速不自动提油门；R 通过后才接受 T。
2. 滑跑时推力推进速度，阻力随速度增大，轮刹只在地面生效。左右输入作用于航向，不直接平移机身。
3. 达到 VR 只解锁正常抬轮能力。玩家按 ↑ 平滑抬头，空速、迎角与襟翼共同决定升力，升力加推力垂直分量达到重量才解除地面约束；速度未到时持续按 ↑ 不应蓄积异常姿态。
4. 离地后保持位移、速度和姿态连续。俯仰改变飞行路径和速度，滚转产生协调转弯，禁止将 ↑／↓ 实现为恒定高度增减。
5. 正爬升后允许收起落架；满足高度与速度条件后允许收襟翼。阻力和升力随收放进度平滑变化，不能只切换模型外观。
6. 升力不足时自然下沉；超过临界迎角进入失速，减小迎角可以恢复。姿态采用限速操纵，平移运动使用三维受力积分；不模拟完整六自由度刚体力矩、尾擦或精细单发故障。

真实起飞应在适当的抬轮速度开始操作，过早或过快抬头会影响起飞表现；这里保留平滑抬轮和安全余度的体验。[Airbus 抬轮说明](https://safetyfirst.airbus.com/a-focus-on-the-takeoff-rotation/)

## 固定客机的气动模型

质量固定为 52,000 kg，机翼参考面积 122.6 m²，最大总推力 275 kN；这些是虚构客机的游戏预设，不提供重量、载重或机场性能输入。海平面空气密度为 1.225 kg/m³，随高度按指数曲线衰减，天气和风尚未接入。系数统一维护于 `AERODYNAMICS`，操作与成功阈值维护于 `FLIGHT`。

每个 1/120 秒逻辑步执行以下计算：

1. 从三维速度得到空速 `V = |v|`、水平速度和航迹角 `γ = atan2(vy, 水平速度)`。俯仰角 `θ` 表示机头方向，迎角 `α = θ − γ` 表示机翼与气流方向的差；飞机抬头不等于必然上升。
2. 动压 `q = ρV²/2`；未失速时 `CL = CL0 + CLα·α + 襟翼增量`，升力 `L = qSCL`。阻力 `D = qS(CD0 + kCL² + 起落架增量 + 襟翼增量 + 分离阻力)`。
3. 油门目标经 0.8 秒发动机响应后产生推力，推力随空速和空气密度变化；熄火后剩余推力平滑衰减。地面轮胎摩擦和轮刹按剩余法向支撑力计算，不施加空中轮刹。
4. 推力沿机身方向，阻力与气流相反，升力与气流垂直，重力始终向下。按 `dv/dt = (T + L + D)/m + g` 对三个分量积分，再更新位置；不把俯仰换成固定爬升率，也不强行把速度拉向目标值。
5. 滚转旋转升力方向：部分升力转向水平产生转弯，垂直分量随坡度增大而减小。航向从水平速度方向连续更新，采用协调转弯假设，不单独模拟侧滑和方向舵。

俯仰目标每次按键调整 1°，持续输入每秒调整 3°，实际响应受动压和失速状态影响。地面目标范围 0–18°、空中 −25–30°，空中最大坡度 45°、滚转变化率最多 25°/s。范围是操纵边界，不代表该范围内都安全；低速或失速时控制效能下降。

爬升把部分动能转换为势能，推力不足时会减速；俯冲把势能转换为动能，阻力随空速平方增加。熄火后不能凭空维持速度和高度。持续大坡度增加维持高度所需升力和诱导阻力，可能导致掉高度或失速。显示升力载荷 `L/(mg)`，用于观察受力变化，不据此宣称已模拟完整结构过载损伤。

G 收轮耗时 2.5 秒，W 收襟翼耗时 2 秒；同一连续进度驱动外观、阻力及襟翼升力。离地前以主轮为抬头支点，离地不重置位置或速度。离地高度由轮胎、机腹及翼尖最低接触点计算。

## 过大／过低角度与失速

- 机头俯仰超过 15°时，中央显示“您的仰角过大，需要降低机头（按 ↓）。”；降到 13°以下持续 0.8 秒才重新允许下一次进入提示。
- 俯仰低于 −10°时，中央提示适当抬高机头；正常小角度下降不报错。低于 120 米且航迹角低于 −6°也提示接地危险；俯仰回到 −7°以上且退出危险下降角持续 0.8 秒后解除。
- 干净构型临界迎角 14°，起飞襟翼增加到 16°。超过临界后升力系数连续衰减、分离阻力连续增大；持续 0.2 秒确认失速。迎角绝对值低于当前临界值至少 3°并持续 0.8 秒后解除失速状态。
- 失速告警优先于俯仰和低速提示，不同时要求玩家“抬头”和“低头”。正迎角过大时降低机头，负迎角过大时抬高机头，以减小迎角绝对值；配合可用推力并保持机翼平稳。低空可能没有足够恢复空间。失速本身不强制结算，实际撞地才失败；持续失速导致撞地会显示对应原因。
- 临时告警单次 2.5 秒，持续操纵、速度变化和同一危险状态不刷新计时；危险状态保留在底部指引与气动读数。退出安全区后再次进入才产生新事件。

气动关系依据 [NASA 升力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/lift-equation/)、[NASA 爬升受力](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/forces-in-a-climb/)及 [FAA 飞行气动力学](https://www.faa.gov/regulations_policies/handbooks_manuals/aviation/glider_handbook/gfh_chapter_3.pdf)。当前升阻力曲线、失速后曲线与发动机响应是可调游戏近似，未采用真实机型风洞／飞行试验数据；不包含完整六自由度、可压缩气流、地面效应、侧滑或结构破坏模型。

## 跑道边界与中止

跑道有效宽度应扣除主轮横向跨度；主轮越过可用边界或冲出末端仍未离地时判定失败，不按飞机中心点容忍半个机身越界。离地后的撞地检查使用机体与起落架最低点，逻辑高度与模型位置使用同一参考点。

滑跑时可按 S 收油、制动并重新给油继续；首版不实现 V1 决断逻辑，不虚构超过某速度就禁止刹车的机制。刹停后保留开关状态、沿用同一段跑道剩余距离，需要完整重来则从暂停页重新开始。

首版飞行空间仅覆盖机场周边与初始爬升；高空性能、巡航高度上限与空气密度分层留到[天空环境规划](04-天空环境规划.md)阶段。

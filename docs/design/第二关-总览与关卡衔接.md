## 范围与状态

本方案对应已实现的第二关初版：关卡切换、装甲坦克、荒原与绿洲场景、环境恐龙、横穿及追行事件。尺寸、频率、音色和表现保留试玩调参空间。

第一关沿用现有玩法，生存满 3 分钟后通关；第二关从零重新开始，进入灰色砂土道路与荒原戈壁，提高天气概率并以大型恐龙追行替代天降炮击，并加入仅限系统车辆的装甲坦克和分阶段恐龙事件。第二关以恐龙替换奶牛横穿与桥下火车，戈壁布置三角龙、剑龙，少量绿洲湖边布置梁龙。第二关暂不设置通关时限，继续生存直至死亡或主动结束。

文中的关卡门槛、事件概率、装甲坦克投放比例、小恐龙两倍横穿速度及恐龙分阶段表现为确定规则；恐龙尺寸、节奏与接触后果为初版试做约定，后续根据实际体验调参。运行参数集中在 `src/config.js`。

## 第一关通关与第二关入口

第一关以有效运行时间判断，2:55 开始在顶部独立状态栏显示“即将过关 · 5 秒”，依次倒数至 1 秒；这是关卡倒计时，不使用临时事件提示。停车仍计时；暂停、答题、被抓、死亡动画及失焦暂停期间不计时，倒计时隐藏并在恢复行驶后继续。最后五秒仍处理正常碰撞、天气与救援。

满 3:00 时先处理截止时刻以内的碰撞与致命事件。只有仍处于 `RUNNING` 才进入 `LEVEL_EXIT`：镜头与道路场景固定，普通车流、警车、白马、横穿动物和未完成的危险事件清空；玩家模型自动沿当前路线向前驶离，持续 3 秒，最低展示速度 100 km/h。动画只移动展示位置，不增加时间、距离或成长，不接受驾驶和切关输入，音效静音；失焦或隐藏页面时动画暂停。救援与死亡状态不得被动画覆盖，成功救援后仍需安全行驶至时限。

驶离动画结束后进入 `LEVEL_CLEAR`，通关界面中央显示：

- 主文案：**恭喜！通过第一关。**
- 操作说明：**空格进入第二关。**
- 追加恐龙踩踏、装甲坦克和金币系统三项实际模型预览，各用一句话说明危险或发射操作。
- 触屏提供“进入第二关”按钮，与空格执行相同行为。

这是需要玩家确认的关卡界面，保持显示直到操作，不属于最长三秒的临时提示。背景道路、车辆、天气、饥饿、氮气和所有事件冻结，音效静音；清空按键与触控状态。空格需要新的按下动作，长按或按键重复不得跳过界面、重复切关或刚进入第二关又暂停。失焦后保持通关界面，回到页面不自动进入第二关。

`LEVEL_CLEAR` 每局只出现一次，进入第二关后不再触发第一关通关流程。普通入口返回首页或重开从第一关开始；首页勾选直达第二关时按该调试选项开局。

首页另提供“调试 · 直接进入第二关”勾选，默认关闭；开启后直接初始化第二关，遵循调试模式的自动判过、死亡复活与不写榜规则。重置继续第二关，返回首页取消勾选后恢复普通第一关入口；仅保存在页面内存。

### 第二关从零开局

- 进入第二关复用完整新局初始化：重新生成种子、道路和车流，玩家从自行车、初始积分、满防御、空氮气、初始速度开始；主路起点、距离和有效时间均归零。
- 金币余额、火箭动画、吞吃统计、最高车型、两次答题救援、饥饿时钟、季节起点及所有事件排程重置；不继承第一关的冰冻、泥巴、弹开、无敌、白马、警车、车队、路障、天气、炮弹或道路收窄状态。
- 只保留玩家选择的涂装和调试模式设置。车流恢复初始容量与净距，季节重新随机；第二关自身 120 秒后规划永久四车道与大型恐龙追行，150 秒后启用独立 X 路障候选。
- 切换时先进入 `PREPARING`，一次性准备新场景与资源，完成后有焦点才开始行驶；失焦时进入暂停。第二关使用小恐龙、戈壁景物和对应音效，关闭炮击调度。
- 第一关通关不写排行榜。第二关死亡或主动结束时，只结算第二关从零开始的距离、时间及统计，不合并第一关成绩。普通入口返回首页或重开从第一关开始；首页勾选直达第二关时按该调试选项开局。

### 有效时间与阶段

下表按当前关从零开始的有效运行时间计算，切关全部重置；暂停、答题、被抓、死亡及通关驶离动画不计时。`activeSeconds` 和 `levelSeconds` 在第二关均从零开始。

| 时间 | 生效内容 |
| --- | --- |
| 每满 1 分钟 | 投放白马；正常情况下第一关在 1:00、2:00 各一次，无可用位置时顺延；3:00 通关时清空事件 |
| 每满 45 秒 | 切换季节，前 10 秒逐渐过渡；第二关荒原基础配色保持不变 |
| 每满 75 秒 | 两关均投放警车；按当前关时间对齐固定周期，切关从零计时 |
| 第一关 2:00 | 解锁天降炮击检查，触发概率 40% |
| 各关 2:30 | 启用前方至少 240 米后的独立 X 路障候选；第一关炮击检查间隔缩短为 5–10 秒 |
| 完成收窄后 | 危险车比例从 15% 提高到 25%，随机变道概率增加 25 个百分点，检查间隔从 6–10 秒缩短到 4–7 秒；完成时刻取决于行驶速度 |
| 第二关 3:00 | 没有额外独立阶段；白马与车流增长继续按各自周期生效 |
| 第一关 2:55 | 顶部开始最后 5 秒通关倒计时，正常危险与碰撞仍生效 |
| 第一关满 3:00 | 固定镜头、清空车流，玩家模型自行驶离 3 秒后显示通关界面 |
| 4:30 | 普通系统车生成净距缩减至初始值的 65% 下限 |
| 6:00 | 普通车流容量增至 160 辆上限 |
| 第二关满 2 分钟 | 规划前方至少 60 米后开始、长度 400 米的永久四车道收窄；停止新增横穿小恐龙，再等待 4–8 秒开始首次大型恐龙追行候选，概率 70% |

车流容量每 15 秒增加 3 辆（88 起、160 封顶），生成净距每档缩短初始值的 2%；第一关炮弹爆炸区域边长从 2:00 的 6 米开始每 30 秒乘以 1.2，2:30 为 7.2 米、3:00 达到通关时限；炮弹尺寸按生成时刻固定。警车按每 75 秒的固定周期投放，天气、奶牛及缓行采用独立随机检查间隔，不存在到 3:00 才统一启动的门槛。

## 两关概率

概率指每次到达随机检查时刻后是否实际触发；检查间隔和事件持续时间沿用现有规则。未触发也重新等待下一次检查，不在下一帧立即重试。

| 项目 | 第一关 | 第二关 | 检查节奏 |
| --- | ---: | ---: | --- |
| 主路天气 | 40% | 80% | 首次 12–25 秒，后续 31–45 秒，任意连续 60 秒内最多两场 |
| 副路天气 | 80% | 100% | 进入副路 0.5 秒后首次检查，天气结束或未触发后等待 3–7 秒，不受主路场次限制 |
| 天降炮弹 | 40% | 不启用 | 第一关 120 秒解锁、150 秒后加密；进入第二关清空炮弹与弹坑并停止调度 |

第二关仍用已有浓雾、雷雨、横风、冰雪机制，主路天气类型沿用当前关有效时间的季节轮换，副路跨季节随机。荒原基础配色不随四季变回第一关的树林湖岸；第二关只保留稀疏绿洲湖泊；雨雪只影响当前天气表现。第二关不再使用炮击及爆炸区域成长规则。

关卡概率通过当前关配置读取，不能永久改写共享默认配置而污染下一局。URL 测试参数仍可覆盖对应概率，去掉参数并重开后恢复所在关默认值。

# 实施顺序与验收

## 开发顺序

实现按下面顺序组织，每阶段先形成可以在浏览器中观察的结果，再增加下一层内容。初版不依赖物理引擎；车辆运动和等级规则采用自有逻辑，Three.js 负责显示。运行入口与当前模块见[实现说明](../implementation/README.md)。

| 阶段 | 交付范围 | 完成条件 |
| --- | --- | --- |
| 1：本机入口与基础体验 | 本机页面、Three.js 场景、六车道直道、自行车、固定纵向视角、左右箭头/下箭头/空格、暂停与主动结束 | 浏览器可以启动；下箭头按住刹车、松开缓慢自动提速至上限；暂停后道路和计分冻结；按钮能结束；方向键无粘键 |
| 2：车辆与相对运动 | 五类车辆模型、尺寸、NPC 同向基础速度区间、对向 1.44 倍速度区间、同向/对向交通、玩家各车型独立速度上限 | 玩家最高速度为 90/110/125/125/125；刹车最低到零；换车型超过新上限自动降速；所有同向车道均允许后方生成，右侧提示接近后车 |
| 3：核心玩法 | 连续碰撞、首次接触面分类、系统车二次接触、同向与对向统一规则、整数成长、死亡动画与单次结算 | 侧面接触且重叠足够可吞吃，端面中央撞击按追尾，擦角与已有重叠只分离；系统车二次接触分离减速回正；同向与对向接触规则一致；高速不穿透 |
| 4：道路规划与循环 | 种子、直道/弯道、玩家自动跟弯、全车道活动、两种四/六车道切换、道路刮擦/实体墙、对象池、系统跟车/随机变道/超车/并道 | 不按左右键也沿弯道前进；渐进收窄刮擦纠偏；突然截止撞墙死亡；系统变道先打灯预告、平滑横移且只检查其他系统车辆；跨环首无跳变；对象数不持续增长 |
| 5：四季与场景 | 春夏秋冬模板、随机起始季节、120 秒轮换、上下坡地形、稀疏楼房/农场/牧场/奶牛/湖泊、固定一套粒子与阴影效果 | 每局起始季节随机；有效游戏时间每两分钟换季；暂停冻结、刹停继续；坡道车辆贴地、循环首尾高度连续；复杂景物低概率出现；随机天气影响视野、横移和速度，日常景物保持安全视野 |
| 6：记录与收尾 | 距离分数、完整结算、localStorage、本机排行榜、异常提示和异常存档重置入口 | 刷新保留排行榜；损坏/禁用存储时仍能玩；损坏存档可经确认重置并恢复保存；死亡动画不增加分数 |
| 7：成长与饥饿 | 单一总积分、车型门槛、伤害与饥饿扣分、降级保护、自行车负分 | 吞吃及伤害汇总后按总分确定车型，不清空；每 10 秒自动扣分，吃车重置，暂停冻结；任何降级保护两秒，低于 −2 死亡，距离和时间锁在事件时刻 |

道路阶段依赖已稳定的车辆尺寸与速度，否则收窄和生成安全距离无法定案；场景阶段依赖道路对象池；持久化阶段依赖结算事件和版本化数据字段。为定位规则问题，复杂环境与强粒子效果安排在核心碰撞之后。

车辆与核心玩法阶段共同落实守车道、宽车道和较大前后净距约束，校验吞吃后下一等级车身的空间。升级不增加无敌；已有重叠沿道路横向分离，不自动吞吃或判成追尾，积分扣分降级统一保护两秒。

## 模块职责

| 模块 | 职责与边界 |
| --- | --- |
| 配置 | 车型、尺寸、速度、碰撞阈值、曲率、季节和规则版本，统一数值来源 |
| 游戏流程 | 状态切换、暂停、死亡、结算，保证每局只结束一次 |
| 输入 | 焦点、方向键状态、下箭头刹车、失焦清理 |
| 玩家 | 当前级别、实际速度、松键自动提速、自动跟弯、横向位置、加减速、侧移与道路纠偏、进度、最高等级 |
| 道路规划 | 种子生成、弧长查找、分段组合、渐进/截止类型、实体墙、宽度与环首校验 |
| 交通 | NPC 相对运动、前后方安全生成与接近提示、生成权重、系统间跟车/超车/并道、侧移和回收；驾驶决策不计玩家 |
| 碰撞与成长 | 首次侧面接触、足够纵向重叠、端面中央和擦角分离、系统车二次接触、车辆/边沿/实体墙规则、事件顺序和整数进度 |
| 场景表现 | Three.js 模型、相机、随机初始季节与 120 秒时间循环、吞吃与死亡动画、对象池 |
| 计分与记录 | 距离积分、结束数据、排名、版本迁移、存储异常与项目键重置 |
| 界面 | HUD、暂停遮罩、结算、历史记录、存储提示与异常存档重置确认 |

逻辑使用道路距离与横向偏移，渲染将逻辑数据映射为相对玩家的 Three.js 坐标。模型动画、粒子和相机震动不能反过来修改碰撞体或路程。固定逻辑步与显示插值分离，暂停仅保留 UI 操作，死亡时仅保留必要表现。

## 浏览器验收清单

以下是后续实现的人工体验验收场景，不要求在文档阶段生成自动化测试：

- 空格按住不会连续开始/暂停；按住下箭头减速至零；松开后自动缓慢起步并提速至上限；失焦再回来保持暂停且无残留按键。
- 吞吃每辆车回气半管，同方向持续侧移超过 0.4 秒时吞吃回气翻倍；同刻伤害导致降级或死亡不回气。气量封顶两管，满级吞吃仍可回气。
- 按住上箭头消耗连续气量，松开保留余量；每管喷气 3.5 秒、满两管可连续喷气 7 秒，停喷后用 0.35 秒回落，暂停冻结、刹车及刮擦时不耗气；低速按实际喷气时长提速，不因点按叠加倍率。
- 调试选项只保存在页面内存，刷新关闭；调试死亡动画结束后保留本局、恢复当前车型门槛积分并保护两秒，失焦保持暂停，调试局主动结束也不写排行榜。
- 按上箭头不改变游戏状态或触发浏览器默认动作；焦点落到页面本身后左右和空格仍有效，编辑区域与浏览器快捷键不被游戏抢占。
- 自行车开局总分 1，吃一辆同级车到 2 升三轮车；三轮车总分 2，吃四辆自行车到 6 升小汽车。三轮车有三只车轮并在两侧车流出现，基础巡航 55–85 km/h；三级交通统一使用小汽车模型；左右后视镜清楚可见，无竖立排气管。
- 交通车各有六种配色，模型和颜色在生成后保持固定；回收及吞吃动画不串色、不替换外观，玩家配色保持一致。
- 同向 NPC 保持基础车型速度区间，对向 NPC 巡航范围为基础区间的 144%；玩家上限为 90／110／125／125／125 km/h。小汽车以 125 km/h 升为卡车保持速度，降为三轮车限制到 110；低于新上限时不凭空加速，车型切换不触发碰撞惩罚，速度条按当前车型正常上限显示。
- NPC 生成后固定巡航，保留安全随机变道；仅临近系统碰撞时闪灯换道，追加前期 15%、后期 25% 不检查空隙的危险车辆；进入后期永久四车道后随机变道概率增至 45%–70%、检查间隔缩至 4–7 秒；系统接触按等级撞毁低级车或同级弹开。
- NPC 的系统跟车/变道决策排除玩家，玩家占据候选空隙时也不触发 NPC 避让；实际接触仍按玩家碰撞规则处理，不能只因 NPC 发起变道就免除碰撞。
- NPC 变道先打灯至少一秒，再平滑横移约 1.5 秒；预告中其他系统车辆使空隙不安全时延后/取消，暂停冻结预告与变道计时。
- 暂停遮罩挡住游戏，空格继续，点击“结束游戏”只结算一次；结算界面空格直接开始新局，按钮获得焦点时也能使用，按住不重复触发；返回待机后空格同样开始新局。
- 车型门槛及吞吃价值为 1／2／6／18／54，开局总分 1。吃一辆自行车到 2 成为三轮车；卡车总分 18 吃六辆小汽车到 54 成为坦克。吞吃和积分扣减引起的升降级保留积分，防御耗尽则设为低一级门槛，总分封顶 54，满级吞吃仍计数量及重置饥饿计时；一次汇总可跨多个门槛，界面只显示车型及总分／门槛。
- 前方两侧新车及缓行车队以低一级 60%、更低级 10%、同级 20%、高级 10% 为基础；三轮车前方自行车 70%，坦克前方卡车 70%，自行车前方同级 90%。距离增长只提高前方高级比例至 15%，不减少吞吃目标；后方保持原有同级 60%、高级 30%、低级 10%。普通补车失败后重选位置、开放车道及车型再尝试一次，成功即停止；运行中新车在前方 160–240 米生成，换级后后续投放采用新等级，已出现的车辆规格与外观保持固定，场内容量从 88 辆起，每 15 秒有效运行时间增加 3 辆，最多 160 辆；普通系统车距每档缩短初始值的 2%，最低保留 65%，生成与安全并道同步采用。暂停冻结，降级不重置，新局恢复；玩家四秒生成接近时间及缓行同队短净距不缩短。
- 侧面接触且纵向重叠达到较短车长的 10% 算侧碰；双方端面中央 60% 宽度区域的横向投影重叠才算追尾。斜向同时接触侧面和端面优先侧面候选，重叠不足算擦角；轻微擦角及已有穿透只横向分离。
- 追尾高级死亡；同级追尾扣低一级价值、速度减半并移除目标，低于当前门槛才降级保护两秒；低级追尾只撞飞，不影响积分与速度。自行车追尾同级自行车直接死亡，不使用负分缓冲。
- 有效侧碰低级车吞吃，自行车可吞吃同级自行车，其他同级侧碰各按自身车宽两倍惯性弹开，再缓慢收尾；玩家 1.5 秒内不能左右控制；侧碰高级车死亡；车头侧面和车尾侧面使用同一规则。
- 被撞偏移的系统车接触其他系统车时只横向分离、平铺继续运行，不额外减速或纵向挪动、不应用玩家等级规则；再次碰到玩家则正常执行玩家规则。
- 连续 10 秒未吞吃按当前车型扣 1／1／2／6／18，暂停冻结、零速继续；自行车开局 1，10／20／30 秒到 0／−1／−2，40 秒死亡。负分吞吃直接累加；射弹按车型消耗独立防御，耗尽后积分固定到低一级门槛并换车，换车型补满防御；自行车耗尽直接死亡，降级均保护两秒。
- 饥饿到期与接触同序处理，同刻有效吞吃取消扣分，无吞吃时伤害与饥饿照常汇总扣分；新局清空计时及负分，死亡按到期时刻锁定距离与有效时间。
- 射击只允许前方生成且当前仍在玩家前方的系统车，后方生成的车超越后仍不带武器，前方有武器的车平齐或落后时不再开火。
- 多辆同时接触时致命规则优先；同车不会重复奖励；目标先退出碰撞再升级，正常交通布局为扩大车身留足空间，不依赖无敌或自动推开车辆。
- 满级不能继续升，追尾同级坦克降为卡车、减速并短暂保护；更宽车身在所有可通行路线中留得下。
- 玩家可进入左侧且朝向不变，同向与对向使用相同首次接触面、阈值、总积分和保护规则。低级侧碰吞吃，自行车可吞吃同级自行车，其他同级侧碰弹开；自行车同级端面接触死亡，其他同级端面接触扣分及减速，低级追尾只撞飞，高级明确接触死亡。
- 所有同向车道均有后方车流，包括本车道；开局覆盖后方 120–240 米，运行中在 120–200 米补车，超过 260 米回收。玩家刹车后可能被追上并按统一规则碰撞，后车巡航目标不重抽、不避让玩家、始终不带武器；右侧接近提示与道路提示同时显示，暂停及结束隐藏。
- 四/六车道切换能提前辨认，渐进收窄刮擦逐渐减速并纠偏，突然截止撞墙死亡，不被边界限制自动绕开。
- 每轮有 18–24 段缓弯，弯道占比通常约 58%；地面和路肩不覆盖路面，上下坡远处没有叠面横纹；标题不显示闪烁文本光标，一级自行车使用宽油箱与粗轮胎的摩托车造型，碰撞宽度约 1.346 米；树木混合簇状阔叶树冠与分层松树。
- 普通弯道上松开左右键仍保持相对道路的横向偏移并自动跟弯；左右键只横移，不产生自然离心漂移，自动跟弯不能绕过截止墙。
- 关闭车道存在可达并道空间，正常同向道路保留生路；弯道入口/出口与环首无几何跳变。
- 上下坡高度与俯仰连续；玩家、交通、标线、路肩和景物贴合地形；道路环首高度为零且无跳变；坡道不额外改变速度上限。
- 坑洞与泥洞稀疏出现并贴合坡道；车轮或履带踩中才触发，高速经过不漏判。坑洞当前速度减半、弹跳并偏向邻道，最右侧只向左，最左侧只向右，横移仍检测碰撞；泥洞减速、挂泥和半速上限保持 8 秒，暂停冻结、升级仍限速、结束后清除；停在同一洞上不反复触发，下一轮可再次触发。
- 楼房、农场和牧场以 18% 候选概率在道路随机一侧出现，奶牛每处两到三头，湖泊以 8% 候选概率且仅在平缓地形出现；对象与实例容量不随长距离运行增长。
- 覆盖完整四季和至少两轮道路循环；检查随机起始季节、120/240/360 秒节点、暂停冻结和刹停继续计时，观察冬春过渡、刷新交通、对象池数量及距离连续性。
- 距离与真实速度一致，刹停/暂停不计分，死亡接触后和死亡动画期间不计分。
- 固定本机地址刷新后读取已完成成绩；禁用存储、损坏 JSON、未知版本、配额失败均不阻止游戏。
- 异常存档重置入口只在待机/结算提供，明确确认后只删除本游戏键；保存恢复后清除提示，重置失败保持内存模式。

## 首版优先处理的风险

| 风险 | 设计处理 |
| --- | --- |
| 自行车侧碰难以准确操作 | 增大车身、连续横移、速度控制；整段侧面可吞吃，使用首次接触面与纵向重叠判断侧碰 |
| 边角轻触被误计吞吃 | 侧面要求足够重叠，端面中央才按追尾；边角轻触及初始穿透只横向分离，不吞吃或降级 |
| 收窄时车辆被堵成必死局 | 长预警、关闭车道抑制生成、NPC 提前并道、按玩家宽度检查可达同向通路 |
| 突然截止被纠偏机制绕过 | 实体墙优先检测，渐进道路纠偏不提供绕墙保护 |
| 正常交通布局没有覆盖升级空间 | 宽车道、稳定车流守车道、系统间较大净距，同时检查吞吃位置的下一车型尺寸；NPC 变道不避让玩家，不额外增加升级保护 |
| 系统变道把玩家当作障碍而偏离约定 | 跟车与变道决策仅使用系统车辆；实际玩家接触交由独立碰撞规则处理 |
| 系统车被撞后互相穿透 | 系统间二次接触单独分离、减速与回正，不套用玩家等级规则 |
| 损坏存档后无法恢复保存 | 第一版提供异常存档重置确认入口，仅重置本项目键并捕获删除/写入异常 |
| 季节或速度被道路环首重置 | 季节仅按有效游戏时间每 120 秒轮换；自动提速遵守刹车、刮擦与车型有效上限，不按道路环首重置 |
| 循环接缝或长距离运行抖动 | 首尾连续校验、独立累计距离、局部渲染原点与有限对象池 |
| 场景效果降低辨识度 | 道路高对比，日常雾与装饰保留安全视距；春雾允许主动缩短视野，雷击与冰区提前显示落点 |
| 本机记录因地址变化不可见 | 固定 HTTP 来源、版本化命名键、明确当前浏览器存档范围 |

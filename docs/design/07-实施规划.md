## 开发顺序

车辆运动与规则使用自有逻辑，Three.js 负责显示；模块见[实现说明](../implementation/README.md)。

| 阶段 | 交付范围 | 完成条件 |
| --- | --- | --- |
| 1：本机入口与基础体验 | 本机页面、Three.js 场景、六车道直道、自行车、固定纵向视角、左右箭头/下箭头/空格、暂停与主动结束 | 浏览器可以启动；下箭头按住刹车、松开缓慢自动提速至上限；暂停后道路和计分冻结；按钮能结束；方向键无粘键 |
| 2：车辆与相对运动 | 五类车辆模型、尺寸、NPC 同向基础速度区间、对向 1.44 倍速度区间、同向/对向交通、玩家各车型独立速度上限 | 玩家最高速度为 90/110/125/125/125；刹车最低到零；换车型超过新上限自动降速；所有同向车道均允许后方生成，右侧提示接近后车 |
| 3：核心玩法 | 连续碰撞、首次接触面分类、系统车二次接触、同向与对向统一规则、整数成长、死亡动画与单次结算 | 侧面接触且重叠足够可吞吃，端面中央撞击按追尾，擦角与已有重叠只分离；系统车接触按等级撞毁低级车或同级惯性弹开；同向与对向接触规则一致；高速不穿透 |
| 4：道路规划与循环 | 种子、直道/弯道、玩家自动跟弯、全车道活动、两种四/六车道切换、道路刮擦/实体墙、对象池、固定巡航/临近避让/随机变道 | 不按左右键也沿弯道前进；渐进收窄刮擦纠偏；突然截止撞墙死亡；系统变道先打灯预告、平滑横移且只检查其他系统车辆；跨环首无跳变；对象数不持续增长 |
| 5：四季与场景 | 春夏秋冬模板、随机起始季节、120 秒轮换、上下坡地形、稀疏楼房/农场/牧场/奶牛/湖泊、固定一套粒子与阴影效果 | 每局起始季节随机；有效游戏时间每两分钟换季；暂停冻结、刹停继续；坡道车辆贴地、循环首尾高度连续；复杂景物低概率出现；随机天气影响视野、横移和速度，日常景物保持安全视野 |
| 6：记录与收尾 | 距离分数、完整结算、localStorage、本机排行榜、异常提示和异常存档重置入口 | 刷新保留排行榜；损坏/禁用存储时仍能玩；损坏存档可经确认重置并恢复保存；死亡动画不增加分数 |
| 7：成长与饥饿 | 单一总积分、车型门槛、伤害与饥饿扣分、降级保护、自行车负分 | 吞吃及接触扣分按总分换级；远程伤害耗尽防御则固定下级门槛；每 10 秒自动扣分，吃车重置，暂停冻结；任何降级保护两秒，低于 −2 死亡，距离和时间锁在事件时刻 |

## 模块职责

模块分工以[实现结构](../implementation/README.md#模块职责)为准；配置统一数值，游戏层组织事件，渲染不得反向修改业务状态。

逻辑使用路线坐标，渲染映射到玩家附近的局部坐标；动画不得改变碰撞体或路程。暂停冻结逻辑，死亡仅保留表现。

## 浏览器验收清单

以下为人工体验验收场景，不要求文档阶段生成自动化测试：

- 空格按住不会连续开始/暂停；按住下箭头减速至零，松开后自动缓慢起步并提速至上限；失焦再回来保持暂停且无残留按键。
- 吞吃回气每级补充半管，同方向持续侧移超过 0.4 秒时翻倍；同刻伤害导致降级或死亡不回气，气量封顶两管，满级吞吃仍可回气。
- 最高速松开后再按上箭头消耗连续气量，松开保留余量；每管喷气 3.5 秒、满两管可连续喷气 7 秒，停喷后 0.35 秒回落；暂停冻结、刹车及刮擦时不耗气；喷气按实际时长额外提速，不因点按叠加倍率。未到最高速按住上键普通加速，停按后再按且已在最高速才消耗氮气。
- 调试选项只存页面内存，刷新关闭；调试死亡动画结束后保留本局、恢复当前车型门槛积分并保护两秒，失焦保持暂停，调试局主动结束也不写排行榜。
- 页面焦点下方向键与空格仍有效，无默认滚动；编辑区域和浏览器快捷键不接管。
- 车型门槛及吞吃价值为 1／2／6／18／54，开局总分 1。自行车吃一辆同级车到 2 升三轮车；卡车总分 18 吃六辆小汽车到 54 成为坦克。三轮车有三只车轮并在两侧车流出现，基础巡航 55–85 km/h；三级交通统一使用小汽车模型；左右后视镜清楚可见，无竖立排气管。
- 吞吃和积分扣减引起的升降级保留积分，防御耗尽则设为低一级门槛，总分封顶 54，满级吞吃仍计数量及重置饥饿计时；一次汇总可跨多个门槛，成长仪表显示车型及总分／门槛，防御另显示百分比。
- 车型和颜色生成后固定，回收及动画不串色；玩家换级沿用所选颜色。
- 同向 NPC 保持基础车型速度区间，对向为其 144%。小汽车以 125 km/h 升为卡车保持速度，降为三轮车限制到 110；低于新上限不凭空加速，车型切换不触发碰撞惩罚，速度条按当前车型正常上限显示。
- NPC 生成后固定巡航，保留安全随机变道；仅临近系统碰撞时闪灯换道，追加前期 15%、后期 25% 不检查空隙的危险车辆；进入后期永久四车道后随机变道概率增至 55%–80%、检查间隔缩至 4–7 秒；系统接触按等级撞毁低级车或同级弹开。
- 玩家占据候选空隙也不触发 NPC 避让；实际接触仍按玩家碰撞规则处理，不因 NPC 发起变道免除碰撞。
- NPC 变道先打灯至少一秒，再平滑横移约 1.5 秒；预告中其他系统车辆使空隙不安全时延后/取消，暂停冻结预告与变道计时。
- 暂停遮罩拦截画布，空格继续；结束只结算一次。待机和结算空格开局，按钮焦点及长按不改变规则。
- 前方两侧新车及缓行车队以低一级 60%、更低级 10%、同级 20%、高级 10% 为基础；三轮车前方自行车 70%，坦克前方卡车 70%，自行车前方同级 90%。距离增长只提高前方高级比例至 15%，不减少吞吃目标；后方保持原有同级 60%、高级 30%、低级 10%。普通补车失败后重选位置、车道及车型再试一次，成功即停止；运行中新车在前方 160–240 米生成，升级至三轮车或小汽车立即在当前路线前方 80–150 米补同级和低一级各五辆；普通后续投放采用新等级，既有车辆规格与外观固定，场内容量从 88 辆起，每 15 秒有效运行时间增加 3 辆，最多 160 辆；普通系统车距每档缩短初始值的 2%，最低保留 65%，仅生成净距采用，安全并道仍使用独立预测窗口。暂停冻结，降级不重置，新局恢复；玩家四秒生成接近时间及缓行同队短净距不缩短。
- 侧面接触且纵向重叠达到较短车长的 10% 算侧碰；双方端面中央 60% 宽度区域的横向投影重叠才算追尾。斜向同时接触侧面和端面优先侧面候选，重叠不足算擦角；轻微擦角及已有穿透只横向分离。
- 追尾高级死亡；同级追尾扣低一级价值并将剩余积分限制在当前门槛以下，速度减半、移除目标并立即降级保护两秒；低级追尾只撞飞，不影响积分与速度。自行车追尾同级自行车直接死亡，不使用负分缓冲。
- 有效侧碰低级车吞吃，自行车可吞吃同级自行车，其他同级侧碰各按自身车宽两倍惯性弹开再缓慢收尾，玩家 1.5 秒内不能左右控制；侧碰高级车死亡，车头侧面和车尾侧面同一规则。
- 被撞偏移的系统车再接触其他系统车，仍按系统等级规则撞毁低级车或同级弹开；再碰玩家则按玩家规则处理。
- 连续 10 秒未吞吃按当前车型扣 1／1／2／6／18，暂停冻结、零速继续；自行车开局 1，10／20／30 秒到 0／−1／−2，40 秒死亡。负分吞吃直接累加；闪电等远程伤害按车型消耗独立防御，耗尽后积分固定到低一级门槛并换车，换车型补满防御；自行车耗尽直接死亡，降级均保护两秒。
- 饥饿到期与接触同序处理，同刻有效吞吃取消扣分，无吞吃时先结算闪电伤害与换级，再按当前车型扣饥饿积分；炮弹在逻辑步末独立处理；新局清空计时及负分，死亡按到期时刻锁定距离与有效时间。
- 多辆同时接触时致命规则优先，同车不重复奖励；目标先退出碰撞再升级，交通布局为扩大车身留足空间，不依赖无敌或自动推开车辆。
- 满级同级追尾仍降级；各车型在可通行路线中留得下。
- 玩家可进入左侧且朝向不变，同向与对向使用相同首次接触面、阈值、总积分和保护规则；自行车同级端面接触死亡，其他同级端面接触扣分及减速。
- 所有同向车道均有后方车流，包括本车道；开局覆盖后方 120–240 米，运行中在 120–200 米补车，超过 260 米回收。玩家刹车后可能被追上并按统一规则碰撞，后车巡航目标不重抽、不避让玩家、始终不带武器；右侧接近提示与场景路标同时显示，暂停及结束隐藏。
- 四/六车道切换能提前辨认；渐进收窄刮擦逐渐减速并纠偏，突然截止撞墙死亡，不被边界限制自动绕开，自动跟弯不能绕过截止墙；松开左右键仍保持相对道路的横向偏移并自动跟弯，左右键只横移、不产生自然离心漂移。关闭车道存在可达并道空间，正常同向道路保留生路；弯道入口/出口与环首无几何跳变。
- 每轮有 18–24 段缓弯，弯道占比通常约 58%；地面和路肩不覆盖路面，上下坡远处无叠面横纹；标题不显示闪烁文本光标，一级自行车用宽油箱与粗轮胎的摩托车造型，碰撞宽度约 1.346 米；树木混合簇状阔叶树冠与分层松树。
- 上下坡高度与俯仰连续，玩家、交通、标线、路肩和景物贴合地形；道路环首高度为零且无跳变，坡道不额外改变速度上限。
- 坑洞与泥洞稀疏出现并贴合坡道，车轮或履带踩中才触发，高速经过不漏判。坑洞当前速度减半、弹跳并偏向邻道，最右侧只向左，最左侧只向右，横移仍检测碰撞；泥洞减速、挂泥和半速上限保持 8 秒，暂停冻结、升级仍限速、结束后清除；停在同一洞上不反复触发，下一轮可再次触发。
- 楼房、农场和牧场以 18% 候选概率在道路随机一侧出现，奶牛每处两到三头，湖泊以 8% 候选概率且仅在平缓地形出现；对象与实例容量不随长距离运行增长。
- 覆盖四季与两轮道路：检查120秒换季、暂停冻结、刹停计时、冬春过渡，以及车流、对象数和累计距离。
- 距离与真实速度一致，刹停/暂停不计分，死亡接触后和死亡动画期间不计分。
- 固定本机地址刷新后读取已完成成绩；禁用存储、损坏 JSON、未知版本、配额失败均不阻止游戏；已知旧规则重建排行榜后恢复写入。
- 异常存档重置入口只在待机/结算提供，明确确认后只删除本游戏键；保存恢复后清除提示，重置失败保持内存模式。

## 关键风险

| 风险 | 处理边界 |
| --- | --- |
| 擦角误吞吃或已有穿透误追尾 | 首次接触面、侧面重叠与端面中央联合分类；已有穿透只分离 |
| 收窄、施工和升级造成无路可走 | 提前预警、合法车道投放及车身空间校验；实体墙不能被纠偏绕过，NPC 不避让玩家 |
| 系统车连锁接触失效 | 独立连续检测，按等级撞毁或同级弹开，不增加玩家收益 |
| 循环或长跑重置状态、增长资源 | 距离与有效时间独立累计，首尾连续、局部原点、有限对象池 |
| 场景妨碍辨识 | 日常保留安全视距，春雾允许短时遮蔽，雷击与冰区提前预警 |
| 存档不可读或来源变化 | 固定 HTTP 来源，版本校验，异常重置只操作本游戏键 |

音效规则见[音效系统](12-音效系统.md)；移动触控、回放和存档导入导出不阻塞当前玩法。

# 实施顺序与验收

[返回总览](../README.md)

## 开发顺序

本阶段只建立设计文档。实现按下面顺序推进，每阶段先形成可以在浏览器中观察的结果，再增加下一层内容。初版不依赖物理引擎；车辆运动和等级规则采用自有逻辑，Three.js 负责显示。

| 阶段 | 交付范围 | 完成条件 |
| --- | --- | --- |
| 1：本机入口与基础体验 | 本机页面、Three.js 场景、六车道直道、自行车、固定纵向视角、左右键/Z/X/空格、暂停与主动结束 | 浏览器可以启动；暂停后道路和计分冻结；按钮能结束；方向与踏板无粘键 |
| 2：车辆与相对运动 | 六类车辆模型、尺寸、NPC 巡航、同向/对向交通、玩家独立速度 | 同向速度不同会形成追赶/远离；对向迎面通过；刹车停车不再增加距离 |
| 3：核心玩法 | 连续碰撞、尾侧分类、等级矩阵、整数成长、死亡动画与单次结算 | 同级三辆升级；前侧不可吞吃；降级/减速/死亡按矩阵执行；高速不穿透 |
| 4：道路规划与循环 | 种子、直道/弯道、四/六车道切换、对象池、安全车流 | 弯道车辆跟随；缩路有预警与可达空位；跨环首无跳变；长时间对象数不持续增长 |
| 5：四季与场景 | 春夏秋冬模板、距离过渡、粒子、简化效果 | 四季清晰可辨；冬春接缝自然；季节效果不挡住安全视野 |
| 6：记录与收尾 | 距离分数、完整结算、localStorage、最近记录、排行榜和异常提示 | 刷新保留已完成成绩；损坏/禁用存储时仍能玩；死亡动画不增加分数 |

道路阶段依赖已稳定的车辆尺寸与速度，否则收窄和生成安全距离无法定案；场景阶段依赖道路对象池；持久化阶段依赖结算事件和版本化数据字段。为定位规则问题，复杂环境与强粒子效果安排在核心碰撞之后。

## 模块职责

| 模块 | 职责与边界 |
| --- | --- |
| 配置 | 车型、尺寸、速度、碰撞阈值、曲率、季节和规则版本，统一数值来源 |
| 游戏流程 | 状态切换、暂停、死亡、结算，保证每局只结束一次 |
| 输入 | 焦点、按键状态、踏板优先级、失焦清理 |
| 玩家 | 当前级别、实际速度、横向位置、进度、最高等级 |
| 道路规划 | 种子生成、弧长查找、分段组合、宽度与环首校验 |
| 交通 | NPC 相对运动、生成权重、时间距、缩路并道和回收 |
| 碰撞与成长 | 首次接触、后半部分类、规则矩阵、事件顺序和整数进度 |
| 场景表现 | Three.js 模型、相机、四季、吞吃与死亡动画、对象池 |
| 计分与记录 | 距离积分、结束数据、排名、版本迁移和存储异常 |
| 界面 | HUD、暂停遮罩、结算、历史记录、存储提示 |

逻辑使用道路距离与横向偏移，渲染将逻辑数据映射为相对玩家的 Three.js 坐标。模型动画、粒子和相机震动不能反过来修改碰撞体或路程。固定逻辑步与显示插值分离，暂停仅保留 UI 操作，死亡时仅保留必要表现。

## 浏览器验收清单

以下是后续实现的人工体验验收场景，不要求在文档阶段生成自动化测试：

- 空格按住不会连续开始/暂停；Z/X 同时按下优先刹车；失焦再回来保持暂停且无残留按键。
- 暂停遮罩挡住游戏，空格继续，点击“结束游戏”只结算一次；回待机后空格开始新局。
- 自身后半部侧撞同级累计三辆升级，低一级九辆升级，混合进度正确，前半部侧擦不计吞吃。
- 直撞同级/高级死亡；直撞低一级降级并清空进度；直撞低两级及以下减速 50% 且无重复折半。
- 多辆同时接触时致命规则优先；同车不会重复奖励；升级变大后重叠按规则处理。
- 满级不能继续升，直撞同级坦克仍死亡；更宽车身在所有可通行路线中留得下。
- 同向更快车可从后接近并有提示，对向车沿左侧道路运动；NPC 不凭空出现在玩家附近。
- 四/六车道切换能提前辨认，关闭车道存在可达并道空间，弯道入口/出口与环首无几何跳变。
- 覆盖完整四季和至少两轮道路循环，观察冬春过渡、刷新交通、对象池数量及距离连续性。
- 距离与真实速度一致，刹停/暂停不计分，死亡接触后和死亡动画期间不计分。
- 固定本机地址刷新后读取已完成成绩；禁用存储、损坏 JSON、未知版本、配额失败均不阻止游戏。

## 首版优先处理的风险

| 风险 | 设计处理 |
| --- | --- |
| 自行车尾侧有效区短，难以准确操作 | 清晰尾部标记、连续横移、速度控制、连续碰撞；先观察可操作性再调横移速度 |
| 角点和前半部侧擦被误计吞吃 | 首次接触法线与位置同时满足才吞吃，其余归直撞 |
| 收窄时车辆被堵成必死局 | 长预警、关闭车道抑制生成、NPC 提前并道、按玩家宽度检查可达通路 |
| 升级后车身增大引起新增重叠 | 当次事件后立即更新尺寸，边界限制并重新检测剩余运动 |
| 循环接缝或长距离运行抖动 | 首尾连续校验、独立累计距离、局部渲染原点与有限对象池 |
| 场景效果降低辨识度 | 季节不改变规则，道路高对比，雾与装饰受安全视距限制 |
| 本机记录因地址变化不可见 | 固定 HTTP 来源、版本化命名键、明确当前浏览器存档范围 |

初版完成后再考虑音效细化、移动端触控、对向越线、回放和存档导入/导出；它们不阻塞当前核心玩法。

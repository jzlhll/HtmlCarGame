## 开发顺序

实现按下面顺序组织，每阶段先形成可以在浏览器中观察的结果，再增加下一层内容。初版不依赖物理引擎；车辆运动和等级规则采用自有逻辑，Three.js 负责显示。运行入口与当前模块见[实现说明](../implementation/README.md)。

| 阶段 | 交付范围 | 完成条件 |
| --- | --- | --- |
| 1：本机入口与基础体验 | 本机页面、Three.js 场景、六车道直道、自行车、固定纵向视角、左右箭头/下箭头/空格、暂停与主动结束 | 浏览器可以启动；下箭头按住刹车、松开缓慢自动提速至上限；暂停后道路和计分冻结；按钮能结束；方向键无粘键 |
| 2：车辆与相对运动 | 六类车辆模型、尺寸、NPC 同向原速度区间、对向八折速度区间、同向/对向交通、玩家各车型独立速度上限 | 玩家最高速度为 65/75/90/90/90/90；刹车到零；换车型超过新上限自动降速；当前车道禁止后方生成，其他车道允许 |
| 3：核心玩法 | 连续碰撞、侧碰车头位置分类、系统车二次接触、同向与对向统一规则、整数成长、死亡动画与单次结算 | 侧面接触时，我方车头超过对方车头或位于对方后半段可吞吃，其余按追尾；系统车二次接触分离减速回正；同向与对向接触规则一致；高速不穿透 |
| 4：道路规划与循环 | 种子、直道/弯道、玩家自动跟弯、全车道活动、两种四/六车道切换、道路刮擦/实体墙、对象池、系统跟车/超车/并道 | 不按左右键也沿弯道前进；渐进收窄刮擦纠偏；突然截止撞墙死亡；系统变道先打灯预告、平滑横移且只检查其他系统车辆；跨环首无跳变；对象数不持续增长 |
| 5：四季与场景 | 春夏秋冬模板、随机起始季节、120 秒轮换、上下坡地形、稀疏楼房/农场/牧场/奶牛/湖泊、固定一套粒子与阴影效果 | 每局起始季节随机；有效游戏时间每两分钟换季；暂停冻结、刹停继续；坡道车辆贴地、循环首尾高度连续；复杂景物低概率出现；不挡住安全视野 |
| 6：记录与收尾 | 距离分数、完整结算、localStorage、本机排行榜、异常提示和异常存档重置入口 | 刷新保留排行榜；损坏/禁用存储时仍能玩；损坏存档可经确认重置并恢复保存；死亡动画不增加分数 |

道路阶段依赖已稳定的车辆尺寸与速度，否则收窄和生成安全距离无法定案；场景阶段依赖道路对象池；持久化阶段依赖结算事件和版本化数据字段。为定位规则问题，复杂环境与强粒子效果安排在核心碰撞之后。

车辆与核心玩法阶段共同落实守车道、宽车道和较大前后净距约束，校验吞吃后下一等级车身的空间。升级采用正常尺寸更新，不加入额外无敌或自动分离规则。

## 模块职责

| 模块 | 职责与边界 |
| --- | --- |
| 配置 | 车型、尺寸、速度、碰撞阈值、曲率、季节和规则版本，统一数值来源 |
| 游戏流程 | 状态切换、暂停、死亡、结算，保证每局只结束一次 |
| 输入 | 焦点、方向键状态、下箭头刹车、失焦清理 |
| 玩家 | 当前级别、实际速度、松键自动提速、自动跟弯、横向位置、加减速、侧移与道路纠偏、进度、最高等级 |
| 道路规划 | 种子生成、弧长查找、分段组合、渐进/截止类型、实体墙、宽度与环首校验 |
| 交通 | NPC 相对运动、当前车道后方生成限制、生成权重、系统间跟车/超车/并道、侧移和回收；驾驶决策不计玩家 |
| 碰撞与成长 | 首次侧面接触、车头超前与目标后半段范围、系统车二次接触、车辆/边沿/实体墙规则、事件顺序和整数进度 |
| 场景表现 | Three.js 模型、相机、随机初始季节与 120 秒时间循环、吞吃与死亡动画、对象池 |
| 计分与记录 | 距离积分、结束数据、排名、版本迁移、存储异常与项目键重置 |
| 界面 | HUD、暂停遮罩、结算、历史记录、存储提示与异常存档重置确认 |

逻辑使用道路距离与横向偏移，渲染将逻辑数据映射为相对玩家的 Three.js 坐标。模型动画、粒子和相机震动不能反过来修改碰撞体或路程。固定逻辑步与显示插值分离，暂停仅保留 UI 操作，死亡时仅保留必要表现。

## 浏览器验收清单

以下是后续实现的人工体验验收场景，不要求在文档阶段生成自动化测试：

- 空格按住不会连续开始/暂停；按住下箭头减速至零；松开后自动缓慢起步并提速至上限；失焦再回来保持暂停且无残留按键。
- 按上箭头不改变游戏状态或触发浏览器默认动作；焦点落到页面本身后左右和空格仍有效，编辑区域与浏览器快捷键不被游戏抢占。
- 自行车吃两辆同级车升为三轮车，三轮车吃三辆同级车升为小汽车。三轮车有三只车轮并在两侧车流出现，基础巡航 50–70 km/h；三级交通的小汽车与拖拉机外观均可随机出现，等级、尺寸、速度、吞吃与回收行为一致。
- 交通车各有六种配色，模型和颜色在生成后保持固定；回收及吞吃动画不串色、不替换外观，玩家配色保持一致。
- 同向 NPC 保持基础车型速度区间，对向 NPC 巡航范围降为基础区间的 80%；玩家上限为 65／75／90／90／90／90 km/h。小汽车以 90 km/h 升为卡车保持速度，降为三轮车限制到 75；低于新上限时不凭空加速，车型切换不触发碰撞惩罚，速度条按当前车型正常上限显示。
- NPC 平时保持所属车道，前车较慢或车道关闭时提前减速、检查其他系统车辆后变道；无空位继续减速寻找时机，不采用先停车等待；车道宽于坦克，系统之间按车身边缘测量较大净距。
- NPC 的系统跟车/变道决策排除玩家，玩家占据候选空隙时也不触发 NPC 避让；实际接触仍按玩家碰撞规则处理，不能只因 NPC 发起变道就免除碰撞。
- NPC 变道先打灯至少一秒，再平滑横移约 1.5 秒；预告中其他系统车辆使空隙不安全时延后/取消，暂停冻结预告与变道计时。
- 暂停遮罩挡住游戏，空格继续，点击“结束游戏”只结算一次；结算界面空格直接开始新局，按钮获得焦点时也能使用，按住不重复触发；返回待机后空格同样开始新局。
- 吞吃固定积分为 1／2／6／18／54／216，升级门槛为 2／6／18／54／216。自行车吃两辆同级车升三轮车，三轮车吃三辆同级车升小汽车，加长卡车吃四辆同级车升坦克；小汽车吃两辆自行车与两辆三轮车后显示 `6 / 18 分`，混合积分精确保留，升级扣除门槛，降级清空，满级停止累积。
- 两侧新车均按当前玩家等级分配基础同级 60%、高级 30%、低级 10% 的候选权重，处理一级和满级缺失组；运行中新车在前方 200–240 米生成，换级后后续投放采用新等级，已出现的车辆规格与外观保持固定，系统净距与接近时间约束继续生效。
- 侧面接触时，我方车头超过对方车头或位于对方后半段算侧碰；位于对方前半段且未超过其车头时算追尾。纯纵向端面接触算追尾；斜向同时接触侧面和端面时按车头位置判断。
- 追尾同级/高级死亡；追尾低一级降级并清空当前进度；追尾低两级及以下减速 50% 且无重复折半，上限恢复后继续缓慢自动提速。
- 有效侧碰同级或低级车吞吃，侧碰高级车死亡；车头侧面和车尾侧面使用同一规则。
- 被撞偏移的系统车接触其他系统车时分离、减速并回正，不穿透、不应用玩家等级规则；再次碰到玩家则正常执行玩家规则。
- 多辆同时接触时致命规则优先；同车不会重复奖励；目标先退出碰撞再升级，正常交通布局为扩大车身留足空间，不依赖无敌或自动推开车辆。
- 满级不能继续升，追尾同级坦克仍死亡；更宽车身在所有可通行路线中留得下。
- 玩家可以越线进入左侧，朝向不变；同向与对向采用相同的车头位置条件和等级规则。对向同级或低级车可侧碰吞吃；对向同级追尾仍死亡，对向低一级追尾降级，低两级及以下追尾减速。
- 玩家当前车道不从后方生成车辆，其他车道可以；变道不删除既有车辆，NPC 不把玩家纳入跟车避让，近处不凭空生成。
- 四/六车道切换能提前辨认，渐进收窄刮擦逐渐减速并纠偏，突然截止撞墙死亡，不被边界限制自动绕开。
- 每轮有 18 段缓弯，弯道占比约 47%–54%；地面和路肩不覆盖路面，上下坡远处没有叠面横纹；标题不显示闪烁文本光标，自行车使用弧形车把。
- 普通弯道上松开左右键仍保持相对道路的横向偏移并自动跟弯；左右键只横移，不产生自然离心漂移，自动跟弯不能绕过截止墙。
- 关闭车道存在可达并道空间，正常同向道路保留生路；弯道入口/出口与环首无几何跳变。
- 上下坡高度与俯仰连续；玩家、交通、标线、路肩和景物贴合地形；道路环首高度为零且无跳变；坡道不额外改变速度上限。
- 坑洞与泥洞稀疏出现并贴合坡道；车轮或履带踩中才触发，高速经过不漏判。坑洞当前速度减半、弹跳并偏向邻道，最右侧只向左，最左侧只向右，横移仍检测碰撞；泥洞减速、挂泥和半速上限保持 8 秒，暂停冻结、升级仍限速、结束后清除；停在同一洞上不反复触发，下一轮可再次触发。
- 楼房、农场和牧场以 18% 候选概率在道路随机一侧出现，奶牛每处两到三头，湖泊以 8% 候选概率且仅在平缓地形出现；对象与实例容量不随长距离运行增长。
- 覆盖完整四季和至少两轮道路循环；检查随机起始季节、120/240/360 秒节点、暂停冻结和刹停继续计时，观察冬春过渡、刷新交通、对象池数量及距离连续性。
- 距离与真实速度一致，刹停/暂停不计分，死亡接触后和死亡动画期间不计分。
- 固定本机地址刷新后读取已完成成绩；禁用存储、损坏 JSON、未知版本、配额失败均不阻止游戏。
- 异常存档重置入口只在待机/结算提供，明确确认后只删除本游戏键；保存恢复后清除提示，重置失败保持内存模式。

## 首版优先处理的风险

| 风险 | 设计处理 |
| --- | --- |
| 自行车侧碰难以准确操作 | 增大车身、连续横移、速度控制；以我方车头是否超过对方车头或位于对方后半段判断侧碰 |
| 边角轻触被误计吞吃 | 侧面接触统一按车头位置条件分类，斜向侧面接触不因角点而自动降级；纯纵向端面仍按追尾 |
| 收窄时车辆被堵成必死局 | 长预警、关闭车道抑制生成、NPC 提前并道、按玩家宽度检查可达同向通路 |
| 突然截止被纠偏机制绕过 | 实体墙优先检测，渐进道路纠偏不提供绕墙保护 |
| 正常交通布局没有覆盖升级空间 | 宽车道、稳定车流守车道、系统间较大净距，同时检查吞吃位置的下一车型尺寸；NPC 变道不避让玩家，不额外增加升级保护 |
| 系统变道把玩家当作障碍而偏离约定 | 跟车与变道决策仅使用系统车辆；实际玩家接触交由独立碰撞规则处理 |
| 系统车被撞后互相穿透 | 系统间二次接触单独分离、减速与回正，不套用玩家等级规则 |
| 损坏存档后无法恢复保存 | 第一版提供异常存档重置确认入口，仅重置本项目键并捕获删除/写入异常 |
| 季节或速度被道路环首重置 | 季节仅按有效游戏时间每 120 秒轮换；自动提速遵守刹车、刮擦与车型有效上限，不按道路环首重置 |
| 循环接缝或长距离运行抖动 | 首尾连续校验、独立累计距离、局部渲染原点与有限对象池 |
| 场景效果降低辨识度 | 季节不改变规则，道路高对比，雾与装饰受安全视距限制 |
| 本机记录因地址变化不可见 | 固定 HTTP 来源、版本化命名键、明确当前浏览器存档范围 |

初版完成后再考虑音效细化、移动端触控、回放和存档导入/导出；它们不阻塞当前核心玩法。

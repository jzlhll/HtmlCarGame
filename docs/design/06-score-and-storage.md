# 得分与本机排行榜

[返回总览](../README.md) · [游戏状态](01-gameplay.md) · [车辆速度](02-vehicles.md)

## 距离计分

只按实际沿道路前进的距离计分：`distanceMeters += speedMetersPerSecond × deltaSeconds`，`score = floor(distanceMeters)`。一米一分，不添加吞吃、升级、季节或连击加分。

距离使用道路中心线的前进弧长，横移不增加路程。内部保留小数，画面显示整数米。仅 `RUNNING` 累计距离；零速、暂停、准备、死亡动画与结算均不加分。致命碰撞推进到首次接触时刻后锁定距离。

## 结算与排行榜

本局结算展示分数、有效行驶时间、最高车型、吞吃数量、起始季节和结束原因。有效行驶时间包含零速状态，不包含暂停。

排行榜分数只由行驶距离计算，与吞吃升级积分独立。吞吃积分仅保存于本局运行状态，用于车型升级，不额外计入排行榜。

只保存本机排行榜前十名，不提供最近记录、累计统计或偏好存档。最佳距离直接取排行榜第一名，不重复保存。主动结束记录 `quit` 并参与排名；死亡记录 `death` 和碰撞原因。页面关闭或刷新导致未结算的局不追加成绩。

排名按分数降序；相同时按实际距离降序，再按结束时间由早到晚。最高等级、吞吃数量和用时不影响排名。同一局只结算一次。

## 本机保存

使用当前浏览器的 localStorage，命名键为 `htmlCarGame.save.v1`，一个 JSON 文档包含：

| 字段 | 内容 |
| --- | --- |
| `schemaVersion` | 结构版本，当前为 1 |
| `rulesVersion` | 玩法规则版本，当前为 1 |
| `updatedAt` | 保存时间 |
| `leaderboard` | 排行榜前十局 |

每局包含 `runId`、`runSeed`、`startSeason`、`rulesVersion`、`endedAt`、`endReason`、`deathCause`、`distanceMeters`、`score`、`activeSeconds`、`highestRank`、`eatenByType`。只保存进入前十名的对局。没有旧字段迁移或兼容逻辑。

启动读取时捕获浏览器存储访问、读取和 JSON 解析异常；校验版本、记录数量、合法车型、非负有限距离和时间，分数按校验后的距离重新计算。无法读取时仍能游玩，提示本机记录暂不可用，不静默覆盖损坏数据。结算时先更新内存排行榜，再一次写入；写入失败时本局仍正常结束，保留当前页面内的排行榜，并在后续结算重试。

异常状态下，在待机或结算页提供“重置本游戏记录”。确认后只删除本游戏键并写入默认排行榜；失败保持内存模式，成功恢复保存。进行中或暂停时不提供重置。不会使用 `localStorage.clear()`。

固定使用 `http://localhost:5173`，依赖与素材在本机加载，安装后无需联网。不同浏览器、协议、主机名或端口分别存档；清除网站数据会删除排行榜。排行榜仅供本机游玩，不提供云同步、续局、导入导出或防作弊。

以单个游戏标签页为写入者；其他页面更新存档时提示，待机和结算状态可重新读取。多页面同时结算不保证零丢失。

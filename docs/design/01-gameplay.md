# 总体玩法与操作

[返回总览](../README.md) · [车辆规格](02-vehicles.md) · [碰撞规则](03-collision-and-growth.md)

## 核心体验

玩家在不断向前延伸的道路上保持生存。观察附近交通，利用加油与刹车把目标车调整到自身后半部旁边，再向目标横移完成吞吃。升级后车身与操控变化，继续跑更远的距离。

初版从一级自行车开始，默认处于右侧同向道路的中间车道；只有两条同向车道时，默认靠中间隔离带的一条。每局重新生成随机种子，第一段为六车道直道，起步前方保留至少 100 米可行驶空间。

## 视角与位置

- 初版采用低多边形风格、俯视斜向透视，既能看清车头车尾，也能看见前方道路。
- 玩家车身中心保持在屏幕高度约 78% 处，允许横向移动与小幅倾斜，不主动向屏幕上方跑远。
- 玩家在逻辑道路中持续前进；画面通过跟随相机与相对坐标，让赛道、景物、车辆产生运动。不能因为画面固定就将玩家的逻辑速度设为零。
- 相机跟随道路切线平滑转向，轻微横向跟随但不完全抵消玩家转向，否则会看不出横移。
- 后方保留少量可见道路，方便看清自身尾侧的目标。车辆只从前方出现，完整被玩家超过后退出交通逻辑，不会再从后面追上。
- 左侧道路上的对向交通向玩家迎面而来，与右侧同向交通形成明确方向差异。
- 玩家可以越过中央双线进入对向车道，车头仍朝原方向；与对向车接触直接死亡，即使目标等级更低。

## 操作

| 输入 | 行为 |
| --- | --- |
| 空格 | 待机时开始；行驶时暂停；暂停时继续 |
| 左右方向键 | 按住连续横向移动，松开停止横移；同时按下相互抵消 |
| Z | 按住刹车，最低可以降到零；不支持倒车 |
| X | 按住加油，向当前车型最高速度加速 |
| 同时按 Z、X | 刹车优先 |
| 暂停窗口“结束游戏” | 点击后主动结束本局并结算 |
| 结算窗口“返回” | 点击返回待机，下一局仍需按空格开始 |

方向键采用连续位移，而不是瞬间切换到相邻车道。这样尾侧吞吃需要控制接触位置，也能在相邻车道之间微调。车身始终朝向道路前进方向，初版不提供自由转向角或掉头。

输入只在游戏画布或游戏容器获得焦点时接管。空格、方向键阻止页面滚动，忽略按键自动重复导致的暂停切换；弹窗按钮拥有焦点时，空格仍由游戏状态处理，避免误触“结束游戏”。点击结束按钮是主动结束入口。

## 状态与窗口

| 状态 | 展示与运行 | 允许的离开方式 |
| --- | --- | --- |
| `READY` | 标题、最佳成绩、操作说明；道路静止 | 空格准备本局 |
| `PREPARING` | 创建道路计划和对象池，显示短暂准备提示 | 准备成功自动进入 `RUNNING`；失败回待机并提示 |
| `RUNNING` | 行驶、交通、碰撞、季节与计分运行 | 空格进入 `PAUSED`；致命碰撞进入 `DYING` |
| `PAUSED` | 半透明深色遮罩覆盖整个游戏，中央暂停窗口 | 空格继续；点击“结束游戏”进入 `RESULT` |
| `DYING` | 冻结本局逻辑与成绩，仅播放死亡表现 | 动画结束进入 `RESULT` |
| `RESULT` | 展示距离、分数、最高等级、吞吃数与结束原因 | 点击“返回”进入 `READY` |

暂停窗口文案：“游戏已暂停”“按空格继续”，并提供清晰的“结束游戏”按钮。遮罩拦截画布上的鼠标事件，窗口后方的道路和车辆全部冻结。

切换标签页或窗口失焦时，从行驶状态自动进入暂停。清空踏板与方向键按下状态，回到页面后不会自动继续。离开页面不弹出额外确认，也不保证保存未结束的一局。暂停不增加距离、升级进度、减速计时或交通生成计时。

## 界面信息

游戏上方显示当前距离/分数、速度、车型等级和升级进度。满级后进度栏替换为“已达最高等级”，保留吞吃总数。进度显示“同级等效 1.33 / 3”，实际计算使用整数单位，见[碰撞专题](03-collision-and-growth.md)。

短提示用于“升级”“降级”“减速 50%”“路边刮擦”，不挡住玩家车身与尾部。危险的高等级车辆拥有清晰等级标识；车型本身仍是第一识别线索。进入对向车道时显示简短危险提示。底部固定操作提示保持简短。

## 死亡与主动结束

致命碰撞当帧锁定成绩，立即停止碰撞、生成、距离和成长计算。初版死亡动画约 1.2 秒：撞击闪光与短促震动，车身拆散、爆炸烟尘，残骸缩小并沿道路远离，最后淡出。动画只影响表现，不能继续吞吃或计分。

自行车表现为车架与车轮破碎，机动车表现为车身爆炸损毁；不表现人物受伤。结算窗口区分直撞、前半部侧擦、尾侧撞高级车辆、对向车辆碰撞和撞墙等结束原因。

主动结束直接结算，记录原因 `quit`，不播放死亡动画。结算只提交一次，避免连续点击造成重复存档。

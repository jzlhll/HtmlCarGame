# 总体玩法与操作

[返回总览](../README.md) · [车辆规格](02-vehicles.md) · [碰撞规则](03-collision-and-growth.md)

## 核心体验

玩家在不断向前延伸的道路上保持生存。观察附近交通，利用自动提速与主动刹车把目标车调整到自身侧面，使我方车头超过对方车头，或位于对方车身后半段，再向目标横移完成吞吃。升级后车身与操控变化，继续跑更远的距离。

初版从一级自行车开始，默认处于右侧同向道路的中间车道；只有两条同向车道时，默认靠中间隔离带的一条。每局重新生成随机种子，第一段为 240 米六车道直道，起步前方保留至少 100 米可行驶空间。

## 视角与位置

- 初版采用低多边形风格、俯视斜向透视，既能看清车头车尾，也能看见前方道路。
- 玩家车身中心保持在屏幕高度约 78% 处，允许横向移动与小幅倾斜，不主动向屏幕上方跑远。
- 玩家在逻辑道路中持续前进；画面通过跟随相机与相对坐标，让赛道、景物、车辆产生运动。不能因为画面固定就将玩家的逻辑速度设为零。
- 相机跟随道路切线平滑转向，轻微横向跟随但不完全抵消玩家转向，否则会看不出横移。
- 后方保留可见道路，方便看清自身尾侧的目标与其他车道的后方来车。玩家当前所在车道不从后方生成车辆，其他车道允许后方交通。
- 左侧道路上的对向交通向玩家迎面而来，与右侧同向交通形成明确方向差异。
- 玩家可以越过中央双线进入对向车道，车头仍朝原方向；对向车道采用相同侧碰、追尾与等级规则，可以侧碰吞吃同级或低级车。

## 操作

| 输入 | 行为 |
| --- | --- |
| 空格 | 待机时开始；行驶时暂停；暂停时继续；结算时直接开始新一局 |
| 左右方向键 | 按住连续横向移动，松开停止横移；同时按下相互抵消 |
| 下箭头 | 按住减速，最低到零；不支持倒车 |
| 上箭头 | 不执行游戏操作，阻止浏览器滚动和光标导航 |
| 松开下箭头 | 每秒自动提高 6 km/h，直到当前车型有效上限；刹停后也会自动起步 |
| 暂停窗口“结束游戏” | 点击后主动结束本局并结算 |
| 结算窗口“返回” | 点击返回待机，下一局仍需按空格开始 |

方向键采用连续位移，而不是瞬间切换到相邻车道。侧碰吞吃需要控制双方车头与车身的前后位置，也能在相邻车道之间微调。车身始终朝向道路前进方向，初版不提供自由转向角或掉头。

游戏按键在页面层捕获，焦点移到页面本身时仍可接收左右、下箭头和空格，并恢复游戏区域焦点；输入框、文本编辑区域和浏览器组合快捷键不接管。上箭头不进入按键状态，也不触发浏览器默认动作。浏览器窗口失焦或页面隐藏时清空按键并暂停，回到页面后由空格继续。

玩家自动跟随道路曲线。松开左右键时，保持相对道路中心线的横向偏移，沿弯道继续前进，不会产生自然漂移或因未打方向冲出普通弯道；左右键只改变该偏移，不直接控制车头转角。道路收窄、外沿刮擦、碰撞侧移仍可改变横向位置，突然截止的实体墙不因自动跟弯而被绕过。

路上系统车辆遇到慢车或车道关闭时，按其他系统车辆的位置和接近方向提前减速、择机变道，不把玩家作为跟车或避让目标。玩家需要观察其动作，发生接触照常执行碰撞规则；初版不提供系统车辆对玩家的自动让行。

系统车辆变道前先显示目标方向的转向灯，初版至少预告一秒，随后约 1.5 秒平滑完成横移。预告和动作不构成对玩家的让行，玩家仍需观察并避让。

输入只在游戏画布或游戏容器获得焦点时接管。空格、左右箭头与下箭头阻止页面滚动，忽略按键自动重复导致的暂停切换；弹窗按钮拥有焦点时，空格仍由游戏状态处理，避免误触“结束游戏”。点击结束按钮是主动结束入口。

## 状态与窗口

| 状态 | 展示与运行 | 允许的离开方式 |
| --- | --- | --- |
| `READY` | 标题、最佳成绩、操作说明；道路静止 | 空格准备本局 |
| `PREPARING` | 创建道路计划和对象池，显示短暂准备提示 | 准备成功自动进入 `RUNNING`；失败回待机并提示 |
| `RUNNING` | 行驶、交通、碰撞、季节与计分运行 | 空格进入 `PAUSED`；致命碰撞进入 `DYING` |
| `PAUSED` | 半透明深色遮罩覆盖整个游戏，中央暂停窗口 | 空格继续；点击“结束游戏”进入 `RESULT` |
| `DYING` | 冻结本局逻辑与成绩，仅播放死亡表现 | 动画结束进入 `RESULT` |
| `RESULT` | 展示距离、分数、最高等级、吞吃数与结束原因 | 空格准备新一局；点击“返回”进入 `READY` |

暂停窗口文案：“游戏已暂停”“按空格继续”，并提供清晰的“结束游戏”按钮。遮罩拦截画布上的鼠标事件，窗口后方的道路和车辆全部冻结。

切换标签页或窗口失焦时，从行驶状态自动进入暂停。清空所有方向键按下状态，回到页面后不会自动继续。离开页面不弹出额外确认，也不保证保存未结束的一局。暂停不增加距离、升级进度、季节计时、减速计时或交通生成计时；继续时从暂停前速度恢复，未刹车且无道路刮擦时逐渐自动提速。

## 界面信息

左侧状态面板显示当前距离/分数、速度、车型等级和升级积分。未满级车型显示“当前积分 / 本级升级门槛 分”，例如自行车 `1 / 2 分`、小汽车 `6 / 18 分`、加长卡车 `54 / 216 分`；进度条按当前积分占门槛的比例填充，不使用同级等效换算或取整份数，不添加侧碰说明。满级后进度栏显示“最高等级”，吞吃总数在结算中展示。积分表与门槛见[碰撞专题](03-collision-and-growth.md)，距离得分与升级积分独立。

短提示用于“升级”“降级”“减速 50%”“路边刮擦”，不挡住玩家车身与尾部。车辆上不显示 LV 或等级标识，用户通过车型外观自行探索。进入对向车道不额外弹出提示。行驶界面不显示季节文字、换季倒计时或右侧悬浮操作面板；隐藏鼠标指针和文本插入光标，禁止选择游戏界面文字，弹窗按钮保留正常鼠标操作。

## 死亡与主动结束

致命碰撞当帧锁定成绩，立即停止碰撞、生成、距离和成长计算。初版死亡动画约 1.2 秒：撞击闪光与短促震动，车身拆散、爆炸烟尘，残骸缩小并沿道路远离，最后淡出。动画只影响表现，不能继续吞吃或计分。

自行车表现为车架与车轮破碎，机动车表现为车身爆炸损毁；不表现人物受伤。结算窗口区分追尾、侧碰高级车辆和撞墙等结束原因。

主动结束直接结算，记录原因 `quit`，不播放死亡动画。结算只提交一次，避免连续点击造成重复存档。结算界面按空格直接准备新一局，不重复保存上一局；替换弹窗时将原弹窗内的焦点移回游戏容器，点击结束后仍可使用空格。

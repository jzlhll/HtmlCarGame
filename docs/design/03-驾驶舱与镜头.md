# 驾驶舱与镜头

[返回总览](../README.md)

已实现外部场景、四秒倒数运镜和七项起飞准备。倒数结束发动机保持关闭；准备完成后底部点亮，D 舱门从 Open 变为 Closed，L／H／A 从 OFF 变为 ON，W 从 ON 变为 OFF；再次按键撤销准备，L 点亮背光，A 点亮仪表，F 驱动发动机转速上升及轻微镜头振动。已接入滑跑、离地与爬升，视角连续跟随机身位置和姿态；结果页冻结画面。

## 画面布局

常规驾驶阶段的下方约 25% 为驾驶舱仪表台和操纵区，上方约 75% 为透过前窗看到的世界。顶框、两侧框与仪表台上沿共同围成一块完整前窗，中央不设立柱或分隔线，外部世界保持连续。

```text
┌────────────────────────────────────────────┐
│ 品牌／阶段          剩余时限        暂停入口 │
│                                            │
│ 航线图       完整前窗             机外姿态  │
│ 交通雷达     跑道／天空／连续世界            │
│              中央无遮挡                    │
├────────────────────────────────────────────┤ 约 75% 高度
│ 空速  高度  姿态  垂直速度  航向             │
```

仪表台是真实遮挡关系中的驾驶舱模型，读数和交互层可用 DOM 叠加；避免整块面板像悬浮在玻璃上的网页卡片。首版以 16:9 桌面横屏为基准，下方高度可在约 23%–28% 内适配；窄窗口压缩次要标签，不遮挡跑道中线和关键读数。

## UI 风格与可见状态

- 玩家可见英文仅第一个字母大写，其余字母小写，只有 OFF／ON 保留全大写；例如 Airspeed、Vertical speed、Wing brake。单字母键帽使用大写字母。
- 采用深色半透明面板、细边框、圆角、暖金色强调和英文主信息／中文辅助信息；天空使用蓝灰与浅青，仪表台使用石墨深色。
- 仪表标题、底部准备与飞行操作、机外姿态卡片均将英文置前，中文缩小置于下方辅助理解；迎角、航迹、升力载荷、航向、姿态与发动机内的减速板／刹车读数沿用此层级。
- 底部 T 提速、S 减速始终点亮，合并的 T／S 项同样常亮且无百分比。Engine 百分比显示自动动力，旁列 Wing brake ON／OFF 和“提速快／减速慢”或“提速慢／减速快”，不再显示手动油门。
- 常规桌面操作名称约 13–14 px、中文辅助约 10 px、状态约 12 px；较窄窗口仍保留约 11 px 英文和 9 px 中文，不用 5–8 px 小字压缩。准备项的状态放在名称下方，给 Open／Closed 留出空间；导航卡片高度约束在仪表区上方，避免字号放大后覆盖仪表。
- 保留低多边形模型风格，让飞机、跑道和驾驶舱具有一致的视觉语言。按钮状态以文字、指示灯和明暗共同表达。
- 熄火时仪表屏幕关闭，窗外仍可见白昼机场；L 切换面板背光与航行灯，A 切换主要仪表，F 启动后发动机转速表由零上升；F 再按取消启动或熄火，转速与振动归零。
- 入舱后上方居中仅显示一次任意顺序操作说明，不显示 Light 等具体单项；首次普通字母或游戏操作按键后本局隐藏，重开恢复。条件不足仍用独立短提示说明原因；底部舱门显示 Open／Closed，其余项显示 OFF／ON 状态，发动机启动中显示 Starting，完成项同时以边框和亮度区分；R 放行后整条替换为 T／S、方向修正与抬轮；离地后整条替换为速度、姿态、转弯、G／W 收放状态。清单上方常驻当前目标，低速状态保持提醒，不重弹中央说明。
- 仪表台常驻显示空速、高度、人工地平仪、垂直速度、航向、发动机状态、减速模式、减速板、起落架和刹车状态；舱门在准备清单中显示 Open／Closed（Closed 才就绪），系带显示 ON／OFF，不另设供电、供油表或重量设置。
- 暂停和结果页使用居中面板的视觉层级；成功标题为“🎉 恭喜！航程完成”，失败为“💥 失败！再试一次”，下方保留具体结果原因与数据。背景停止运动，恢复后仍在同一驾驶舱位置。

## 四秒倒数运镜

每个数字显示一秒，总长四秒。使用同一场景中的连续收拢环绕轨迹；镜头沿飞机左侧保持同一绕行方向，半径持续缩小、高度逐渐下降，视线平滑转向跑道前方，不能中途反向绕行或突然掉头。镜头位置、朝向与视野角共用连续进度，数字不重置轨迹。

| 时间 | 倒数 | 镜头重点 |
| --- | --- | --- |
| 0–1 秒 | 4 | 从跑道斜前方较宽视角推进，建立机场与跑道方向 |
| 1–2 秒 | 3 | 沿飞机左侧绕行，展示机身、机翼和静止的起落架 |
| 2–3 秒 | 2 | 经过左后方上空并向驾驶舱收拢，视线连续转向跑道纵深 |
| 3–4 秒 | 1 | 沿避开实体遮挡的路径进入驾驶舱眼位，仪表台逐渐占据下方四分之一 |
| 4 秒 | 隐藏倒数 | 驾驶舱眼位稳定，飞机仍熄火，显示一次任意顺序操作说明 |

相机路径在模型尺度确定后校准，避免穿过实心机鼻、椅背或在窗框内卡住。必要时只在进入内舱的短暂过渡中隐藏外机壳相应部分，不做明显黑场跳切。四秒轨迹以建立体验为目标，不在这段时间内加入复杂飞行表演。当前轨迹从跑道左前方出发，沿飞机左侧绕至左后方上空，再朝前收拢至驾驶舱眼位；极角和水平朝向保持单调变化，首尾减速。接近眼位前淡出外部模型，随后淡入内舱几何，避免实体机壳遮挡。外部待机位置与起点共用参数，终点与驾驶舱前视眼位一致，不使用黑场切换。机壳与内舱渐隐期间保留深度写入，避免部件混合排序造成破面；地面、跑道与标线使用固定深度层级，避免远处闪烁。静止场景的阴影不随相机绕行重复计算。

## 驾驶舱视角

首版固定飞行员眼位，视线相对机头向下 5°以保留爬升地景，无需鼠标转头；方向键用于飞行，不兼任相机控制。外部世界随机身姿态运动，仪表台跟随机身保持稳定。转弯时可见外部地平线倾斜，抬头时跑道向窗口下方移动，离地后地面逐渐远去。

完整前窗使用一个主场景与相机，仅由外围驾驶舱几何形成遮挡。外部机身在内舱视角避免遮住前窗；灯光不能让玻璃反射淹没前方跑道。

F 被有效受理后加入轻微、连续的发动机振动，启动初期稍明显，约 3 秒内平滑减弱为怠速微振；暂停或失焦冻结相位，继续保持进度，重开清零。振动只改变观察眼位，不改变飞机姿态或位置；仪表读数保持稳定。相机不加入强烈抖动，首版不模拟气流。云海和云中视野属于后续[天空环境规划](04-天空环境规划.md)，当前已实现清朗天空、河湾城市、轮廓地标和远山，云层与巡航仍为规划。

飞行显示使用相邻逻辑快照插值，同一个显示姿态驱动机体和眼位；暂停保留最后显示姿态，恢复不补算暂停时间。外机壳隐藏时不随飞行位置重算机场静态阴影。结果页列出成功／失败原因、用时、最高高度、离地速度和最高空速，可重新开始。

## 机外姿态卡片

驾驶舱右上角常驻一个小型机外三维卡片，取代顶部“返回外部”按钮。卡片实时显示同一飞机的俯仰、坡度、起落架和减速板；相机跟随航向，固定从后侧观察，让抬头、低头和滚转始终易于比较。数字标出实际俯仰和坡度，A 仪表关闭也保留此学习辅助。

卡片使用同一 WebGLRenderer 的独立场景与裁剪视口，主画面仍为第一人称；暂停与结果同步冻结。重新开始只放在暂停与结果窗口，不用机外按钮打断飞行。仪表台上缘常驻迎角、航迹角、升力载荷与危险状态，中央仰角／俯角／失速提示单次最多 2.5 秒。

左上航线图显示计划直线、金色实际轨迹与五星目的地目标，下方航向朝上的交通雷达以箭头、相对高度和闪烁标出遭遇；卡片不遮挡底部仪表。任务计时、导航与雷达契约见[航程专题](07-航线与关卡.md)。

## 低空脚部视角

右侧姿态卡片下方增加 Gear view（脚部视角）。驾驶舱内 AGL 小于 200 米显示，爬升达到 200 米隐藏，下降回到 200 米内重新出现；准备、滑跑和接地后均可观察，COMPLETE／RESULT 隐藏。画面使用实际世界、实际机轮和地面，显示 AGL、下降速度、起落架及减速板状态。镜头在机轮附近随高度调整下视角度，近处观察机轮与下方地面；共用主渲染器和插值姿态，不生成独立示意地板，不自动替玩家拉平。

两个卡片在右侧纵向排列，短窗口缩小画面高度，保持标题和读数，不遮挡仪表。脚部视角出现／隐藏后刷新两个裁剪视口；暂停冻结，恢复与重开不残留旧布局。

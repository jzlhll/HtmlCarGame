# 驾驶舱与镜头

[返回总览](../README.md)

第一阶段已实现外部与驾驶舱预览，仪表未通电，七步按键只作静态展示。下文的倒数运镜、开关照明和飞行中的视角变化属于后续设计。

## 画面布局

常规驾驶阶段的下方约 25% 为驾驶舱仪表台和操纵区，上方约 75% 为透过前窗看到的世界。窗框向上延伸形成左右两扇主前窗，中间一根较窄立柱；不能将“两扇窗”实现成两张互不相关的景物图片。

```text
┌────────────────────────────────────────────┐
│ 品牌／阶段       当前双语步骤        暂停入口 │
│                                            │
│           左前窗   │   右前窗              │
│      跑道／天空    │   同一个连续世界       │
│                   │                        │
├────────────────────────────────────────────┤ 约 75% 高度
│ 空速  高度  姿态  垂直速度  航向             │
│ 灯光 舱门 系带 仪表 发动机 襟翼 起落架 油门   │
└────────────────────────────────────────────┘
```

仪表台是真实遮挡关系中的驾驶舱模型，读数和交互层可用 DOM 叠加；避免整块面板像悬浮在玻璃上的网页卡片。首版以 16:9 桌面横屏为基准，下方高度可在约 23%–28% 内适配；窄窗口压缩次要标签，不遮挡跑道中线和关键读数。

## UI 风格与可见状态

- 采用深色半透明面板、细边框、圆角、暖金色强调和中文主信息／英文辅助信息；天空使用蓝灰与浅青，仪表台使用石墨深色。
- 保留低多边形模型风格，让飞机、跑道和驾驶舱具有一致的视觉语言。按钮状态以文字、指示灯和明暗共同表达。
- 熄火时仪表屏幕关闭，窗外仍可见白昼机场；L 后面板背光亮起，A 后主要仪表点亮，F 后发动机转速表由零上升。
- 启动清单位于上方居中，显示当前步骤及七步完成状态；进入滑跑后切换为速度／抬轮引导，爬升时切换为起落架和襟翼任务。
- 仪表台常驻显示空速、高度、人工地平仪、垂直速度、航向、发动机状态、油门、襟翼、起落架和刹车状态；舱门与系带通过紧凑指示灯呈现，不另设供电、供油表或重量设置。
- 暂停和结果页使用居中面板的视觉层级；背景停止运动，恢复后仍在同一驾驶舱位置。

## 四秒倒数运镜

每个数字显示一秒，总长四秒。使用同一场景中的连续曲线相机轨迹，关键点之间平滑插值；镜头位置变化、视线方向与视野角同步，数字不重置轨迹。

| 时间 | 倒数 | 镜头重点 |
| --- | --- | --- |
| 0–1 秒 | 4 | 从跑道斜前方较宽视角推进，建立机场与跑道方向 |
| 1–2 秒 | 3 | 掠向飞机前侧，展示机身、机翼和静止的起落架 |
| 2–3 秒 | 2 | 镜头绕向机鼻前窗，带出周围机场环境与跑道纵深 |
| 3–4 秒 | 1 | 沿避开实体遮挡的路径进入驾驶舱眼位，仪表台逐渐占据下方四分之一 |
| 4 秒 | 隐藏倒数 | 驾驶舱眼位稳定，飞机仍熄火，显示 L 开灯步骤 |

相机路径在模型尺度确定后校准，避免穿过实心机鼻、椅背或在窗框内卡住。必要时只在进入内舱的短暂过渡中隐藏外机壳相应部分，不做明显黑场跳切。四秒轨迹以建立体验为目标，不在这段时间内加入复杂飞行表演。

## 驾驶舱视角

首版固定飞行员前视眼位，无需鼠标转头；方向键用于飞行，不兼任相机控制。外部世界随机身姿态运动，仪表台跟随机身保持稳定。转弯时可见外部地平线倾斜，抬头时跑道向窗口下方移动，离地后地面逐渐远去。

两扇窗共用一个主场景与相机，通过驾驶舱几何形成遮挡，不采用左右独立渲染。外部机身在内舱视角避免遮住双窗；灯光不能让玻璃反射淹没前方跑道。

相机不加入强烈抖动，首版不模拟气流。山地、云海和云中视野属于后续[天空环境规划](04-天空环境规划.md)，首版只需清朗天空、地平线和机场附近地景。

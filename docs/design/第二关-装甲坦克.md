## 身份与外观

新增“装甲坦克”，只在第二关作为系统车辆生成。玩家最高车型仍为现有坦克，成长门槛仍为 1／2／6／18／54；装甲坦克不进入玩家升级、吞吃价值、氮气奖励、玩家防御或五项吞吃统计。

“比现有坦克高一倍”按高度为现有坦克两倍设计，长度仍为 6.0 米，宽度仍为 3.0 米，避免扩大到占满两条车道。高度统一包含车身、履带与上层装甲的完整模型包围高度，由现有坦克模型实际高度计算，不单凭颜色区分。

使用更高的双层装甲顶盖、厚重侧裙、深色履带与沙色／深灰撞色，增加醒目的装甲拼块和顶部轮廓。保持远处及俯视角也能辨认其更高、更重，不能只把普通坦克整体竖向拉伸；不增加主动射击。地面碰撞仍使用实际长宽，装甲顶盖不侵入相邻车道。

## 投放规则

| 生成候选时玩家车型 | 装甲坦克概率 |
| --- | ---: |
| 自行车、三轮车、小汽车 | 0%，不新生成 |
| 卡车 | 5% |
| 坦克 | 15% |

比例是每次新车候选的车型抽签概率，不是强制维持场上精确占比。抽中后仍需通过现有投放空间与安全距离检查，不为补足占比挤入车辆。

主路、副路、同向、对向及前后普通车流使用同一规则；缓行车队逐辆选车型时也按此规则抽签，共享既有队伍速度与间距，因此短时占比可波动。升级至三轮车、小汽车时的定向补车仍严格补同级和低一级，不被装甲坦克抽签替换。

装甲概率从原有同级车型份额中划出，剩余份额保持原低级吞吃目标及高级车型分布；玩家为坦克时装甲坦克属于更高级威胁，不再被“满级没有高级车辆”的现有分支过滤。若某投放来源的原同级份额不足，先保留低级目标，将剩余非低级份额归一化后分配，不能出现负权重。

每次候选只抽签一次，不在同一生成流程中叠加两次装甲概率。已生成的车种、颜色和尺寸保持固定，玩家升级、降级或更换路线不使其变身，也不重抽。

## 行驶、碰撞与回收

- 基础巡航速度为 60–80 km/h，对向沿用 1.44 倍并四舍五入，即约 86–115 km/h；转向灯、临近避让和随机变道沿用普通坦克；独立模型与模板缓存必须可被现有实例合批正确识别。
- 对碰撞等级而言高于普通坦克；玩家是普通坦克且正在氮气喷气时，端面追尾装甲坦克只退一级到卡车，按坦克低一级价值扣成长积分并获得两秒降级保护，同一接触组只计算一次装甲退级；装甲坦克保持在场，不被吞吃或撞飞。有效侧碰仍遵循车型等级约定，装甲坦克高于所有玩家车型，喷气侧碰也直接死亡。其他车型无论是否喷气，以及未喷气的普通坦克，端面撞击均直接死亡。擦角及已有重叠仍按现有分离规则，不能把全部接触扩大为致命。
- 白马无敌、降级保护及答题／调试复活保护按现有车辆接触规则处理；白马可撞飞装甲坦克但不提供积分。系统车辆间接触时，装甲坦克高于其余车型，两辆装甲坦克按同级处理。
- “装甲”不引入额外 NPC 血量或护甲条；第二关关闭天降炮击。
- 玩家降到小汽车及以下后停止新投放，场上已有装甲坦克继续正常行驶，不新增按玩家等级清场或主动回收逻辑。
- 保留现有车辆移除与距离回收：已损毁车辆按原流程移除，存活车落后玩家超过 260 米或位于前方超过 480 米时回收。现有 100 米清理属于白马撞破记录，不用于装甲坦克车辆回收。

`MAX_RANK=5` 固定玩家最高可升级等级，`ARMORED_RANK=6` 表示系统专属碰撞等级；追加系统车型不改变玩家升级、成长封顶、存档校验或五项统计。

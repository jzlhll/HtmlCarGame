# 多关卡与可调参数

[返回总览](../../README.md) · [完整规则](07-关卡与学习闭环.md)

每关固定 12 个词，桌面按编号交替：奇数关为 300 秒空战，大 Boss 全对后切为完整五秒拾箱；偶数关为 180 秒碎片组装和 90 秒陨石连线。手机每关均使用两阶段碎片模式。相同模式的难度、生成节奏及规则一致，详见[交替关卡与碎片模式](09-交替关卡与碎片模式.md)。未完成及重玩沿用本账号保存的十二词，新关重新抽取保存。默认不随时间加速；不以生命或最终 Boss 是否击败判负。结算统一“恭喜通关！”，通过率为成功／（成功＋写错＋没写完）。

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `LEVELS.durationSeconds` | 300 | 空战关卡有效时长 |
| `ASSEMBLY.stageSeconds` | [180,90] | 碎片组装／陨石连线有效时间 |
| `ASSEMBLY.maxChecks` | 3 | 每阶段验证上限 |
| `ASSEMBLY.maxChunkLength` | 5 | 无元音分界且超过此长度时，每三字母分块兜底 |
| `LEVELS.wordCount` | 12 | 每关固定的不同词数量 |
| `WORDS.spawnIntervalSeconds` | [10,14] | 普通飞机生成间隔 |
| `WORDS.fallDurationSeconds` | [60,76] | 正常下降作答时长 |
| `WORDS.maxEditable` | 2 | 普通可编辑飞机上限 |
| `WORDS.blankMinCount` / `blankMaxFraction` | 2 / 0.5 | 至少挖两个，最多词长一半并向下取整；二至三个字母的短词也挖两个 |
| `WORDS.verifySeconds` / `successSeconds` | 0.5 / 1 | 验证与成功表现 |
| `LETTERS.fireIntervalSeconds` | 0.06 | 严格大于 0.02 秒 |
| `LETTERS.shotCountRatio` / `shotCountMultiple` | 0.7 / 2 | 每字母按原亮点七成取最近偶数发，字形不变 |
| `WORDS.inputLockSeconds` | 0.75 | 单格完成后锁定时间 |
| `WORLD.playWidthScale` | 1.25 | 横向活动宽度上限，窄屏受可视宽度约束 |
| `BOSSES.miniAt` / `finalAt` | 90 / 240 | 小 Boss 与最终 Boss 出现时间 |
| `BOSSES.miniFaces` / `finalFaces` | 3 / 4 | 单词面数 |
| `BOSSES.durationSeconds` / `turnSeconds` | 60 / 0.6 | 限时与换面时间 |
| `BOSSES.xRange` / `yRange` | 275 / 45.5 | 左右／上下浮动振幅（逻辑坐标） |
| `BOSSES.xAngularSpeed` / `yAngularSpeed` | 0.16 / 0.45 | 左右／上下正弦移动角速度（rad/s） |
| `ENEMIES.maxActive` / `bulletPoolSize` | 16 / 64 | 活动敌机及敌弹容量 |
| `WORDS.inputLockSeconds` | 1 | 每格完成后的输入锁定及待定闪烁 |
| `SUPPLIES.intervalSeconds` / `fallSeconds` | 120 / 22 | 周期幸运箱间隔与每屏下降时长 |
| `SUPPLIES.maxActive` | 16 | 箱子及收藏飞行动画池，箱子满时排队 |
| `CHOICES.ratio` / `batchSize` | 0.3 / 10 | 普通题每十题七拼写、三选择 |
| `CHOICES.hitsToSelect` | 20 | 单个选项完全透明并提交所需命中数 |
| `CHOICES.width` / `height` | 720 / 200 | 航母题面及三个等宽命中区 |
| `CHOICES.successCrates` / `failureEnemies` | 2 / 2 | 选择题正确出箱、错误变敌机 |
| `SHELLS.flightSeconds` | 0.35–1.6 | 按目标距离限制跟踪弹飞行时间 |
| `SHELLS.arcRange` / `arcDistanceFraction` | 90–180 / 0.35 | 二次弧线控制点的偏移范围与距离比例 |
| `SHELLS.trailPoints` / `trailIntervalSeconds` | 12 / 0.035 | 每发预备尾迹点数与采样间隔 |
| `BOSSES.miniCrates` / `finalCrates` | 3 / 5 | 全部面答对后的奖励箱数 |
| `BOSSES.victorySeconds` | 5 | 大 Boss 全对后的自由拾箱倒计时 |
| `SUPPLIES.flightSeconds` | 0.75 | 收藏飞入 HUD 时间 |
| `REVIEW.secondsPerWord` | 10 | 每个不同失败词复习时间 |
| `LEARNING.pageSize` | 100 | 历史每页词数 |

普通飞机投放先检查完整作答预算，包含每格 0.75 秒输入锁定，不再为 Boss 预留冻结时段，不把临近结算的新题强行塞入。逻辑固定 120 Hz；暂停、失焦和卡顿不补发历史事件。正常结束帧先结算已判成功的题，再将所有已出现的剩余题记为没写完；不生成终点之后的箱子或普通题。

背景保留十七种背景每 15 秒一次、用完才洗牌的队列；月／地／日／银河参考半径为 22／64／180／400，包含装饰的最大宽高占视区 72%／60%，背景速度每秒 21 逻辑单位。所有值集中在 config.js。

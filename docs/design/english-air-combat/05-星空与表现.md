# 星空、美术与声音

[返回总览](../../README.md)

## 视觉目标

深蓝黑太空衬托飞机、积木弹和单词。战斗内容只保留倒计时、三类结果计数、得分、战斗炮弹、收藏、题面及中文释义；不在题块周围叠加教程、年级分类、进度数字或警戒线文字。

背景采用细星点、大光斑、银河点云、星球和星座连线五层：1200 个星点中包含 240 个中光斑、60 个大光斑；基础尺寸整体放大 1.45 倍，再按每颗星的固定随机值做 0.85–1.25 倍差异，大光斑约为 11–27 像素，使用柔和光晕与少量十字星芒，不密集闪烁。暖黄、冷蓝、琥珀黄及深红约占 36%／36%／18%／10%，每颗星的颜色固定，不随移动跳色。战斗和首页背景蒙版透明度分别为 0.52／0.28，较原值增加 10 个百分点；蒙版位于星空之上、玩法内容之下。星球采用明确的视觉尺寸梯度，使用十七个复用槽位承接相邻出场的天体，离开屏幕后隐藏。

首页右侧挖空词上方的随机敌方展示复用既有几何，在初始化阶段创建一个选中的模型并预热材质；小／大 Boss 分别保留四／五条触手并缩小，不在游玩中克隆、生成或编译。切入战斗时隐藏，返回首页复用同一个模型。

## 地球与星球体系

素材包括八颗行星以及作为额外矮行星外观的冥王星。九种星球、月球、太阳和银河及五种星座连线图共十七种背景进入同一个随机队列，地球与其他天体遵循相同规则，土星保留倾斜环。画面不作为真实天体位置、比例或轨道模拟。

地球采用 512×256 的程序纹理：项目自绘经纬轮廓表现主要大陆，深蓝海洋与青蓝浅海分层，陆地有绿色植被、暖色沙漠、海岸和极地冰盖，白色云带覆盖少量表面。共享球面外增加轻薄蓝色大气光晕。纹理与点云全部在 Worker 中生成，游玩时只更新现有对象。

银河是由 6000 个三维点构成的四条旋臂与明亮星核，使用冷蓝、淡紫及暖白过渡。倾斜的盘面缓慢下移和转动，无碰撞、遮挡输入或新增玩法效果。

## 星座连线图

追加北斗七星、射手座、猎户座、仙后座、天蝎座五种背景，分别保留勺形、茶壶形、腰带三星、W 形和弯钩形轮廓。星位是便于辨认的平面示意，不作为真实天球坐标、距离或完整星座边界。冷白亮星带柔和蓝晕，细蓝线连接；不加名称标签、不闪烁、不旋转变形，随背景缓慢下移。

星位、点径和连线顶点在 Worker 中生成，持久缓存并在开放操作前上传；十七个槽位共享五套点云和连线几何及两种材质，出场时只切换已预热资源。尺寸、颜色、透明度集中在 `BACKGROUND`；沿用背景蒙版、屏幕占比上限与首页右半边限制。

## 月球、太阳与视觉比例

新增月球和太阳，尺寸用于清楚表达“小卫星、普通行星、大恒星、广阔星系”的层次，采用压缩比例，不按真实天文比例缩放。参考半径集中在 `BACKGROUND.models`，单位为逻辑坐标：

| 天体 | 半径 | 相对地球直径 | 外观 |
| --- | --- | --- | --- |
| 月球 | 22 | 约 0.34 倍 | 灰白月面、深浅月海、46 个大小环形坑及坑缘明暗 |
| 地球 | 64 | 1 倍 | 蓝海、大陆、云层和大气光晕 |
| 木星 | 91 | 约 1.42 倍 | 气态条带，保持在太阳之下 |
| 太阳 | 180 | 约 2.81 倍 | 橙金色颗粒表面、少量暗斑、自发光外观和柔和日冕 |
| 银河 | 400 | 不作物理比例比较 | 四旋臂盘面，比原 308 半径放大约 30% |

其余行星半径为水星 42、金星 61、火星 49、土星 82、天王星 70、海王星 68、冥王星 36。太阳日冕外缘为球体半径的 1.3 倍，不使用真实光源照亮或漂白其他物体，不采用全屏泛光和快速闪烁。月面、太阳纹理均在 Worker 准备阶段生成，日冕材质与已有模型在可开始前预热。

含土星环、太阳日冕的外观包围宽度最多为可视区的 72%，高度最多为 60%；超过时只缩小装饰。银河按完整旋转外缘预留高度预算，在窄屏适当缩小，宽屏保留更大尺度。大模型横向位置向屏幕边缘内收，避免中心完全跑到屏幕外；背景蒙版和题面不透明底板维持可读性。

## 出场节奏与无放回轮换

每 15 秒安排一个天体入场，首个从本局 0 秒开始进入画面；一个天体入场不清除仍在画面中的其他天体。每轮将八颗行星、冥王星外观、月球、太阳、银河和五种星座连线图洗牌，十七种全部出现一次后才开始下一轮。轮内不重复，跨轮避免紧接着重复上一轮末项；每轮约 255 秒，但不按两分钟或固定总时长截断。

队列由背景种子与轮次确定，独立于出题随机流；每轮只重排十七个已有模型的标识，不生成新几何、纹理或 GPU 资源。横向位置和星球整数尺寸在开局前预备，运行时按包含光晕、土星环和银河旋转外缘的包围边界预留至少 24 个逻辑单位间距；优先调整新天体的横向位置，空间不足时在屏幕外增加进入距离，已入场天体不跳位或突然缩小。出场后连续下移直至离屏。首页参考半径达到 60 的大型天体（含银河）仅在右半边出现，连光晕／土星环也不越过中线；最大宽度收至视区的 42%，保留 16 个逻辑单位的中线间隔。小天体仍可在左侧出现，战斗场景使用全宽并遵循同一避让规则。菜单采用独立背景时间；开始新局从本局第一个随机天体重新播放，暂停冻结，重开复用内存。任意时间跳转可恢复对应轮次，队列缓存只保留当前及上一轮。

背景原始速度统一乘 0.7 后取整：星光从每秒 4–16 调为 3–11 逻辑单位，星球与银河从每秒 30 调为 21。星光移动跨度为 2400，银河外缘参考半径为 400；出场间隔独立于下移速度，不用加快模型来维持出场节奏。银河也按队列出现，不作为常驻模型提前重复显示。

## 前景可读性与渲染

Three.js 场景中在背景之后、飞机和弹体之前放置深蓝蒙版，战斗透明度 0.52、菜单为 0.28。蒙版只降低星空、银河和星球的亮度；单词 DOM、HUD、玩家、敌机与积木弹不被压暗。题块使用接近不透明的底板，英文和中文保持高对比度。

星点与银河使用点云，弹体使用 `InstancedMesh`，模型共享几何、材质与缓存。中文字使用系统字体，不下载字体或外部美术资源；默认无实时阴影、全屏后处理。预先创建字符格和点阵，填字只改变显示状态。

验证 0.5 秒与成功 1 秒通过边框颜色和缓慢亮度脉冲表达，不显示额外判题文案。减少闪烁时使用静态轮廓，状态持续时间不变。受伤保护不使用全屏白闪。

普通单词由带斜眉与小獠牙的咬题怪兽承载，文字保持正向，英文及中文增大 2 像素；满格字母显示紫色待定真字母并闪烁 0.75 秒，字符使用 550 字重，点阵颗粒稍加粗；Boss 使用可复用的紫色恶魔怪兽模型。小 Boss 为亮紫圆脸、双弯角、大眼睛、坏笑、小虎牙和三条卷曲触手；大 Boss 使用深紫色、四角头冠、额头宝石、蝙蝠翼和四条触手。触手带粉色吸盘，保持圆润玩具质感，不使用血腥或写实恐怖细节。所有怪兽几何、材质及触手在可开始前生成和预热，战斗只更新未处理面对应的触手数量、姿态及坐标，界面不叠加面数或 Boss 名称提示。选择题使用 Worker 预生成的共享顶点色航母，包含船体、飞行甲板、舰岛和跑道，三个等宽选项与命中区对齐。幸运箱采用开局前由金色礼箱 SVG 预绘的共享位图，带青绿色绑带及星徽，复用 16 个 DOM 槽。普通飞机／航母答对箱先慢晃两秒再按距离飞入 HUD，周期箱及 Boss 箱仍需碰触。

## 音效

通过 `src/audio.js` 的 Web Audio 实时合成，配置位于 `AUDIO`。默认主音量 0.35、无背景音乐，首次开始手势解锁音频；禁音或浏览器不支持音频不影响判题。

| 事件 | 表现 |
| --- | --- |
| 字母发射 | 轻短脉冲；音效合并限频到每秒最多 8 次，不能一颗建一个长期音源 |
| 字母构建完成 | 轻提示音，不表示答案已正确 |
| 撤销命中 | 短下滑音，无目标不连续报警 |
| 判题成功 | 柔和上行和弦，奖励到账同步库存变化 |
| 变敌机 | 低沉短音，与普通填字区分 |
| 炮弹／击毁 | 中低频发射与短爆炸，控制峰值 |
| 受伤 | 简短警示，保护期重复接触不重复播放 |
| 最后 10 秒 | 秒提示限每秒一次，避免持续噪音 |

声音以事件触发，不从每帧画面状态重复触发。暂停、失焦、首页和结算面板出现后停止所有声音并保持静音；通关和失败通过文字、图形反馈。声音不可用时保留文字、图形反馈，不把音频初始化失败当成游戏资源失败。

## 可爱反派与飞行道具

咬题怪兽、八爪鱼和红色小怪用上挑眼角、斜眉、卷角、小獠牙表达淘气与敌意，保持圆润身体、大眼睛与浅色脸颊。Boss保留双角／四角和蝙蝠翼造型；每完成一面，眉眼及嘴型逐步转为微怒、发怒，后期泛起少量紫红外光。外光不遮住题面、不引入全屏闪光。

玩家飞机以座舱玻璃、喷口、进气口、灯条和通风栅丰富层次；补给箱增加金属倒角和发光锁扣。回收残片使用不暴露答案的金属轮廓，护航战机、航标与缓慢旋转陨石共用预建矢量原型。装饰可转动，英文、中文和命中区域保持稳定；减少动态时静止。

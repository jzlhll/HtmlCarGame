# 词库、加权选词与学习数据库

[返回总览](../../README.md)

## 教材范围

目标为沪教版新版一年级起点、一至六年级与初中词汇，保持三至六练习 80%、一至二练习 5%、初中拓展 15%。数字六年级只归高小组，不因五四学制重复计入初中。正式教材档案须包含真实出版社、版次、起点、学制、册别、单元与来源，不能把练习难度当教材年级。

当前提供 191 个练习词，全部保留 `verified:false`、`bookId:null`，`practiceBand` 仅为项目练习难度。沪教新版全册逐册核验仍未完成，首页与说明保留这一限制，不声称全册覆盖。规范显示词形保留 Chinese、English、China、星期、Earth、USA、UK 等大小写；词条 id 不随大小写调整改变。

## 每关词池

每关固定 12 个不同词，难度相同、只改变关卡编号。目标比例为三至六练习 80%、一至二练习 5%、初中拓展 15%。使用带种子的随机起点等距分配：12 词中的三组数量分别为 9–10、0–1、1–2，单关总计仍为 12；多关长期保持目标比例。同种子结果可复现，组内继续无放回加权选词，不改变教材来源状态。

在组内按历史单词正确率作为概率权重，逐次无放回选取，同一词池不重复词条。下一局入选权重：正确率严格高于 50% 为 0.5，高于 75% 为 0.25，高于 85% 为 0.01，未超过或无记录为 1，只取最高档、不相乘。正确率包含成功、写错和没写完。该权重用于下次组词，本局普通飞机与 Boss 共用已定词池，每轮用完才洗牌重用。

## 三类独立记录

每架普通飞机及 Boss 每面为一个独立统计单位，产生唯一尝试标识；同词一局出现多次就保存多条明细。分类为成功、写错、没写完：填写完整且正确为成功，完整但不正确为写错，漏掉、Boss 超时或局末未完成为没写完。撤销重做过程中不提前记错，变形后的邪恶飞机不重复记词。

每条保存账号 id、词池 id、词条 id、规范单词、中文、填写内容、分类、关卡、是否 Boss 面、本局 id 与时间。另存逐词累计成功／写错／没写完，以三者合计为分母计算历史正确率。

## 数据库与历史

每账号独立的学习库使用 `words`、`attempts`、`runs` 三个对象仓库；每次结算单事务保存本局明细、逐词汇总和局完成标记。按局去重，事务失败不留下部分记录；汇总在事务内读取当前值后加本局增量，避免多标签覆盖已有次数。

写入前保存可重试批次；刷新重试已完成的局不会重复累计。旧版无账号学习汇总和明细直接清理，不迁入新账号。账号的设置、成绩、关卡、复习锁定、十二词状态及历史分别隔离；旧默认账号条目移除，已创建账号继续使用各自学习库和存档，其他游戏数据保持独立。存储不可用明确降级本页内存，写入未完成显示暂存状态。

首页学习记录仅显示当前账号，每页 100 个词，按写错加没写完次数降序，同次数按最近练习排序。列为单词（中文）、成功（绿）、写错（红）、没写完（橙）、播放；点击单词查看该词各次独立明细。左右翻页保留总数量与页码。

朗读使用浏览器 SpeechSynthesis，优先 Samantha 等自然英语声音，排除特效和低沉音色，朗读速率为 0.75，方便听清发音，略提高音调。点击才播放；切词、离开列表、开局和失焦取消旧请求，没有英语语音时提示系统安装，不下载音频文件。参考 [浏览器语音能力](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)。

## 重置学习记录

学习记录顶部提供重置按钮，首次点击只打开确认说明，取消或 Escape 返回列表且不写数据；必须再点击“确认清空”才执行。清理范围仅为当前账号的单词累计统计、每次作答明细、学习库的局去重标记、旧学习缓存及待入库批次，下一局选词恢复默认概率。账号、十二词记录、成绩、关卡进度、设置、模型缓存及其他账号／游戏数据保留，复习锁不能借重置绕过。

清理前等待本局保存完成，数据库清理复用现有串行队列，在同一事务中清空三个学习仓库；清理期间禁止重复提交及界面操作。成功后刷新为空列表，失败明确提示可重试，不冒充清理成功。调试重置只影响当前 TEST 账号，不影响普通账号。当前未结算的游戏结束后仍会按正常规则产生新记录。

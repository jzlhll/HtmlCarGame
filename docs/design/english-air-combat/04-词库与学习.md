# 分阶段词库、例子与独立学习记录

[返回总览](../../README.md)

## 四个阶段

首页登录后提供词库选择，依次为小六、初中进阶、英语四级、英语六级。每个阶段使用自己的词表和学习记录；词量不是难度的唯一判断依据，按分级课标与对应阶段资料选词，不按字母顺序截断凑数。

| 词库 | 词数 | 定位 |
| --- | ---: | --- |
| 小六 | 500 | 小学日常主题、数词与月份等基础表达 |
| 初中进阶 | 2200 | 小学基础、初中核心与衔接拓展 |
| 英语四级 | 6259 | 官方大纲四级基础部分，含派生词与拼法展开 |
| 英语六级 | 1718 | 官方大纲星号六级新增部分，含派生词，不重复四级基础拼写 |

小学与初中分级参考《义务教育英语课程标准（2022 年版）》及阶段词表；初中进阶 2200 为本项目的选编规模。大学词形与分级以《全国大学英语四、六级考试大纲（2016年修订版）》为准，释义与例子采用固定版本开源语料和原创修订，来源、筛选范围和 BSD-3-Clause 许可见[来源说明](../../../third-party/english-vocabulary/SOURCE.md)。不声称逐册覆盖某版教材。官方词目按同行主词、派生词及合法英美拼法展开，同形跨级归基础级，单字母、短语、连字符和明确排印错误排除；游戏拼写数不等于官方原始词目数。六级是新增进阶库，不是四级累计全集。跨词库可有相同拼写，每个词库均去重，学习映射由词库与词条 ID 确定。

每个词条包含稳定 ID、词库 ID、规范英文、中文释义及 `example`（大学与初中条目另保留对应 `partOfSpeech`）。例子必须包含英文、准确中文及 phrase／sentence 类型，并与展示释义采用同一义项；单义项优先短语，没有合适短语时用完整句子；像 spring 的“春天／泉水／弹簧”这类常用且差异明显的多义词，保留各义项并分别提供英中例句，不用一个例子代替所有义项。保留星期、国家、语言等规范大小写，不能把人名中的同形词当普通词的用法。

## 卡片

预习横滑卡片显示单词、中文、常用短语或例句及其中文；多义词按义项逐组显示英中例句；按释义长度、例子数量和英中总文本量自动采用普通、紧凑或密集排版，优先完整展示，内容超过可用高度时滚动浏览卡片，导航与开始按钮保持可见；每关仍须完整看过十二张卡片才能开始。强制错词复习同样显示例子，计时与锁定不变。复习完成后的通关页可以用左右按钮或方向键浏览本关全部十二张词卡，朗读按钮播放当前单词。

战斗题面保持单词、释义和必要选项，不把短语叠加到射击目标上。长单词使用准备期预建的字位，题面收缩到逻辑画面可用宽度；不在飞行中增加 DOM 或点阵节点。

## 每关词池与权重

每关从当前词库固定抽取十二个不同词，关卡编号递增但同一词库内不额外提高战斗难度。普通拼写、选择题和 Boss 共用词池，用完才重复。选择题干扰项也仅来自当前词库。小六沿用基础／主组／拓展分组配额，其余词库在本库内加权无放回抽取。

正确率包含成功、写错和没写完。历史正确率严格高于 50%／75%／85% 时，后续入选权重分别为 0.5／0.25／0.01，只取最高档、不相乘；无记录为 1。切到另一词库后，即使同词曾在其他库练习，也不继承正确率和权重。

预习前保存当前账号、词库、关卡、种子和十二词 ID。未完成或重玩沿用原词，新关重新抽取。切库后显示该库自己的关卡进度；切回恢复它自己的词池和记录。不能在战斗、暂停或强制复习期间切换词库。

## 学习映射与数据库

每次普通题或 Boss 面产生唯一尝试 ID，分类为成功、写错、没写完；同词多次出现保留多条明细，变形敌机不重复记词。明细和局结果均包含 accountId、libraryId、wordId，并保存规范拼写、释义、例子、答案、题型、关卡、局 ID 和时间。

学习库按“账号＋词库”隔离，使用 words、attempts、runs 三个仓库；局末单事务更新汇总、写入明细和局标记，按局去重。待写入数据可重试，切换前等待保存及数据库队列完成，外来账号、词库或词条的结果被拒绝。无旧记录迁移，不从原来未分词库的学习快照导入。

账号名称、音量、画质等设置属于账号；成绩、关卡进度、复习、词池、汇总和明细属于账号下的当前词库。设置对象原地更新，切换词库不重新生成共享模型。

学习记录标题显示当前词库。每页一百词，按写错加没写完次数降序，同次数按最近练习排序；点击单词查看按时间倒序的逐次明细。重置须二次确认，只清理当前账号当前词库的学习汇总、明细、局去重标记及待入库批次，保留其他词库和账号、词池、成绩、关卡与设置；复习锁不能借重置绕过。

朗读按需使用浏览器自然英语声音，rate 为 0.75；切词、离开列表、开局或失焦取消旧请求，不下载音频。存储不可用时明确提示本页暂存，不声称持久保存成功。

官方分级清单与逐项排除原因保存于 `scripts/data/cet-official-2016.js`，提取器按原 PDF 指纹和字符基线重建；不会直接把 PDF 连写或尾词缩写当作可学习拼写。释义、词性和例子直接维护在游戏词库中；导入保留已有词条内容，仅为新增词形补充内容。

仍在同库的词保持 ID；小学旧练习词沿用 `practice-*`，新增小学词及其他阶段采用“词库＋小写拼写”。重新分级后失效的旧十二词词池会按已有校验重新抽取，旧学习数据不跨词库迁移，不清理账号和其他游戏缓存。

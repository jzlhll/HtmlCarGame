# 总体玩法与操作

[返回总览](../README.md) · [车辆规格](02-车辆规格与速度.md) · [碰撞规则](03-碰撞与成长.md)

## 核心体验

玩家在不断向前延伸的道路上保持生存：利用自动提速与主动刹车把目标车调整到自身侧面，纵向重叠足够后横移完成吞吃；直接撞上车尾中央按追尾处理，轻微擦角只做横向分离。

初版从一级自行车开始，默认处于右侧同向道路的中间车道；只有两条同向车道时，默认靠中间隔离带的一条。每局重新生成随机种子，第一段为 240 米六车道直道，起步前方保留至少 100 米可行驶空间。

## 视角与位置

- 初版采用低多边形风格、俯视斜向透视。
- 玩家车身中心保持在屏幕高度约 78% 处，允许横向移动与小幅倾斜，不主动向屏幕上方跑远。
- 玩家在逻辑道路中持续前进，画面通过跟随相机与相对坐标产生运动，不因此将玩家逻辑速度设为零。
- 相机跟随道路切线平滑转向，轻微横向跟随但不完全抵消玩家转向。
- 后方保留可见道路并布置后方车流；减速后可能被后车追上，右侧显示正后方、左后方或右后方来车及距离。
- 玩家可越过中央双线进入对向车道，车头仍朝原方向；对向车道适用与同向相同的侧碰、追尾与等级规则，详见[碰撞规则](03-碰撞与成长.md)。

## 操作

| 输入 | 行为 |
| --- | --- |
| 空格 | 待机时开始；行驶时暂停；暂停时继续；结算时直接开始新一局；通关界面进入第二关 |
| 左右方向键 | 按住连续横向移动，松开停止横移；同时按下相互抵消 |
| 下箭头 | 按住减速，最低到零；不支持倒车 |
| 上箭头 | 低速按住普通加速不耗气；达到车型最高速后持续按住自动喷气，极速仍耗气，松开保留气量 |
| 松开下箭头 | 无道路刮擦且未冰冻时每秒自动提高 20 km/h，直到当前车型有效上限；刹停后也会自动起步 |
| 暂停窗口“结束游戏” | 点击后主动结束本局并结算 |
| 手机左侧摇杆 | 左右拖动连续横移，中心设死区，松手回中；上下拖动不加减速 |
| 手机右侧刹车 / 加速·氮气 | 按住对应下 / 上箭头规则；支持与摇杆同时操作，松开停止对应操作 |
| 手机顶部暂停 / 重置 | 暂停后可点击继续；重置直接生成新一局，放弃当前未结算成绩，保留排行榜及座驾颜色 |

### 手机浏览器

优先通过 `pointer: coarse`、浏览器移动设备标识及触控设备信息识别手机和平板；宽度不超过600 CSS像素的窄窗口也启用紧凑布局和触屏操作。手机采用竖屏，使用实际可视窗口高度适配约1:2及更长的屏幕，不固定画布比例；浏览器地址栏伸缩时同步调整，并避开刘海与底部手势安全区。横屏时暂停当前行驶并显示竖屏提示，转回竖屏后手动继续。

顶部暂停、重置按钮距顶部安全区 2 CSS 像素，左右仪表列顶部统一距顶部安全区 64 CSS 像素。竖屏仪表拆分为左右两侧的半透明竖列：左侧依次显示距离、时间、速度，右侧依次显示车型成长、防御、氮气，中央不铺设信息栏背景，保留远处道路视线。底部左侧为半透明固定摇杆，右侧为刹车与加速 / 氮气圆形按钮；操作时提高对比度。相机在窄屏扩大纵向视野，保留横向道路与底部操作区上方的玩家车辆。开始、继续、再来一局和答题均可点按完成，详细玩法可在首页展开。

每个触点独立跟踪，拖出操作区域仍保持当前操作，松手、触摸取消、丢失捕获、暂停、答题、重开、页面隐藏或失焦时清空触控状态，避免残留转向、刹车和氮气。

方向键采用连续位移而非切换相邻车道；侧碰吞吃需控制双方车头与车身的前后位置，也能在相邻车道间微调。车头始终朝向道路前进方向，没有漂移偏转；不提供自由转向角或掉头。

游戏按键在页面层捕获，页面获得焦点时仍可接收左右、下箭头和空格，并恢复游戏区域焦点；输入框、文本编辑区域和浏览器组合快捷键不接管，方向键与空格不触发浏览器默认动作，忽略按键自动重复导致的暂停切换。弹窗按钮拥有焦点时，空格仍由游戏状态处理。

玩家自动跟随道路曲线：松开左右键时保持相对道路中心线的横向偏移，沿弯道继续前进，不会因未打方向冲出普通弯道；左右键只改变该偏移，不直接控制车头转角。道路收窄、外沿刮擦、碰撞侧移仍可改变横向位置，突然截止的实体墙不因自动跟弯而被绕过。

系统车辆生成后保持固定巡航，不主动避让玩家。变道前先显示目标方向的转向灯，初版至少预告一秒，随后约 1.5 秒平滑完成横移，预告和动作不构成让行。生成、避让与危险车辆规则详见[车辆规格](02-车辆规格与速度.md)。

## 状态与窗口

| 状态 | 展示与运行 | 允许的离开方式 |
| --- | --- | --- |
| `READY` | 标题、最佳成绩、操作说明、座驾颜色及调试勾选；道路静止 | 空格准备本局 |
| `PREPARING` | 创建道路计划和对象池，显示短暂准备提示 | 准备成功自动进入 `RUNNING`；失败回待机并提示 |
| `RUNNING` | 行驶、交通、碰撞、季节与计分运行 | 空格进入 `PAUSED`；第一关满 3 分 30 秒进入 `LEVEL_EXIT`；前两次致命事件进入救援 `QUIZ`，两次救援用完后进入 `DYING`；被网抓进入 `CAUGHT`，碰警车进入 `QUIZ` |
| `LEVEL_EXIT` | 第一关最后 5 秒倒计时后安全达到 3:30：固定镜头、清空车流，玩家模型自动前行 3 秒；有效时间与成绩冻结，静音 | 动画完成进入 `LEVEL_CLEAR`；失焦暂停动画，驾驶与空格不响应 |
| `LEVEL_CLEAR` | 显示“恭喜！通过第一关。”，全场冻结且静音 | 新按空格或点击“进入第二关”；长按不跳过，失焦不自动继续 |
| `PAUSED` | 半透明深色遮罩覆盖整个游戏，中央暂停窗口 | 空格继续；点击“结束游戏”进入 `RESULT` |
| `DYING` | 冻结本局逻辑与成绩，仅播放死亡表现 | 普通局或答题失败时动画结束进入 `RESULT`；调试局非答题死亡恢复当前车辆，失焦时进入 `PAUSED` |
| `CAUGHT` | 冻结逻辑，播放渔网收拢动画 | 动画结束进入 `QUIZ` |
| `QUIZ` | 冻结驾驶逻辑，显示题目及真实时间倒计时，数学45秒、语文与英语30秒 | 警车题答对继续，救援题答对复活（失焦则暂停）；答错或超时进入 `DYING`，结算展示原题及填回的正确答案 |
| `RESULT` | 展示距离、分数、最高等级、吞吃数与结束原因 | 空格准备新一局；点击“返回”进入 `READY` |

暂停窗口文案：“游戏已暂停”“按空格继续”，提供“结束游戏”按钮；遮罩拦截画布上的鼠标事件，窗口后方道路和车辆全部冻结。

窗口失焦或页面隐藏时从行驶状态自动进入暂停，清空所有方向键按下状态，回到页面后不自动继续；离开页面不弹额外确认，也不保证保存未结束的一局。暂停不增加距离、升级进度及侧移、氮气、饥饿、季节、减速、交通生成计时；继续时从暂停前速度恢复，未刹车且无道路刮擦时逐渐自动提速。

## 调试模式

首页提供“调试模式 · 死亡后复活”勾选项，默认关闭，只保存在当前页面内存，不写入 localStorage；本局开始时固定所选模式，只有返回首页才能切换。另提供独立的“调试 · 直接进入第二关”勾选项，默认关闭；勾选后按空格或开始按钮直接从第二关全新开局，并使用调试规则、不写排行榜。重置或再来一局继续从第二关开始，取消勾选后恢复从第一关开始。两项勾选独立保存在当前页面内存，换色或返回首页保留，刷新恢复默认。结算页不显示调试模式开关或调试局不计入排行榜的提示。

调试局跳过全部答题，警车或渔网接触直接按答对放行，不播放被抓动画、不生成题目或启动倒计时。前两次致命事件仍各消耗一次救援机会，但直接按答对原地复活；之后非答题死亡播放完整约 1.2 秒动画，再恢复死亡时的车型和位置，不重新生成道路或车流，保留本局距离、有效时间、吞吃统计和剩余氮气。总积分至少恢复到当前车型门槛，已有更高积分保留并封顶 54，饥饿计时重新开始；清除横向冲量和坑洞弹跳，车速至少恢复为开局速度且遵守当前车型与泥巴限速。

恢复时清空当前路线前方50米内的车流，沿路线实际弧长量距，副路出口后接主路；后方车辆、50米外车辆及分离的另一条路线保持原状。恢复后闪烁并保护两秒，以有效行驶时间计时，暂停冻结。保护覆盖车辆、天降炮弹与天气落点、奶牛、截止墙、施工封闭区、坑洞、泥巴接触及饥饿事件，到期恢复普通检测；保护期间不吞吃，原有同级追尾保护规则保持独立。复活清空按键及死亡效果；页面有焦点时自动继续，失焦或隐藏时进入暂停，需按空格继续。

调试局非答题死亡不进入结算，所有答题入口直接判定通过，所有调试局均不写成绩；主动结束显示结算但不写入排行榜。结束或返回首页后仍可重新选择模式，勾选状态保留。

## 界面信息

左侧状态面板显示行驶距离、运行时间、速度、车型、统一总积分进度、防御百分比及氮气条。车型只显示名称，积分显示“当前总积分 / 下一车型门槛”；坦克显示“54 / 54”，进度条最多填满；自行车负分按实际值显示，进度条为空。不显示耐久格、基础或额外积分标签、“分”单位及独立饥饿条。吞吃统计放在结算中，排行榜仍按距离计分。

短提示用于答题或调试复活、答题放行及启动失败，不挡住玩家车身与尾部。吞吃回气、坑洞减速、泥巴限速、追尾减速和路边刮擦不弹提示；升级车型、受击降级、饥饿扣分及饥饿降级也不弹提示，车型与积分在左侧面板正常更新。收窄、截止墙和施工只用场景标志预警，不弹文字提示；右侧后方接近提示保留。车辆不显示 LV 或等级标识，进入对向车道不额外提示。行驶界面不显示季节文字、换季倒计时或右侧悬浮操作面板；隐藏鼠标指针和文本插入光标，禁止选择游戏界面文字，弹窗按钮保留正常鼠标操作。

## 吞吃回气与喷气

吞吃车辆按车型回气，每级补充半管氮气（封顶两管）；同方向持续侧移超过 0.4 秒时吞吃，回气翻倍。未到最高车速时按住上箭头普通加速不耗气；达到车型最高速后持续按住自动喷气，达到喷气上限仍持续耗气，每管可喷 2.8 秒，满两管连续 5.6 秒，每秒额外提速 70 km/h，各车型喷气最高速度统一为 215 km/h；松开保留剩余气量，超出正常上限的速度用 0.35 秒回落，允许立即再次喷气。喷气期间低级追尾按吞吃处理并获得积分与回气，同级追尾只撞飞目标，不扣分、不降级、不减速；同级侧碰仍吞吃。泥巴限速仍优先，暂停冻结，详见[横移与氮气](09-横移与氮气.md)。

## 成长与饥饿

成长积分开局为 1，吞吃加目标价值；饥饿每 10 秒按扣分发生时的实际车型扣 1／1／2／6／18，只记录截止时间不缓存扣分量，吃车重新计时。车型门槛为 1／2／6／18／54，吞吃与普通扣积分保留实际积分，总分封顶 54，满级吞吃仍计数量及重置饥饿计时。闪电与天降炮弹等远程伤害使用独立防御，防御清零则积分固定到低一级门槛并换车，自行车耗尽直接死亡；只有实际换车型才补满防御，同车型吞吃不回血。降级均保护两秒，自行车普通扣积分仍允许到 −2，低于 −2 才死亡。暂停冻结、零速继续，详见[成长积分与饥饿](10-成长与饥饿.md)。

## 死亡与主动结束

普通局每局前两次致命事件各转入一次救援答题，数学45秒、语文与英语30秒；答对原地复活，保持车型和本局成绩，恢复当前车型满防御、积分至少恢复到该车型门槛，重置饥饿，清空当前路线前方50米内的车流并保护两秒（含墙、道路障碍及警车）。救援资格在出题时消耗，两次机会用完后第三次死亡直接结束。警车题或救援题答错、超时均直接结束，不再触发救援，调试模式跳过答题并直接按答对处理。新局恢复两次救援机会。

致命碰撞当帧锁定成绩，立即停止碰撞、生成、距离和成长计算。初版死亡动画约 1.2 秒：撞击闪光与短促震动，爆炸烟尘、车身缩小淡出；动画只影响表现，不能继续吞吃或计分。

死亡表现不包含人物受伤。结算窗口区分追尾、侧碰高级车辆、撞墙和饥饿死亡等结束原因。

主动结束直接结算，记录原因 `quit`，不播放死亡动画。普通局结算只提交一次；调试局不写入存档。结算界面按空格准备新一局，不重复保存上一局；替换弹窗时将原弹窗内的焦点移回游戏容器。

## 第二关

第一关最后 5 秒在顶部显示通关倒计时，满 3 分 30 秒且安全时固定镜头、清空车流，玩家模型自动驶离后显示通关界面。空格或触屏进入第二关，完整从零开局，仅保留涂装和调试设置，结算只计算当前关成绩。第二关为灰色砂土道路、荒原与绿洲，新增系统装甲坦克和恐龙，详细概率、模型、碰撞与声音规则见[第二关与荒原恐龙](第二关-总览与关卡衔接.md)。

# 总体玩法与操作

[返回总览](../README.md) · [车辆规格](02-车辆规格与速度.md) · [碰撞规则](03-碰撞与成长.md)

## 核心体验

玩家在不断向前延伸的道路上保持生存。观察附近交通，利用自动提速与主动刹车把目标车调整到自身侧面，纵向重叠足够后横移完成吞吃；直接撞上车尾中央按追尾处理，轻微擦角只做横向分离。升级后车身与操控变化，继续跑更远的距离。

初版从一级自行车开始，默认处于右侧同向道路的中间车道；只有两条同向车道时，默认靠中间隔离带的一条。每局重新生成随机种子，第一段为 240 米六车道直道，起步前方保留至少 100 米可行驶空间。

## 视角与位置

- 初版采用低多边形风格、俯视斜向透视，既能看清车头车尾，也能看见前方道路。
- 玩家车身中心保持在屏幕高度约 78% 处，允许横向移动与小幅倾斜，不主动向屏幕上方跑远。
- 玩家在逻辑道路中持续前进；画面通过跟随相机与相对坐标，让赛道、景物、车辆产生运动。不能因为画面固定就将玩家的逻辑速度设为零。
- 相机跟随道路切线平滑转向，轻微横向跟随但不完全抵消玩家转向，否则会看不出横移。
- 后方保留可见道路，方便看清自身尾侧目标。所有同向车道均布置后方车流，包括玩家当前车道；减速后可能被后车追上，右侧显示正后方、左后方或右后方来车及距离。
- 左侧道路上的对向交通向玩家迎面而来，与右侧同向交通形成明确方向差异。
- 玩家可以越过中央双线进入对向车道，车头仍朝原方向；对向车道采用相同侧碰、追尾与等级规则，可以侧碰吞吃低级车；自行车可吞吃同级自行车，氮气喷气期间同级侧碰吞吃，其他时候各按自身车宽两倍惯性弹开，再缓慢收尾；玩家 1.5 秒内不能左右控制。

## 操作

| 输入 | 行为 |
| --- | --- |
| 空格 | 待机时开始；行驶时暂停；暂停时继续；结算时直接开始新一局 |
| 左右方向键 | 按住连续横向移动，松开停止横移；同时按下相互抵消 |
| 下箭头 | 按住减速，最低到零；不支持倒车 |
| 上箭头 | 按住消耗连续气量喷气加速，松开保留余量；阻止浏览器默认导航 |
| 松开下箭头 | 无道路刮擦时每秒自动提高 6 km/h，直到当前车型有效上限；刹停后也会自动起步 |
| 暂停窗口“结束游戏” | 点击后主动结束本局并结算 |
| 结算窗口“返回” | 点击返回待机，下一局仍需按空格开始 |

方向键采用连续位移，而不是瞬间切换到相邻车道。侧碰吞吃需要控制双方车头与车身的前后位置，也能在相邻车道之间微调。车头始终朝向道路前进方向，没有漂移偏转；不提供自由转向角或掉头。

游戏按键在页面层捕获，焦点移到页面本身时仍可接收左右、下箭头和空格，并恢复游戏区域焦点；输入框、文本编辑区域和浏览器组合快捷键不接管。Z 进入按住状态，上箭头只处理首次按下的释放事件，不进入按住状态或触发浏览器默认动作。浏览器窗口失焦或页面隐藏时清空按键并暂停，回到页面后由空格继续。

玩家自动跟随道路曲线。松开左右键时，保持相对道路中心线的横向偏移，沿弯道继续前进，不会因未打方向冲出普通弯道；左右键只改变该偏移，不直接控制车头转角。道路收窄、外沿刮擦、碰撞侧移仍可改变横向位置，突然截止的实体墙不因自动跟弯而被绕过。

路上系统车辆生成后保持固定巡航，不因前车或玩家跟车减速。普通车辆只在临近其他系统车或道路障碍碰撞时闪灯避让，保留原有随机变道开关；独立 15% 概率生成危险车辆，定期主动换道且不检查目标空隙。所有系统车均不主动避让玩家，系统碰撞按等级撞毁低级车或同级弹开。

系统车辆变道前先显示目标方向的转向灯，初版至少预告一秒，随后约 1.5 秒平滑完成横移。预告和动作不构成对玩家的让行，玩家仍需观察并避让。

页面层捕获游戏按键并恢复游戏容器焦点，保留文本编辑和浏览器组合快捷键。空格、方向键与 Z 阻止页面默认动作，忽略按键自动重复导致的暂停切换；弹窗按钮拥有焦点时，空格仍由游戏状态处理，避免误触“结束游戏”。点击结束按钮是主动结束入口。

## 状态与窗口

| 状态 | 展示与运行 | 允许的离开方式 |
| --- | --- | --- |
| `READY` | 标题、最佳成绩、操作说明及调试勾选；道路静止 | 空格准备本局 |
| `PREPARING` | 创建道路计划和对象池，显示短暂准备提示 | 准备成功自动进入 `RUNNING`；失败回待机并提示 |
| `RUNNING` | 行驶、交通、碰撞、季节与计分运行 | 空格进入 `PAUSED`；致命碰撞进入 `DYING` |
| `PAUSED` | 半透明深色遮罩覆盖整个游戏，中央暂停窗口 | 空格继续；点击“结束游戏”进入 `RESULT` |
| `DYING` | 冻结本局逻辑与成绩，仅播放死亡表现 | 普通局动画结束进入 `RESULT`；调试局恢复当前车辆并继续，失焦时进入 `PAUSED` |
| `RESULT` | 展示距离、分数、最高等级、吞吃数与结束原因 | 空格准备新一局；点击“返回”进入 `READY` |

暂停窗口文案：“游戏已暂停”“按空格继续”，并提供清晰的“结束游戏”按钮。遮罩拦截画布上的鼠标事件，窗口后方的道路和车辆全部冻结。

切换标签页或窗口失焦时，从行驶状态自动进入暂停。清空所有方向键按下状态，回到页面后不会自动继续。离开页面不弹出额外确认，也不保证保存未结束的一局。暂停不增加距离、升级进度、侧移计时、氮气计时、饥饿计时、季节计时、减速计时或交通生成计时；继续时从暂停前速度恢复，未刹车且无道路刮擦时逐渐自动提速。

## 调试模式

开始前的首页与结算页提供“调试模式 · 死亡后复活”勾选项，默认关闭。选项只保存于当前页面内存，刷新后恢复默认，不写入 localStorage；本局开始时固定所选模式，行驶和暂停期间不能切换。

调试局仍按普通规则发生死亡并播放完整约 1.2 秒的动画，动画结束后恢复死亡时的车型和位置，不重新生成道路或车流，保留本局距离、有效时间、吞吃统计和剩余氮气。总积分至少恢复到当前车型门槛，已有更高积分保留并封顶 54，饥饿计时重新开始；清除横向冲量和坑洞弹跳，车速至少恢复为开局速度且遵守当前车型与泥巴限速。

恢复后闪烁并保护两秒，以有效行驶时间计时，暂停冻结。调试复活保护覆盖车辆、射弹、奶牛、截止墙、施工封闭区、坑洞、泥巴接触及饥饿事件，保护到期恢复普通检测；保护期间不吞吃。原有同级追尾保护规则保持独立。复活清空按键及死亡效果；页面有焦点时自动继续，失焦或隐藏时进入暂停，需按空格继续。

调试局死亡不进入结算，也不写成绩；主动结束显示结算但不写入排行榜。结束或返回首页后仍可重新选择模式，当前页面内的勾选状态保留。

## 界面信息

左侧状态面板显示行驶距离、运行时间、速度、车型、统一总积分进度及氮气库存／集气条。车型只显示名称，积分显示“当前总积分 / 下一车型门槛”，例如“8 / 18”；坦克显示“54 / 54”，进度条最多填满。自行车负分按实际值显示，进度条为空。不显示耐久格、基础或额外积分标签、“分”单位，不增加独立饥饿条。吞吃统计放在结算中，排行榜仍按距离计分。

短提示用于奶牛接触及调试复活，不挡住玩家车身与尾部。吞吃回气、坑洞减速、泥巴限速、追尾减速和路边刮擦不弹文字提示，保留实际效果与车身表现。升级车型、受击降级、饥饿扣分及饥饿降级不弹提示，车型与积分在左侧面板正常更新；渐进收窄不显示文字提示，截止墙和施工封闭的文字预告各显示 2.5 秒，同一处只提醒一次；右侧后方接近提示保留。车辆上不显示 LV 或等级标识，用户通过车型外观自行探索。进入对向车道不额外弹出提示。行驶界面不显示季节文字、换季倒计时或右侧悬浮操作面板；隐藏鼠标指针和文本插入光标，禁止选择游戏界面文字，弹窗按钮保留正常鼠标操作。

## 吞吃回气与喷气

吞吃任何一辆车补充半管氮气；同方向持续侧移超过 0.4 秒时吞吃，回气翻倍为一整管。按住上箭头低速加速及持续喷气，每管可喷 3.5 秒，满两管可连续喷气 7 秒，每秒额外提速 70 km/h，最高速度提高 66%；松开保留剩余气量，超出正常上限的速度用 0.35 秒回落，允许立即再次喷气。泥巴限速仍优先，暂停冻结，详见[横移与氮气](09-横移与氮气.md)。

## 成长与饥饿

成长积分开局为 1，吞吃加目标价值；饥饿每 10 秒按扣分发生时的实际车型扣 1／1／2／6／18，只记录截止时间，不提前缓存扣分量，吃车重新计时。车型门槛为 1／2／6／18／54，吞吃与普通扣积分保留实际积分，总分封顶 54，满级吞吃仍计数量及重置饥饿计时。射弹使用独立防御，防御清零则积分固定到低一级门槛并换车，自行车耗尽直接死亡；只有实际换车型才补满防御，同车型吞吃不回血。降级均保护两秒，自行车普通扣积分仍允许到 −2，低于 −2 才死亡。暂停冻结、零速继续，详见[成长积分与饥饿](10-成长与饥饿.md)。

## 死亡与主动结束

致命碰撞当帧锁定成绩，立即停止碰撞、生成、距离和成长计算。初版死亡动画约 1.2 秒：撞击闪光与短促震动，车身拆散、爆炸烟尘，残骸缩小并沿道路远离，最后淡出。动画只影响表现，不能继续吞吃或计分。

自行车表现为车架与车轮破碎，机动车表现为车身爆炸损毁；不表现人物受伤。结算窗口区分追尾、侧碰高级车辆、撞墙和饥饿死亡等结束原因。

主动结束直接结算，记录原因 `quit`，不播放死亡动画。普通局结算只提交一次，避免连续点击造成重复存档；调试局不写入存档。结算界面按空格直接准备新一局，不重复保存上一局；替换弹窗时将原弹窗内的焦点移回游戏容器，点击结束后仍可使用空格。

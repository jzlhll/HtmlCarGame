# 实施规划

[返回总览](../README.md)

## 当前交付

已具备广州、长沙、武汉三关完整航线与共用机场：四秒入舱、六项自由准备及条件点火／放行、手动变速起飞与巡航、进近、放轮并打开减速板、安全接地、刹车滑行和跑道内停稳胜利。初始爬升不再提前结算。

已接入近山峡谷、河流瀑布、田野、城市地标、村庄、丹霞山、张家界悬空瀑布、橘子洲石像、洞庭湖、黄鹤楼与当前目的地机场，飞机与山体／建筑／交通目标碰撞，瀑布一次性奖励，显示9900米的硬限高与循环地景，迎面大雁及不同航向飞机遭遇。导航显示真实轨迹、五星目的地和方向雷达，危险有闪烁与合成短音，暂停与结果静音。

已接入75%白云／25%移动乌云、云内能见度和雷达规则，以及低概率雷击、加速故障、3秒警报与仪表旁故障标志。

已接入倒数、开关／锁扣、启动／发动机推力、风、轮胎／刹车及收放电机合成音效，环境声与本地英文播报默认开启，无声音开关；暂停／失焦／结算取消声音。语音接口已接入，统一女声音色仍待实际设备验收。

全部玩法参数仍为固定虚构客机预设，不增加重量或机场性能表单。姿态限速控制、独立前进速度与垂直航迹积分，不宣称完整六自由度或真实机型性能。完整边界与数值见[航程专题](07-航线与关卡.md)。

## 后续工作

1. 实际设备试听并微调混音，确认英文女声音色与跨设备降级效果。
2. 在已实现白云／乌云、视距与雷达影响、雷击故障基础上扩展降水和更多天气。
3. 气流与路面类型分别扩展风推力和地面摩擦／滚阻。
4. 在已实现的固定槽位循环与细节层级基础上，继续按实测瓶颈优化更长航程。
5. 标点键观察、辅助键盘示意和渐隐提示，保持英文主标签与中文辅助。

自动驾驶、真实空管、真实航图与更复杂故障另行设计；当前确定性交通遭遇不等于空中交通管理系统。首版不提供存档或排行榜。

## 开发原则

保持原生 ES Modules、锁定 Three.js 与本机 HTTP 服务；逻辑、共用世界数据、地景渲染、交通渲染、导航、音频各自保持边界。显示与碰撞使用同一数据，计时统一依赖有效游戏时间，不用多个定时器推进任务。文档只保留当前结论，验证按[约定](../implementation/validation.md)执行，不主动生成测试文件。

当前地面掠过按世界水平位移4倍实现，原空速和操纵规则保留；主要城区和景点纵向扩大5倍，4／7／10段短过渡与覆盖所有区域的林带已接入并在准备阶段分批生成。

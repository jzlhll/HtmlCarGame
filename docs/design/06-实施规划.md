## 当前交付

第一阶段已完成：飞行入口、模块骨架、机场跑道、双发客机与驾驶舱预览，可切换视角、暂停／继续和返回外部。双窗共用世界场景，下方仪表台约占四分之一屏幕。飞行游戏在 `codex/flight-simulator` 分支继续开发。

第一阶段使用 `READY → PREVIEW` 预览流程，进入驾驶舱直接切换眼位，不播放倒数或执行开关。四秒运镜从第二阶段接入，第三阶段再开启七步启动。

音频接口和事件 ID 在第 3 阶段接入，环境声和音色在第 6 阶段集中校准；不能到最后才给逐帧逻辑补防重播处理。完整数值与成功条件见[飞机与起飞](02-飞机与起飞.md)。

首版不做重量、机场性能条件和复杂气动计算，不增加配置表单。推力、升力响应和起飞速度采用固定预设。不要为了未来天气先实现可变气压、跑道温度或载重系统。

## 后续阶段

1. **持续巡航与地景。** 明确飞行目标和结束方式，连接首版爬升终点，加入山地、河流、地面与分块回收。
2. **三层天空。** 实现低空、云中、高空的连续过渡，补齐海拔与离地高度，保持两扇窗的统一视差。
3. **天气和路面变化。** 独立加入风与能见度，再扩展湿滑、碎石等地面类型；天气与路面参数分别生效，不新增重量输入。

键位学习贯穿首版：七步任务有英文首字母与清晰键帽，允许静止找键。后续巡航稳定后再加入逗号、句号、分号的左右观察和仪表扫视，不挤进起飞七步；辅助键盘示意和渐隐提示留作学习体验扩展。

降落、航线、自动驾驶、空中交通和故障玩法需后续独立设计，不属于本轮首版或已承诺的天空内容。

## 开发原则

- 保留无构建开发方式、锁定的 Three.js 依赖、本机 HTTP 服务与通用启动脚本。
- UI 使用深色面板、暖金强调和双语排版，围绕驾驶舱、开关与飞行仪表组织页面。
- 飞行模型、七步开关、飞机和机场模型、驾驶舱、镜头轨迹、状态与控制独立编写。
- 音效生成与事件触发分离；输入统一处理焦点、快捷键与失焦清理。
- 页面名称、包描述、启动日志与发布素材统一使用飞行游戏名称，明确区分设计阶段与已实现功能。
- 首版不提供存档或排行榜；未来加入飞行存储时使用明确的键名和版本。

范围检查与实际体验确认按[验证约定](../implementation/validation.md)执行，不主动生成测试文件。

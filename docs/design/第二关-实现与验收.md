## 实现组织与边界

| 模块 | 职责与边界 |
| --- | --- |
| `config.js`、`test-overrides.js` | 统一关卡门槛、45 秒换季、天气概率、第二关 120 秒永久收窄与恐龙参数；人工验证使用白名单覆盖 |
| `game.js`、`ui.js` | 关卡状态、倒计时与驶离动画、通关界面、从零开局时钟、碰撞时序与救援；调试模式跳过题目直接判过 |
| `weather.js`、`shell.js` | 天气按所在关概率调度；炮击仅用于第一关，切关清空炮弹和弹坑并停止调度 |
| `traffic.js`、`models.js`、`collision.js` | 装甲坦克投放、独立模型与碰撞等级，玩家等级仍封顶五级 |
| `road.js`、`render.js`、`branch-road-view.js`、`scenery.js` | 第二关 120 秒后永久收窄，主副路、荒原、绿洲与静态缓存切换 |
| `dinosaurs.js`、`dinosaur-models.js`、`dinosaur-view.js` | 横穿与追行逻辑、环境恐龙、左右交替瞄准玩家的跳跃、接地判定、完整奔跑模型与有限足印实例复用 |
| `arsenal.js`、`arsenal-models.js`、`arsenal-view.js`、`arsenal-icons.js`、`level-guide.js` | 第二关金币连续拾取、消耗金币发射、火箭范围清车、实例复用及真实模型预览 |
| `infrastructure.js`、`infrastructure-view.js`、`audio.js` | 桥下火车替换为恐龙奔跑，环境与路面音效合成，暂停及结算静音 |

当前排行榜保留五级统计，装甲坦克及恐龙不得写入 `highestRank` 或 `eatenByType`。玩法规则版本为 3，沿用现有存档政策重建旧规则排行榜，保留独立涂装存储；存档结构版本仍为 2，玩家等级与吞吃统计仍只有五项。

性能约定：金币拾取与过期火箭在原数组内压缩回收；金币先归还离场模型，再分配新模型。金币及恐龙展示复用临时坐标和集合，金币栏只在余额或可操作状态变化时更新。恐龙腾空阶段和残留脚印跳过车流伤害遍历，只有与当前逻辑步相交的接地窗口参与判定。共享几何、材质、模型池与实例合批继续保留，通关模型预览只生成一次并缓存。

## 验收重点

- 每 45 秒换季，最后 10 秒平滑过渡；暂停冻结，各关从零计时。第一关 2:30 不启用永久收窄；第二关自身满 120 秒才规划收窄，停车不跳过过渡，重开恢复初始道路。
- 2:55 顶部显示 5 秒倒计时，依次至 1 秒；满 3:00 才通关，同刻致命事件优先；暂停与答题冻结，恢复继续，零速计时。
- 通关后镜头固定、路上其他车辆清空，玩家模型沿当前路线自动前行 3 秒，分叉出口连续；逻辑位置、距离与时间不变，失焦冻结动画；结束后只弹一次通关界面，长按空格不跳过。
- 空格或触屏进入第二关后，道路、车流、车型、积分、距离、时间、氮气、防御、救援次数、季节与全部事件重新初始化；只保留涂装和调试设置。第二关结算不计入第一关成绩。
- 两关天气使用所在关概率，跳过触发仍排下一次；第一关炮击概率为 40%，第二关无炮弹、红圈或弹坑；重开恢复第一关炮击调度与景物。
- 装甲坦克只在第二关按卡车 2.5%、坦克 7.5% 的新车候选概率生成，其他车型不新生成；降级不清理既有装甲坦克；玩家无法升级到装甲坦克。
- 远处及俯视能看出装甲坦克双倍高度与装甲结构，模型不占邻道；只有普通坦克喷气端面追尾装甲坦克时退一级，有效侧碰及其他端面撞击直接死亡；装甲坦克不被该撞击回收，保护及擦角保持原规则。
- 主副路均为偏灰砂土路，照明减少黄色偏色，路外为荒原与少量绿洲湖泊，四季切换不恢复第一关的茂盛树林湖岸；车道、施工、脚印和冰区仍清晰可辨。
- 戈壁三角龙与剑龙具有独立轮廓和错开的低头啃食动作；湖边梁龙同时有低头喝水与抬头姿态，头颈、尾部和身体不侵入道路，环境动物不造成碰撞。
- 第二关不再出现奶牛横穿、桥下火车、铁路或轮轨声；桥下恐龙沿地面奔跑且每座结构只触发一次，第一关原有奶牛与火车保持原规则。
- 路过食草恐龙、湖边梁龙和桥下奔跑群时能听到对应距离与方向的声音，驶离停止，暂停及答题静音；重复进出可听范围不重置冷却或积累声源。
- 路面小型恐龙横穿速度为奶牛的两倍，范围 3.2–4.4 米/秒，奔跑动画与实际位移一致，高速横穿仍连续检测接触。
- 第二关两分钟前只有小型恐龙候选，两分钟后不再追加小型恐龙；大型恐龙从前方随机开放车道出现，速度始终按玩家实际速度跟随。
- 左右脚严格交替跳跃，身体随目标左右移动并抬升；起跳后玩家横移不改变本次落点，不出现橙色脚印或文字预警。
- 完整身体、抬脚与残留脚印无伤害，起跳固定落点且不显示预警，接地才判定；至少可换到其他开放车道躲避，减速、零速、喷气、白马、坡道、分叉与汇流均符合速度和落脚规则。
- 六种系统车型均可在位置快照不含车型字段时正确处理踩踏，只有接地窗口致命；完整头部、身体、尾巴和双腿清晰可见，两步至少间隔 1 秒，残留脚印 1.8 秒淡出。
- 三角龙与剑龙保持 2.4 倍、梁龙保持 3.2 倍基础模型尺寸，模型回收复用不丢失比例。
- 恐龙接触、答题救援与同刻车流碰撞遵循统一优先级；暂停不推进跳跃、脚步、音效或残影，长时间行驶对象数不持续增长。
- 装甲坦克向前伸出 4.8 米长炮筒，模型仍为普通坦克两倍高度，车身碰撞维持 6×3 米。
- 大型恐龙从玩家前方 12–18 米生成，同路线前方间距趋近 32 米时收敛至玩家速度，地面追行后左右交替跳向玩家预计位置，停车后完成在途跳跃再停步；玩家转入分离路线时不瞬移追踪。

- 金币独立随机散落在开放车道内，不按固定间距成串排列；小金币直径 1.68 米、大金币直径 2.66 米。小金币 3、大金币 6，高速连续接触不漏算且同枚只拾取一次；金币及余额不进入成长、氮气、统计或存档。
- 按 1 消耗 20 金币直接发射普通炮，按 2 消耗 50 金币直接发射高级炮；金币不足或发射容量已满时不扣款、不弹提示，按 3 不发射；普通宽 8 米、高级并排三发宽 25 米，清理及飞行距离都为 140 米，边界按车辆盒体相交判定。
- 范围内六种系统车型及警车可被击毁，范围外、后方和自身保留，恐龙与金币不受影响；长按不连射，答题数字键不触发武器。
- 右侧只显示金币图标与余额，两个按钮直接发射对应炮型，余额即时同步，暂停冻结金币及火箭，重开和切关清空余额与火箭动画；第一关通关说明显示三项实际模型并可正常进入第二关。
- 两关主副路与路肩均接入玩家水平距离雾，浓雾中 50 米及更远的车辆、金币和火箭完全隐入雾色，不能在第二关砂土路面上显出白色轮廓；天气结束及重新开局恢复正常显示。
- 普通及高级火箭飞行展示持续 1.09375 秒，清理及飞行距离为 140 米，速度为 128 米/秒，模型各维度放大为原来的 2 倍；尾翼与尾焰同比例放大，命中范围仍由武器影响宽度及射程控制。

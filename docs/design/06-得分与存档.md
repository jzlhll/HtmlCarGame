# 得分与本机排行榜

[返回总览](../README.md) · [游戏状态](01-玩法与操作.md) · [车辆速度](02-车辆规格与速度.md)

## 距离计分

只按沿道路实际前进的距离计分：`distanceMeters += speedMetersPerSecond × deltaSeconds`，`score = floor(distanceMeters)`。一米一分，无吞吃、升级、季节或连击加分。

距离取道路中心线前进弧长，横移不加路程；内部留小数，显示整数米。仅 `RUNNING` 累计；暂停、准备、死亡动画与结算均不加分，致命碰撞锁定于首次接触时刻。

## 结算与排行榜

结算展示分数、有效行驶时间（含零速，不含暂停）、最高车型、吞吃数量、起始季节和结束原因。排行榜分数只由行驶距离计算；吞吃积分仅存于本局运行状态，用于车型升级，不计入排行榜。

只保存本机前十名，无最近记录或累计统计；座驾颜色另行保存，最佳距离取第一名不重复保存。主动结束记录 `quit` 并参与排名，死亡记录 `death` 和碰撞原因，页面关闭或刷新的未结算局不追加成绩。

排名按分数降序，同分按实际距离降序，再按结束时间由早到晚，最高等级、吞吃数量和用时不影响排名；同一局只结算一次。

## 本机保存

存储于浏览器 localStorage，键名 `htmlCarGame.save.v1`，一个 JSON 文档包含：

| 字段 | 内容 |
| --- | --- |
| `schemaVersion` | 结构版本，当前为 2 |
| `rulesVersion` | 玩法规则版本，当前为 3 |
| `updatedAt` | 保存时间 |
| `leaderboard` | 排行榜前十局 |

旧存档中的 `grade` 字段忽略，题目范围固定，不影响当前规则的排行榜读取。座驾颜色不入排行榜存档，单独存于 `htmlCarGame.color.v1`（涂装 id）；读取失败或非法值回落默认绿色。

每局包含 `runId`、`runSeed`、`startSeason`、`rulesVersion`、`endedAt`、`endReason`、`deathCause`、`distanceMeters`、`score`、`activeSeconds`、`highestRank`、`eatenByType`。`highestRank` 为 1–5，`eatenByType` 固定五项，依次为自行车、三轮车、小汽车、卡车、坦克。已知结构（版本 1 或当前版本）的旧规则存档重建空排行榜，不迁移旧成绩或车型编号；直接替换本游戏键，写入失败保留原档并允许后续重试。未知结构或较新规则继续保护原档，不自动覆盖；独立颜色键不受影响。

读取时捕获存储访问、读取和 JSON 解析异常，校验版本、记录数量、合法车型、非负有限距离和时间，分数按校验后距离重算。无法读取时仍可游玩，提示本机记录暂不可用，不静默覆盖损坏数据。结算先更新内存排行榜再一次写入，失败时本局仍正常结束，保留页面内排行榜并在后续结算重试。

待机或结算页提供“重置本游戏记录”：确认后只删除本游戏键并写入默认排行榜，失败保持内存模式，成功恢复保存；进行中或暂停时不提供重置，不使用 `localStorage.clear()`。

固定使用 `http://localhost:5173`，安装后无需联网；不同浏览器、协议、主机名或端口分别存档，清除网站数据会删除排行榜。仅供本机游玩，不提供云同步、续局、导入导出或防作弊。

以单个游戏标签页为写入者，其他页面更新存档时提示，待机和结算状态可重新读取；多页同时结算不保证零丢失。

第一关通关不结算、不写排行榜；驶离动画不增加成绩。进入第二关完整重置距离、有效时间和成长统计，第二关结束后仅保存第二关成绩，不合并第一关。装甲坦克为系统专属车型，不扩展玩家最高等级与五项吞吃统计。规则版本 3 沿用旧规则成绩重建政策，独立涂装键保留。

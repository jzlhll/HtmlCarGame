# 声音与引导

[返回总览](../README.md)

当前已实现倒数、开关／舱门锁扣、发动机启动／怠速／推力、风声、轮胎滑跑／刹车、起落架与减速板电机及安全警报合成音效。英文短句通过本地 Speech Synthesis 接入，设备无本地英文语音时降级为文字与确认音。统一女声音色和实际扬声器混音仍待试听验收。

## 英文播报与音色

采用类似即时战略游戏指挥播报的简短、清晰、冷静的英文女声。借鉴语气和节奏，不使用原游戏音频，也不复刻特定角色声音。启动播报与有效操作绑定，保留 `Light`、`Fire` 等易记口令。

当前使用浏览器 Speech Synthesis 调用本机英文语音，不下载音频文件、不依赖云端 TTS。通过 `audio.js` 统一选择和管理语音，与 Web Audio 环境声共用游戏状态门控。

浏览器语音列表由设备提供，标准接口没有性别属性，也不保证存在相同的女声音色。配置优先匹配本地 Samantha、Karen、Moira、Serena，找不到则使用其他本地英文声音；这些名称是候选偏好，不代替实机女声音色验收，也不通过提高 pitch 冒充女声。只选本地服务语音，避免将离线能力建立在在线语音上。[MDN 语音接口](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice)、[本地语音标志](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)

语音不可用时保留双语文字与短确认音，游戏仍可完成；这属于降级状态，不算女声效果验收通过。如果后续要求所有设备完全一致的女声，再单独调整声音资源方案，当前不引入录音素材或额外服务。

## 事件与播报

| 事件 | 确认播报 | 触发规则 |
| --- | --- | --- |
| L 灯光开启 | Light | 每次有效切换为开启 |
| D 舱门锁定 | Door closed | 舱门关闭完成 |
| H 安全带扣好 | Harness secured | 每次有效切换为就绪 |
| A 飞行仪表开启 | Avionics | 仪表点亮完成 |
| F 启动受理 | Fire | 前置条件满足，每次有效开始新的启动序列 |
| 发动机达到怠速 | Engines ready | 约 3 秒启动结束 |
| W 关闭减速板，起飞就绪 | Wing brake closed | 减速板 OFF |
| R 松驻车刹车 | Brakes released | 成功进入滑跑 |
| 首次达到 VR | Rotate | 本次滑跑第一次达到抬轮速度 |
| 首次建立正爬升 | Positive climb | 确认离地且爬升为正 |
| G 起落架收妥 | Gear up | 收起动画完成 |
| W 打开减速板，着陆配置 | Wing brake open | 减速板 ON |
| 首次进入低速危险状态 | Airspeed low | 危险状态进入事件；先恢复到安全区再允许下一次进入 |
| 仰角过高／危险下降 | Lower nose / raise nose | 对应警告进入事件；不得与失速改出指引冲突 |
| 失速／失速恢复 | Stall / stall recovered | 迎角危险进入与恢复事件；优先于普通确认 |
| 超速 | Airspeed high | 超速进入事件，先恢复安全区再允许下一次进入 |
| 航程成功／失败 | 文字结果 | 结算时立即静音，不播放新的完成短句 |

撤销准备、取消启动／熄火与重新驻车也按有效变化产生事件，播放关闭确认音及相应短句；D 打开时播报 Door open。取消启动立即取消当前 Fire，后续只有实际 engine-ready 事件才会播报 Engines ready。

倒数数字以画面为主，首版不额外叠加四句倒数语音。未满足步骤的按键不播放确认播报，只展示一次简短缺项提示。

短句通常约 0.5–1.5 秒，上限为 2.5 秒有效游戏时间；只保留当前一句，新的普通确认替换旧确认，不积压队列。安全警告优先于普通确认，失速与超高优先级最高；失速中不再播报可能冲突的普通俯仰／低速指引。持续环境声在播报期间适度降低音量，语音停止后恢复；浏览器原生语音不假设可以接入 Web Audio 滤波链。

## 操作清单与双语提示

底部操作清单与具体动作提示统一采用 `English（中文含义）[键]`，例如 `Fire（发动机启动）[F]`、`Thrust（提速）[T]`、`Rotate（抬头起飞）[↑]`。英文是助记词，中文解释实际动作，不能只显示首字母让玩家猜测。

提示同时承担键位学习：键帽保持足够大小与对比度，不将当前操作键藏进长段说明。允许初学者在启动阶段一直查看底部双语操作清单；中央入舱说明只概括任意顺序操作，首次按键后隐藏，不再显示具体推荐项；未来标点提示展示物理键帽 `,`、`.`、`;`，旁边给出逗号／句号／分号名称，避免中英文标点外形混淆。

| 界面内容 | 生命周期 |
| --- | --- |
| 中央入舱说明 | 只写 L、D、H、A、W 可任意顺序操作，保持到入舱后首次普通字母或游戏操作按键；本局隐藏后不再出现，重开恢复，不按短提示计时 |
| 底部阶段清单 | 准备时舱门 Open／Closed，其余项 OFF／ON；R 放行后整条替换为滑跑操作，离地后替换为爬升、收轮和减速板操作；常驻显示双语名称和键帽 |
| 仪表、机外姿态卡片、开关灯、刹车与持续危险状态 | 随状态常驻，通过颜色和标签更新，不反复弹框 |
| 高／低俯仰、失速、低速／超速、完成确认、条件未满足、区域进入 | 临时提示 2–3 秒，单次上限 3 秒 |
| 倒数 | 每个数字显示 1 秒，数字变化不影响其他提示计时 |

临时提示使用 `runId + eventType + stepId/episodeId` 等稳定身份记录首次出现时间，不能把速度、高度、距离或当前帧编号放进事件标识。一次失败输入提示以操作键和缺失条件组合去重；相同条件下连续按错不刷新倒计时，也不在到期后重新弹出。准备项、发动机或刹车发生有效状态变化后建立新的事件轮次，允许同一操作在新轮次再次确认或显示一次缺项提示；倒数、转速刷新和镜头振动不建立新轮次。Rotate 不因速度在阈值附近波动反复播报。

## 环境声与静音

- Web Audio 实时合成开关短音、发动机启动／怠速／推力声、轮胎滑跑声、风声、起落架和减速板电机声。
- 发动机声音跟随启停与自动动力，风声随空速，轮胎声仅接地时播放。开场飞机熄火，不提前播放发动机声。
- F 点火以逻辑事件触发；渲染重绘、按键连发、窗口缩放均不能重新播放事件声。
- 开始按钮或空格提供首次用户手势，用于解锁音频；未解锁或播放失败不阻断步骤。
- 音效与英文播报默认开启，不设置声音开关；点击开始或按空格时解锁音频，不增加额外操作。
- 暂停、失焦、失败、COMPLETE 和结果页立即停止持续声、短音与英文播报；完成反馈使用文字，不额外播放成功语音。
- 继续后恢复当前持续声的参数，不重新建立声源，不重播暂停前被取消的开关确认。重新开始清空语音队列和本局去重标识。

参数集中到 `config.js` 的 `AUDIO`；文本与事件 ID 独立存放，方便检查双语名称、按键首字母和播报的一致性。

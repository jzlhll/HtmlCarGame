# 声音与引导

[返回总览](../README.md)

当前已实现倒数、开关、发动机、风、轮胎、收放电机与警报合成音效；英文播报使用同一Samantha女声的固定短句，通过Web Audio播放实际语音数据。起降阶段不叠加确认短音。

## 英文播报与音色

使用原Samantha英文女声，保持简短、清晰、冷静的语气。31个固定短句存入一份约1.11 MB、单声道16 kHz／16-bit WAV语音库，片段表记录精确偏移和时长，文件名含内容哈希；配置在`AUDIO.voice`，原始播报词与必要语音源素材一并纳入发布。环境声及开关音继续实时合成，不加载录音文件。

进入页面后预取语音库，首次用户手势创建AudioContext后解码一次，重开复用同一个AudioBuffer；每次播报只创建短期BufferSource并按片段范围播放。开始点击先请求Welcome aboard，起飞、进近和接地事件播放对应英文短句，独立增益并在说话时降低环境声；不依赖浏览器系统TTS起播，暂停、失焦、换局和结算立即停止。素材尚未就绪只保留最近一句，过期丢弃，不积压队列。

`node scripts/generate-voice.mjs`在macOS用原Samantha声线更新源素材，校验每句实际PCM非静音后合并；生成仅在开发时执行，普通启动和Pages发布无需安装系统语音或在线服务。`prepare-pages.mjs`验证所有配置短句均有有效片段后复制源素材，避免发版只有提示音而没有女声。语音库属于必要声音源素材，不属于程序模型或关卡缓存，不参与模型生成器版本失效。

浏览器Speech Synthesis仅在素材加载失败或新增短句尚未入库时尝试英文女声回退，不选择未知男声／特殊音效；起降事件不以短音效冒充成功播报。首次点击直接请求的设计参考[WebKit语音启动门控](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/Modules/speech/SpeechSynthesis.cpp)，正常路径通过已解锁的Web Audio播放语音。

## 事件与播报

| 事件 | 确认播报 | 触发规则 |
| --- | --- | --- |
| 点击开始 | Welcome aboard | 每局首次开始操作 |
| L 灯光开启 | Light | 每次有效切换为开启 |
| D 舱门锁定 | Door closed | 舱门关闭完成 |
| H 安全带扣好 | Harness secured | 每次有效切换为就绪 |
| A 飞行仪表开启 | Avionics | 仪表点亮完成 |
| E 启动受理 | Engine | 前置条件满足，每次有效开始新的启动序列 |
| 发动机达到怠速 | Engines ready | 约 1.5 秒启动结束 |
| W 手动关闭减速板 | Wing brake closed | 减速板 Closed |
| R 松驻车刹车 | Cleared for takeoff | 成功进入滑跑 |
| 首次建立正爬升 | Airborne. Positive climb | 确认离地且爬升为正 |
| 初始爬升完成 | Climb complete | 保持爬升达标后一次 |
| 安全接地 | Touchdown. Apply brakes | 已由正式接地判定确认 |
| G 起落架收妥 | Gear up | 收起动画完成 |
| W 打开减速板，着陆配置 | Wing brake open | 减速板 Open |
| 危险下降 | Raise nose | 危险下降进入事件，不能修改实际角度 |
| 失速／失速恢复 | Stall / stall recovered | 低于150 km/h进入、达到165 km/h恢复的事件；优先于普通确认 |
| 航程成功／失败 | 文字结果 | 结算时立即静音，不播放新的完成短句 |

撤销准备、取消启动／熄火与重新驻车也按有效变化产生事件，播放关闭确认音及相应短句；D 打开时播报 Door open。取消启动立即取消当前 Engine，后续只有实际 engine-ready 事件才会播报 Engines ready。

倒数数字以画面为主，首版不额外叠加四句倒数语音。未满足步骤的按键不播放确认播报，只展示一次简短缺项提示。

短句通常约 0.5–1.5 秒，上限为 2.5 秒有效游戏时间；只保留当前一句，新的普通确认替换旧确认，不积压队列。起降阶段播报优先于普通开关确认；安全警告优先于阶段播报与普通确认，失速与超高优先级最高；失速中不再播报可能冲突的普通俯仰／低速指引。持续环境声在播报期间适度降低音量，语音停止后恢复；浏览器原生语音不假设可以接入 Web Audio 滤波链。

## 操作清单与双语提示

底部操作清单与具体动作提示统一采用 `English（中文含义）[键]`，例如 `Engine（发动机启动）[E]`、`Thrust（提速）[T]`、`Rotate（抬头起飞）[↑]`。英文是助记词，中文解释实际动作，不能只显示首字母让玩家猜测。

提示同时承担键位学习：键帽保持足够大小与对比度，不将当前操作键藏进长段说明。允许初学者在启动阶段一直查看底部双语操作清单；中央入舱说明只概括任意顺序操作，首次按键后隐藏，不再显示具体推荐项；未来标点提示展示物理键帽 `,`、`.`、`;`，旁边给出逗号／句号／分号名称，避免中英文标点外形混淆。

| 界面内容 | 生命周期 |
| --- | --- |
| 中央入舱说明 | 只写 L、D、H、A 可任意顺序操作，保持到入舱后首次普通字母或游戏操作按键；本局隐藏后不再出现，重开恢复，不按短提示计时 |
| 底部阶段清单 | 准备时舱门 Open／Closed，其余项 OFF／ON；R 放行后整条替换为滑跑操作，离地后替换为爬升、收轮和减速板操作；常驻显示双语名称和键帽 |
| 仪表、机外姿态卡片、开关灯、刹车与持续危险状态 | 随状态常驻，通过颜色和标签更新，不反复弹框 |
| 低于200米进近 | 顶部常驻60–180 km/h约束，速度合格提示保持、偏低提示提速；高于上限只显示范围；与危险警告共存，接地后解除，不播放循环语音 |
| 失速、危险下降、放轮异常、交通碰撞风险与故障 | 仅异常时在屏幕上沿显示单条带颜色／背景的警告，恢复隐藏；不显示角度读数或常规操作教学，不使用toast或短时计时 |
| 非安全类操作条件未满足、撞卡车与瀑布奖励 | 临时反馈2–3秒，单次上限3秒 |
| 倒数 | 每个数字显示 1 秒，数字变化不影响其他提示计时 |

临时提示使用 `runId + eventType + stepId/episodeId` 等稳定身份记录首次出现时间，不能把速度、高度、距离或当前帧编号放进事件标识。一次失败输入提示以操作键和缺失条件组合去重；相同条件下连续按错不刷新倒计时，也不在到期后重新弹出。准备项、发动机或刹车发生有效状态变化后建立新的事件轮次，允许同一操作在新轮次再次确认或显示一次缺项提示；倒数、转速刷新和镜头振动不建立新轮次。不播放正常抬轮Rotate播报。

## 环境声与静音

- Web Audio 实时合成开关短音、发动机启动／怠速／推力声、轮胎滑跑声、风声、起落架电机声。
- 发动机声音跟随启停与当前推进响应，引擎基音／谐波和气流声增益分别为0.075／0.0175和0.0375，风扇喷气声单独使用0.049增益，警报、按键、语音和轮胎不受影响；风声随空速，轮胎声仅接地时播放。开场飞机熄火，不提前播放发动机声。
- 空中发动机运行时，离地18–28秒后可首次播放柔和的双音客舱提示声，之后随机间隔45–75秒。一高一低两声以Web Audio合成，间隔0.38秒，不加载音效文件；复用Mission.flightSeconds，重开重置，暂停不计时。播报、警报及危险下降优先并取消客舱提示声，落地与损毁后不再触发，不补播积压次数。
- E 点火以逻辑事件触发；渲染重绘、按键连发、窗口缩放均不能重新播放事件声。
- 开始按钮或空格提供首次用户手势，用于解锁音频；未解锁或播放失败不阻断步骤。
- 音效与英文播报默认开启，不设置声音开关；点击开始或按空格时解锁音频，不增加额外操作。
- 暂停、失焦、COMPLETE 和结果页立即停止持续声、短音与英文播报；完成反馈使用文字，不额外播放成功语音。实体损毁的CRASH阶段先停发动机、风、轮胎、告警与播报，仅播放一次合成撞击／爆炸，2.8秒视觉特效播完再结算。暂停中断爆炸声，恢复不重播；大雁碰撞只播放短促撞击与Bird strike播报，不停止飞行。
- 继续后恢复当前持续声的参数，不重新建立声源，不重播暂停前被取消的开关确认。重新开始清空语音队列和本局去重标识。

参数集中到 `config.js` 的 `AUDIO`；文本与事件 ID 独立存放，方便检查双语名称、按键首字母和播报的一致性。

常规接近机场、Prepare to land和Runway ahead进近播报关闭，不影响进近阶段与着陆判定；触地、起落架未放妥及其他危险声音保留。降落调试倒数只显示3／2／1，不显示准备或接近说明。

## 雷击故障音与标志

雷击命中时复用Web Audio警报声源，连续3秒在430–920Hz间以2.6Hz周期变调，形成“呜啦呜啦”警报；雷声由现有噪声源低通合成，参数集中AUDIO.lightningAlarm／thunder。不新增音频文件或替换固定Samantha女声源。警报优先于客舱提示铃；3秒后停止故障警报，其他仍有效的失速／起落架警报按自身条件保留。

雷击后仪表旁常驻红色Lightning fault／雷击故障标志，显示本关无法提速；顶部故障文字与其他危险告警共用优先级。暂停和失焦立即静音，恢复按剩余有效时间继续；结算静音并隐藏标志，重开清除故障。


城市上空提示只使用顶部中英文字，不追加语音素材或合成确认音。首次进入每座城市按稳定城市ID去重，持续3秒、暂停冻结、重开重置；与危险警告及进近速度范围并列显示，不延长任务时间。

## 第二关恐龙事件

第二关关闭原有奶牛横穿调度，由下述小型恐龙横穿替代；第一关保留奶牛横穿。小型恐龙仍只在第二关前两分钟新投放，两分钟后不重新启用奶牛。

路面恐龙事件计时从进入第二关开始，仅在 `RUNNING` 推进；暂停、通关界面、答题、死亡与结算时冻结或停止。本局使用独立随机序列与稳定事件 ID，不因速度、距离、车道或最近目标变化重置事件。

### 前两分钟：小型恐龙横穿

`0 <= levelSeconds < 120` 时，偶尔在前方出现小型恐龙，从路肩一侧跑向另一侧，左右方向随机。低多边形实体能看出头、细尾和奔跑双腿，尺寸明显小于普通坦克，不用奶牛换色代替。

初版试做参数：

| 参数 | 初值 |
| --- | --- |
| 首次候选 | 进入第二关后 15–30 秒 |
| 后续候选间隔 | 上一批离场后 25–40 秒 |
| 候选触发概率 | 40% |
| 每批数量 | 1–2 只 |
| 单只尺寸 | 长约 2.4 米、宽约 0.8 米、高约 1.2 米 |
| 横穿速度（确定规则） | 奶牛横穿速度的两倍，即 3.2–4.4 米/秒 |
| 出现位置 | 当前路线前方，至少 60 米且预留不少于 3 秒接近时间 |

横穿速度以现有奶牛的 `1.6–2.2` 米/秒为基准，最小值、最大值及每次随机采样结果均乘以 `2`，即 `3.2–4.4` 米/秒；生成后保持该速度，不随玩家车速调整。实施时将奶牛基础横穿速度与小恐龙倍率集中到 `config.js`，避免两个模块各自写死不同基准。

最多一批在场，投放避开截止墙、施工封闭区、桥梁和分叉出入口，不跨越空间分离的两条道路。若没有合适位置，本次取消并等待下一次候选，不连续重试。

初版接触沿用横穿奶牛后果：自行车、三轮车接触致命，小汽车及以上按原奶牛接触扣分和降级规则处理；不吞吃、不回气、不弹文字提示，保护规则与奶牛一致。恐龙独立使用身份和死亡原因，界面不得把恐龙显示成奶牛。同一只只处理一次命中，抵达对侧路肩后回收。

到两分钟后停止新投放小型恐龙，已在横穿的个体正常跑完，不突然消失。

### 两分钟后：大型恐龙追行

`levelSeconds >= 120` 后开始大型恐龙追行事件。大型恐龙从玩家前方的当前路线随机开放车道进入，同向追行并左右交替跳跃踩踏；路线指主路或玩家所在副路，不能凭空跨越另一条分离的路线。

呈现一只完整的巨型双足恐龙，头、眼睛、牙齿、短前肢、身体、长尾与交替迈步的后腿清晰可见。恐龙追行时左右交替跳跃，抬起另一条腿并倾斜身体，单次跳跃最高抬升 3 米；每次尽量将接地脚踩向玩家预计位置。接地前不绘制落点、橙色足形或文字预警，落地后显示脚印，避免整片阴影盖住道路。

初版试做参数：

| 参数 | 初值 |
| --- | --- |
| 首次候选 | 第二关运行满 120 秒后等待 4–8 秒 |
| 后续候选间隔 | 上一只离场后 20–35 秒 |
| 候选触发概率 | 70% |
| 同时在场上限 | 1 只 |
| 起点 | 玩家前方 12–18 米，当前路线随机开放车道 |
| 前方距离上限 | 32 米，接近上限时额外速度逐渐降为零 |
| 完整模型尺寸 | 长 22 米、宽 5.8 米、高 10 米 |
| 跳跃间追行速度 | 每个逻辑步取玩家当前实际速度的 1.00–1.08 倍；初始倍率固定，额外速度随前方间距递减 |
| 持续时间 | 12–18 秒，最后一秒缩小离场 |
| 脚印接地尺寸 | 单脚宽约 2.2 米、长约 3.6 米 |
| 步伐间隔 | 行进约 24–32 米落一步，且两步至少间隔 1 秒，两脚交替 |
| 单次跳跃 | 起跳至接地 0.8 秒，最高抬升 3 米，无落点或文字预警 |
| 接地危险时间 | 0.35 秒 |
| 普通残留脚印 | 1.8 秒淡出，仅装饰 |

两次起跳至少间隔 1 秒，跳跃期间不累计下一步步距；低速须走完步距再起跳，不在原地堆积脚印。首次出场后可直接起跳，后续左右脚严格交替。

跳跃之间的追行速度跟随玩家刹车、氮气、白马和冰冻后的实际速度计算。玩家零速时停止追行和新起跳，已经起跳的本次踩踏按既定目标完成后停步；不反复在原处生成命中。道路弧长运动和落点预测按当前路线 `pathScale` 换算，坡道和副路均使用实际路面距离。

每次起跳时，沿玩家当前路线和实际速度预估 0.8 秒后的纵向位置，横向瞄准起跳瞬间玩家所在位置；起跳后本次落点保持固定，玩家可以横移或改变速度避开。左右脚交替接地，足部相对身体中心左右各偏移 1.8 米，因此身体在玩家左右两侧交替落下，而接地脚尽量对准玩家。身体中心位于脚印前方 4 米，按道路边界和身体宽度约束；无法正对路边玩家时选择身体可达的最近落点。单次跳跃从原位置平滑移动到本次目标，不瞬移到玩家头上。

追行至少留下一个其他开放车道作为横向躲避通道；遇到道路收窄、施工或汇流使下一脚无法留下通道时，跳过该步或提前离场。离开副路时沿汇流连续运动；玩家改走空间分离路线时，旧恐龙保持原路线，按持续时间正常离场，不瞬移追踪。

### 踩踏判定与保护

初版试做采用有效踩踏致命，所有玩家车型一致，走现有死亡／答题救援流程；大型恐龙不作为可吞吃车辆，不提供成长、氮气或排行榜额外奖励。

- 只有足部实际接地危险窗口参与碰撞；完整身体、腾空双腿及淡出的普通脚印均不伤害玩家。
- 连续接触检测覆盖玩家车身与接地脚掌的运动，按实际坡度及路线换算世界位置；不能仅按所在车道判定命中，也不能高速穿脚。
- 每次落脚使用稳定 ID，同一次接地只命中一次；同刻踩踏致命与其他事件按现有致命优先规则处理。
- 白马无敌、降级保护及答题／调试复活保护期间免踩踏，不撞飞整个恐龙、不取消其余步伐。救援冻结恐龙及跳跃，复活后按剩余有效时间继续，不补算答题期间脚步。
- 系统车辆连续碰撞的起点从位置快照恢复，车型、尺寸和朝向取当前车辆，避免位置快照缺少车型造成运行中断。系统车辆被实际踩中时损毁回收，不产生吞吃奖励；踩踏区域不自动清除施工、道路墙体或其他脚印。
- 追行恐龙不参与普通道路目标清理；残留脚印没有伤害。
- 不显示落点预警或事件文字提示；脚步音效只在实际接地时触发，跳跃动作与接地时间一致。

### 渲染、音效与生命周期

完整恐龙使用共享模型模板与实例批次，缓存双腿和尾巴的动作节点；地面追行按实际速度驱动迈步，跳跃按起跳至接地进度抬升身体、侧倾并收腿。停车后完成在途跳跃，再停止新增跳跃；暂停冻结全部动作。纵横位置按逻辑步插值，同刻踩踏或答题冻结时同步回退位置；副路汇流切换时使用新路线位置，避免跨路线插值。结束前最后一秒缩小离场，不再投放无法在离场前完成危险窗口的新脚印。

脚印在实际接地后显示，使用起跳时固定的落点和接地尺寸，按路面采样贴合坡道、高架和副路。完整身体及腿部动作仅用于表现，危险只在接地后的 0.35 秒足形范围内生效，不追加身体或尾巴碰撞。初版在场上限为一只大型恐龙、十二枚在途或接地及残留脚印与一批小型恐龙；完整模型回收复用，足印固定容量，达到容量时跳过新起跳，不截断已生效的危险足印。

路面事件音效在 `src/audio.js` 用 Web Audio 合成，小型恐龙使用轻脚步，大型恐龙复用低频恐龙吼声，并使用接地脚步声，音量与距离参数放入 `AUDIO`。脚步只在实际接地时发声，不逐帧重复触发；环境动物的声音按[路过环境恐龙的声音](第二关-荒原场景与环境恐龙.md#路过环境恐龙的声音)独立管理；暂停、通关界面、答题和结算必须静音。

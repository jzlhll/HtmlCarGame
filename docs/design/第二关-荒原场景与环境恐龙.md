## 灰色砂土道路与荒原戈壁

第二关主路、副路及高架行驶面统一变为偏灰的压实砂土道路：灰色底面、浅灰轮迹、细砂与稀疏碎石斑驳。路肩使用浅灰色，照明与远景减少黄色偏色，保留路外戈壁的灰褐土色。道路边缘、中央分隔与车道标记保持清楚的明暗对比，便于识别车辆、路障与脚印。第一关柏油道路与四季树林保持原样。

道路外以砂砾荒地、裸岩、戈壁石块、低矮枯灌木及少量枯木为主，替换第一关的茂盛树冠和成片绿草。原湖泊候选地块可保留少量绿洲湖泊，其余使用干涸盆地、龟裂地或石滩；绿洲只在平缓地形出现，沿用视野内最多四处湖泊的容量限制。农场、牧场及居民建筑的装饰布局在第二关停用，换成风蚀岩石与恐龙活动地块，保持道路净空。

道路曲率、坡道、车道数、施工、分叉、路面坑洞和泥洞机制保持。高架结构保留，第二关移除桥下铁路、列车及轮轨声，改为桥下恐龙奔跑，详见下文；河谷水流接触若仍承担减速，必须保留可辨认的水流或湿地外观，不能把仍会减速的水流直接画成普通干地。

基础主题不随季节切回绿草或积雪地表，冬雪作为临时天气叠加即可。灰色路面、脚印、冰区和泥洞必须有清楚的色差；岩石、灌木与枯木继续保持路肩外至少两米净空。景物和轮迹采用共享材质、程序化纹理或合并几何，不依赖外部图片下载，复用现有附近地块缓存与实例批次。

### 戈壁食草恐龙

在路外有低矮植被的地块布置三角龙和剑龙，两种都绘制完整的低多边形实体，作为第二关全程可见的环境动物，不受道路事件前两分钟限制。

- 三角龙与剑龙使用 2.4 倍基础模型尺寸，显示与复用时保留该比例，确保路过时能辨认。
- 三角龙具有三只角、宽颈盾和粗壮四肢；剑龙具有背部两列骨板、小头和带尖刺的长尾，远处也能凭轮廓区分。
- 在稀疏蕨类、嫩叶与低矮植被间表现“吃草”：低头啃食、轻微咀嚼，间或抬头张望、缓慢摆尾及短距离挪步。剑龙为植食性恐龙，食草场景用低矮植物表达，不铺设现代牧场式草坪。
- 同一地块安排少量不同朝向和动作相位的个体，避免整齐排列或同步低头；动物活动范围固定在道路外，整个身体、头颈和尾部均保持路肩外至少两米净空。
- 不进入道路、不参与玩家或系统车碰撞，不提供积分，也不参与道路危险目标清理；不沿用奶牛斑纹或农场装饰。

### 绿洲湖边梁龙

长颈恐龙采用**梁龙（Diplodocus）**，属于长颈、长尾的蜥脚类恐龙。湖边保留小块湿地与低矮植被，与周围干燥戈壁形成对比，不把整张地图恢复成第一关的湖岸树林。

每处可见湖泊安排 2–3 只梁龙，四足站在岸上，长颈伸向水面。布局中同时保留低头喝水和抬头张望的姿态；个体按不同相位缓慢低头、在水面停留、再抬头，抬头不机械摆成完全竖直。喝水时嘴部接近水面并有轻微涟漪，脚和躯干不能悬空或沉入湖底。

梁龙使用 3.2 倍基础模型尺寸，模型突出长颈、细小头部、长尾与庞大四足身体，尺寸明显大于三角龙和剑龙；颈尾活动范围沿湖岸排布，避开道路、桥梁和玩家视线。没有湖泊的地块不凭空出现喝水梁龙。梁龙同样属于环境动物，不参与碰撞或成长，也不替代路上完整双足奔跑的大型追行恐龙。

### 桥下恐龙奔跑

第二关高架桥下移除火车和铁路视觉，改为一小群可见完整身体的恐龙沿桥下地面奔跑。使用小型双足恐龙或其稍大变体，头、双腿和尾部具备清晰奔跑动作，沿横穿桥下的通道运动并带少量扬尘；不复用列车车厢模型或铁轨。

沿用现有基础设施经过时机：玩家距桥面交叉点不大于当前速度对应的提前量时，按桥梁稳定 ID 触发一次桥下奔跑。提前量由独立配置 `DINOSAURS.bridgeLeadSeconds` 管理，默认 2.5 秒。生成后独立向前运动，不随玩家变速重新计时或重复生成；零速未到触发条件时不额外投放。

奔跑路径位于桥下地面，模型高度须低于桥面且避开桥墩，不穿桥、不跑上玩家车道，不参与道路碰撞。整群跑出视野后回收，暂停冻结；它与路面小恐龙横穿、两分钟后大型恐龙追行分别调度，在第二关任意时段都可出现。

### 路过环境恐龙的声音

三角龙、剑龙和梁龙在玩家靠近时有稀疏低鸣、啃食或饮水声；路过高架桥时，桥下奔跑群必须有清晰的恐龙叫声，叠加有节奏的轻脚步，完整替换原轮轨声。声音体现不同体型，不逐帧反复播放同一叫声；恐龙叫声为游戏化合成表现，不声称复原真实声音。

使用玩家与恐龙的实际世界位置计算距离衰减及左右声像，接近时渐强、驶离时渐弱，经过后停止；路过湖泊必须能听到梁龙低鸣，喝水动作另叠加短水声，不能只有流水声或仅在抬头时偶发发声。每个环境动物或群体按稳定 ID 记录发声冷却，距离、速度及车道变化不重置冷却。共享景物批次保留独立发声来源，禁止逐只创建长期不释放的音频对象。所有声音由 `src/audio.js` 的 Web Audio 实时合成，参数集中在 `AUDIO`，暂停、答题、通关和结算静音。

环境动物沿用附近地块缓存与固定容量实例复用，离开缓存范围后归还模型、动作状态及声源，重开与切关清空；不让环境群体占用路面危险事件的一只大型恐龙上限。湖泊上限四处，每处梁龙最多三只，戈壁食草动物及桥下奔跑群另设有限容量。

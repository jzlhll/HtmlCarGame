# 技术与实施说明

[返回总览](../README.md)

## 技术与本机开发

原生 JavaScript ES Modules、Three.js `0.186.1`、DOM／CSS／SVG 界面与 Web Audio 合成音效、本地固定Samantha女声播报，无编译或打包步骤。入口为 `index.html`，import map 从本机依赖目录加载 Three.js 与 BufferGeometryUtils；运行不依赖 CDN。

依赖缺失时执行 `npm ci`，随后 `npm start`，地址为 [http://localhost:5186](http://localhost:5186)。多工作目录可用 `PORT=5187 npm start` 选择空闲端口，不停止用户已有服务。`scripts/serve.mjs` 只监听回环地址并限制资源根目录，通过 HTTP 加载，不直接打开 HTML。

保留现有 macOS 启动脚本与 Release 资源整理工具；当前不发布飞行分支。增加资源或 addons 时同步维护服务白名单和发布拷贝清单。

## 状态与时钟契约

主要流程为 `READY → INTRO → STARTUP → TAKEOFF_ROLL → INITIAL_CLIMB → CRUISE → APPROACH → LANDING_ROLL → TAXI → COMPLETE → RESULT`；实体损毁独立经过`CRASH → RESULT`。满足进近空间条件时也可从爬升直接进入 APPROACH；没有达到初始爬升目标不会阻止玩家尝试安全着陆。安全接地是 LANDING_ROLL 的唯一入口；任务胜利还必须在跑道内停稳。

准备、四秒开场与1.5秒启动不消耗航程时限。首次 R 合法放行调用 Mission.start，此后即使刹停、重新驻车或恢复准备，本关时限仍继续；只有重开清空。所有物理、遭遇、收放、提示、停机保持和任务时限都由有效游戏步推进，暂停／失焦冻结，恢复不补算停留时间。

Game 优先处理飞行接地／越界与世界／交通碰撞失败，再处理任务完成。本关时限之外不接受停机胜利。完成冻结飞机，1.5 秒短反馈后进入静止结果页；失败只结算一次。结果用时为任务时钟而不是准备耗时。

滑跑、爬升、巡航、进近和着陆之间保留持续操纵；暂停、结果、重开及准备／放行等输入门控切换清理按住集合。普通开关和受阻指令不重置逻辑步余量。

## 飞行与世界数据

内部采用米／秒／弧度，Three.js Y 向上，计划航线沿 −Z。`aircraft.position` 与轮子、机腹、翼尖接触点使用同一参考点；高度表显示最低接触点离地高度 AGL，导航显示海拔 MSL，限高检查 MSL。固定质量存于 AERODYNAMICS，不引入载重或机场性能表单。

飞行采用游戏化前进速度与垂直运动。姿态限速跟随用户输入，↑／↓点按调整0.2°，长按时每次键盘重复触发调整0.8°，机体以3°/s平滑跟随，不按持续时间额外累加角度，失速不削弱俯仰或滚转，不按迎角自动低头／抬头。空中低于150 km/h进入失速，达到165 km/h解除，150–165之间维持原状态；仅将垂直航迹限制为低速下沉，机头角度、前进速度和左右操纵不受失速影响。下沉目标为`7.5 + 52.5 × clamp(1 − speed/150, 0, 1)`米/秒，最大60米/秒；该上限指失速造成的低速下沉，玩家主动俯冲仍可更快下降。解除后连续恢复用户姿态对应的垂直运动，不跳变高度。 前进速度由有效T／S、固定每秒5 km/h阻力、W打开时额外每秒10 km/h阻力和明确碰撞事件改变，enginePower仅平滑声音反馈。

G的EXTENDING／RETRACTING进度同步视觉；W无过渡状态，flaps／flapsPosition保留内部标识，CLEAN／0为关闭，TAKEOFF／1为打开，按键同时更新两者并发出flaps-up／flaps-down完成事件。起飞W关闭、安全接地不检查Wing brake状态；G保留收轮高度与放轮速度限制。Flight.landingStatus统一四项接地条件和姿态颜色；isWithinRunway由接地、落地滑跑和stoppedOnRunway共同使用，机身位置即可，不另查机翼／机轮边界。安全接地后landingAlignment在1.2秒内归正，暂停冻结、重开重置，最低接触点贴机场标高，不搬到跑道中心。

每个关卡页面创建一次RouteWorld并复用，重开不重建静态场景；通过 ?level=1／2／3 选择关卡，原生页面导航结束旧页面和声音，不在运行中改写全局配置。createRoute生成独立规则与机场数据，terrainElevation返回零海拔，实际山体与外围地形查高读取对应网格。建筑／地标用包络和空间网格索引，山体以固定高度网格直接定位对应三角形并线性插值查高，近景绘制使用同一网格，远景索引简化不改写碰撞；飞机多个带半径采样点扫过前后位置，每个固定步只计算一次前后姿态的采样端点，世界与交通碰撞共用。整体扫掠包围盒先排除不可能接触的建筑、山体和交通目标，再保留原有逐点窄相检查及山面采样间距；不得通过降低物理频率或扩大穿透容差提速。交通碰撞使用双方相对位置线段，飞鸟逐只检查，固定队形偏移随航向缓存。详细边界和着陆阈值见[航程专题](../design/07-航线与关卡.md)。

## 渲染、导航与事件

完整前窗使用主场景／主相机，固定飞行员眼位向下 5°保留地景；机外姿态使用同一显示姿态与独立裁剪视口，不新增 WebGL 上下文。开场以有效时间采样平滑轨迹，外壳和内舱渐变保留深度写入；对数深度、表面 polygonOffset、36 km 远裁剪及 32 km 天空球控制远近景闪烁。阴影只在可见机体、收放、机壳透明度或 WebGL 恢复时失效；山谷遮蔽在建图时烘焙为顶点数据，不每帧扩大阴影范围。

首屏直接展示标题、可点击开始入口与轻量客机预览，完整场景在随后等待窗口准备；点击开始时若必需资源尚未就绪，显示真实进度，完成后立即进入原有四秒运镜。进入运镜前异步预编译主场景与姿态卡片材质、预上传基础纹理，并用小视口提交全部细节级别的几何，随后恢复可见性、裁剪状态与机场阴影。加载不消耗游戏时钟。

逻辑快照按帧余量插值，暂停／结果保留最后显示姿态。机场与地景的静态变换矩阵在创建时确定，后续仅更新可见性和纹理偏移；新增会移动的地景必须恢复相应节点的矩阵更新。飞机按材质合并静态几何，并保留轮、减速板和航行灯的独立控制；飞机合批保留材质需要的UV属性，蒙皮与金属共享纹理和生成结果。机场在各自局部坐标中按材质与阴影属性合并不透明标线和建筑，透明编号保留独立排序；其他静态地标按640米空间单元合批，山体细节与实例森林保持独立。驾驶舱17块面板与框体按三种材质实例化，尺寸变化时统一更新实例矩阵。建筑实例化；山体共享网格顶点、法线及颜色，通过不同索引切换远近细节，森林按区块切换实体树冠／交叉树片并裁剪；瀑布只更新纹理偏移，交通模型预先建立，读取逻辑对象位置。当前地图有限，不声明已实现无限巡航或地形回收。

航线轨迹每 0.25 秒记录真实世界位置，包含偏航；导航和雷达以 8 Hz 更新 SVG，固定网格与计划线只创建一次，实际轨迹只格式化新增采样，目标节点按稳定 ID 复用，重开清空轨迹和目标。仪表复用文字节点，仅写入变化的字段；同一帧的多个状态通知合并为一次界面刷新，输入门控和音频静音仍即时执行。雷达目标、箭头与场景模型使用同一位置／速度／航向，前 10 秒预告闪烁，危险依据最近接近距离与高度差，暂停不闪烁、不移动。A 关闭雷达时不显示目标。

临时提示以有效事件 ID 去重，最多 2.5 秒，不由速度／高度刷新计时。安全区恢复后才允许新的危险进入事件；失速与超高故障优先于交通／姿态，后者优先于普通操作。每道瀑布按独立ID每局只奖励一次。常驻仪表、任务与故障状态不使用短提示生命周期。

舱门内部 `systems.door` 为准备完成标志：true 表示关闭并锁定，界面显示 Closed；false 表示打开，显示 Open。E／R 继续依据同一准备状态检查，不以显示文案反向推断。

输入以 event.code 区分物理位置，小写、Shift 与 Caps Lock 等效，Ctrl／Alt／Meta 不误触。T／S 直接提速／减速，常亮且无数值，主仪表仅四项，移除Engine及百分比；W的Open／Closed状态保留在底部。中文由共享dom模块将汉字和中文标点单独增大1px，静态入口及动态文案统一处理；保持文本值、英文数字字号和既有节点缓存，不使用逐帧扫描或MutationObserver。所有英文只有首字母大写，OFF／ON 例外；未来标点采用 Comma／Period／Semicolon。

音效使用单个 Web Audio 上下文、复用振荡器与噪声缓冲区，发动机跟随启动进度及实际动力，风声跟随空速，轮胎声仅接地时出现，刹车加强摩擦声，电机声跟随收放状态。game.onEvent 触发短音和播报，逐帧 update 只更新持续声与倒数变化，相同 AudioParam 目标不重复排程，连续静音不重复取消声源，恢复时重新设置主增益。音效与播报默认开启，不设置声音开关，首次真实手势解锁；暂停、失焦、COMPLETE 和 RESULT 立即关闭主增益、停止短音并取消语音。恢复只读取当前持续状态，不排队重播；重开使用现有 runId 清理本局瞬态。参数集中 AUDIO。

Speech Synthesis 只选择 localService 的英文声音，优先匹配配置内的本机音色；没有本地英文语音时保留文字与合成音效。播报最多保留当前一句，新事件替换旧的普通句子，安全警告优先，单句最多 2.5 秒有效游戏时间；播报时环境声按原始目标音量降低，警报不降低。不可把接口接入或信号采样当作已通过实际女声音色／扬声器混音验收。

## 新增关卡与地景

新关卡只扩展LEVELS与JOURNEY，通用Flight／Mission不按城市分支。RouteWorld的地面山面、独立凸岩体与建筑包络为渲染和碰撞的共用来源；悬空岩体不进入heightAt。水幕只有可见面与穿越区域，岩石仍有实体检测。目的地跑道与基准地面统一零海拔；AirportView整体应用目的地标高，机轮约束和接地使用同一标高。

一局仅有深圳与当前终点机场。跑道、机坪、地图目标、距离、进近与胜利统一读取route.destination，模板参数变化必须覆盖所有关卡。完整契约见[三关航线与机场](../design/07-航线与关卡.md#共用机场契约)。

## 准备耗时与资源预算

首屏从必需资源和基础模块就绪起计，2秒内显示标题、开始入口和轻量预览，资源下载耗时另记。开局从点击开始至可操控计时，包含加载、缓存、生成、编译、上传和四秒运镜；第二阶段配置为8秒。真实任务可利用3秒Loading窗口，不额外空等；重开复用场景。`First screen visible`、`Scene prepared`、`Flight loading completed`和`Flight control ready`分别记录首屏、完整场景、加载和可操控时刻，不混用计时口径。

当前第二阶段发布资源预算为小于25 MB，不是必须占满的目标；当前山形、岩纹和树木均由代码生成，没有新增二进制模型或外部纹理下载。预生成属于必要时的后备方案，产物只能进忽略目录与部署包，不能提交Git。当前Pages资源整理流程继续复制源码与必要Three.js模块，未增加模型编译步骤。

GitHub Pages站点最大1 GB、带宽软限制100 GB／月，部署10分钟超时；自定义Actions构建不受每小时10次构建限制。发布大小与Git仓库历史独立核算，详见[官方限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)。

速度控制参数集中FLIGHT.speedRate／speedBrakeRate／speedMultiplier／takeoffSpeedMultiplier／airSpeedMultiplier／speedTapKmh；起飞前onGround且未landed时T使用18倍，空中T使用15倍，所有S和接地后T使用10倍。canChangeSpeed按CLEAN／TAKEOFF即时状态门控；speedDecayRate／wingBrakeDeceleration以km/h每秒存储，固定5与W额外10的阻力和主动变速独立叠加，不扣T／S点按额度；合并后统一截断到0–maxSpeed，持续T可达到上限；W切换、暂停和结算清空speedTapRemaining。点按末步截取额度，长按不叠加速率。只有T有效请求时throttle和thrust非零；超高故障缩放提速率。脚部视角复用主场景和飞机，临时恢复壳体并隐藏内舱，finally恢复状态，两个小窗共用同帧矩阵与裁剪更新。

Flight.updateSpeedLimits读取固定150 km/h触发与165 km/h恢复阈值；Flight在垂直运动前更新带恢复区的stalled状态，低速只限制垂直目标，不修改俯仰、滚转、前进速度、推力或接地条件。下沉参数以km/h存储（27–216），积分时换算为7.5–60 m/s。stallGuidance按发动机和T故障给出一致指引。Mission.flightSeconds只累计离地后时间，elapsed仍从R放行起算；遭遇捕获生成时的相遇预测后固定运动。

## 第二阶段共享表面资源

`src/surface-assets.js`组织12份基础纹理、24份共享几何与11项纹理增强任务。首屏不等待这些工作；基础模型、碰撞与必要GPU对象完成后进入四秒运镜。当前按第二阶段资源预算验收，额外准备余量以`GAME.scenePrepareLimitSeconds`为准。发布仍是原生ES Modules，只保存生成代码、配置和种子，不增加模型／纹理下载。

机身80个径向分段，发动机使用64段外壳、空心进气道与32片弯掠叶片。主翼和尾翼使用保留原平面轮廓的弧面翼型，增加圆钝前缘、薄后缘、翼尖收薄与金属前缘；起落架补充支杆、轮毂紧固件与圆肩轮胎。机场补充窗框、屋顶设备和机库结构。基础几何在开始前生成、合批并预热；机轮与减速板保持独立动画，碰撞采样与关卡布局不变。

本游戏允许在READY、四秒INTRO、入舱后的STARTUP及已放行但尚未加速／位移的静止阶段继续补充细节。首次T指令或位移会按现有runId锁住本局生成窗口：先暂停队列并终止Worker，再处理提速，松开T不会恢复。飞行／滑跑中禁止继续生成、解码或上传。暂停和结果页可继续，恢复前同步停止；重开清除本局锁定并复用同一静态队列。R起算的任务时限不因可选细节生成而延长。

`src/generation-queue.js`用requestIdleCallback调度非紧急任务；真实Loading改为后台scheduler.postTask持续推进，批间scheduler.yield，不支持时用setTimeout。CPU批次目标4毫秒，高刷新率或长帧时收紧可选批次。纹理按行／256像素块、机身按截面、其他几何按对象设置让出点。像素及mip计算由模块Worker完成，ArrayBuffer直接转移；停止时终止Worker，未完成数据在下次许可窗口重算。异步读取只保存返回值，重新校验队列状态及当前窗口后才继续创建或上传。

静止等待时逐步把主要立面和岩纹提升至2048，其他地表与蒙皮纹理升至1024，舱框细纹512，金属256。颜色纹理在线性空间生成mip层，数值纹理直接平均；GPU按每层32行分批上传，整张完成才替换材质，释放旧GPU对象。上下文丢失使用AbortController中止未提交上传，恢复后重传，防止采用失效进度。反射集中用于玻璃、蒙皮和金属，粗糙地面与森林不增加环境反射采样。共享纹理及mip的估算体积约97.8 MiB，含单张待提交纹理时受128 MB生成预算约束；该值不是发布体积，也不代表整个场景显存。

`src/surface-cache.js`通过IndexedDB保存原始像素、mip及几何属性／索引，键包含项目、生成器版本、配置哈希、关卡和种子。像素以512 KiB块读写，元数据最后提交；不完整或不匹配记录重新生成，旧配置记录按关卡清理。缓存不可用时退回内存，同页重开仍复用；命中持久缓存仍需初始化GPU对象。逻辑地形与查高继续使用同源世界数据，不混入旧视觉缓存。

部署仅包含源码、必要Three.js模块和模块Worker，兼容Pages项目子路径；生成缓存和部署副本均不加入Git。生成、Worker、编译、上传与真实帧耗时分别记录，不能用CPU提交耗时或绘制次数推断GPU速度。具体实测见[第二阶段地景验收](validation.md#第二阶段地景验收)。

## 程序版本与启动升级

`src/version.js` 的 `APP_VERSION` 是程序发布版本唯一来源，当前为1.0.1，独立于生成器版本5及缓存格式1；包描述与锁文件同步。Pages准备流程校验正式Release标签（`v1.0.1`或`1.0.1`），不匹配即失败，并写入同版本`version.json`，游戏标题栏显示版本。具体升级与发布规则见根目录`AGENTS.md`，不因整理部署文件自动发布。

启动先显示轻量预览与版本检查，再读取IndexedDB的`cloud-cockpit/meta/completed-version`。无历史为首次准备；有历史且版本不同显示“版本升级”、实际进度和失败重试入口，完成前不允许开始。同版本直接进入开始界面，不强制再等升级；当前关卡的资源始终按自身清单校验。首次／升级时完成32项基础数据及11项增强纹理的读取、增量生成、持久化与GPU准备，再清理未再引用的当前关卡生成记录，确认成功版本写入后开放开始。生成任务沿用4毫秒目标分批和Worker；升级耗时独立于点击开始计时。

缓存按项目、关卡、资源名称、生成器／格式版本及该项实际配置依赖生成键；程序版本和调度参数不使资源失效。旧整组配置键在配置完全一致时逐块迁移，不重新生成数据。更新前保留旧记录，完成后仅清理当前关卡未再引用的生成缓存；其他关卡按进入时的清单更新，不影响存档、设置或其他项目。失败可重试，部分完成数据复用；存储不可用时明确提示仅本次会话准备，成功版本不登记为持久完成。

## 碰撞反馈与鸟击限速

`Game.finish`区分实体损毁和非实体失败：撞地、障碍物及其他飞机携带destructive标记，进入CRASH。复用completionElapsed推进2.8秒特效，飞行积分、任务时钟、交通和activeSeconds均冻结，期间不接受飞行指令。暂停冻结特效，恢复后续播，结束后才显示RESULT；重复失败不会重启或提前结束特效。重开以现有runId和reset清理状态，成功仍走原COMPLETE反馈。

`src/impact-effects.js`在场景准备时预分配236个点粒子、24个实例碎片和一次闪光，加入既有材质编译／几何预热。运行时只更新uniform、实例矩阵和可见性，不创建几何、纹理或Worker；重开复用同一池。固定种子的小型初始参数和GPU对象与本会话绑定，代码即为完整配方，不额外持久化这些廉价缓冲；现有共享模型／纹理的IndexedDB缓存策略不变。火光／烟雾使用解析点精灵，不新增贴图、后处理或资源下载。音效继续由Web Audio复用噪声缓冲合成，暂停与结果静音。

`Mission`按雁群hit去重。Flight.maxSpeed读取FLIGHT.maxSpeed，正常前进上限600 km/h，首次鸟击后为480 km/h；limitSpeed仅缩放水平分量与airspeed，保留垂直动量。第二次禁用T并清空正向额度，S和方向操纵保留；暂停和动力故障恢复不解除，重开或下一关恢复。

## 公制速度约定

速度状态和规则参数统一使用km/h：aircraft.airspeed／verticalSpeed、Flight的失速／安全／最高速度、结果最大／离地速度，以及FLIGHT／AERODYNAMICS／ROUTE／LEVELS中的速度阈值和交通速度均为同一单位。界面、起飞标记、进近、起落架、着陆、鸟击提示和结果页直接读取这些值，不再做节的换算；三关巡航约370／417／454 km/h，抬轮250 km/h，进近60–180 km/h，安全接地60–180 km/h且俯仰±3°，起落架放出门槛约407 km/h。极限速度600 km/h，持续T或点按均不得超过；不产生超速提示或语音，鸟击上限为极限速度的80%，即480 km/h。垂直速度与下降率也显示km/h，但不作为接地失败条件。

位置、三维velocity与碰撞扫掠仍使用米／秒，前进速度通过FLIGHT.kmhPerMps=3.6换算。airspeed不再从三维速度模长反算，避免下坠误算为提速。鸟击保留垂直速度，卡车事件将前进速度和三维velocity各保留90%。速度规则不使共享几何／像素缓存失效。


姿态卡交通示意由`PreviewTraffic`在场景准备时创建6个可复用目标槽及箭头缓冲，飞机／雁群轮廓共用两份极小几何，不新增像素纹理。它们属于可直接重建的小型GPU显示对象，初始化成本低，不单独持久化；已有大型模型／像素缓存保持复用。位置直接读取TrafficView的同帧插值结果，在同一参考航向下均匀变换相对三维坐标；图标为辨认用途，不作为碰撞尺寸。危险色读取Mission.danger，不另写接近判断；A关闭、暂停、重开与主交通一致。目的地跑道通过route.destination统一6000×240米，AirportView边灯按实际长度铺设，Flight安全接地和滑跑边界同源；机场标高保持同源。


张家界石柱的截面由`createRockFootprint`按独立种子和形态参数做半平面裁切，保留凸性；各高度截面同源生成可见三角面和碰撞平面。使用顶点均值作为内部参照点统一法线方向，保留原中心、半径、高度和布局随机流。峰顶树木由实际顶面多边形内插落位；暖黄、浅黄、褐色风化和绿色顶面在场景准备时写入顶点颜色，复用既有岩纹及材质，不在游玩中重建。截面与逻辑凸体每次按当前配置轻量生成，不读旧岩柱几何缓存；共享模型／像素配方未改，继续复用兼容IndexedDB资源。

目的地停放布局使用AIRPORT_TRAFFIC独立固定种子，三关各4架客机及8辆卡车，渲染和碰撞共用位置／朝向／机场标高。停放客机直接实例化已有客机几何并克隆一组材质，避免玩家入舱淡出影响它们；卡车低面数几何在场景准备时建立一次并复用，不持久化这份极小基本体组合，不新增模型或像素文件。共享飞机几何／纹理仍走已有持久缓存，无数据配方变化，不修改生成器版本。开局前统一GPU预热，碰撞时只改变已有矩阵与状态。移除停机圈及其标签纹理，地图星标指向跑道中部；安全接地后机身位置位于跑道内、速度≤7.2 km/h连续1秒完成，机坪不计成功。卡车每辆只扣当前速度10%一次，抛落先完成才接受成功；暂停／重开沿用Game时钟和Mission状态。

世界水平位移统一经过config.worldHorizontalSpeed（当前4倍），Flight仅在X／Z坐标积分处使用，空速、T／S额度、姿态响应与Y积分保留；Mission的交通预测和相对速度、PreviewTraffic航迹箭头、卡车抛飞继承动量使用同一倍率，交通velocity保存世界坐标速度，不能再次放大。地面、地标和目的地已绑定统一布局；总里程为78.5／158／206公里，进近距离和目标下降曲线按同一空间倍率换算，关卡时限为300／480／600秒。clusterZ按景点中心和regionScale=5定位群内纵向偏移；实体的纵深、山体半径与岩柱轮廓同步扩展，地形种子读取sourcePosition，移动山群不重抽山脊。

新增过渡带来自JOURNEY.transitions：小丘48分段，显示、碰撞和查高共用RouteWorld生成的网格；草坡与平地使用同一草纹和世界UV以隐藏底座边缘，溪流与草地不增加像素资源。LandscapeView.prepare复用GenerationQueue逐段／逐座创建显示对象，Renderer.prepare等待该队列结束、登记新材质并统一预热，随后才开放操控。新增低成本逻辑网格和基本显示对象直接重建，重开保留，不为几千个顶点单独引入持久化恢复开销；共享模型与纹理仍使用32项基础／11项增强持久缓存，现有配方未变，生成器5、缓存格式1与尚未发布的程序1.0.1继续使用。

滨海前段由coastal-terrain.js集中定义海岸、机场陆地平台和连接道路；RouteWorld初始化与配置对应的逻辑海岸网格，显示复用同一顶点，查高按同一非均匀网格三角形插值，水下高度由可见海平面覆盖。机场及机坪保持原标高；草地、溪流与机场树木按实际陆地过滤。第一关保留滨海平原与低缓小丘，不设置高山或瀑布岩壁，后续丹霞、石柱与两道空中瀑布保留。CoastalView通过现有GenerationQueue准备海面和沿岸高架高速：桥面、三道护栏与桥墩按路段划分实例构件，位置、尺寸和朝向直接读取World碰撞数据；有向六平面保留桥下通行空间。海面不使用新增像素资源，波纹只更新既有材质时间，暂停冻结，GPU预热完成后才开放操控。逻辑网格为轻量确定性计算，显示对象同页重开复用；共享几何和像素缓存配方未改变，生成器5、缓存格式1和未发布程序1.0.1保持。


`windshield-damage.js`预创建两组独立蛛网裂纹与轻量玻璃面，首次／二次鸟击分别显示一组；复用相机局部坐标随窗口缩放，暂停沿用有效时钟。几何为极小固定种子线段／面片，在驾驶舱准备时创建并统一GPU预热，同页重开复用；没有贴图、解码或昂贵计算，单独持久读写成本高于重建，因此沿用轻量基本体的内存例外，不改变共享模型／像素配方。鸟击计数归Aircraft，每雁群一次；Flight派生T故障，指令与持续变速均门控，Mission在第二次撞击清空待执行正向额度。未放轮下降警告由Flight统一产生，UI／Audio读取同一危险条件，触地走原有CRASH流程。


`flight-status`只承载当前最重要的一条异常警告，贴近屏幕上沿并使用深黄／深红背景；正常时隐藏。已移除常规操作教学、抬轮目标及所有角度／扩展气动读数，基本仪表和按键图例保留，右侧飞机图不包含安全文字。Prompts仅保留短时操作／奖励反馈，安全状态直接读取Flight／Mission，不用事件文本维持过期警告；放轮因速度受阻时记录操作条件，在速度恢复或放轮后解除顶部提醒。AircraftPreview只放大有交通时的本机显示，继续复用既有模型与材质；预览相机、其他交通符号比例、相对位置换算及缓存配方保持，黄色／红色用更深的状态色。


起降语音统一由FlightAudio处理：released、liftoff、climb-complete、approach、final-approach、landed使用短英文阶段提示，优先于普通开关确认。英文短句优先通过固定Samantha语音库播放：页面预取、首次手势解码一次，按VOICE_CLIPS的偏移／时长播放，voiceGain独立于环境声master。暂停、换局与结算停止当前BufferSource并清理待播请求；旧source.onended不能清除新source。浏览器Speech Synthesis仅为语音素材失败回退，起降不发确认短音。

遭遇时刻在createRoute按基础时刻乘关卡时限比例，再加index×30秒，保持预创建的六个遭遇槽与同源预告／碰撞。RouteWorld读取courseBuildings按关卡添加第三关陆地高楼，LandscapeView.addCity直接复用这些建筑实例。广州塔和中央丹霞山调整复用原几何创建流程，低成本关卡几何始终按当前配置重建，未从旧关卡几何缓存恢复；共享像素／客机缓存配方未变，生成器5、缓存格式1与未发布程序1.0.1保持。


## 降落调试入口

启动页checkbox仅在READY阶段选取，requestEnter在等待场景前捕获选项，准备和版本更新中禁用。Game.enterCockpit接收landingDebug，复用INTRO但在驾驶舱内倒数3秒；introDuration统一驱动UI／音效，Renderer跳过外部运镜。Game.prepareLandingDebug只初始化同一架飞机、Flight快照与Mission起点，不生成新世界。倒数结束才Mission.start并切入APPROACH；接管清空倒数期间按住的输入。NavigationUI按现有runId或path引用更换清理旧轨迹，避免从深圳误连调试出生点。参数集中LANDING_DEBUG；G动画读取FLIGHT.gearSeconds=0.5，放轮无高度门槛，收轮保留30米和正爬升门槛。W默认CLEAN／0，UI起步清单从STARTUP_STEPS排除W，E／R仍检查实际准备条件。

进入目的地进近、离地高度低于200米且尚未接地时，屏幕顶部始终显示Landing speed 60–180 km/h，速度合格时用绿色背景并提示保持，偏低时提示提速；高于着陆上限时仅保留速度范围，不提示速度过高或减速，也不因此改变飞机图颜色。其他危险警告与速度范围在同一条顶部状态中并列显示，不覆盖速度约束；存在两次鸟击导致提速失效时不给出无法执行的提速建议。达到200米或接地后解除速度常驻提示，暂停保持，重开清除；不使用短时toast或反复播报。

基础飞行声增益由AUDIO.engineGain／harmonicGain／fanGain／windGain配置，客舱双音参数集中AUDIO.cabinChime。FlightAudio复用Mission.flightSeconds和已有runId重置播放时刻，按首次18–28秒、后续45–75秒的间隔触发；短音共用shots与静音清理，播报或警报可取消尚未开始的第二声，不增加异步计时器或音效文件。

## 第二阶段区块架构

景点群中心与机场按航线配置统一定位，城市街区和田园过渡使用各自明确的范围。外围使用12公里区块、四种固定种子模板和7×7槽位池，随飞机位置重新分配已有对象；模板的192段地形、颜色、法线及植被权重在开始前生成并持久缓存。显示范围按600 km/h飞行40秒并计入4倍水平位移，即半径约26.67公里；外围由固定高山墙体封闭。循环仅复用已预热模型与变换，不在游玩中生成地形、纹理、碰撞对象或启动Worker。返回同一区域使用相同模板和碰撞，不复制目标机场或产生额外胜利点。

所有机场和航线基准地面保持零海拔。飞机实际MSL上限1980米，对应显示9900米；到顶只停止上升，不改变姿态。建筑混合细长高楼、宽厚高楼、中层和低层；高层主体与主要山峰围绕显示12000米形成障碍，普通物体最高实际4000米／显示20000米；外围山墙例外，为实际6000米／显示30000米。AGL、MSL和相对高度统一乘5，水平距离、空速及垂直速度不换算，显示200米低空门槛对应实际40米。

`loop-world.js`提供模板配方、稳定区块映射和同源网格查高；`loop-view.js`管理已预热槽位、LOD、内部水面与圆形显示边界；`building-layout.js`给出建筑分段尺寸，`city-blocks.js`消费同一尺寸创建实例化立面。循环地形配方版本独立为LOOP_WORLD.recipeVersion，缓存清单覆盖全部参数；兼容飞机和纹理缓存继续复用，程序版本及缓存格式不因添加地景无条件失效。

循环城市碰撞使用512米空间索引，查询只检查本次机身扫掠覆盖的单元。实例矩阵和颜色在槽位间共享，静态世界矩阵仅跨区时更新；预热选取每种模板一个代表，轻量预览保留到预热完成，避免重复同步编译。

田园派生数值持久保存于scene/country组，按关卡、全景配置、尺寸、中心与种子定位；COUNTRYSIDE.cacheRecipe为4。每块数据校验顶点属性、索引范围、实例数量和有限数值，全部写入成功后才保存目录。GPU材质与树冠当前页资源不序列化；持久恢复后重建对象，同页重开复用对象。基础资源和循环高度网格维持独立清单；缓存不可用时继续内存准备。

`world-boundary.js`提供固定山墙的可缓存网格和相同三角插值；`region-blend.js`统一所有区域的衔接范围及水面／街区／跑道排除条件。城市按1.68公里空间块分批创建，材质与单位几何在主场景共享，外围仅复用代表街区。


## 分批创建与GPU预热

浏览器入口通过Game的deferWorld选项仅创建轻量状态，再由现有GenerationQueue消费RouteWorld.build；其他同步调用保持兼容。山体网格按行计算，完成后显示、碰撞与查高读取同一份缓冲。GameRenderer构造器只登记对象队列，prepare依次完成交通／驾驶舱、地标／古塔／静态合批及地景资源。首次T与位移的增强门控保持。

scene-preparation.js先收集材质变体及共享几何／实例缓冲的代表对象，分批compileAsync，再以每批四个对象、一个实例及少量三角形预提交。几何范围、分组和视口在每批提交后恢复，实际场景不被临时重挂；已有光源只在准备场景中引用。预提交使用正式主画布的色彩空间和色调映射，准备结束前隐藏画布并保留轻量预览，避免普通离屏目标生成另一套着色器。全部必需资源准备完成后才首次绘制正式画面与开放操控。

初始化WebGL解包状态时使用Three.js状态管理，避免第一次copyTextureToTexture通过getParameter同步等待此前绘制；上下文恢复时重新登记。增强像素与mip仍逐块上传、保留取消与旧纹理回退，不降低贴图尺寸。每类队列、编译CPU与等待、提交CPU、单批峰值独立记录；原生编译和驱动调用不能仅凭4毫秒调度目标宣称没有长尾。


城市实体细节只保留屋顶、女儿墙和设备箱，不再生成每55米一圈的1.1米薄条。city-blocks的facadeSize实例属性同时提供宽、高、深，侧面UV读取实际进深；颜色采样用textureGrad按窗格投影足迹平滑扩大过滤，亚像素窗格同时降低凹凸与粗糙度变化，实体屋顶材质设深度偏移。显示和碰撞继续消费同一buildingParts；楼体尺寸与街区布局对应layoutRecipe=4，像素配方、全局生成器及缓存格式不变。

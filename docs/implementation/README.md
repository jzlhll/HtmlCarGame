# 技术与实施说明

[返回总览](../README.md)

## 技术与本机开发

原生 JavaScript ES Modules、Three.js `0.186.1`、DOM／CSS／SVG 界面与 Web Audio 合成音效、本地 Speech Synthesis 英文播报，无编译或打包步骤。入口为 `index.html`，import map 从本机依赖目录加载 Three.js 与 BufferGeometryUtils；运行不依赖 CDN。

依赖缺失时执行 `npm ci`，随后 `npm start`，地址为 [http://localhost:5186](http://localhost:5186)。多工作目录可用 `PORT=5187 npm start` 选择空闲端口，不停止用户已有服务。`scripts/serve.mjs` 只监听回环地址并限制资源根目录，通过 HTTP 加载，不直接打开 HTML。

保留现有 macOS 启动脚本与 Release 资源整理工具；当前不发布飞行分支。增加资源或 addons 时同步维护服务白名单和发布拷贝清单。

## 状态与时钟契约

主要流程为 `READY → INTRO → STARTUP → TAKEOFF_ROLL → INITIAL_CLIMB → CRUISE → APPROACH → LANDING_ROLL → TAXI → COMPLETE → RESULT`。满足进近空间条件时也可从爬升直接进入 APPROACH；没有达到初始爬升目标不会阻止玩家尝试安全着陆。安全接地是 LANDING_ROLL 的唯一入口；任务胜利还必须在圈内停稳。

准备、四秒开场与三秒启动不消耗航程时限。首次 R 合法放行调用 Mission.start，此后即使刹停、重新驻车或恢复准备，本关时限仍继续；只有重开清空。所有物理、遭遇、收放、提示、停机保持和任务时限都由有效游戏步推进，暂停／失焦冻结，恢复不补算停留时间。

Game 优先处理飞行接地／越界与世界／交通碰撞失败，再处理任务完成。本关时限之外不接受停机胜利。完成冻结飞机，1.5 秒短反馈后进入静止结果页；失败只结算一次。结果用时为任务时钟而不是准备耗时。

滑跑、爬升、巡航、进近和着陆之间保留持续操纵；暂停、结果、重开及准备／放行等输入门控切换清理按住集合。普通开关和受阻指令不重置逻辑步余量。

## 飞行与世界数据

内部采用米／秒／弧度，Three.js Y 向上，计划航线沿 −Z。`aircraft.position` 与轮子、机腹、翼尖接触点使用同一参考点；高度表显示最低接触点离地高度 AGL，导航显示海拔 MSL，限高检查 MSL。固定质量存于 AERODYNAMICS，不引入载重或机场性能表单。

平移使用推力、升力、阻力与重力三维积分，T／S 通过固定步有限施力控制纵向变速，点按不直接缩放速度，自动动力只补偿正常配平阻力，提速受推力上限约束，发动机读数和声音平滑跟随。迎角由俯仰减航迹角得到，临界后升力连续衰减、分离阻力上升；恢复有安全区保持时间。操纵效能受动压和失速影响，俯仰／滚转变化率受限；不直接跟随目标高度或垂直速度，点按短促施力属于游戏辅助，不采用完整刚体力矩／侧滑／结构损伤模型。

G／W 的 EXTENDING／RETRACTING 进度驱动视觉和受力。flaps／flapsPosition 保留内部标识，CLEAN／0 为减速板关闭，TAKEOFF／1 为打开。W 无高度或速度门槛，起飞完全关闭，安全接地完全打开；G 保留收轮高度和放轮速度限制。接地后自动减升增阻，S 直接减速并显示轮刹反馈。

每个关卡页面创建一次RouteWorld并复用，重开不重建静态场景；通过 ?level=1／2／3 选择关卡，原生页面导航结束旧页面和声音，不在运行中改写全局配置。createRoute生成独立规则与机场数据，terrainElevation是共用地面标高的唯一来源。建筑／地标用包络和空间网格索引，山体以固定高度网格直接定位对应三角形并线性插值查高，近景绘制使用同一网格，远景索引简化不改写碰撞；飞机多个带半径采样点扫过前后位置，每个固定步只计算一次前后姿态的采样端点，世界与交通碰撞共用。整体扫掠包围盒先排除不可能接触的建筑、山体和交通目标，再保留原有逐点窄相检查及山面采样间距；不得通过降低物理频率或扩大穿透容差提速。交通碰撞使用双方相对位置线段，飞鸟逐只检查，固定队形偏移随航向缓存。详细边界和着陆阈值见[航程专题](../design/07-航线与关卡.md)。

## 渲染、导航与事件

完整前窗使用主场景／主相机，固定飞行员眼位向下 5°保留地景；机外姿态使用同一显示姿态与独立裁剪视口，不新增 WebGL 上下文。开场以有效时间采样平滑轨迹，外壳和内舱渐变保留深度写入；对数深度、表面 polygonOffset、36 km 远裁剪及 32 km 天空球控制远近景闪烁。阴影只在可见机体、收放、机壳透明度或 WebGL 恢复时失效；山谷遮蔽在建图时烘焙为顶点数据，不每帧扩大阴影范围。

进入开场前异步预编译主场景与姿态卡片材质，预上传纹理，并用小视口提交全部几何；随后恢复可见性、裁剪状态与机场阴影。准备期间暂时禁用开始按钮和空格进入，完成后才允许四秒倒数，准备时间不计入游戏时钟。避免远景首次进入镜头时集中编译造成约两秒处的卡顿。

逻辑快照按帧余量插值，暂停／结果保留最后显示姿态。机场与地景的静态变换矩阵在创建时确定，后续仅更新可见性和纹理偏移；新增会移动的地景必须恢复相应节点的矩阵更新。飞机按材质合并静态几何，并保留轮、减速板和航行灯的独立控制；当前飞机材质无贴图，增加贴图时须保留所需顶点属性。机场仅合并同材质的不透明平面，透明编号保留独立排序。建筑实例化；山体共享网格顶点、法线及颜色，通过不同索引切换远近细节，森林按区块切换实体树冠／交叉树片并裁剪；瀑布只更新纹理偏移，交通模型预先建立，读取逻辑对象位置。当前地图有限，不声明已实现无限巡航或地形回收。

航线轨迹每 0.25 秒记录真实世界位置，包含偏航；导航和雷达以 8 Hz 更新 SVG，固定网格与计划线只创建一次，实际轨迹只格式化新增采样，目标节点按稳定 ID 复用，重开清空轨迹和目标。仪表复用文字节点，仅写入变化的字段；同一帧的多个状态通知合并为一次界面刷新，输入门控和音频静音仍即时执行。雷达目标、箭头与场景模型使用同一位置／速度／航向，前 10 秒预告闪烁，危险依据最近接近距离与高度差，暂停不闪烁、不移动。A 关闭雷达时不显示目标。

临时提示以有效事件 ID 去重，最多 2.5 秒，不由速度／高度刷新计时。安全区恢复后才允许新的危险进入事件；失速与超高故障优先于交通／姿态，后者优先于普通操作。每道瀑布按独立ID每局只奖励一次。常驻仪表、任务与故障状态不使用短提示生命周期。

舱门内部 `systems.door` 为准备完成标志：true 表示关闭并锁定，界面显示 Closed；false 表示打开，显示 Open。F／R 继续依据同一准备状态检查，不以显示文案反向推断。

输入以 event.code 区分物理位置，小写、Shift 与 Caps Lock 等效，Ctrl／Alt／Meta 不误触。T／S 直接提速／减速，常亮且无数值，Engine 百分比表示自动动力，旁列 W 状态。所有英文只有首字母大写，OFF／ON 例外；未来标点采用 Comma／Period／Semicolon。

音效使用单个 Web Audio 上下文、复用振荡器与噪声缓冲区，发动机跟随启动进度及实际动力，风声跟随空速，轮胎声仅接地时出现，刹车加强摩擦声，电机声跟随收放状态。game.onEvent 触发短音和播报，逐帧 update 只更新持续声与倒数变化，相同 AudioParam 目标不重复排程，连续静音不重复取消声源，恢复时重新设置主增益。音效与播报默认开启，不设置声音开关，首次真实手势解锁；暂停、失焦、COMPLETE 和 RESULT 立即关闭主增益、停止短音并取消语音。恢复只读取当前持续状态，不排队重播；重开使用现有 runId 清理本局瞬态。参数集中 AUDIO。

Speech Synthesis 只选择 localService 的英文声音，优先匹配配置内的本机音色；没有本地英文语音时保留文字与合成音效。播报最多保留当前一句，新事件替换旧的普通句子，安全警告优先，单句最多 2.5 秒有效游戏时间；播报时环境声按原始目标音量降低，警报不降低。不可把接口接入或信号采样当作已通过实际女声音色／扬声器混音验收。

## 新增关卡与地景

新关卡只扩展LEVELS与JOURNEY，通用Flight／Mission不按城市分支。RouteWorld的地面山面、独立凸岩体与建筑包络为渲染和碰撞的共用来源；悬空岩体不进入heightAt。水幕只有可见面与穿越区域，岩石仍有实体检测。地面网格须显式包含海拔剖面折点，目的地入口后保持平面；AirportView整体应用目的地标高，机轮约束和接地使用同一标高。

一局仅有深圳与当前终点机场。停机圈、机坪、地图目标、距离、进近与胜利统一读取route.destination，模板参数变化必须覆盖所有关卡。完整契约见[三关航线与机场](../design/07-航线与关卡.md#共用机场契约)。

## 准备耗时与资源预算

优先使用浏览器在开始前生成关卡与山体，初次准备结束才允许开始，重开不重新生成。总准备时间从本次页面导航起至开始按钮可用，预算12秒；`Scene prepared`英文日志拆分模块加载、世界生成、景物生成与GPU准备，超时另输出警告。日志与Performance条目用于定位和复测，不向游戏界面添加技术信息。超过预算先优化最耗时阶段，仅仍无法达标时才考虑预生成相应部分。

发布资源预算上限50 MB，不是必须占满的目标；当前山形、岩纹和树木均由代码生成，没有新增二进制模型或外部纹理下载。预生成属于必要时的后备方案，产物只能进忽略目录与部署包，不能提交Git。当前Pages资源整理流程继续复制源码与必要Three.js模块，未增加模型编译步骤。

GitHub Pages站点最大1 GB、带宽软限制100 GB／月，部署10分钟超时；自定义Actions构建不受每小时10次构建限制。发布大小与Git仓库历史独立核算，详见[官方限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)。

速度控制参数集中 FLIGHT.speedRate／speedBrakeRate／speedModeRatio／speedTapSeconds；W 打开进度 p 的倍率 m=1+9p，提速基准为 speedRate/m，减速为 speedBrakeRate*m/10。内部 throttle 为自动动力需求，不是玩家输入或停机条件。脚部视角复用场景与主飞机，绘制期间临时恢复机壳可见性并隐藏内舱，finally 恢复材质、可见性与裁剪状态；不新建 WebGL 上下文、地景或飞机模型。两个小窗布局改变后更新缓存边界。

Flight.updateSpeedLimits使用当前密度、减速板和坡度计算平飞Vs与1.2Vs，失速判据仍为迎角；自动动力排除分离／超速额外阻力并在低动压下衰减。正常俯仰操纵和失速气动低头叠加，速度、位移和碰撞持续积分。Game暂停与结算清空speedTapRemaining。Mission.flightSeconds只累计离地后有效飞行时间，遭遇捕获生成时的三维相遇预测，此后固定运动；任务elapsed仍从R放行起算。TrafficView使用同一birdScale／trafficScale与逻辑椭球，雁群镜像使用独立共享左翼几何，不向InstancedMesh写入负缩放矩阵。

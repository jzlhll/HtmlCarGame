# 本机运行与实现结构

[返回设计总览](../README.md)

## 运行入口

`npm ci` 安装锁定版本的 Three.js，`npm start` 启动内置 Node.js 静态服务，地址固定为 `http://localhost:5173`，只监听本机回环地址。依赖安装完成后无需联网，无构建步骤，无外部模型或图片下载。macOS 提供根目录 `启动游戏.command`。

通过 HTTP 服务加载 ES 模块，不直接双击 `index.html`。服务只提供入口页面、`src` 与依赖文件，不提供项目文档或隐藏文件。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `config.js` | 六车型尺寸、巡航速度、玩家上限、横移速度、整数成长值与公共插值 |
| `main.js` | 组装模块、固定逻辑步、按需帧调度、页面失焦与跨标签存档变化 |
| `input.js` | 页面捕获游戏按键、拦截无操作的上箭头、左右横移、下箭头刹车、空格重复保护与焦点恢复；保留编辑输入和浏览器快捷键 |
| `game.js` | 游戏状态、积分、速度限制、碰撞分组、升级降级、死亡与单次结算 |
| `collision.js` | 分离轴连续接触、首次接触车头位置、侧碰／追尾分类 |
| `road.js` | 种子有限道路计划、平滑曲率、三维弧长采样、上下坡、跨轮平移连接、车道过渡与墙位置 |
| `hazards.js` | 稀疏坑洞与泥洞计划、椭圆轮迹连续接触、每轮障碍身份与接触记录 |
| `traffic.js` | 有限车流、前后净距、仅系统车辆参与的跟车与变道决策、预告与回正 |
| `models.js` | 六类低多边形车辆、复用几何与材质；车辆上无等级标识 |
| `render.js` | 相对坐标、固定道路网格、实例化景物、车辆池、四季材质混合与效果 |
| `scenery.js` | 附近地块布局缓存；楼房、谷仓、粮仓、作物、围栏及奶牛静态部件与动画的独立实例批次 |
| `storage.js` | 单键版本存档、校验、排名、存储降级与异常重置 |
| `ui.js` / `style.css` | 游戏信息、危险提示、暂停窗口、结算和记录 |

逻辑道路位置使用累计弧长 `s` 和横向偏移 `d`。`Road.at` 提供高度与坡度；每次显示将世界位置转换为玩家附近的局部坐标，循环道路跨轮沿上一轮终点连接，不重置累计距离。道路和景物使用固定容量实例或网格，车流最多 44 辆；车辆按车型回收复用。

连续碰撞使用每秒 120 步的分离轴平移扫掠，车辆盒体采用本步起始位置的道路切线方向，纵向长度按坡度投影到水平面。首次侧面接触时，将目标实际车头、车尾投影到玩家纵轴，按我方车头是否超过对方车头或位于对方后半段判断侧碰。路面障碍采用车轮与履带采样点对椭圆区域的连续接触，并加入相同的事件时序。坑洞弹跳仅抬升显示模型，逻辑碰撞仍在道路平面；步内曲线方向变化很小，但该实现不是完整刚体旋转扫掠，若加入真实腾空、急弯或自由转向，需要扩展三维旋转连续碰撞。

同一步中先处理最早接触，等时接触按当前等级统一判断，致命事件优先；非致命事件处理完之后重新检查余下运动。致命接触按实际接触时刻锁定距离和有效时间。升级不提供无敌或推开周围车辆。

同向与对向车道采用相同的侧碰、追尾和等级规则。分类仅依据首次接触形态与车型等级；目标方向用于确定其实际车头、车尾，并影响相对接近速度，不阻止对向吞吃。

## 绘制与更新策略

- 新局及返回首页时归还旧车辆与动画残影，清空车辆 ID 映射并保留模型池；绘制前同时核对车流对象身份，避免不同对局重合 ID 复用错误外观。闲置车辆从场景树移除，重新取得时加入，继续复用几何与材质。
- 树木、树干、岩石、湖泊、道路标线和路柱在实例矩阵或数量更新后重算包围球，包含空批次与换局情况；少量爆炸粒子及季节粒子关闭视锥剔除，避免沿用旧范围而消失。
- 吞吃与损毁残影在行驶和死亡动画中继续计时，暂停冻结；结算立即回收剩余残影。已标记移除的车辆不再创建正常模型，避免同一步吞吃后死亡时重复显示。
- 玩家车辆在死亡动画末尾隐藏，死亡结算及其后续重绘保持隐藏，只有新局或返回首页时恢复；主动结束的结算保留车辆。
- 行驶和死亡动画期间持续调度帧。首页、暂停和结算只在状态切换、尺寸变化或镜头尚未稳定时绘制；镜头缓动期间仅更新相机，稳定后停止帧循环。重新唤醒时从当前时刻计时，不补算静止时间。
- 道路九条条带共享 109 个中心采样，复用宽度、方向、坡度与法线，通过横向偏移得到两侧顶点；条带采样的 `local()` 调用为每帧 109 次，保持曲线、上下坡与边界效果。
- 车流每步先缓存截止车道判断并稳定分为两组，优先处理需并道的车辆；寻找前车采用一次遍历选取最近同向目标，不生成候选排序数组。系统车仅记录前一步的纵横位置，不保留递归快照、无效 `push` 或 `contact` 状态；玩家踩坑的横向冲量继续生效。
- 道路生成时单独保存收窄／截止路段及截止墙路段。关闭与墙体查询只扫描对应的小列表，并换算本轮与下一轮的累计位置，不反复遍历完整道路计划。
- 系统车每步共用附近截止墙列表。未完全进入安全车道时，根据距墙距离、车身长度、制动距离及剩余并道时间降低目标速度；空隙受阻时持续提前减速。先用边界修正前的完整车身轨迹扫掠墙体，触墙车辆回收且不再参与跟车、空隙判断或系统车分离，随后才处理道路边界，避免被瞬间推入保留车道而漏检。
- 路边布局只缓存附近至多八个候选区块，驶离后释放，换道路时清空。建筑、农田、围栏与奶牛静态部件只在区块进出时改写实例矩阵，每帧通过父节点转换玩家参考系，并单独更新奶牛腿、尾巴动画；季节材质只在季节值变化时更新。
- 左侧仪表显示本局运行时间，使用有效行驶时间按分秒显示，暂停、死亡与结算时停止，新局归零。仪表缓存已显示的整数距离、整秒时间、取整速度、车型与升级积分，仅数值变化时格式化并写入页面；速度条保持连续比例，比例未变时跳过写入。

## 数值与可调整入口

- 车型顺序为自行车、三轮车、小汽车、卡车、加长卡车、坦克。三轮车为玩家和交通车辆共有的独立车型；三级交通车辆随机使用小汽车或拖拉机外观，共用相同规格和等级。每类交通车六种配色，外观与颜色在生成时固定，按等级、外观和颜色分池回收；玩家保持金色。
- 车型参数集中在 `config.js`。玩家速度上限为 65／75／90／90／90／90 km/h，速度条按当前车型正常上限显示比例，交通车辆速度保持独立配置。
- `XP` 配置各目标固定积分 1／2／6／18／54／216，`UPGRADE_POINTS` 采用下一车型积分值作为门槛 2／6／18／54／216。`Game.eat` 直接增加目标积分，升级扣除门槛保留余分，降级清空；界面仅显示当前积分／门槛，不附加“分”字，加长卡车需要四辆同级车升为坦克，满级停止累计升级积分。`ONCOMING_SPEED_SCALE` 为 0.8，对向 NPC 巡航速度比基础区间低 20%。
- `SIDE_REAR_FRACTION` 为 0.5；首次侧面接触时，我方车头超过对方车头，或位于对方后半段，即为侧碰。其余接触按追尾处理；同时接触侧面与端面时也按位置条件判断。
- 车身长度采用基础尺寸的 2.4 倍，宽度采用 1.6 倍，碰撞与画面共用；最宽坦克为 3.00 米，车道宽 3.6 米。自行车使用弧形车把、深色握把和短立管。路面、路肩和地面分区铺设，镜头近裁面为 0.5 米，减少远处深度抖动；游戏界面禁止文本插入光标与选择。固定一套效果，没有车底色块、随车说明、季节提示或右侧悬浮操作面板。
- `AUTO_ACCELERATION` 为 6 km/h 每秒，未刹车且无道路刮擦时自动提速至当前有效上限；`game.js` 控制刹车 35、刮边 15 km/h 每秒，减速惩罚保持两秒再恢复上限 1.5 秒。
- `road.js` 每局生成约 8–12 公里计划，首段 240 米直道，每轮包含 18 段左右缓弯，弯道占比约 47%–54%，并安排成对上下坡、渐进收窄、突然截止与扩道；坡道长 520–700 米，高差 22–31 米。
- `hazards.js` 每 100 米安排候选位置，坑洞概率 10%、泥洞概率 6%，避开道路切换区域；起点前 260 米无障碍。坑洞弹跳 0.65 秒、横向冲量以 4.4 米/秒² 衰减；泥巴限速与泥斑同步保持 8 秒，暂停冻结。接触记录只保留近处已踩障碍，渲染使用四个容量为 16 的实例批次和一层车身泥斑，空批次隐藏。
- `scenery.js` 的候选地块约每 90 米一处，出现概率 18%，每处只安排在随机一侧；农场两头奶牛、牧场三头奶牛、作物四排。每个实例批次容量 1024，空批次隐藏并跳过更新。
- 湖泊候选出现概率 8%，仅在平缓地形显示，视野内最多四处；复杂景物随机稀疏出现，不连续铺满道路两侧。
- `traffic.js` 控制净距、车型权重、密度、至少一秒变道预告和约 1.5 秒横移。`TRAFFIC_WEIGHTS` 为两侧新车提供同级 60%、高级 30%、低级 10% 的基础分布，缺失组转给同级；高级权重每两公里增加 1 个百分点，最高 35%。`TRAFFIC_SPAWN_AHEAD` 将运行中新车投放到前方 200–240 米，按生成时玩家等级选型，保留接近时间和前后净距约束，已生成车辆不替换。
- 四季由有效行驶时间轮换，每季 120 秒，最后十秒混合下一季，刹停仍轮换，暂停完全冻结。

## 首版边界

桌面键盘操作；无移动触控、音效、回放与存档导入导出。系统车遵守系统间约束，不主动避让玩家。正常生成通过车道和净距约束留下空间，玩家仍需判断实时变道、对向交通及道路关闭风险。

复杂多车连锁偏移和长时间道路循环仍需在实际游玩中持续观察和调参。当前不引入物理引擎；修改车型尺寸、曲率或最高速度时，需同时检查吞吃判定、并道空间和预警距离。

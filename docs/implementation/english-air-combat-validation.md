# 英语空战验证

## 验收范围

- 本地账号内嵌首页，创建时编辑名字、保存后不改名；重名及 TEST01–TEST09 保留名校验。学习、成绩、进度、复习与十二词续玩按账号隔离，切换等待保存完成。
- 每关固定十二词，完整预习后开局，普通题与 Boss 共用用完才重复的词池；未完成及重玩沿用原词，新关重新抽取。常规倒计时 300 秒，大 Boss 全对后切为完整五秒拾箱。
- 普通题每十题七道拼写、三道选择；仅成功投放消耗题型。选择题英译中／中译英各三个不重复选项、唯一正确，两种方向每两题各一次。拼写题保持原点阵、同键连射、换字清旧弹、输入锁定和撤销规则。
- 航母题面与三个命中区严格等宽，按实际子弹横坐标选择左／中／右；默认累计 20 发淡出后验证。换字母、换区不清进度，数字／撤销／退格不能改选。首个满额选项锁定后停下、停止接弹；正确爆两箱、错误变两架敌机，每题只记录一次。
- Boss 90／240 秒出场，四／五面各限时一分钟；保留已有普通题，所有面继续拼写。只有全部面答对才算击败，小／大 Boss 分别爆三／五箱；中途写错、超时均不触发击败奖励。
- 大 Boss 全对后清理普通题、敌机、待投放敌机及全部子弹，保留幸运箱。已成功普通题按成功结算，其余已出现题按没写完；不重复记账。完整五秒内停止新题、敌机、周期箱与射击，四方向自由移动、斜向不加速，碰触箱子领取；暂停与失焦冻结，到零结算。原剩余不足五秒仍给完整五秒，重开恢复底部位置。
- 周期幸运箱每 120 秒一个，奖励箱散开后下降，子弹不可领取；纵横移动用相对扫掠判定。箱子和收藏动画各预建 16 槽，箱满保留奖励队列；收藏仍仅计数，结算同步未飞完的已领取数量。
- 结果仍为“恭喜通关！”，成功／写错／没写完分列，每个不同失败词锁定复习十秒，刷新继续、失焦暂停。选择题明细保存题型、方向和实际选项文本，兼容旧明细；学习列表按总失败降序、每页 100、点击朗读。
- 航母及背景几何、纹理在开局前生成、缓存和预热，Worker 在开放操作前停止。游玩只复用几何、材质、DOM 及对象池，十七种背景无放回轮换；静态包包含全部依赖且小于 10 MB。

## 实际结果

验证日期 2026-10-22。二十个固定种子共 2000 次普通出题，选择题 600 道，两种方向各 300 道，每十题恰为七拼写、三选择；全部选择题均有三个不重复文本和唯一正确项。真实 Game.update 与弹道路径验证任意字母射击满 20 发后验证、三个命中区、在途弹不改选、正确两箱、错误两架敌机和单次结果记录。

一次性逻辑核对覆盖小／大 Boss 全对奖励 3／5 箱、混入一次错误不触发击败奖励、清场记录范围、弹体及敌机队列清除、禁止射击、五秒暂停冻结及四方向扫掠领取。Boss 截止及关卡截止前已验证正确、仍在成功表现中的最后一面正常计入全对并开启拾箱；未完成面仍记没写完。原剩余一秒时击败大 Boss，仍在完整五秒后以 boss-defeated 结算，有效时间可到 304 秒；重开恢复底部位置。周期箱在 120 秒生成一次并将下次设为 240 秒；奖励箱超容量五个时保留队列，空出槽位后全部补发。

本机 Chrome 实际显示了两种航母题面，三个选项宽度一致；10 发对应透明度 0.5，实按 d 射击右侧选项后命中为 [0,0,20]，生成一条 choice 成功记录及两个箱子。浏览器场景夹具核对小／大 Boss 的 3／5 箱、清场和顶部倒数 5；通过正常暂停面板继续后，实按上方向键飞离底部并领取一个箱子，倒数结束显示“恭喜通关！”与收藏数量。浏览器夹具仅使用内存存储，不写普通账号或调试账号成绩。

航母共享几何为 240 个三角形。敌机两个材质原型与原九部件逐顶点核对，每架仍为 11,598 三角形，位置最大浮点差 0.00000382、单位法线差小于 0.00000005；三角形及材质未减少。紫色 Boss 初始化后几何数 25、WebGL 纹理数 12，箱子图片在 DOM 中共享。原 SVG、箱子双重阴影、敌机轮廓、题面和文字位置已进行同场景画面对照，未降低 DPR、原飞机部件细分或奖励数量。

全资源首次无缓存时，资源及位图准备约 335 毫秒、模块启动至就绪约 940 毫秒，其中 Boss 准备约 39 毫秒；刷新后星空、航母、Boss 与箱子位图均持久命中，全部准备约 47 毫秒、至就绪约 299 毫秒，其中 Boss 恢复约 6.8 毫秒、位图恢复约 1.7 毫秒，Worker 均已停止。兼容旧完整配置指纹的星空／航母缓存复用已在禁止创建对应 Worker 的条件下核对命中，成功登记新键并保留持久位图。静态运行包为 31 文件、2,373,164 字节，包含共享位图准备及独立 Boss 生成模块，不含预制图片、模型或新增外部依赖。

## 性能对比

调度和合批对比固定使用同一个基准 Boss 模型，隔离该两项优化的成本；紫色 Boss 的独立测量见下文。本机 Chrome，952×761 CSS 视口、DPR 2、种子 42；优化前使用本轮修改前的独立源码快照。每场景预热 30 帧、采样 300 个 rAF 间隔，DOM 另采 120 帧，固定场景与运动方式。密集敌机采用静态渲染快照；移动航母及奖励动画由夹具推进，未运行整局 Game.update。

容量压力场景 P95 降低约 65%，中位帧间隔减半；重复基线仍出现 16.7／25.0 ms。密集场景绘制调用降低约 80%，三角形保持 226,844；Scene.render 的 CPU 包围计时中位／P95 从 1.0／1.7 ms 到 0.7／1.1 ms，UI.render 从 0.2／0.4 ms 到 0.0／0.1 ms（0.0 为采样精度内）。这些 CPU 计时不等于 GPU 耗时，密集场景帧间隔仍受本机约 120 Hz 刷新率限制，不能将调用下降比例换算为 FPS 提升。容量压力场景每帧 16 次收藏文字节点替换已消除。

稳定暂停一秒的观察窗口内，优化前 Scene／UI 各调用约 120 次，优化后均为 0；状态、尺寸和设置变化仍会主动刷新。真实调度通过暂停面板恢复五秒拾箱，实按上方向键后玩家 y 从 950.4 移至约 695.6、领取一颗星，elapsed 从 250 推进至 255 后正常结算。复习失焦期间余时保持十秒，页面重新聚焦后完成倒计时并解除锁定。二十轮两种紫色 Boss 的切换、触手收起和恢复后，几何／WebGL 纹理仍为 25／12，全部箱子共享图片已完成解码；这只验证资源数量复用，不代替堆内存峰值测量。

独立合成学习库含一万条同词明细，版本 1 原位升级版本 2 后首／末页各返回一百条，时间倒序正确、总数一万，未丢记录。各五次读取的中位耗时：原全量读取并排序约 33.1 ms，新首页分页约 16.3 ms，不含 DOM 创建。实际明细界面每页一百行，点击下一页显示 2/100 及对应记录；合成数据库已清理，普通账号及调试账号成绩未写入。

## 紫色恶魔模型

小 Boss 为双弯角、四卷曲触手；大 Boss 为四角头冠、额头宝石、蝙蝠翼与五触手，两者保持大眼睛、斜眉、坏笑、小虎牙、粉色脸颊及吸盘。首页与战斗均已实际查看，战斗表情露在原题面上方，头冠保留顶部 HUD 间隔；未改变题面位置、碰撞、Boss 面数、转面、判题、全对奖励或清场规则。

主体按顶点色合批、触手实例化；独立四份几何为 2,594,160 字节。结构化克隆后数组类型及值有效；部件分批生成的 Node 单步最大约 1.15 ms，该数值不代表浏览器生成耗时。

本机 Chrome 797×761 CSS 视口、DPR 2，每种模型预热后采样 300 帧，夹具推进触手动画：小／大 Boss 的 rAF 帧间隔中位／P95 均为 8.3／9.3 ms；Scene.render 的 CPU 包围计时分别为 0.5／0.9 ms、0.5／0.8 ms，包含整个场景且不等于 GPU 时间。每个战斗画面共 16 次绘制，分别为 31,640／35,612 三角形。浏览器逐一核对 0–4／0–5 条未处理触手状态，反复切换二十轮后几何／纹理数保持 25／12。 转面中点的模型 Y 旋转为 0.85 弧度；减少动作设置下，在不同有效时间生成的触手实例矩阵一致。

全资源首次生成至就绪约 940 ms，其中 Boss 生成、转移和缓存约 39 ms。Boss 配方改变时星空、航母和箱子缓存命中，仅更新 Boss；最终配方这一准备路径中 Boss 约 59 ms、全部准备约 101 ms、就绪约 298 ms，两个 Worker 均在开放操作前停止。 完整持久命中时 Boss 恢复约 6.8 ms；强制无 Worker 的分批降级约 61.1 ms，返回的两种几何校验通过、三角形数量一致。

## 抽词比例

练习分组为三至六年级 80%、一至二年级 5%、初中拓展 15%；三年级练习归入主组，现有 191 个词按该组序分别为 92、40、59 个，词条 id、规范词形、来源核验状态和学习记录不变。每关十二词使用带种子的随机起点等距整数分配，组内保留历史正确率权重和无放回抽取。

一万个固定种子共十二万词，实际三组占比为 80.013%、5.000%、14.987%；每关分别为 9–10、0–1、1–2 词，均无重复词，重复相同种子结果一致。已保存的 7／3／2 旧配额词池在续玩及重玩时保持原十二词和种子；新比例只用于新抽词池。词库说明从配置读取并显示 80%／5%／15%。

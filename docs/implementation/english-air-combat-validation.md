## 验收范围

- 本地账号内嵌首页，创建时编辑名字、保存后不改名；重名及 TEST01–TEST09 保留名校验。学习、成绩、进度、复习与十二词续玩按账号隔离，切换等待保存完成。
- 每关固定十二词，完整预习后开局，普通题与 Boss 共用用完才重复的词池；未完成及重玩沿用原词，新关重新抽取。常规倒计时 300 秒，大 Boss 全对后切为完整五秒拾箱。
- 普通题每十题七道拼写、三道选择；仅成功投放消耗题型。选择题英译中／中译英各三个不重复选项、唯一正确，两种方向每两题各一次。拼写题保持原点阵、同键连射、换字清旧弹、输入锁定和撤销规则。
- 航母题面与三个命中区严格等宽，按实际子弹横坐标选择左／中／右；默认累计 20 发淡出后验证。换字母、换区不清进度，数字／撤销／退格不能改选。首个满额选项锁定后停下、停止接弹；正确爆两箱、错误变两架敌机，每题只记录一次。
- Boss 90／240 秒出场，四／五面各限时一分钟；保留已有普通题，所有面继续拼写。只有全部面答对才算击败，小／大 Boss 分别爆三／五箱；中途写错、超时均不触发击败奖励。
- 大 Boss 全对后清理普通题、敌机、待投放敌机及全部子弹，保留幸运箱。已成功普通题按成功结算，其余已出现题按没写完；不重复记账。完整五秒内停止新题、敌机、周期箱与射击，四方向自由移动、斜向不加速，碰触箱子领取；暂停与失焦冻结，到零结算。原剩余不足五秒仍给完整五秒，重开恢复底部位置。
- 周期幸运箱每 120 秒一个，奖励箱散开后下降，子弹不可领取；纵横移动用相对扫掠判定。箱子和收藏动画各预建 16 槽，箱满保留奖励队列；收藏仍仅计数，结算同步未飞完的已领取数量。
- 结果仍为“恭喜通关！”，成功／写错／没写完分列，每个不同失败词锁定复习十秒，刷新继续、失焦暂停。选择题明细保存题型、方向和实际选项文本，兼容旧明细；学习列表按总失败降序、每页 100、点击朗读。
- 航母及背景几何、纹理在开局前生成、缓存和预热，Worker 在开放操作前停止。球体索引、飞机专用细分及合批索引须正确恢复；无 Worker 时分批让出主线程。游玩只复用几何、材质、DOM 及对象池，十七种背景无放回轮换；静态包包含全部依赖且小于 10 MB。
- 高／标准／省电画质按账号隔离并在登录时恢复，旧或非法设置回退高画质。仅三维画布调整 DPR／像素预算，尺寸与显示器 DPR 改变同步相机和点径；菜单最高 60／30 帧、覆盖弹窗冻结，战斗固定逻辑步、暂停和复习倒计时保持。

## 实际结果

验证日期 2026-10-22。二十个固定种子共 2000 次普通出题，选择题 600 道，两种方向各 300 道，每十题恰为七拼写、三选择；全部选择题均有三个不重复文本和唯一正确项。真实 Game.update 与弹道路径验证任意字母射击满 20 发后验证、三个命中区、在途弹不改选、正确两箱、错误两架敌机和单次结果记录。

一次性逻辑核对覆盖小／大 Boss 全对奖励 3／5 箱、混入一次错误不触发击败奖励、清场记录范围、弹体及敌机队列清除、禁止射击、五秒暂停冻结及四方向扫掠领取。Boss 截止及关卡截止前已验证正确、仍在成功表现中的最后一面正常计入全对并开启拾箱；未完成面仍记没写完。原剩余一秒时击败大 Boss，仍在完整五秒后以 boss-defeated 结算，有效时间可到 304 秒；重开恢复底部位置。周期箱在 120 秒生成一次并将下次设为 240 秒；奖励箱超容量五个时保留队列，空出槽位后全部补发。

本机 Chrome 实际显示了两种航母题面，三个选项宽度一致；10 发对应透明度 0.5，实按 d 射击右侧选项后命中为 [0,0,20]，生成一条 choice 成功记录及两个箱子。浏览器场景夹具核对小／大 Boss 的 3／5 箱、清场和顶部倒数 5；通过正常暂停面板继续后，实按上方向键飞离底部并领取一个箱子，倒数结束显示“恭喜通关！”与收藏数量。浏览器夹具仅使用内存存储，不写普通账号或调试账号成绩。

航母共享几何为 240 个三角形。飞机球体使用 24×12 细分，敌机两种材质继续实例化；每架从 11,598 降至 2,958 三角形（减少 74.5%），16 架从 185,568 降至 47,328。两个敌机原型从 34,794 降至 1,823 个顶点记录，位置／法线／索引数据从 835,056 降至 61,500 字节（减少 92.6%），两种材质的包围盒外沿保持一致。星球球体保留 48×24 细分，按索引展开的位置、法线和 UV 与原数据逐项相同，字节从 221,184 降至 53,024；飞机球体额外 13,856 字节。移除未引用的旧 `monster` 数据 165,888 字节。纹理像素、星位、星座、航母、机身和背景布局与基线逐项一致。同步及分批生成结果完全相同，结构化克隆及五类损坏索引／属性缓存拒绝路径均已核对。

当前启动入口并行导入场景和准备资源，星空／飞机、Boss、补给位图三条链并行；必需任务失败时等待其余任务结束才关闭数据库，且不清理旧成功记录。独立可控等待核对三条链同时启动、失败完整等待、进度不回退、写入失败进入内存降级。并行调整前后的星空缓存键一致，生成器和格式保持 8，程序版本保持 `v1.0.9`。

## 启动加载与预热

本机 macOS Chrome，797×761 CSS 视口、设备 DPR 2，独立本机端口对照相同源码种子 42。首次使用两个独立站点的空资源库，随后各自刷新验证持久命中；首页预览随机，未清除 GPU 驱动缓存。下表为短样本，模块启动至就绪从 `bootstrap.js` 执行开始计时，包含重叠的模块导入、资源准备、构造与预热，不是公网导航基准。

| 路径 | 调整前资源／至就绪 | 当前资源／至就绪 |
| --- | --- | --- |
| 全资源首次生成 | 270.9／515.2 ms | 209.9／346.7 ms |
| 持久缓存全部命中 | 30.9／236.1 ms | 59.9–62.0／166.5–177.4 ms |

首次当前场景导入约 29.8 ms，与资源准备重叠；场景构造约 32.8 ms，预热约 61.4 ms。命中路径导入约 35.1–38.0 ms、构造约 37.5–38.9 ms、预热约 30.4–38.9 ms。并发读取和解析竞争会影响单阶段耗时，缓存路径资源耗时在此样本增加，总至就绪仍缩短；不能把三条链耗时相加或承诺固定毫秒收益。

资源请求记录中，调整前三个相关请求按资源准备后依次开始：`scene.js`、`three.module.js`、`three.core.js`；当前两个 Three.js 模块与 `bootstrap.js` 均在导航后约 31.4 ms 发起，场景在约 108.0 ms 开始导入。两个预加载 URL 在发布整理后均指向有效 `vendor/three/build/` 文件。慢网条件下的具体节省尚未测量，不声明固定 300 ms 收益。

预热主体两次整场景绘制、一次编译等待，覆盖五套星座共十份点／线缓冲及太阳 Basic／普通 Standard 材质，槽位状态正确还原。实际浏览器预热后按十五秒间隔轮换十七种背景，几何／程序数保持 26／17，未调用新的 `bufferData` 分配。纹理数保持 12，游玩不补做资源生成。

无 Worker 且禁用 IndexedDB 的当前浏览器路径约 160.3 ms，位图已解码、Worker 停止，期间主线程间隔定时器执行七次，进度为 10、20、30、60、75、75，明确报告内存降级。完整静态包 31 个文件、2,380,987 字节，无新增预制资源或外部依赖。

## 题面与大屏预算

真实卡片更新方法以三张十字母拼写题、稳定 100 帧对照：宽度赋值从 300 次降为零，字号从 3,300 次降为零，行高和高度各从 300 次降为零；一张卡换宽后只写一次宽度。这里只统计属性赋值，不将次数换算为浏览器布局或帧耗时。浏览器实际字号在缩放 0.4 时为字母 50 px、释义 45 px、行高 50 px；缩放约 0.7885 时为 36／22.8269／25.3633 px，与原计算一致，`will-change` 为 transform。

高／标准／省电均限制总像素，预算分别为 4,500,000／3,686,400／2,073,600。浏览器将画布设为 1600×1100 CSS 像素、设备 DPR 2 时，高档实际 DPR 约 1.599，绘制尺寸 2558×1758，共 4,496,964 像素，比原 DPR 2 的 7,040,000 像素减少约 36.1%。DOM 文字继续按 CSS 像素绘制；这是像素数量的减少，不是填充率、MSAA 成本、FPS 或无损画质的承诺。

源码范围只保留 24 个英语空战 JavaScript 模块和一份样式，依赖图与发布清单一致；赛车源码、设计与玩法验证从 `main` 分支查阅，不进入当前目录的检索范围。

## 抽词比例

练习分组为三至六年级 80%、一至二年级 5%、初中拓展 15%；三年级练习归入主组，现有 191 个词按该组序分别为 92、40、59 个，词条 id、规范词形、来源核验状态和学习记录不变。每关十二词使用带种子的随机起点等距整数分配，组内保留历史正确率权重和无放回抽取。

一万个固定种子共十二万词，实际三组占比为 80.013%、5.000%、14.987%；每关分别为 9–10、0–1、1–2 词，均无重复词，重复相同种子结果一致。已保存的 7／3／2 旧配额词池在续玩及重玩时保持原十二词和种子；新比例只用于新抽词池。词库说明从配置读取并显示 80%／5%／15%。

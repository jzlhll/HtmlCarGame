第一阶段确认外部场景与驾驶舱显示、约四分之一的仪表台、外围边框内的完整前窗、中央无遮挡、空格与按钮进入、暂停／继续、失焦自动暂停、重新开始重置及窗口适配。第一阶段飞机应始终熄火、静止。第二阶段新增四个数字各一秒、总长四秒的连续运镜；检查倒数期间暂停／恢复保持进度、重新开始重置、单向环绕与连续朝向、两端相机连续和过渡遮挡。倒数期间字母键不能提前改变飞机，结束时仍熄火。第三阶段检查 L、D、H、A、W 任意顺序就绪，舱门显示 Closed，L／H／A 显示 ON，W 显示 OFF，F／R 条件不足不执行，长按不反复切换、F 可取消启动或熄火，仪表与轻微振动反馈、暂停冻结和重开复位。当前继续接入三个关卡的完整航程、安全接地、停机、山体／建筑碰撞、雷达与交通目标；操作与环境合成音效、本地英文播报已接入，统一女声音色与实际设备混音仍待试听验收。

集成确认覆盖七步到目的地停机的受力流程、一次失败后重开，并在浏览器确认真实起飞、导航轨迹和交通预告；在倒数、发动机启动、滑跑和爬升中检查暂停与失焦。无需通过随机长时间游玩覆盖未实现的天气或天空区域。

浏览器确认使用已安装、获准的工具；优先使用可用的 `cua_repl`，实际打开当前工作目录的本机地址。启动前检查端口与服务归属，占用时选择其他端口，保留用户已有页面、服务和游戏状态。

警报门控检查用户手势解锁、暂停／失焦／结算静音，不把截图当作实际试听。统一女声音色未经实际试听不得标记验收完成；缺少实际试听且影响结论时报告缺口。性能只有在出现卡顿、对象持续增长或新增大型场景时测量，先定位再优化，不默认扩大回归范围。

结束后关闭本次创建的临时服务与页面，交付仅报告结果和影响结论的问题。检查范围仅覆盖本次实现的飞行流程。

关卡改动需额外确认：每关开场路线与目的地一致；后关只保留当前终点机场；相同前段海拔一致、沿途逐渐升高，深圳起点保持0，目的地标高300／650／1000；地面、标线、机轮和碰撞匹配，无悬空或钻地。浏览器查看丹霞红岩、张家界独立石柱与悬空水幕、橘子洲石像、洞庭湖和黄鹤楼；水幕可穿、岩体不可穿，悬空岩体下方不误判。关卡时限包含着陆停机，胜利入口与重开正确；原有暂停、声音默认开启、结果表情保持有效。

山体改动需确认裸岩／森林山坡与丹霞层理、岩柱顶面树群、远近细节滞回和山脚无方形色块；近景画面与固定碰撞网格一致，悬空岩体下方及水幕仍可通行。测量三关从导航开始到开始按钮可用的准备耗时，均须在12秒预算内；按模块／世界／景物／GPU定位超时环节后优化并重新测量，不默认生成提交模型文件。观察林地密集视角与岩柱视角的稳定帧开销，确认新增资源体积仍在50 MB预算内，重开无重新生成或资源持续增长。

性能优化需在相同关卡、姿态与视角比较绘制提交、三角形数、界面节点写入及物理热路径耗时；区分局部 CPU 基准和实际帧率，不能把绘制提交降幅表述为帧率增幅。合并几何后检查起落架／减速板动画、航行灯、淡出、阴影和透明标线；静态矩阵优化后检查目的地标高与地景细节切换。碰撞优化用相同输入对照原有世界／交通结果和完整固定步轨迹，保留采样密度。界面缓存需覆盖 A 关闭／恢复、目标出现／移出、暂停恢复和重开清空，音频缓存需覆盖主增益静音／恢复。临时基准放在仓库外，避免引入长期维护的测试框架。

脚部视角验证 AGL 199／200／201 米两侧显隐，起飞后关闭、下降后重现；地面为实际机场或山面，轮位置、收放、下降速度与主画面一致；主机壳不能残留在驾驶舱中，视口不擦除主画面。1280×720与800×600确认两个右侧小窗和仪表不重叠；暂停冻结，重开恢复。临时采样覆盖十倍变速、起飞W关闭、着陆W打开、发动机熄火和三关限时停机。

速度与交通调整需对照平翼配平、低速升力不足、持续大仰角、俯冲和左右滚转的受力采样；点按S前后垂直速度不能突变，熄火后机械能随阻力损耗。低空持续低速／失速要实际撞地失败，及时减小迎角和提速保留恢复空间。核对海拔／坡度／W变化时Vs与安全参考同步，低速警告保持事件去重。固定航线不避让需发生交通冲突，合理避让仍能按三关时限完成。视觉验证远／中／近距离雁群实体、距离标记、2倍客机及同源碰撞，暂停冻结、重开清理；新增模型继续开局程序生成，核对12秒准备与50 MB资源预算。

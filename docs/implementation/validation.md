# 验证约定

[返回实现说明](README.md)

按改动范围选择检查，不主动新增测试文件或引入测试框架。文档检查内容、索引、相对链接、按键一致性，以及“已实现／规划”的表述；实现检查按下表选取对应范围。

第一阶段确认外部场景与驾驶舱显示、约四分之一的仪表台、共用世界的双窗、空格与按钮进入、暂停／继续、失焦自动暂停、重新开始重置及窗口适配。第一阶段飞机应始终熄火、静止。第二阶段新增四个数字各一秒、总长四秒的连续运镜；检查倒数期间暂停／恢复保持进度、重新开始重置、单向环绕与连续朝向、两端相机连续和过渡遮挡。倒数期间字母键不能提前改变飞机，结束时仍熄火。第三阶段检查 L、D、H、A、W 任意顺序点亮为 ON，F／R 条件不足不执行，长按不反复切换、F 可取消启动或熄火，仪表与轻微振动反馈、暂停冻结和重开复位。第四、五阶段已接入滑跑、飞行和结果页；音效尚未实现。

## 按范围验证

| 改动范围 | 必要确认 |
| --- | --- |
| 模块或入口 | 对修改的 JavaScript 做语法检查，确认浏览器通过 HTTP 加载且无模块错误 |
| 开场镜头 | 四个数字各 1 秒，轨迹共 4 秒，暂停恢复保持进度，沿飞机左侧单向环绕且视线不掉头，两端连续、镜头不穿挡；检查远处跑道／地面无交错闪烁，机身与内舱渐隐不出现排序破面，静止场景阴影不随镜头重复更新；结束时熄火、零速、油门为零 |
| 七步启动 | L、D、H、A、W 任意顺序切换 OFF／ON；F 开启要求五项准备全部就绪，再按可取消启动或熄火；R 开启要求发动机就绪和零油门，再按恢复驻车；静止零油门时准备关闭或熄火后撤销就绪、恢复驻车，重新放行仍检查条件；长按不反复切换；三秒启动与轻微振动暂停后连续恢复，取消启动与重开清零；不出现供电供油额外步骤 |
| 地面控制 | T／S 点按 5% 和持续调油门，S 怠速后使用轮刹；从开始加油门到 145 kt 约 20 秒；左右修正随速度减弱；低速按 ↑ 不瞬间离地；边界按轮子范围判定 |
| 离地与爬升 | VR 只提示抬轮；↑／↓改变姿态；地面到空中连续；G 在 30 米且正爬升、W 在 200 米且 180 kt 后收起，进度与动力同步；高俯仰减速、低俯仰下降与加速，滚转改变升力方向；区分俯仰／航迹／迎角，失速进入和恢复有滞回，升阻力在临界迎角附近连续；低速与失速可恢复，撞地才失败 |
| 受力与能量 | 以临时采样检查有限数值、固定步积分和正常起飞；熄火待推力衰减后，总机械能随阻力消耗；高仰角持续操作会减速失速，及时减小迎角可以恢复，持续失速撞地结束；俯冲会加速并触发超速，避免直接设置目标爬升率掩盖受力 |
| 结束与重开 | 500 米、180–220 kt、正爬升、坡度不超过 10°、轮与襟翼收妥持续 3 秒才完成，反馈 1.5 秒后进入结果页；失败只结算一次；结果页静止；新局所有步骤、姿态、油门和事件重新初始化 |
| 提示 | 入舱中央仅显示任意顺序说明，首次普通字母或游戏操作按键即隐藏，暂停恢复、反向开关和条件失败不再出现，重开恢复；底部双语清单按准备／滑跑／爬升整条替换且仍可见，条件失败提示独立保留；高仰角／危险下降／失速居中提示，失速优先，正负迎角的恢复方向正确；普通按键不清除安全提示，安全区恢复后才重置警告轮次；双语名称对应正确操作，临时提示不超过 3 秒；速度／高度变化和重复按错不延长或重弹 |
| 键位学习 | 玩家可见英文仅首字母大写，只有 OFF／ON 全大写；底部清单同时显示英文、中文动作和物理键帽；首字母无冲突；小写、Shift＋字母及 Caps Lock 等效，Ctrl／Alt／Meta 不误触；静止启动阶段允许从容找键，按错不跳步；未来标点提示与 `Comma`／`Period`／`Semicolon` 位置一致 |
| 声音 | 实际用户手势解锁并试听；女声音色、短句时机、环境声与油门对应；暂停和结果页静音，继续不重播过期句子 |
| 视图 | 双窗显示连续世界，下方仪表约占 1/4；在 100–500 米爬升阶段可见河流、楼群、地标和远山；右上角姿态卡片显示实际俯仰／坡度、轮与襟翼，暂停冻结，窗口缩放后仍对齐且不遮挡主要仪表，无机外切换按钮；熄火、灯光、飞行仪表和发动机的画面状态区分明确 |

首版集成确认至少覆盖完整七步到起飞成功，以及一次失败后重开；在倒数、发动机启动、滑跑和爬升中检查暂停与失焦。无需通过随机长时间游玩覆盖未实现的天气或天空区域。

浏览器确认使用已安装、获准的工具；优先使用可用的 `cua_repl`，实际打开当前工作目录的本机地址。启动前检查端口与服务归属，占用时选择其他端口，保留用户已有页面、服务和游戏状态。

声音不能仅凭截图认定正常；缺少目标设备女声或实际试听时，报告对应缺口。性能只有在出现卡顿、对象持续增长或新增大型场景时测量，先定位再优化，不默认扩大回归范围。

结束后关闭本次创建的临时服务与页面，交付仅报告结果和影响结论的问题。检查范围仅覆盖本次实现的飞行流程。

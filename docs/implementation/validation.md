# 验证约定

按改动范围选择检查，不主动新增测试文件或引入测试框架。文档检查内容、索引、相对链接、按键一致性，以及“已实现／规划”的表述；实现检查按下表选取对应范围。

第一阶段确认外部场景与驾驶舱显示、约四分之一的仪表台、外围边框内的完整前窗、中央无遮挡、空格与按钮进入、暂停／继续、失焦自动暂停、重新开始重置及窗口适配。第一阶段飞机应始终熄火、静止。第二阶段新增四个数字各一秒、总长四秒的连续运镜；检查倒数期间暂停／恢复保持进度、重新开始重置、单向环绕与连续朝向、两端相机连续和过渡遮挡。倒数期间字母键不能提前改变飞机，结束时仍熄火。第三阶段检查 L、D、H、A、W 任意顺序就绪，舱门显示 Closed，L／H／A 显示 ON，W 显示 OFF，F／R 条件不足不执行，长按不反复切换、F 可取消启动或熄火，仪表与轻微振动反馈、暂停冻结和重开复位。当前继续接入三个关卡的完整航程、安全接地、停机、山体／建筑碰撞、雷达与交通目标；操作与环境合成音效、本地英文播报已接入，统一女声音色与实际设备混音仍待试听验收。

## 按范围验证

| 改动范围 | 必要确认 |
| --- | --- |
| 模块或入口 | 对修改的 JavaScript 做语法检查，确认浏览器通过 HTTP 加载且无模块错误 |
| 开场镜头 | 首次加载等待场景准备完成后才允许按钮／空格进入；准备完成不残留交通模型或阴影，四秒运镜内无首次材质编译、纹理上传或几何提交造成的集中卡顿；四个数字各 1 秒，轨迹共 4 秒，暂停恢复保持进度，沿飞机左侧单向环绕且视线不掉头，两端连续、镜头不穿挡；检查远处跑道／地面无交错闪烁，机身与内舱渐隐不出现排序破面，静止场景阴影不随镜头重复更新；结束时熄火、零速、自动动力为零 |
| 七步启动 | L、D、H、A、W 任意顺序准备；D 初始 Open、不点亮、不计完成，按 D 后 Closed、点亮并计完成，再按恢复 Open、撤销完成并阻止 F／R；L／H／A 以 ON 就绪，W 初始 ON、关闭为 OFF 才就绪；F 开启要求五项准备全部就绪，再按可取消启动或熄火；R 开启要求发动机就绪并停稳，再按恢复驻车；静止时准备关闭或熄火后撤销就绪、恢复驻车，重新放行仍检查条件；长按不反复切换；三秒启动与轻微振动暂停后连续恢复，取消启动与重开清零；不出现供电供油额外步骤 |
| 地面控制 | T／S 点按直接小幅变速、按住持续变速，S 优先；W 关闭时 T 从静止约20秒到145 kt；W 开／关两端的加速与减速基准各相差十倍，过渡连续；未点火或驻车时 T 不推进，熄火不能持续提速；左右修正与跑道边界仍有效 |
| 离地与爬升 | W 完全关闭才允许离地；G 在30米且正爬升时可收、220 kt以内可放；W 无旧高度／速度条件、收放2秒且动画不连发；俯仰、迎角、航迹、重力、滚转、失速与恢复继续有效 |
| 受力与能量 | 以临时采样检查有限数值、固定步积分和正常起飞；熄火待推力衰减后，总机械能随阻力消耗；高仰角持续操作会减速失速，及时减小迎角可以恢复，持续失速撞地结束；俯冲会加速并触发超速，避免直接设置目标爬升率掩盖受力 |
| 航程与碰撞 | 三关按200／225／245 kt巡航、动态海拔和160–180 kt进近，实际受力采样可分别在200／225／255秒内着陆停妥并保留余量；偏航／超时失败；机翼触楼、机身触山、山面高度与画面一致；12000 米侧峰存在，超过 10000 米故障并降额，回安全高度恢复 |
| 着陆与停机 | 起落架放下、机翼减速板完全打开、航向／坡度／俯仰／速度／下降率满足边界才接地；未放轮、重着陆或跑道外接地失败；接地有实际滑跑和刹车；飞过圈上空、圈外停稳或仍在移动不算胜利 |
| 雷达与遭遇 | 大雁迎面、飞机迎面／同向／侧向／斜向，窗口可见目标和雷达同源；箭头、相对高度、预告闪烁和危险音正确；相向运动不穿透；暂停冻结，重开清空；关闭 A 不显示目标 |
| 结束与重开 | 初始爬升达标后继续航程，不提前结束；R首次放行后必须在本关200／225／255秒内于当前目的地跑道安全接地并在金色圈完整停妥 1 秒才成功，反馈 1.5 秒后进入结果页；失败只结算一次；结果页静止；新局所有步骤、姿态、速度和事件重新初始化 |
| 提示 | 入舱中央仅显示任意顺序说明，首次普通字母或游戏操作按键即隐藏，暂停恢复、反向开关和条件失败不再出现，重开恢复；底部双语清单按准备／滑跑／爬升整条替换且仍可见，条件失败提示独立保留；高仰角／危险下降／失速居中提示，失速优先，正负迎角的恢复方向正确；普通按键不清除安全提示，安全区恢复后才重置警告轮次；双语名称对应正确操作，临时提示不超过 3 秒；速度／高度变化和重复按错不延长或重弹 |
| 键位学习 | 玩家可见英文仅首字母大写，OFF／ON 例外；英文为主中文为辅，保留键帽。T（Thrust）提速、S（Slow）减速始终点亮，无油门输入百分比；Engine 显示自动动力和W模式。L／H／A ON、D Closed、W OFF 才准备完成；大小写和Shift/Caps Lock等效，不误触系统快捷键 |
| 声音 | 手势解锁，倒数不因重绘重复，L／D／H／A／W 正反操作有确认音，受阻或连发不播确认；F 启动升音、取消停音、怠速和推力跟随动力，轮胎仅接地、刹车加强，风随空速，收放电机随状态；默认开启且无声音开关，开始后即可播放；暂停／失焦／完成／失败静音，恢复不重播，重开不累积声源；本地英文语音可用／缺失均可完成游戏，无语音时保留合成短音；实机试听音色、音量和混音 |
| 视图 | 完整前窗显示连续世界，仅四周边框遮挡，中央无立柱或分隔线，下方仪表约占 1/4；在 100–500 米爬升阶段可见河流、楼群、地标和远山；右上角姿态卡片显示实际俯仰／坡度、轮与减速板，暂停冻结，窗口缩放后仍对齐且不遮挡主要仪表；1280×720 与 800×600 检查放大的英文／中文标签、状态、导航卡片和底部两行准备项，无重叠和截断，无机外切换按钮；熄火、灯光、飞行仪表和发动机的画面状态区分明确 |

集成确认覆盖七步到目的地停机的受力流程、一次失败后重开，并在浏览器确认真实起飞、导航轨迹和交通预告；在倒数、发动机启动、滑跑和爬升中检查暂停与失焦。无需通过随机长时间游玩覆盖未实现的天气或天空区域。

浏览器确认使用已安装、获准的工具；优先使用可用的 `cua_repl`，实际打开当前工作目录的本机地址。启动前检查端口与服务归属，占用时选择其他端口，保留用户已有页面、服务和游戏状态。

警报门控检查用户手势解锁、暂停／失焦／结算静音，不把截图当作实际试听。统一女声音色未经实际试听不得标记验收完成；缺少实际试听且影响结论时报告缺口。性能只有在出现卡顿、对象持续增长或新增大型场景时测量，先定位再优化，不默认扩大回归范围。

结束后关闭本次创建的临时服务与页面，交付仅报告结果和影响结论的问题。检查范围仅覆盖本次实现的飞行流程。

关卡改动需额外确认：每关开场路线与目的地一致；后关只保留当前终点机场；相同前段海拔一致、沿途逐渐升高，深圳起点保持0，目的地标高300／650／1000；地面、标线、机轮和碰撞匹配，无悬空或钻地。浏览器查看丹霞红岩、张家界独立石柱与悬空水幕、橘子洲石像、洞庭湖和黄鹤楼；水幕可穿、岩体不可穿，悬空岩体下方不误判。关卡时限包含着陆停机，胜利入口与重开正确；原有暂停、声音默认开启、结果表情保持有效。

山体改动需确认裸岩／森林山坡与丹霞层理、岩柱顶面树群、远近细节滞回和山脚无方形色块；近景画面与固定碰撞网格一致，悬空岩体下方及水幕仍可通行。测量三关从导航开始到开始按钮可用的准备耗时，均须在12秒预算内；按模块／世界／景物／GPU定位超时环节后优化并重新测量，不默认生成提交模型文件。观察林地密集视角与岩柱视角的稳定帧开销，确认新增资源体积仍在50 MB预算内，重开无重新生成或资源持续增长。

性能优化需在相同关卡、姿态与视角比较绘制提交、三角形数、界面节点写入及物理热路径耗时；区分局部 CPU 基准和实际帧率，不能把绘制提交降幅表述为帧率增幅。合并几何后检查起落架／减速板动画、航行灯、淡出、阴影和透明标线；静态矩阵优化后检查目的地标高与地景细节切换。碰撞优化用相同输入对照原有世界／交通结果和完整固定步轨迹，保留采样密度。界面缓存需覆盖 A 关闭／恢复、目标出现／移出、暂停恢复和重开清空，音频缓存需覆盖主增益静音／恢复。临时基准放在仓库外，避免引入长期维护的测试框架。

脚部视角验证 AGL 199／200／201 米两侧显隐，起飞后关闭、下降后重现；地面为实际机场或山面，轮位置、收放、下降速度与主画面一致；主机壳不能残留在驾驶舱中，视口不擦除主画面。1280×720与800×600确认两个右侧小窗和仪表不重叠；暂停冻结，重开恢复。临时采样覆盖十倍变速、起飞W关闭、着陆W打开、发动机熄火和三关限时停机。

速度与交通调整需对照平翼配平、低速升力不足、持续大仰角、俯冲和左右滚转的受力采样；点按S前后垂直速度不能突变，熄火后机械能随阻力损耗。低空持续低速／失速要实际撞地失败，及时减小迎角和提速保留恢复空间。核对海拔／坡度／W变化时Vs与安全参考同步，低速警告保持事件去重。固定航线不避让需发生交通冲突，合理避让仍能按三关时限完成。视觉验证远／中／近距离雁群实体、距离标记、2倍客机及同源碰撞，暂停冻结、重开清理；新增模型继续开局程序生成，核对12秒准备与50 MB资源预算。

# 验证约定

[返回实现说明](README.md)

按改动范围选择检查，不主动新增测试文件或引入测试框架。文档检查内容、索引、相对链接、按键一致性，以及“已实现／规划”的表述；实现检查按下表选取对应范围。

第一阶段确认外部场景与驾驶舱显示、约四分之一的仪表台、共用世界的双窗、空格与按钮进入、暂停／继续、失焦自动暂停、返回外部重置及窗口适配。此阶段飞机应始终熄火、静止，不验证尚未实现的倒数、开关、飞行或音效。

## 后续实现检查

| 改动范围 | 必要确认 |
| --- | --- |
| 模块或入口 | 对修改的 JavaScript 做语法检查，确认浏览器通过 HTTP 加载且无模块错误 |
| 开场镜头 | 四个数字各 1 秒，轨迹共 4 秒，暂停恢复保持进度，镜头不穿挡；结束时熄火、零速、油门为零 |
| 七步启动 | L、D、H、A、F、W、R 按序完成；乱序无效；长按不重复；F 启动不被反复重置；不出现供电供油额外步骤 |
| 地面控制 | T／S 操作油门，S 怠速后使用轮刹；左右修正随速度减弱；低速按 ↑ 不瞬间离地；边界按轮子范围判定 |
| 离地与爬升 | VR 只提示抬轮；↑／↓改变姿态；地面到空中连续；G 和 W 检查安全阈值；低速可恢复，撞地才失败 |
| 结束与重开 | 成功条件连续满足才完成，失败只结算一次；结果页静止；新局所有步骤、姿态、油门和事件重新初始化 |
| 提示 | 双语名称对应正确操作，临时提示不超过 3 秒；速度／高度变化和重复按错不延长或重弹 |
| 键位学习 | 任务同时显示英文、中文动作和物理键帽；首字母无冲突；静止启动阶段允许从容找键，按错不跳步；未来标点提示与 `Comma`／`Period`／`Semicolon` 位置一致 |
| 声音 | 实际用户手势解锁并试听；女声音色、短句时机、环境声与油门对应；暂停和结果页静音，继续不重播过期句子 |
| 视图 | 双窗显示连续世界，下方仪表约占 1/4；熄火、灯光、飞行仪表和发动机的画面状态区分明确 |

首版集成确认至少覆盖完整七步到起飞成功，以及一次失败后重开；在倒数、发动机启动、滑跑和爬升中检查暂停与失焦。无需通过随机长时间游玩覆盖未实现的天气或天空区域。

浏览器确认使用已安装、获准的工具；优先使用可用的 `cua_repl`，实际打开当前工作目录的本机地址。启动前检查端口与服务归属，占用时选择其他端口，保留用户已有页面、服务和游戏状态。

声音不能仅凭截图认定正常；缺少目标设备女声或实际试听时，报告对应缺口。性能只有在出现卡顿、对象持续增长或新增大型场景时测量，先定位再优化，不默认扩大回归范围。

结束后关闭本次创建的临时服务与页面，交付仅报告结果和影响结论的问题。检查范围仅覆盖本次实现的飞行流程。

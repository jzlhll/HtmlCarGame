## 范围与方式

按改动风险选择已有检查，不主动新增测试框架或仓库内测试文件；必要的物理／资源采样脚本和预览页面放在仓库外。游戏通过当前worktree的HTTP服务加载，保留用户已有服务和页面，结束后关闭本次临时服务与页面。

2026-10-18，本机macOS内嵌浏览器，1280×720、设备像素比2、渲染像素比上限1.5。当前worktree游戏名为“低空穿越”，程序未发布1.0.1。预算为点击至可操控8秒，含四秒入舱，部署25 MB；首屏必需资源就绪后2秒可见。

### 场景、穿行与边界

广州城区8×28街区，9.6×33.6公里，212栋楼，纵深为扩大前的5倍；长沙五一广场5×21街区，6×25.2公里，80栋楼。主城区空间块1.68公里，共享立面、单位几何、屋顶构件及柔化遮蔽；五类宽板楼／退台轮廓与碰撞同源。外围模板只抽取8排代表街区，保持12公里模板尺寸。

丹霞、石柱群的纵向位置与实体纵深同步扩大5倍，橘子洲长7.5公里，洞庭湖长17.5公里，黄鹤楼山脊纵深约25公里。黄鹤楼加12座灰绿屋顶古塔；主楼宽厚五层、唯一金黄且最高，基础均落在共用山面并以石台补齐坡面高差。所有区域采用通用衔接规则，各关14／27／35段林带覆盖城市、景点、田野、山脚与外围之间，避开内部水面和街区，机场前13公里中央通道保持林木净空。

广州四类各53栋，长沙四类各20栋。普通楼体矩形边缘保守计入1.1米外挑后，广州最近楼间距509.18米、长沙514.92米；四条连续纵向通道最窄分别501.60米、507.79米。循环城区采用同源52栋代表楼体，四通道最窄506.21米。三关在实际高度300／1000／1900米、各通道中心及左右35米、沿程每100米共54612个整机碰撞采样均通过，地标没有堵死通道；同步／分批楼体与山面一致，三关降落调试出生点保持无碰撞。

宽厚楼体平均高宽比广州3.37、长沙3.19；细长楼体约7.65，低层为宽平体量。每55米一圈的实体楼层细条已移除；近景保留窗格与屋顶构件，远景按窗格屏幕足迹平滑过滤颜色、淡出凹凸与粗糙度变化。浏览器已查看近景与远景，并在远景进行了150帧小幅横向／前进采样；窗格远处平滑收敛，密集实体横条已消失，几何809份／纹理21份保持不变，Worker未运行。着色器编译无错误；该观察不保证所有设备、角度与速度下完全无混叠。
飞机实际上限1980米、显示9900米，收轮后的主高度表与最高高度记录同样不超限。高层主体／石柱高度偏向显示12000米，少量高峰接近20000米；本局静态实体最高约19982.5显示米，山墙例外。高峰树冠不越过普通物体高度上限。

固定山墙四边封闭：横向内缘±22公里，前端Z=6500、后端Z=-235000，外扩3.5公里，峰顶显示30000米。高处缺口仍高于飞机上限，外侧停止循环显示。866个网格插值采样与可见Float32三角面的非转角误差低于1e-9米，转角取重叠面的最高值；四边与转角撞击可损毁。完整游戏状态采样确认先进入2.8秒CRASH，再到RESULT，原因保留“偏离航道太远，撞上高山。”

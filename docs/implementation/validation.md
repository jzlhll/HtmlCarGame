# 常规验证流程

本文件集中维护验证步骤，按本次改动选择必要检查；不默认执行完整玩法回归。

1. **确认范围。** 先确认改动入口、直接调用方和相关设计规则，确定预期行为及关键边界，再修改代码；按需读取文件，避免全库扫描。
2. **按风险选择检查。** 文档改动检查内容和链接；局部数值、样式或导入改动检查对应结果，影响浏览器模块加载时检查启动；模型改动检查实际外观、尺寸、碰撞范围及合批兼容性；碰撞、路线切换、状态和事件时序改动检查相关正常路径及关键边界。音效改动检查对应事件触发、暂停静音与新局恢复；`AudioContext` 依赖用户手势，浏览器验证需实际开始一局确认声音与控制台。
3. **检查代码与逻辑。** 修改 JavaScript 后对改动文件执行 `node --check`，交付前检查 diff。逻辑边界必要时用一次性 Node 脚本验证；核心逻辑重构必要时使用相同种子与输入对照新旧行为。不主动新增测试文件或引入构建步骤。
4. **确认实际表现。** 先按下文检查浏览器端口与服务；有 `cua_repl` 的会话优先使用该工具，其他环境可按下文选择轻量 Playwright 方案，并遵循各自的浏览器操作限制。同一批改动完成后统一刷新加载最新代码，检查实际画面、对应操作和控制台错误。自测勾选“调试模式”，避免写入排行榜；已有页面可能丢失用户进行中的游戏时使用临时标签，保留用户状态。
5. **补充必要边界与测量。** 涉及时钟、状态、缓存或对象池时，检查对应的暂停冻结与新局重置。性能优化先做小规模基线测量，比较时保持场景、车辆数量、种子、步数和计时范围一致；区分逻辑步与完整帧耗时，不将合成压力结果直接推算为普通游戏帧率。只有测量不足、出现失败或仍有边界疑点时扩大种子、运行时长及压力规模。
6. **结束并清理。** 必要检查通过且没有未解决疑点后结束验证；后续仅重验受新增修改影响的部分。关闭自行创建的临时标签和服务，清除临时调试入口，保留用户已有的页面、服务和工作内容。交付说明报告结果、有效证据及影响结论的验证缺口，不逐项列出常规检查通过情况。

## 浏览器端口与服务检查

预览前确认端口可达，且服务指向当前工作目录；默认使用 `5173`，占用时通过 `PORT` 指定空闲端口，不停止用户已有服务。

启动后确认成功日志和 HTTP 响应，再用当前环境允许的浏览器工具打开对应地址，刷新检查最新画面与控制台。连接失败先检查服务和端口，权限错误按工具流程处理，避免无依据地反复重试。

验证结束只关闭自行创建的临时标签和服务，保留用户已有页面与游戏状态。

## 轻量 Playwright 验证方案

默认采用一次性 Node 脚本验证受影响的逻辑，再集中做一次浏览器确认。已有 `cua_repl` 时无需额外安装；缺少浏览器工具且环境允许时，可选择以下方案：

- 在仓库之外的通用工具目录（如 `/Users/allan/dev-tools/browser-check`）安装 `playwright-core`，固定版本并维护该目录自己的 `package.json` 和锁文件；不全局安装，不改各项目依赖，也不引入完整测试框架。通用验证脚本放在工具目录并从该目录执行，各项目传入 URL、端口及输出路径，跨项目复用。
- 本方案浏览器固定使用已安装的 Google Chrome，通过 `chromium.launch({channel:'chrome',headless:false})` 启动独立验证浏览器；这里的 `chromium` 是 Playwright API 名，`channel:'chrome'` 指定实际使用 Chrome，无需执行 `playwright install`。环境没有 Chrome 时先披露缺口，不自动安装浏览器。此方式复用浏览器程序，不复用用户正在使用的进程或个人资料。[浏览器配置官方说明](https://playwright.dev/docs/browsers)
- 每次验证使用独立浏览器上下文及临时产物目录，避免项目之间状态混用；只使用一个浏览器和一个页面，打开已确认的本机 HTTP 地址，启用游戏调试模式，检查当前改动涉及的操作、画面和控制台。音效验证需通过实际点击或按键开始游戏并试听，不能仅凭截图或控制台认定声音正常。
- 不默认开启并行、录像或完整追踪，截图按需保留；用 `try/finally` 关闭本次启动的浏览器和服务，只清理本次临时产物，长期保留通用工具目录及其他项目输出。共享目录减少重复安装与磁盘占用；实际内存主要来自浏览器与游戏场景，具体占用与速度收益需实测。

固定种子和直接进入目标场景是独立的开发入口方案，`cua_repl`、手动浏览器或 Playwright 均可使用；目前属于待验证建议，不能通过只改时钟跳过事件逻辑，仍需验证触发前后的边界。

## URL 测试参数(随机事件快速触发)

随机事件(警车、白马、奶牛、施工、低速车队、天气、断头路、天降炮击)默认节奏为分钟级,浏览器验证时通过 URL 查询参数在启动早期覆盖 `config.js` 白名单字段,不改代码、不落存档；移除 URL 参数后刷新恢复默认;生产环境不带参数即默认值。

- `?fast=1`:一键测试档,主要随机事件压缩到秒级(警车每 5 秒、数学/语文/英语答题均为 5 秒、第一关白马每 8 秒（8、16、24 秒）、其他关卡每 8 秒、奶牛 4–8 秒、施工从道路 10 米处开始候选、低速车队 3 秒首现、天气 2–4 秒首次检查后每 6–10 秒检查，触发概率仍为主路 40%、副路 80%、分叉候选概率为 100%、建筑间距压缩到 500–800 米；分叉仍受最小跨度与可用空间限制，不保证生成、炮弹 8 秒开始检查且每 3–5 秒检查一次，15 秒后每 1.5–2.5 秒检查一次，普通投弹概率仍为 40%，16、24 秒扩大范围时必投一枚，下落 1.5 秒；第一关车流强化在 24 秒达到上限；独立 X 路障 15 秒后启用，每 240 米检查且候选概率为 100%，仍避开施工、道路过渡和桥梁分叉)。
- 精确覆盖:`?POLICE.intervalSeconds=5&WHITE_HORSE.intervalSeconds=5&WEATHER.intervalMin=6&ROAD_FORKS.chance=1&SHELL.intervalMin=3`,概率可用 `WEATHER.chance`、`ROAD_FORKS.weatherChance` 和 `SHELL.chance` 覆盖（例如 `1` 表示必定触发）。只接受白名单配置字段（含警车距离、倍率与网尺寸，不含车型尺寸与车辆碰撞阈值）,答题时限可用 `POLICE.quizMathSeconds`、`POLICE.quizChineseSeconds`、`POLICE.quizEnglishSeconds` 单独覆盖；非法 key 或非数值直接忽略并控制台告警,防止误改物理与碰撞参数。
- 覆盖生效时页面右上角显示测试参数角标,截图即可确认当前处于测试节奏,避免把测试结果当默认行为;`?fast=0` 关闭预设。
- 验证火车或其他环境事件时可用 `?TRAFFIC_DENSITY.capacity=0&TRAFFIC_DENSITY.maxCapacity=0` 清空普通车流；两个容量同时为零可避免运行中容量增长后重新补车。需要少量车流时将两者设为相同的小整数，例如 `6`；也可单独覆盖 `TRAFFIC_DENSITY.capacityPerStep` 调整增长量。不带这些参数即恢复正常车流，不写入存档。

实现见 `src/test-overrides.js`,由 `config.js` 末尾在启动早期应用;Node 端导入无 `location` 自动跳过。独立 X 路障可用 `ROADBLOCKS.afterSeconds`、`first`、`interval`、`chance`、`warningDistance` 覆盖启用及候选节奏；炮击加密阶段可用 `SHELL.frequencyAfterSeconds`、`lateIntervalMin`、`lateIntervalMax` 覆盖。警车固定周期使用 `POLICE.intervalSeconds` 覆盖，旧的 `POLICE.intervalMin/Max` 不再支持。新增随机事件时在 `WHITELIST` 登记节奏字段,并按需加入 `FAST_PRESET`。

流程的效率改进与待验证建议见[开发与验证效率](development-workflow.md)，其中推测意见不作为默认执行要求。

## 第二关验证参数

`LEVELS.firstSeconds` 可缩短第一关通关门槛；取值至少 8 秒可检查完整 5 秒顶部倒计时。仍须实际行驶，检查到时清空车流、镜头固定、玩家模型前行 3 秒后显示通关界面，再点击或按空格切关，确认第二关自行车、时间、距离、资源与事件从零初始化；`LEVELS.weatherChance`、`branchWeatherChance` 只覆盖第二关天气概率；第二关关闭炮击调度。`DINOSAURS.smallFirstMin/Max`、`smallIntervalMin/Max`、`smallChance` 可加快横穿；`DINOSAURS.chaseAfterSeconds`、`chaseFirstMin/Max`、`chaseIntervalMin/Max`、`chaseChance`、`durationMin/Max` 可加快追行生命周期。其余尺寸、伤害及速度倍率不开放覆盖。

示例：`?LEVELS.firstSeconds=2&DINOSAURS.smallFirstMin=1&DINOSAURS.smallFirstMax=2&DINOSAURS.smallChance=1&DINOSAURS.chaseAfterSeconds=8&DINOSAURS.chaseFirstMin=1&DINOSAURS.chaseFirstMax=2&DINOSAURS.chaseChance=1`。人工验证启用调试模式；去掉参数刷新后恢复第一关 2 分 30 秒通关及正常两分钟恐龙分界。

`ROAD_DIFFICULTY.afterSeconds` 按第二关自身有效运行时间控制永久收窄，默认 120 秒；第一关不受该参数影响。

金币生成节奏可通过 `COINS.firstSeconds`、`intervalMin/Max`、`chance`、`aheadMin/Max` 加速，金币价值、价格、清理车道数和射程不开放 URL 覆盖。第二关启用调试后验证小／大金币累计，按 1 或触屏按钮消耗 25 金币发射一枚普通炮；余额 24 时不可用、25 时恰好发射并归零，发射容量已满及旋转失控时不扣款，按 2／3 不发射。前方 100 米清理范围包含装甲坦克，保留警车及捕网，追击和撒网继续；清理自身和左右各一车道，覆盖路边、对向、弯道及副路汇流边界。桌面和手机仅显示一个普通炮按钮，第一关通关说明使用普通火箭模型并标明 25 金币，切关余额与火箭动画归零。

## 侧碰与无敌回气

验证同级有效侧碰在未领先、未喷气和喷气时均吞吃；同级追尾喷气也降级，自行车同级追尾仍致命。高级车侧碰速度变为 60%、失控旋转 1.5 秒，接触点位于前后端及左右侧时检查转向和偏移；期间加速、刹车、横移、氮气、发炮无效，暂停冻结，结束或复活恢复控制。每次从侧撞及预计偏转的最多三条车道中投放一辆后车，检查路边、对向、副路、满容量及车长较大时整车在屏幕下方且不重叠，随后按普通车流运行。白马无敌撞飞车辆只按车型及连续侧移规则回气，两管封顶，不重复奖励、不改变积分、吞吃统计或饥饿时刻。

## 挖空边界

语文题核对所有二至五年级半句均有人工词组候选，原句对应的起始位置和答案完全匹配，干扰项也为同长度完整词组；“忙趁东风放纸鸢”不得生成“放纸”或“风放”。英语检查 `Month → Mon__`、`Teach → T__ch` / `Tea__`、`Those → __ose`、`happy → ha__y`，以及无组合单词的单字母挖空；保持大小写，四个选项唯一且同长度，答题失败回看能准确还原完整原词。数学和英语句子选词仍沿用原规则。

## 恐龙弱化与炮击

核对追行模型首次创建、缓存克隆和实例合批均无投影，其他恐龙及车辆阴影正常。对比起跳后横移的躲避窗口，出场等待 1.2 秒、起跳至接地 1.2 秒、两次起跳至少 2.4 秒、36–48 米步距、1.8×3 米脚掌及 0.2 秒危险窗口；停在原落点仍会受踩踏，残留脚印无伤害且无预警。普通炮每发消耗 25 金币，三次命中击败，每发只扣一次防御，未命中及发射失败不伤害。击败取消在途及接地危险脚印，不再起跳，暂停冻结离场，下一只正常等待且防御重置；检查前后方、车道、射程和主副路边界，以及桌面与手机防御显示。

## 数学学习帮助与分数

确认只有最大公因数、最小公倍数题有学习帮助；整数、小数、分数、混合运算及语文、英语不显示帮助按钮，普通计算题不能暂停答题计时。帮助至少包含两道数字例题，分叉与取数方式正确。打开前后保留原题和选项，阅读超过原期限不会超时、数字键不答题或发炮；多次打开关闭、失焦及返回后仍按原剩余时间，已经超时不能打开，重开和返回首页不残留帮助。警车题与救援题共用。核对题干、选项和答错回看中的分数均为上下分式，正确答案比较不变；窄屏无横向溢出、图解可看清，正文可滚动且返回按钮可操作。

## 语文两句与作者

核对每道语文题均注明朝代和作者，并按原顺序显示同一首诗的相邻两句；上下句补全只挖一整句，词组题只挖一个完整词组，另一句完整保留，选项仍为四个且唯一正确。二至五年级诗篇及其配对关联正确，同名诗篇不会错配；答错回看保留朝代、作者和两句完整诗。桌面与窄屏检查五言、七言、整句挖空及词组挖空都可读，数学上下分式与英语题格式不受影响。

## 语文课外拓展

固定随机种子抽样，语文题中课外比例应接近 10%，两种题型及六首拓展诗均能抽到；比例改为 0 或 1 时分别全为课内或课外。逐题确认错误选项只来自二至五年级课内完整诗句或人工标注词组，长度相同、选项唯一，课外正确项不会混入错误选项。检查朝代、作者与两句配对、挖空边界、答错完整回看，课外数量不影响科目比例与答题时间。

## 第二关恐龙及变道

用相同抽签确认第二关普通车变道意图为原概率乘 1.2 后取整百分比（前期 36%–66%、永久四车道后 66%–96%），第一关不变，保留安全邻道、危险车与固定个体开关。检查小恐龙 3、4、5、6 只都能生成，两列队形一致、模型和接触尺寸翻倍且互不重叠；桥下显示尺寸保持。检查追行底圈贴合身体位置与坡面，无脚印及模型投影，接地窗口内各等级系统车死亡消失，腾空、到期、分离路线不命中，同一次踩踏不重复处理。核对湖泊、河谷与桥下水域均有梁龙，道路净空与环境容量有效；检查三角龙、剑龙和霸王龙的实际轮廓、皮肤、动作、包围范围及模型池复用。

## 第二关三分十五秒通关

默认第二关时限为 195 秒，可用 `LEVELS.secondSeconds` 缩短验证（至少 8 秒可观察完整五秒倒计时）；与首页“调试 · 直接进入第二关”组合，不修改存档。确认倒计时后出现第二关通关说明，停止驾驶、事件、计时和音效；新的空格或触屏操作进入第三关，时钟、车辆和资源从零开始，不播放死亡动画、不写第二关通关成绩。检查跨界逻辑步、零速、暂停、答题、失焦、截止前致命与救援、重复结算；第一关仍在 150 秒进入驶离与第二关入口。普通 `complete` 成绩可重新加载，原 `death`、`quit` 成绩仍有效，调试通关不写榜；返回首页及再来一局从新局初始化。

## 第三关环境与灾害

首页勾选“调试 · 直接进入第三关”验证；`LEVELS.thirdSeconds`、`DISASTERS.environmentSeconds` 和 `narrowSeconds` 可缩短时限、换景与四车道门槛，`volcanoInterval`、`waveInterval`、`iceInterval`、`collapseInterval`、`icebergInterval` 可加速事件。确认三种环境两轮、六分钟最后五秒倒计时与最终结算，满三分钟主副路仅四车道，暂停与答题冻结，复活及重开清空横移和浸泡状态。核对岩浆自行车死亡／其他车直接降一级、海啸自行车死亡／其他车扣满防御 60% 并旋转 1.5 秒、覆盖区连续主动横移超过 0.8 秒旋转一秒、车道冰山无保护时各车型直接死亡；同点不重复命中，重叠覆盖不加倍计时。实看整片覆盖浮桥且无阴影的涌浪、不对称冰峰、喷发飞行与直径五米的圆形危险区，确认道路冰山每十秒生成，静态缓存最多七块、同区块内不重复写入，换景与收窄后更新，低画质减少装饰但保留全部危险；去除测试参数后恢复默认。普通第三关成绩重载有效、调试局不写榜，前两关季节、侧撞和车型规则保持。

## 第一关事件压缩节奏

默认第一关 150 秒通关，`FIRST_LEVEL_EVENTS` 控制末次强化时间 145 秒、白马次数 3 与 X 路障启用时间 120 秒；三个字段允许 URL 覆盖。验证白马在 48⅓、96⅔、145 秒各投放一次，车流容量及生成净距分别在 145 秒达到 160 辆及 65%，此前逐档变化。炮击 100 秒开始检查、125 秒加密，122.5、145 秒扩大范围时各必投一枚，即使普通投弹概率为零也要执行，同刻普通检查不重复投弹；最后一枚默认 147.5 秒落地。检查暂停冻结、重开清空、答题后不补发以及第一关结束后清场。第二、三关白马仍每 60 秒投放。第二关车距和容量总增长时长各缩短 20 秒，分别在 250、340 秒达到原上限，X 路障 130 秒启用；第三关车流每 15 秒增长一档、X 路障 150 秒启用。警车第二关每 55 秒、其他关卡每 75 秒投放，第一、二、三关的最长追击时间分别为 25、35、45 秒。

## 第二关警车与渐进难度

`SECOND_LEVEL_EVENTS.trafficCompressionSeconds` 默认 20 秒，仅缩短车距及容量从初始值到原上限的总时间，保持每档 2%／3 辆及原上下限，不能在 195 秒通关时突然拉满。分别检查 250 秒的车距下限和 340 秒的容量上限；通关前只体验到曲线中间档位。X 路障在第二关 130 秒启用，第一关仍为 120 秒、第三关仍为 150 秒。三个关卡警车周期分别为 75、55、75 秒，追击上限分别为 25、35、45 秒；检查超时自动撤离、撤离后对齐下一节点、被拦查答对后不重新计满周期、暂停冻结与切关重新选择节奏。测试覆盖 `POLICE.secondLevelIntervalSeconds` 可缩短第二关周期；`fast=1` 为各关统一使用五秒周期，第二关路障十五秒启用。

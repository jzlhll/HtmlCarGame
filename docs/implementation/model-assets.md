## 当前契约

浏览器从导航至完整场景、精细像素与必需GPU对象就绪的目标为4秒；首次下载受网络影响，实测须注明环境与缓存状态。首屏在基础资源就绪后2秒内显示，四秒入舱保留，点击至可操控总预算8秒。四关、引擎、语音、源素材及全部生成包合计小于50 MB；构建耗时不计浏览器准备，但不得从部署体积中排除生成包。

原生JavaScript与Three.js模块无需代码打包。`npm run prepare:assets`用正式生成器在Node构建固定数值资源，`npm start`、`npm run play`及双击启动脚本自动检查；Pages整理同样先构建。产物仅在已忽略的 `assets/generated/` 与 `.pages-output/` 中，Git保存代码、配置和必要源素材。

## 全模型盘点及处理

| 模型范围 | 最终处理 | 浏览器保留的工作 |
| --- | --- | --- |
| 玩家、交通客机、姿态卡客机 | 基础机身／翼／发动机／轮胎及最终合批模板预生成；保留索引，所有飞机共享最终几何 | 每架独立材质、减速板、轮组与灯光节点，避免动画／透明度／颜色串改 |
| 驾驶舱、风挡与裂纹 | 舱框原型预生成；三块窗框实例化；完整裂纹预创建 | 窗口适配、绘制范围、亮度与透明度 |
| 跑道、机场楼房、灯、编号 | 小型局部模板准备期合批；两机场共享编号图集，灯实例化 | 按当前目的地绑定位置、尺寸和标高 |
| 停放飞机与卡车 | 停放飞机共享客机几何，卡车共享一份合批几何 | 独立材质、碰撞反馈与预创建抛落动画 |
| 雁群及交通符号 | 极小共享几何，预创建实例与目标槽；不增加单独下载包 | 真实位置、扑翼和既有矩阵更新 |
| 六种树与机场小树 | 六树十八原型预生成并保留兼容缓存，森林只使用完整模型；机场树同样不换冠形 | 1.2公里分块装配、接触索引及保守裁剪，7–8.4公里平滑淡出 |
| 主山面、岩柱及循环地形 | 循环模板、山面法线／颜色／植被权重／太阳遮蔽与山林落点预生成；岩柱等小型同源面在准备期装配 | 山面绑定逻辑位置，规则索引与共享材质档位；循环49槽复用四模板，不序列化196份克隆 |
| 城市、古建与景点 | 共享预制曲面与原有构件实例化；材质和最终属性复用 | 小型分组及楼房本局随机偏移，碰撞同步移动 |
| 田园、林带、道路与静态街车 | 四关共享记录按内容去重；田块几何、树矩阵、道路布局／路面／车辆矩阵预生成；道路原型与材质单页共享 | 对象恢复、空间裁剪、小窗实例索引；不逐页重算数值 |
| 海岸、高速、江湖与瀑布 | 江湖三角化／水深／颜色预生成；海岸与高速读取物理同源数据；瀑布小纹理由数值构建 | 小型几何／矩阵装配，水纹仅改时间 |
| 六种云、闪电与损毁特效 | 六份连续云壳预生成；闪电顶点、粒子、碎片开局预分配 | 本局布局与往返移动、既有顶点／uniform更新 |
| 表面、叶片与环境纹理 | 精细表面及手工mipmap预生成；齐备时直接上传最终精度；叶片保留源图解码并持久缓存 | 首次叶片解码、GPU上传及极小图集，不在飞行中生成 |

第四关的代表规模为2600栋普通建筑、42642个景点构件、29个路网、72802辆静态街车、57片主山面。前三关的同ID路网按内容共享；各关资源签名仍包含关卡作用域，云布局及目的地相关数据不能因跨关去重而串用。

## 编码、共享与兼容

资源包只含数值及类型信息。TypedArray按字节保存，按包比较直接gzip和字节预测后gzip并选择较小者；内容SHA决定文件名。法线使用snorm16、0–1颜色与biome使用unorm16，法线单分量误差上限约1.53×10⁻⁵；位置、UV及碰撞数值保持Float32，不用位置量化移动障碍或改变通道。

共享原型、像素、田园、街道、水体、云、树和山面按现有资源配置签名恢复。构建指纹含生成代码、配置、必要PNG源及依赖锁；命中时核对文件大小与SHA，缺失或损坏重新构建。构建不把本局随机天气位置或楼房偏移烘死。

浏览器并行恢复压缩包，校验大小、SHA与解码格式后持久保存；所有异步任务结束后才开放数值记录。坏持久包重新下载，单包失败沿用对应生成器，不使其他有效包失效。存储不可用时仍从发布包恢复并复用本页内存，持久成功登记继续遵守版本模块。

升级确认当前资源完成后，只清本关旧签名记录，以及全四关发布清单不再引用的本游戏压缩包；保留其他关卡、设置、存档和其他项目。程序版本、资源编码与数值配方分别管理；本次兼容布局、像素和碰撞继续有效，不递增全局配方。

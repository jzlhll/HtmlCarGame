# 云端驾驶舱

面向桌面浏览器的单人民航客机模拟游戏，采用 Three.js 与原生 JavaScript。玩家先观看跑道、飞机与机场的外部镜头，在 `4、3、2、1` 倒数中进入驾驶舱，再完成六步启动、起飞、三关航线与机场、着陆并在跑道内停稳。

游戏的重要目标是让使用者在操作飞机的过程中，逐步熟悉键盘字母按键的位置。每个动作结合英文助记词、中文含义和清晰键帽提示，通过真实操作反馈建立“动作—字母—键位”的联系；后续还会规划逗号、句号、分号等标点键练习。

视觉采用低多边形场景、半透明深色面板、暖金色重点和中英文文字层级。飞行时使用第一人称视角，下方约四分之一屏幕用于驾驶舱仪表与操纵区，完整前窗由四周边框围合，中央无遮挡，呈现连续的外部世界。

## 当前状态

当前分支为 `codex/flight-simulator`，已实现深圳起飞的三个逐段延长关卡。开场可选关，并显示计划路线与地面海拔剖面；每关都从深圳重新准备起飞，后关共用前段地景，只保留当前目的地机场。成功后可进入下一关。

| 关卡 | 航线与新增景观 | 总时限 | 建议巡航 | 终点地面海拔 |
| --- | --- | --- | --- | --- |
| 1 | 深圳 → 广州：滨海机场、沿江高速、珠江河口、田野、城市与地标 | 3:20 | 370 km/h | 300 m |
| 2 | 深圳 → 长沙：保留前段，延伸丹霞山、张家界石柱／空中瀑布、橘子洲石像 | 3:45 | 417 km/h | 650 m |
| 3 | 深圳 → 武汉：再延伸宽阔洞庭湖、高耸黄鹤楼 | 4:15 | 454 km/h | 1000 m |

同一空速下地面掠过速度为原来的2倍，景点群保留尺寸并拉开距离，三关航程为26.4／35／44.8公里；组间增加溪流、草地和低缓连绵小丘。海拔从深圳沿途逐渐增加，江心岛和湖区保留平坦水面，不是把整关统一抬高。R首次放行后计时，包含滑跑、飞行、着陆和停机；安全着陆后机身位置在目的地跑道内停妥1秒才成功，暂停冻结时限。空格暂停／继续，失焦自动暂停，重开返回同关深圳起点。
L、D、H、A可任意顺序准备：D关闭，其余三项开启，W默认Closed；F点火约3秒后R松刹车。正常最高速度为600 km/h，首次鸟击后限为480 km/h。W关闭时按T从静止约13.0秒达到250 km/h，再↑平滑抬轮，离地后G收轮。T／S每次点按累计10 km/h主动变速额度，同向累计，反向取消，按住持续变速；W即时切换，关闭只允许T，打开只允许S。切换W清空旧额度，不在切回后自动续跑。起飞前地面T主动提速为原慢档基准18倍，约6.714 m/s²（24.169 km/h每秒）；空中T主动提速为原慢档15倍，约5.595 m/s²（20.141 km/h每秒），扣除自然降速后净增约15.141 km/h每秒；S主动减速保持10倍，即6 m/s²（21.6 km/h每秒）。接地后T／S仍使用10倍，W位置不参与速率插值；提速仍受发动机、驻车、超高降额和鸟击故障门控。飞机始终自然降速：W关闭每秒减速5 km/h，打开时再加10、合计每秒减速15 km/h；与T／S主动变速独立叠加，不消耗点按额度，速度最低为0。姿态与下落不被换算成被动提速。 进近将速度降至100–180 km/h，放下Gear（起落架），俯仰保持±3°并在跑道内接地；Wing brake仅用于减速，不是接地条件，在跑道内停妥1秒。目的地有4架飞机与8辆卡车；撞卡车扣速10%并撞飞，撞其他飞机爆炸失败。

入舱中央说明只显示一次，首次按键后本局隐藏。运动中D、H、R禁止操作，L、A、F不会自动驻车。飞行采用游戏化前进速度与垂直运动。姿态限速跟随用户输入，↑／↓点按1°、按住3°/s，失速不削弱俯仰或滚转，不按迎角自动低头／抬头。空中低于150 km/h进入失速，达到165 km/h解除，150–165之间维持原状态；仅将垂直航迹限制为低速下沉，机头角度、前进速度和左右操纵不受失速影响。下沉目标为`7.5 + 52.5 × clamp(1 − speed/150, 0, 1)`米/秒，最大60米/秒；该上限指失速造成的低速下沉，玩家主动俯冲仍可更快下降。解除后连续恢复用户姿态对应的垂直运动，不跳变高度。 左侧航图记录真实轨迹，目的地为五角星；雷达与窗外标记辅助辨认交通。碰山、碰楼或其他飞机会失败；每道瀑布独立奖励一次。超过10000米触发动力故障，下降至安全高度恢复。合成音效与Samantha英文女声播报默认开启，暂停和结算静音；云层与天气未实现。启动页可勾选调试停机，以400 km/h、起落架收起、W关闭，在当前目的地前约30秒航程接管；3／2／1倒数后正常操纵。完整规则见[航程专题](docs/design/07-航线与关卡.md)。

## 操作与规划

| 操作 | 行为 |
| --- | --- |
| 空格 | 开始；过程中暂停或继续 |
| L / D / H / A / W | 任意顺序准备；L／H／A 开启，D 关闭锁定，W 关闭减速板 |
| F → R | 四项就绪后 F 点火；发动机就绪且停稳后 R 放行 |
| T / S | 点按累计±10 km/h主动额度逐步执行；W关闭只允许T，打开只允许S，起步T为原慢档18倍，空中T为15倍、S为10倍 |
| ← / → | 地面修正方向；空中协调转弯 |
| ↑ / ↓ | 抬头／低头，通过姿态与速度改变爬升或下降 |
| G | 离地至少 30 米且正爬升后收起落架；已收起时不高于 407 km/h 可放下 |
| W | 起飞必须关闭、接地时开关均可；关闭只允许T提速，打开只允许S减速，即时开关，关闭每秒减速5 km/h，打开每秒减速15 km/h |

`T` 取自 Thrust，`S` 取自 Slow，`W` 用 Wing brake 助记，表示游戏化的机翼减速板。抬轮速度暂定 **250 km/h**，属于固定游戏预设，不能用于真实机型操作。

字母按键不区分大小写，支持 Shift 与 Caps Lock；尽量采用动作英文名称的首字母，避免重复占用；标点键作为后续观察类操作规划，按物理键位识别，不依赖输入法输出中文还是英文标点。学习方式与标点键初案见[游戏流程与操作](docs/design/01-游戏流程与操作.md#键位学习与标点键规划)。

## 本机开发

需要 Node.js 18 或更高版本。缺少依赖时安装锁定版本：

```bash
npm ci
npm start
```

通过浏览器打开 [http://localhost:5186](http://localhost:5186)，不直接打开 HTML。端口已占用时可用 `PORT=5187 npm start`。无编译或打包步骤，Three.js 从本机依赖目录加载。

启动后显示外部机场场景，可观看四秒开场后进入驾驶舱完成起飞与目的地航程。macOS 也可使用根目录启动脚本，当前没有飞行游戏发布地址。

山体与森林在进入关卡时由浏览器生成，采用固定种子、共享岩纹和远近细节切换；重开复用场景。总准备预算12秒，整套发布资源上限50 MB，生成模型不提交Git；当前无需模型编译或额外素材包。具体策略见[山体与森林表现](docs/design/04-天空环境规划.md#山体与森林表现)。

左右转向通过滚转与最大60°坡度实现。雁群使用17只立体V阵，其他飞机为2倍模型，碰撞同源；窗外与飞机图显示相对高度差，雷达显示直线距离。首次雁群从离地后6秒开始安排，交通需要主动避让。

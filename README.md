# 云端驾驶舱

面向桌面浏览器的单人民航客机模拟游戏，采用 Three.js 与原生 JavaScript。玩家先观看跑道、飞机与机场的外部镜头，在 `4、3、2、1` 倒数中进入驾驶舱，再完成七步启动、跑道滑跑与离地爬升。

游戏的重要目标是让使用者在操作飞机的过程中，逐步熟悉键盘字母按键的位置。每个动作结合英文助记词、中文含义和清晰键帽提示，通过真实操作反馈建立“动作—字母—键位”的联系；后续还会规划逗号、句号、分号等标点键练习。

视觉采用低多边形场景、半透明深色面板、暖金色重点和中英文文字层级。飞行时使用第一人称视角，下方约四分之一屏幕用于驾驶舱仪表与操纵区，两扇前窗共同呈现连续的外部世界。

## 当前状态

当前分支为 `codex/flight-simulator`，处于设计与实施规划阶段。当前开发入口为静态筹备页，飞行玩法尚未实现；后续按实施规划创建驾驶舱、机场与游戏逻辑。

首个可玩版本完成开场、七步启动、跑道加速、抬轮与初始爬升；三层天空巡航只做规划，天气暂不开发。

## 计划操作

| 操作 | 行为 |
| --- | --- |
| 空格 | 开始；过程中暂停或继续 |
| L → D → H → A → F → W → R | 依次完成灯光、舱门、安全带、飞行仪表、发动机启动、襟翼、松刹车 |
| T / S | 按住增加／减小油门；地面收至怠速后继续按 S 使用轮刹 |
| ← / → | 地面修正方向；空中协调转弯 |
| ↑ / ↓ | 抬头／低头，通过姿态与速度改变爬升或下降 |
| G | 正爬升后收起落架 |
| W | 达到安全高度和速度后收起襟翼 |

`T` 取自 Throttle，`S` 取自 Slow；`W` 用 Wing Flaps 助记，实际操纵的是襟翼。抬轮速度暂定 **145 kt，约 269 km/h**，属于游戏初始调参值，真实起飞速度的含义和限制见[飞机与起飞](docs/design/02-飞机与起飞.md)。

字母按键尽量采用动作英文名称的首字母，避免重复占用；标点键作为后续观察类操作规划，按物理键位识别，不依赖输入法输出中文还是英文标点。学习方式与标点键初案见[游戏流程与操作](docs/design/01-游戏流程与操作.md#键位学习与标点键规划)。

## 本机开发

需要 Node.js 18 或更高版本。缺少依赖时安装锁定版本：

```bash
npm ci
npm start
```

通过浏览器打开 [http://localhost:5173](http://localhost:5173)，不直接打开 HTML。端口已占用时可用 `PORT=5186 npm start`。无编译或打包步骤，Three.js 从本机依赖目录加载。

目前启动后显示静态筹备页；飞行玩法实现后继续使用上述方式运行。macOS 也可使用根目录启动脚本，当前没有飞行游戏发布地址。

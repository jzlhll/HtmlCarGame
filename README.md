# 四季车途

基于 Three.js 的本机浏览器赛车游戏，采用五级车辆、侧碰吞吃与升级、双向交通、四季场景和本机成绩记录。道路包含高架桥、河道谷底和干燥低谷；铁路与火车仅在高架桥下运行。分叉跨度 880–1760 米、副路实际弧长约 800–2000 米，中段道路边缘间隔 40–60 米。系统车固定巡航，普通车临近系统碰撞时闪灯避让，前期 15%、后期 25% 的危险车主动换道且不检查空隙；系统碰撞按等级撞毁或弹开。有效运行满 150 秒后，前方平滑收至永久四车道，过渡期间子弹概率增加 10 个百分点；进入后期四车道后，子弹相对基础增加 25 个百分点、火箭增加 20 个百分点，随机变道概率提高至 45%–70%、检查间隔缩至 4–7 秒。

一级自行车采用摩托车造型，具有宽油箱、粗轮胎、阶梯座垫与前后车灯，玩家和系统共用 1.584 米宽、2.4 米长的碰撞范围。树木混合簇状阔叶树冠与分层松树冠，按种子变化高度和冠幅。每轮道路增加额外弯组候选，通常约 58% 里程为平滑弯道。卡车车身长 9 米，玩家和交通车辆共用尺寸与碰撞范围。

玩家最高速度依次为自行车 90、三轮车 110、小汽车／卡车／坦克 125 km/h。系统车辆同向巡航区间依次为 20–45、55–85、55–95、45–75、25–55 km/h，对向巡航区间依次为 29–65、79–122、79–137、65–108、36–79 km/h。前方普通新车在 160–240 米生成，前后补车失败后重试一次。场内容量从 88 辆起，每 15 秒有效运行增加 3 辆，最多 160 辆；系统车距逐档缩短至初始值的 65%，暂停不累计。

## 开始游玩

需要 Node.js 18 或更高版本。项目首次安装依赖后，运行游戏不需要联网。

```bash
npm ci
npm start
```

浏览器打开 **http://localhost:5173**。本项目已经安装好依赖，本机直接 `npm start` 即可；macOS 也可以双击根目录的 `启动游戏.command`。

开始前可勾选“调试模式 · 死亡后复活”。选项只保存在当前页面内存中，刷新后默认关闭；死亡动画结束后恢复当前车型及其门槛积分，闪烁保护两秒继续本局。调试局不写入排行榜，主动结束仍显示结算。

同时运行多个 worktree 时可指定不同端口，例如 `PORT=5184 npm start` 后打开 `http://localhost:5184`，浏览器成绩按各自地址独立保存。

保持启动窗口开启，结束服务时按 `Ctrl+C`。始终使用同一个地址，避免浏览器把不同来源的成绩分开保存。

| 操作 | 行为 |
| --- | --- |
| 空格 | 开始、暂停、继续；结算时开始新一局 |
| ← / → | 按住横移，自动跟随道路弯曲；吞吃回气半管，同方向持续侧移超过 0.4 秒时吞吃回气翻倍 |
| ↓ | 按住刹车，松开后自动缓慢提速至车型上限 |
| ↑ | 低于车型最高速度 60% 时普通加速，不消耗氮气；达到门槛后按住喷气，松开留气 |
| 暂停窗口“结束游戏” | 主动结束并保存成绩 |

横向靠近车身侧面且纵向重叠足够时吞吃低级车；自行车可吞吃同级自行车，其他同级侧碰各按自身车宽两倍惯性弹开，再缓慢收尾；玩家 1.5 秒内不能左右控制；端面中央接触按追尾，擦角及已有重叠只分离。总积分用于成长与饥饿储备，车型价值和门槛为 1／2／6／18／54，开局为 1。吞吃增加目标价值，车型由实际总积分决定，吞吃和积分扣减引起的升降级保留积分；防御耗尽则设为低一级门槛，总积分上限为 54，满级吞吃只计数量并重置饥饿计时。追尾低级车只撞飞，不加分、不扣分、不减速；自行车追尾自行车直接死亡；其他同级追尾扣当前车型低一级价值、速度减半并移除目标，低于车型门槛才降级。任何扣分降级均保护两秒，碰撞更高级车直接死亡；同向与对向规则一致。左侧显示车型、总积分／门槛和当前防御百分比，排行榜仍按距离计分。

每分钟必定出现一匹 60 km/h 白马，奔跑 6 秒后闪烁 2 秒消失。任何接触都可获得冲刺：1 秒提至当前车型正常最高速度的两倍，无敌共 10 秒（最后 2 秒保护罩闪烁），随后 2 秒回落。无敌期间撞飞车辆与路障，不吞吃、不加分，饥饿计时冻结，详见[白马与无敌冲刺](docs/design/11-白马事件.md)。

连续 10 秒未吞吃，按当前车型扣 1／1／2／6／18，之后每 10 秒继续扣分；吃车重新计时。自行车允许总分为 0、−1、−2，低于 −2 才死亡，负分吞吃直接累加。暂停冻结，刹停计时，详见[成长积分与饥饿](docs/design/10-成长与饥饿.md)。

氮气使用连续气量槽，吞吃车辆是唯一补充来源：每辆回气半管，同方向持续侧移超过 0.4 秒时吞吃回气翻倍为一整管；满两管后不保留溢出气量。喷气每秒额外提速 70 km/h，最高速度提高 66%，松开后用 0.35 秒回落，可立即再次喷气；刹车、刹停或刮擦路边时不消耗气量。暂停冻结，泥巴限速及碰撞减速继续生效，详细参数见[横移与氮气](docs/design/09-横移与氮气.md)。

路面稀疏出现坑洞和泥巴沼泽洞：踩坑立即减速 50%、弹跳并偏向邻道，最右侧只往左；踩泥洞立即减速 50%，车身挂泥并将最高速度限制为正常值的 50%，8 秒后清除泥巴并恢复上限。暂停冻结效果计时。

所有同向车道均有后方来车，包括玩家所在车道；开局在后方 120–240 米布置，运行中在后方 120–200 米补车，落后超过 260 米回收。后车巡航目标生成时固定，只为其他系统车和道路约束调整速度，不为玩家刹车；减速后可能被追撞。右侧独立显示接近后车的方向和距离，暂停或结束隐藏。

路上随机出现施工封道：一个同向或对向车道暂时封闭随机 30–100 米，入口与出口有红色 X 路牌及路障，锥桶围出施工区，提前 240 米展示绕行标志。道路宽度保持不变，施工结束后该车道恢复通行；驶入封闭区会结束游戏，系统车提前减速并道，无空隙时停在路障前。

随机出现 1–2 个同向车道排队缓行，每队 3–7 辆，车尾到下一辆车头的净距约 2.5–4 米，同队以随机 10–30 km/h 目标速度缓慢行驶，遇到前车或道路约束仍会进一步减速。车队亮双闪并保持队形，不主动随机换道或相互超车；普通车辆仍可超车。双车道道路最多安排一队、三车道最多两队，留出同向通路；车队避开施工和道路切换区域，暂停冻结，新局重新生成。

平坦地面道路低概率出现一队 5–7 头奶牛横穿，避开高架、坡道和河谷，结构两端保留 20 米缓冲。自行车、三轮车接触立即死亡，氮气不免疫；小汽车及以上每头接触扣当前车型低一级价值，按剩余总积分决定降级与两秒保护。

本局曾达到坦克或运行超过 75 秒后，道路左右外围每 120 米出现一组固定防御建筑，两侧独立等概率选择碉堡（火箭炮，4 秒间隔）或塔楼（子弹，6 秒间隔）。前方 260 米内建筑按玩家车型的原有概率开火，车辆均不再攻击。射弹按车型消耗独立防御，耗尽降级并保护两秒，详见[射击与防御](docs/design/08-射击与防御.md)。

五级车型使用第 2 版存档规则，仅检测到本游戏第 1 版排行榜缓存时清空一次，不保留或迁移旧成绩；第 2 版成绩刷新后继续保留。

成绩使用当前浏览器的 `localStorage`，只保存已结算的局，不恢复进行中的局。存储不可用时仍能游玩；异常提示出现后，可在待机或结算页确认重置本游戏记录。

## 项目入口

- [设计总览与专题](docs/README.md)：最终玩法约定及分专题设计。
- [实现说明](docs/implementation/README.md)：模块职责、运行方式与数值入口。
- `src/main.js`：入口、显示循环和每秒 120 次的逻辑更新。
- `src/config.js`：车型尺寸、NPC 巡航速度、玩家速度上限与操控参数。

游戏资源在本机加载，无 CDN、在线账号或服务器成绩。当前版本面向带键盘的桌面浏览器。

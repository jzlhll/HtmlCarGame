# 英语空战 · LETTER WING

使用原生 JavaScript ES Modules + Three.js 的英语拼写空战游戏。驾驶底部飞机左右移动，按字母键发射点阵颗粒，补全咬题怪兽与怪兽身上的单词。桌面首关随机选择空战或四轮组装飞机／航母碎片，之后严格交替（两轮碎片组装、两轮护航编队，每轮九词、一分三十秒，各最多验证三次）。手机及主指针为触屏的设备也逐关交替；对应空战的关卡改为点选挑战，无需输入字母；仅缩窄桌面窗口不切换模式。空战小六 4 分 30 秒，初中／四级／六级各递增 15 秒，普通题按 70% 拼写、15% 双向释义选择、15% 挖空选择分配；大 Boss 全对后改为五秒自由拾箱。先预习本关词卡，再进行战斗，最后回顾错题，再进入简洁的通关弹窗。首页随机展示 airplane、planet、galaxy 的挖空词形，十字标题“以单词为帆，向星海启航”位于中央账号／开局区上方，品牌及图标固定左上角，移除 SECTOR 标识，首页保留鼠标箭头、按钮保留手形，文字不显示插入光标，首页场景无矩形外框，延伸至页面顶部，学习记录、词库说明和玩法介绍集中在顶部中央。

## 本机运行

```bash
npm ci
PORT=5186 npm start
```

通过 HTTP 打开 `http://localhost:5186`，默认端口 5173，可通过 `PORT` 指定独立端口。JavaScript 无需编译；Three.js 随依赖提供。`npm run prepare:pages` 只整理静态包到忽略目录 `.pages-output`，不会自动发布。

| 操作 | 行为 |
| --- | --- |
| ← / → | 飞机横移；预习时切换词卡；大 Boss 全对后配合 ↑ / ↓ 自由拾箱 |
| A–Z | 拼写题按字母连射；选择题按任意字母射击并横移瞄准选项 |
| 1–4 | 选择当前目标的前四个缺字格之一 |
| Shift | 单发弧线跟踪弹，自动锁定红色小怪；无目标不发射、不耗弹 |
| 退格键 / 反引号（1 左边） | 从末尾删除自填字母 / 发射撤销弹 |
| 空格 / Esc | 开始或暂停、继续，按当前界面执行 |

整个单词飞机都能接弹，无需对准单个缺字；弹道未被遮挡时可以打后面的飞机。未完成的字母换键会清空重填。元音与辅音均可随机挖空，至少两个字母；四个及以上字母的单词最多挖词长的一半，向下取整，二至三个字母的短词也挖两个。补满后验证 0.5 秒，正确闪绿 1 秒、奖励 2 枚战斗炮弹，错误变红色小怪。

每关固定 12 个词，桌面空战与碎片关交替、手机点选关与碎片关交替，同模式难度不随关号增加；空战四词库时长为 270／285／300／315 秒，本关词池用完后才重复。普通飞机按缩放后的间隔尝试生成，小六约 8.33–11.67 秒。小 Boss 在普通出题预算一半时出现，大 Boss 在结束前 60 秒出现，各限时一分钟；Boss 期间保留已有普通飞机，只停止生成新飞机；不显示面数提示。普通咬题怪兽和选择题八爪鱼答对均爆两个幸运箱，先在击败位置随机慢晃两秒，再按到右上角对应收藏栏的距离飞入；近处更快、远处更久，约两秒为参考，抵达才增加数量。无需飞机碰触；暂停及失焦冻结慢晃与飞行。周期幸运箱每两分钟刷新一个，碰触后随机收藏红心、星星、炮弹，飞入右上角计数，收藏暂不影响战斗资源。全部面答对击败小／大 Boss，分别爆 3／5 个幸运箱；大 Boss 全对后清除敌对单位及子弹，保留箱子，顶部切为完整五秒倒数，使用 ↑ ↓ ← → 自由飞行撞箱子后结算。

桌面普通题每二十题混排十四道拼写、三道释义选择、三道挖空选择。挖空选择按易混字母组临时生成，如 au／ou、ie／ei、ious／ous、th／ch、c／s 和双写，题面只挖一个片段，横线数量对应实际缺失字母数，配三个候选。选择题的八爪鱼显示“英文＋三个中文释义”或“中文＋三个英文单词”，只有一个正确答案；按住任意字母，横移瞄准题面左／中／右三分之一，选项随命中逐渐透明，默认累计 20 发后停下验证。选对爆两个幸运箱并获原有分数及战斗炮弹，选错变两架红色小怪。命中阈值可在 `CHOICES.hitsToSelect` 调整。

按住字母即可攒满当前格，点阵立即切为紫色待定真字母并锁定该飞机输入 0.75 秒；退格键可删除末尾填写。

取消生命耗尽失败。关卡结束先清空战斗物体与天体，星光背景的回顾页按词合并，直接摆放飞机、航母或小／大 Boss 小模型、当时填写的字母／点阵／选中答案，以及大字正确答案和释义；相同错误写法合并标注次数，不同写法放在同一词下面。回顾不使用卡片，优先一屏展示，内容较多时在星空最右侧滚动，每个不同失败词复习 10 秒；刷新恢复回顾进度，失焦暂停。回顾结束后进入“恭喜通关！”小弹窗，仅保留“重玩本关”和动态的“第 N 关”按钮。成功、写错、没写完仍按每架普通飞机或 Boss 每面独立保存。

## 本地账号与续玩

无密码本地账号直接显示在首页中央，替代预习按钮、时间和关卡信息，没有遮罩。随机新建时可编辑名字，确认保存后不再改名。名称会查重，点击账号后须再次确认登录。首屏直接呈现账号区，准备期间账号操作暂不可用，登录后词库选择和预习按钮等宽对齐。设置按账号保存，学习记录、成绩、关卡进度、复习锁和词池按账号＋词库独立保存。首页开局按钮上方可切换当前账号。启动时清理旧版无账号存档与学习缓存，不生成默认账号；没有账号时直接随机新建。

每关预习前保存 12 个词。未完成时关闭、刷新或切账号，回来继续使用这些词，从本词库及模式的完整时限重新开始；重玩沿用原词，新关重新抽取并保存。词池历史按账号＋词库保留，切回词库恢复其原有十二词与关卡。

## 词库与学习记录

首页登录后可按学习阶段选择“小六 1000 词、初中进阶 2200 词、英语四级 6259 词、英语六级 1718 词”。小学和初中分级参考课标及阶段资料，大学词库依官方2016年大纲分为四级基础与六级进阶，含派生词及合法英美拼法；释义和例子采用固定版本开源语料及项目原创修订。来源、筛选和许可见 [SOURCE.md](third-party/english-vocabulary/SOURCE.md)。不按字母顺序凑数量，不声称覆盖某版教材；游戏拼写数与官方词目计数不同，六级进阶不重复四级基础拼写。

每个词都附英文短语及中文，短语不合适时使用例句。预习标题与关卡信息分行，圆点和页码分两行居中；上一个、朗读、下一个在词卡下方共用一行。预习展示短语与例句；过关回顾集中展示当时的错误作答、规范拼写和释义。保留 Chinese、English、Earth、USA 等规范大小写。

局末把每次成功、写错、没写完分别存入浏览器 IndexedDB；同词多次出现保留多条明细。学习记录每页 100 词，按总失败次数降序，可查看明细和点击朗读。顶部重置须二次确认，只清空当前账号当前词库的学习统计及作答明细，保留账号、词池、成绩、关卡和设置。历史正确率严格高于 50%／75%／85% 时，下局入选权重分别为 0.5／0.25／0.01，只取最高档。本关已选词仍用完再重复。

朗读按需使用浏览器英语语音，优先清晰自然的声音，排除特效人声，不生成音频文件。语音取决于系统可用声音；缺少英语语音时界面会提示。

## 实现与资源

- 数值集中在 [src/config.js](src/config.js)，游戏逻辑与渲染分离。
- Three.js 提前预加载，场景模块导入与资源准备并行；星空／飞机、Boss、箱子位图三条链同时恢复或生成。
- 模型、纹理由 Worker 在开局前生成、校验、持久缓存并预热，进入游玩前停止 Worker。地球有蓝色海洋、大陆、云层和大气光晕；九种星球、月球、太阳、银河及北斗七星、射手座、猎户座、仙后座、天蝎座连线图共十七种背景，每 15 秒随机出场一个，每轮全部用完才重复，持续轮换。背景蒙版保证前景可读。
- 小／大 Boss 为可爱的紫色恶魔：双角四触手与四角头冠、蝙蝠翼五触手两套造型，保留大眼睛、坏笑和小虎牙；模型在开局前独立生成、缓存和预热。
- 箱子沿用原图案与阴影，在准备期预绘并缓存；飞机使用专用 24×12 索引球体，敌机按原材质合批并保留索引，星球保留 48×24 细分。页脚提供高／标准／省电画质，默认高画质，三档均有像素预算；菜单最高 60／30 帧，覆盖弹窗、暂停和结算按需绘制，无 Worker 时按行分批生成。历史作答明细每页 100 条；性能对比见 [验收记录](docs/implementation/english-air-combat-validation.md)。
- 设置、成绩、学习记录、复习进度与生成缓存使用独立 `english-air-combat` 命名空间；学习记录再按账号与词库隔离，保留其他游戏的数据。存储失败明确提示，待入库批次在下次打开时按局重试。
- `?seed=42&debug=1&testAccount=TEST01` 使用 TEST01–TEST09 独立持久调试账号，默认 TEST01；普通用户不能创建或改为这些保留名称。测试数据与普通账号隔离，提供只读快照 `window.__airCombat.snapshot()`。

## 手机网页

两端首关各有 50% 概率选择一种模式，起始结果共用并逐关交替；手机对应空战时使用点选挑战，普通题和 Boss 都无需打字，释义与挖空选择各占一半，奖励自动收藏；碎片关支持牵引残片、装载释义机库和规划战机护航航线，起始结果按账号与词库保存，刷新和重玩不重抽。设备类型依据主指针的 `pointer: coarse`，在进入本关预习时确定本局模式，旋转屏幕或游玩中切换指针不改当前局。触屏界面使用安全区域与动态视口高度，放大点击区域；内容可滚动，提交和预习开始按钮保持可达。残片采用金属刻面和铆钉，释义显示为机库或航标；护航路径有缓慢转动的陨石，文字和按钮固定，暂停及减少动态时停下。手机游玩时收起导航与设置栏，保留回收／护航的简短操作提示，释义竖屏三行、横屏居左，碎片独立滚动；暂停入口与底部提交保持可达。设置在暂停时可用。切后台自动暂停，回来后点击继续。

开发预览可用 `?debug=1&testAccount=TEST08&touch=1` 在桌面浏览器检查触屏分支，调试覆盖仅在 debug 模式生效；实际手机自动识别，无需参数。手机与桌面沿用同一账号、词池、学习和关卡进度。

## 网站接入

英语空战由 `jzlhll/jzlhll.github.io` 的固定版本清单统一打包，访问路径为 `/games/english/`，四季车途为 `/games/cargame/`。本分支工作流只上传静态包，不向 `/HtmlCarGame/` 部署，避免覆盖已上线的赛车。更新英语游戏后，在博客仓库的 `games.json` 中更新完整提交号，再按博客正式 Release 流程发布。普通 commit、push 和本机打包不自动创建 Release。

## 空战怪兽题面

普通题由上下颚咬住题面的怪兽承载，翻译三选一由八爪鱼的三根粗触手分别卷住选项，瞄准时选项、触手与题目同时高亮。题面保留现有字号，按内容增高；空战中文释义随机显示最多两个分号义项，每题生成后固定，预习、学习记录和错题复习保留完整词义。红色小怪替代原错题敌机，玩家仍驾驶飞机。

回收关支持拖动牵引链按顺序收集残片、投放释义机库；护航关从单词战机拖向释义航标，调整航线光点绕过旋转陨石后统一出击。保留点选、四轮九词和三次验证，避障不会记作英语答错。Boss保留原造型，逐面变化眉眼和嘴型，后期增加轻微紫红外光。

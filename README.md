# 四季车途

基于 Three.js 的本机浏览器赛车游戏。自行车、三轮车、小汽车、卡车、加长卡车、坦克六级车型、侧碰吞吃与升级、双向交通、带上下坡的四／六车道循环道路、四季场景和本机成绩记录。沿途稀疏出现楼房、农场、牧场、奶牛与湖泊。三轮车适用于玩家和路上交通；路上的小汽车随机采用小汽车或拖拉机外观，两者规则相同。

## 开始游玩

需要 Node.js 18 或更高版本。项目首次安装依赖后，运行游戏不需要联网。

```bash
npm ci
npm start
```

浏览器打开 **http://localhost:5173**。本项目已经安装好依赖，本机直接 `npm start` 即可；macOS 也可以双击根目录的 `启动游戏.command`。

保持启动窗口开启，结束服务时按 `Ctrl+C`。始终使用同一个地址，避免浏览器把不同来源的成绩分开保存。

| 操作 | 行为 |
| --- | --- |
| 空格 | 开始、暂停、继续；结算时开始新一局 |
| ← / → | 按住横移，自动跟随道路弯曲 |
| ↓ | 按住刹车，松开后自动缓慢提速至车型上限 |
| 暂停窗口“结束游戏” | 主动结束并保存成绩 |

首次侧面接触时，我方车头超过对方车头，或位于对方车身后半段，即按侧碰吞吃同级或低级车；其余接触按追尾处理。吞吃自行车、三轮车、小汽车、卡车、加长卡车、坦克分别获得 1、2、6、18、54、216 积分；升级门槛采用下一车型积分值，达到 2、6、18、54、216 分依次升级，扣除门槛并保留余分。界面显示当前积分与本级门槛，排行榜仍按行驶距离计分。追尾同级／高级车、侧碰高级车会损毁；同向与对向车道采用相同碰撞和吞吃规则。

路面稀疏出现坑洞和泥巴沼泽洞：踩坑立即减速 50%、弹跳并偏向邻道，最右侧只往左；踩泥洞立即减速 50%，车身挂泥并将最高速度限制为正常值的 50%，8 秒后清除泥巴并恢复上限。暂停冻结效果计时。

成绩使用当前浏览器的 `localStorage`，只保存已结算的局，不恢复进行中的局。存储不可用时仍能游玩；异常提示出现后，可在待机或结算页确认重置本游戏记录。

## 项目入口

- [设计总览与专题](docs/README.md)：最终玩法约定及分专题设计。
- [实现说明](docs/implementation/README.md)：模块职责、运行方式与数值入口。
- `src/main.js`：入口、显示循环和每秒 120 次的逻辑更新。
- `src/config.js`：车型尺寸、NPC 巡航速度、玩家速度上限与操控参数。

游戏资源在本机加载，无 CDN、在线账号或服务器成绩。当前版本面向带键盘的桌面浏览器。

# 云端驾驶舱

面向桌面浏览器的单人民航客机模拟游戏，采用 Three.js 与原生 JavaScript。玩家先观看跑道、飞机与机场的外部镜头，在 `4、3、2、1` 倒数中进入驾驶舱，再完成七步启动、起飞、三关航线与机场、着陆和驶入停机圈。

游戏的重要目标是让使用者在操作飞机的过程中，逐步熟悉键盘字母按键的位置。每个动作结合英文助记词、中文含义和清晰键帽提示，通过真实操作反馈建立“动作—字母—键位”的联系；后续还会规划逗号、句号、分号等标点键练习。

视觉采用低多边形场景、半透明深色面板、暖金色重点和中英文文字层级。飞行时使用第一人称视角，下方约四分之一屏幕用于驾驶舱仪表与操纵区，完整前窗由四周边框围合，中央无遮挡，呈现连续的外部世界。

## 当前状态

当前分支为 `codex/flight-simulator`，已实现深圳起飞的三个逐段延长关卡。开场可选关，并显示计划路线与地面海拔剖面；每关都从深圳重新准备起飞，后关共用前段地景，只保留当前目的地机场。成功后可进入下一关。

| 关卡 | 航线与新增景观 | 总时限 | 建议巡航 | 终点地面海拔 |
| --- | --- | --- | --- | --- |
| 1 | 深圳 → 广州：近山、河流、田野、现有城市与地标 | 3:20 | 200 kt | 300 m |
| 2 | 深圳 → 长沙：保留前段，延伸丹霞山、张家界石柱／空中瀑布、橘子洲石像 | 3:45 | 225 kt | 650 m |
| 3 | 深圳 → 武汉：再延伸宽阔洞庭湖、高耸黄鹤楼 | 4:15 | 245 kt | 1000 m |

海拔从深圳沿途逐渐增加，江心岛和湖区保留平坦水面，不是把整关统一抬高。R首次放行后计时，包含滑跑、飞行、着陆和停机；目标圈内停妥1秒才成功，暂停冻结时限。空格暂停／继续，失焦自动暂停，重开返回同关深圳起点。
L、D、H、A、W 可任意顺序准备：舱门 D 关闭（Closed），减速板 W 关闭（OFF），其余三项开启（ON）；随后 F 点火，约 3 秒后 R 松刹车。按 T 提速，持续约 **20 秒**达到 **145 kt** 后 ↑ 平滑抬轮；S 减速。W 关闭时提速快、减速慢，打开时提速慢、减速快，各方向的开关档位相差 **10 倍**。离地后 G 收轮，W 保持关闭；进近先 W 打开减速板、S 减速至 160–180 kt，再 G 放轮、对准跑道轻柔接地，S 减速驶入金色停机圈。发动机动力自动调节，角度、升阻力、重力与失速继续参与计算。右上保留姿态卡片，离地 **200 米内**另显示实际机轮与地面的脚部视角，超过 200 米隐藏，下降后恢复。

入舱中央说明只显示一次，首次按键后本局隐藏。静止时可撤销准备、熄火或重新驻车；运动中 D、H、R 禁止操作，L、A、F 不会自动拉驻车。飞行按固定质量计算推力、升力、阻力与重力，区分俯仰角、航迹角和迎角；过度抬头、危险下降、低速、超速和失速均有提示。失速可以通过正确操纵恢复，持续下坠撞地才结束。此模型用于游戏学习，尚未模拟完整刚体力矩和真实机型性能。左上航线图持续记录真实方向与轨迹，目的地标为五角星，下方雷达预告大雁与不同方向的飞机。沿途在山谷、河流、田野、城市和区域地标间连续变化，第三关湖面飞越约40秒；碰山、碰楼或碰撞交通目标会失败，安全飞越河流瀑布或穿越空中水幕有恭喜提示，每道每局一次。海拔超过 10000 米触发动力故障和安全警报，侧方最高山峰为虚构的 12000 米。已接入倒数、开关／舱门锁扣、发动机启动与推力、风声、轮胎滑跑／刹车、收放电机与安全警报；音效及播报默认开启，点击开始后解锁播放，暂停和结算静音。设备有本地英文语音时播报 Light、Fire 等短句，具体音色随设备而异，尚未验收统一女声效果；云层与天气未实现。完整规则见[三关航线与机场](docs/design/07-航线与关卡.md)。

## 操作与规划

| 操作 | 行为 |
| --- | --- |
| 空格 | 开始；过程中暂停或继续 |
| L / D / H / A / W | 任意顺序准备；L／H／A 开启，D 关闭锁定，W 关闭减速板 |
| F → R | 五项就绪后 F 点火；发动机就绪且停稳后 R 放行 |
| T / S | 点按短促施力提速／减速，按住持续变速，S 优先；松开后自动动力补偿正常配平阻力 |
| ← / → | 地面修正方向；空中协调转弯 |
| ↑ / ↓ | 抬头／低头，通过姿态与速度改变爬升或下降 |
| G | 离地至少 30 米且正爬升后收起落架；已收起时不高于 220 kt 可放下 |
| W | 起飞必须关闭、着陆必须打开；关闭时提速快减速慢，打开时提速慢减速快，两个档位相差十倍 |

`T` 取自 Thrust，`S` 取自 Slow，`W` 用 Wing brake 助记，表示游戏化的机翼减速板。抬轮速度暂定 **145 kt，约 269 km/h**，属于固定游戏预设，不能用于真实机型操作。

字母按键不区分大小写，支持 Shift 与 Caps Lock；尽量采用动作英文名称的首字母，避免重复占用；标点键作为后续观察类操作规划，按物理键位识别，不依赖输入法输出中文还是英文标点。学习方式与标点键初案见[游戏流程与操作](docs/design/01-游戏流程与操作.md#键位学习与标点键规划)。

## 本机开发

需要 Node.js 18 或更高版本。缺少依赖时安装锁定版本：

```bash
npm ci
npm start
```

通过浏览器打开 [http://localhost:5186](http://localhost:5186)，不直接打开 HTML。端口已占用时可用 `PORT=5187 npm start`。无编译或打包步骤，Three.js 从本机依赖目录加载。

启动后显示外部机场场景，可观看四秒开场后进入驾驶舱完成起飞与目的地航程。macOS 也可使用根目录启动脚本，当前没有飞行游戏发布地址。

山体与森林在进入关卡时由浏览器生成，采用固定种子、共享岩纹和远近细节切换；重开复用场景。总准备预算12秒，整套发布资源上限50 MB，生成模型不提交Git；当前无需模型编译或额外素材包。具体策略见[山体与森林表现](docs/design/04-天空环境规划.md#山体与森林表现)。

Min speed显示随海拔、减速板和坡度变化的平飞安全参考；低速会因升力不足下沉，过度拉升会减速／失速，俯冲会加速掉高度。S不再抹去垂直动量。左右转向通过更快滚转与最大60°坡度实现。雁群使用17只立体V阵和更清楚的实体轮廓，其他飞机为2倍模型，碰撞范围同步；窗外类型／距离标记和雷达共同辅助辨认。首次雁群从离地后6秒开始安排，后续交通需要主动避让。

# 低空穿越

面向桌面浏览器的单人民航客机模拟游戏，采用 Three.js 与原生 JavaScript。玩家先观看跑道、飞机与机场的外部镜头，在 `4、3、2、1` 倒数中进入驾驶舱，再完成六步启动、起飞、四关航线与机场、着陆并在跑道内停稳。

游戏的重要目标是让使用者在操作飞机的过程中，逐步熟悉键盘字母按键的位置。每个动作结合英文助记词、中文含义和清晰键帽提示，通过真实操作反馈建立“动作—字母—键位”的联系；后续还会规划逗号、句号、分号等标点键练习。

视觉采用低多边形场景、半透明深色面板、暖金色重点和中英文文字层级。飞行时使用第一人称视角，下方约四分之一屏幕用于驾驶舱仪表与操纵区，完整前窗由四周边框围合，中央无遮挡，呈现连续的外部世界。

L、D、H、A可任意顺序准备：D关闭，其余三项开启，W默认Closed；E点火约1.5秒后R松刹车。主动提速上限为600 km/h，首次鸟击后为480 km/h；顺风可超过此值，结束后按阻力自然降速。W关闭时按T从静止约13.0秒达到250 km/h，再↑平滑抬轮，离地后G收轮。T／S每次点按累计10 km/h主动变速额度，同向累计，反向取消，按住持续变速；W即时切换，关闭只允许T，打开只允许S。切换W清空旧额度，不在切回后自动续跑。起飞前地面T主动提速为原慢档基准18倍，约6.714 m/s²（24.169 km/h每秒）；空中T主动提速为原慢档15倍，约5.595 m/s²（20.141 km/h每秒），扣除自然降速后净增约15.141 km/h每秒；S主动减速保持10倍，即6 m/s²（21.6 km/h每秒）。接地后T／S仍使用10倍，W位置不参与速率插值；提速仍受发动机、驻车、鸟击故障门控。飞机始终自然降速：W关闭每秒减速5 km/h，打开时再加10、合计每秒减速15 km/h；与T／S主动变速独立叠加，不消耗点按额度，速度最低为0。姿态与下落不被换算成被动提速。 进近将速度降至60–180 km/h，放下Gear（起落架），俯仰保持±3°并在跑道内接地；Wing brake仅用于减速，不是接地条件，在跑道内停妥1秒。目的地有4架飞机与8辆卡车；撞卡车扣速10%并撞飞，撞其他飞机爆炸失败。

入舱中央说明只显示一次，首次按键后本局隐藏。运动中D、H、R禁止操作，L、A、E不会自动驻车。飞行采用游戏化前进速度与垂直运动。姿态限速跟随用户输入，↑／↓点按0.2°、长按重复1.2°，机体以3°/s平滑跟随，松开上下键后清除积压目标，仅保留最多0.2°收尾、约0.07秒停止，失速不削弱俯仰或滚转，不按迎角自动低头／抬头。空中低于150 km/h进入失速，达到165 km/h解除，150–165之间维持原状态；仅将垂直航迹限制为低速下沉，机头角度、前进速度和左右操纵不受失速影响。下沉目标为`7.5 + 52.5 × clamp(1 − speed/150, 0, 1)`米/秒，最大60米/秒；该上限指失速造成的低速下沉，玩家主动俯冲仍可更快下降。解除后连续恢复用户姿态对应的垂直运动，不跳变高度。 左侧航图记录真实轨迹，目的地为五角星；雷达与窗外标记辅助辨认交通。碰山、碰楼或其他飞机会失败；每道瀑布独立奖励一次。合成音效与Samantha英文女声播报默认开启，暂停和结算静音；已接入云层、能见度、雷达干扰与雷击故障。启动页可勾选调试停机，以400 km/h、起落架收起、W关闭，在当前目的地前约30秒航程接管；3／2／1倒数后正常操纵。完整规则见[航程专题](docs/design/07-航线与关卡.md)。

## 操作与规划

| 操作 | 行为 |
| --- | --- |
| 空格 | 开始；过程中暂停或继续 |
| L / D / H / A / W | 任意顺序准备；L／H／A 开启，D 关闭锁定，W 关闭减速板 |
| E → R | 四项就绪后 E 点火；发动机就绪且停稳后 R 放行 |
| T / S | 点按累计±10 km/h主动额度逐步执行；W关闭只允许T，打开只允许S，起步T为原慢档18倍，空中T为15倍、S为10倍 |
| ← / → | 地面修正方向；空中协调转弯 |
| ↑ / ↓ | 抬头／低头，通过姿态与速度改变爬升或下降 |
| G | 离地至少 30 米且正爬升后收起落架；已收起时不高于 407 km/h 可放下 |
| W | 起飞必须关闭、接地时开关均可；关闭只允许T提速，打开只允许S减速，即时开关，关闭每秒减速5 km/h，打开每秒减速15 km/h |

`T` 取自 Thrust，`S` 取自 Slow，`W` 用 Wing brake 助记，表示游戏化的机翼减速板。抬轮速度暂定 **250 km/h**，属于固定游戏预设，不能用于真实机型操作。

字母按键不区分大小写，支持 Shift 与 Caps Lock；尽量采用动作英文名称的首字母，避免重复占用；标点键作为后续观察类操作规划，按物理键位识别，不依赖输入法输出中文还是英文标点。学习方式与标点键初案见[游戏流程与操作](docs/design/01-游戏流程与操作.md#键位学习与标点键规划)。

## 本机开发

需要 Node.js 18 或更高版本。缺少依赖时安装锁定版本：

```bash
npm ci
npm start
```

开发调试使用 `npm start`，按当前工作目录自动选择5200–6199中的稳定端口；以终端打印的实际地址为准，不直接打开 HTML。不同worktree分别分配，端口占用时在开发范围内自动换空闲端口。需要固定端口时仍可使用 `PORT=5187 npm start`，显式指定的端口被占用会报错，不自动跳转。程序代码无需编译或打包，固定模型和像素在启动服务前预生成；Three.js 从本机依赖目录加载。

游玩使用 `npm run play`，macOS 双击根目录的 `启动游戏.command` 会使用同一游玩模式并自动打开浏览器。游玩优先使用 [http://localhost:5186](http://localhost:5186)，占用时在5186–5199中自动选择空闲端口，与开发默认范围分开；不会停止已有服务。启动后显示外部机场场景，可观看四秒开场后进入驾驶舱完成起飞与目的地航程，当前没有飞行游戏发布地址。端口隔离不隔离同一目录的源文件，游玩期间若刷新页面，会重新读取该目录的最新代码。

固定模型、山体属性、树木、云、田园、路网、水体和精细纹理在启动服务或发布前预生成，采用固定种子与内容去重；浏览器恢复共享数值并准备GPU对象，完整准备目标4秒；山体按远近切换细节，树木在视野内始终保持同一完整形态，通过空间分块和视锥裁剪控制开销；重开复用场景。开局至可操控预算8秒，整套发布资源上限50 MB，生成模型不提交Git；当前无需模型编译或额外素材包。具体策略见[山体与森林表现](docs/design/04-天空环境规划.md#山体与森林表现)。

左右转向通过滚转与最大60°坡度实现；空中转弯角速度同步4倍水平位移，最大45°/s。水平飞行满坡度时，400／600 km/h的转弯半径约0.73／1.63公里。雁群使用17只立体V阵，其他飞机为2倍模型，碰撞同源；窗外与飞机图显示相对高度差，雷达显示直线距离。首次雁群从离地后6秒开始安排，交通需要主动避让。

广州、长沙和外围城区采用三级井字格道路，360米主干道连接96米副路与36米街区小路，包含中央隔离带、车道线与斑马线；路面独立划分路口，细标线随距离过滤。城市中有静态轿车和巴士，实例分区裁剪并与碰撞位置一致；布局和缓冲在准备阶段生成、持久保存，飞行时不追加生成。

云层沿航路间隔分布：75%静止白云、25%以最高100 km/h、约15秒完整往返的乌云，每片横向宽约2.8公里、沿航路长4公里、厚5376显示米（实际1075.2米），沿航路约14.5公里一朵，横向错落分布。全部白云、乌云与稀薄云均在各自高度带内随机分布；普通云中心6800–8500显示米，约10%的稀薄云中心4800–6500显示米。云朵采用饱满的连续外壳，不叠加透明球体；乌云横向移动以保持前后间隔。白云内雷达失效、视距显著缩短，乌云内雷达正常、视距减半。乌云闪电低概率命中后，本关T失效，播放3秒变调警报，并在仪表旁持续显示雷击故障；可继续调整姿态、转弯和减速，重开或下一关恢复。云模型与雷击特效开局准备并缓存，游玩中不生成。

白云视距按正常视距10%保底，浓白云约2.67公里、稀薄白云4公里；按600 km/h及4倍水平位移，前方至少2秒的物体仍可辨认，雷达失效规则保留。加宽的360米主干道与相邻小路之间保留12米净空，交叉路口按同源宽度重新裁切。

机场采用米字跑道：深圳四条各4500×60米，目的地四条各9000×240米；任一跑道内满足原接地条件均可着陆，跑道内停稳即可成功。交叉口为单层铺面并过滤远景标线，删除机场黑色滑行连接带。沿江高速宽160米，超过四个翼展，绕开扩大的深圳机场平台。

树木接触不会直接撞毁飞机：每次轻微减速5%并增加玻璃损伤5%，大雁增加20%；树／鸟各自按3秒合并计次。左上角橙黄色百分比显示累计损伤，达到100%玻璃完全破碎后失败。树林高度按连续区域曲线缓慢起伏，常见树高缩为80%，极少数高树仍可达10000显示米；高山树身最高1200显示米，机场行道树同样缩矮20%并保留净空。

植被采用杨树、榕树、柳树、松树、银杏及灌木六种轮廓，榕树带垂根与落地拱枝。张家界采用宽体黄岩峰林，红色丹霞保留薄片形态；乌云约15秒左右往返。视野内始终使用带叶脉、细枝和空隙的完整树形，远端仅平滑淡出，不替换为低面树冠；树木原型、叶片图集与实例布局在准备期生成并持久缓存。

橘子洲位于曲折湘江中，长沙城区分布两岸；洞庭湖加入湾汊、半岛和沙洲。空中每70秒有一次气流：普通顺逆／左右风12秒，15%概率乱流10秒，可操纵抵消约一半扰动。城市及两端机场横风影响为原来的10%，真实树林上方为1.2倍，城市／机场优先；其他气流不变。城市设计净空650米，张家界、丹霞及景点中的穿行通道同步加宽30%。


模型资源由 `npm start`、`npm run play` 和 `启动游戏.command` 自动在打开页面前检查并生成；也可执行 `npm run prepare:assets`。首次构建在终端完成，生成文件位于已忽略的 `assets/generated/`，不提交Git。Pages整理执行相同构建并校验整套发布目录小于50 MB；程序代码仍使用原生ES Modules，无需打包。全模型盘点、缓存与性能边界见[模型资源与预算](docs/implementation/model-assets.md)。

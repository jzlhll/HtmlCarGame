# 云端驾驶舱

面向桌面浏览器的单人民航客机模拟游戏，采用 Three.js 与原生 JavaScript。玩家先观看跑道、飞机与机场的外部镜头，在 `4、3、2、1` 倒数中进入驾驶舱，再完成七步启动、跑道滑跑与离地爬升。

游戏的重要目标是让使用者在操作飞机的过程中，逐步熟悉键盘字母按键的位置。每个动作结合英文助记词、中文含义和清晰键帽提示，通过真实操作反馈建立“动作—字母—键位”的联系；后续还会规划逗号、句号、分号等标点键练习。

视觉采用低多边形场景、半透明深色面板、暖金色重点和中英文文字层级。飞行时使用第一人称视角，下方约四分之一屏幕用于驾驶舱仪表与操纵区，两扇前窗共同呈现连续的外部世界。

## 当前状态

当前分支为 `codex/flight-simulator`，已实现从外部开场到起飞、初始爬升与结果页的完整流程。四秒倒数进入双窗驾驶舱，底部七项准备完成后按 R 松刹车，清单切换为跑道起飞；离地后自动切换为爬升操作。空格暂停／继续，页面失焦自动暂停，可在暂停窗口或结果页重新开始。

L、D、H、A、W 可任意顺序切换 OFF／ON；五项就绪后 F 点火，约 3 秒后发动机达到怠速。T 加油门，约 **20 秒**达到 **145 kt**，再用 ↑ 平滑抬轮。离地后 G 收轮、W 收襟翼，达到 500 米并持续满足稳定爬升条件后成功。仪表实时显示空速、高度、姿态、航向、垂直速度和油门；支持跑道越界、冲出末端及撞地失败与重开。窗外已加入河流、楼群、广州塔、深圳春笋等风格化地标和远山；右上角机外姿态卡片同步显示飞机的俯仰、坡度、起落架和襟翼。

入舱中央说明只显示一次，首次按键后本局隐藏。静止零油门时可撤销准备、熄火或重新驻车；运动中 D、H、R 禁止操作，L、A、F 不会自动拉驻车。飞行按固定质量计算推力、升力、阻力与重力，区分俯仰角、航迹角和迎角；过度抬头、危险下降、低速、超速和失速均有提示。失速可以通过正确操纵恢复，持续下坠撞地才结束。此模型用于游戏学习，尚未模拟完整刚体力矩和真实机型性能。声音、天空巡航和天气尚未实现。

## 操作与规划

| 操作 | 行为 |
| --- | --- |
| 空格 | 开始；过程中暂停或继续 |
| L / D / H / A / W | 任意顺序完成灯光、舱门、安全带、飞行仪表和起飞襟翼，完成项显示 ON |
| F → R | 五项准备就绪后 F 点火；发动机就绪且油门为零后 R 松刹车 |
| T / S | 点按调节 5%，按住连续增减；地面收至怠速后继续按 S 使用轮刹 |
| ← / → | 地面修正方向；空中协调转弯 |
| ↑ / ↓ | 抬头／低头，通过姿态与速度改变爬升或下降 |
| G | 离地至少 30 米且正爬升后收起落架 |
| W | 离地至少 200 米且达到 180 kt 后收起襟翼 |

`T` 取自 Throttle，`S` 取自 Slow；`W` 用 Wing flaps 助记，实际操纵的是襟翼。抬轮速度暂定 **145 kt，约 269 km/h**，属于游戏初始调参值，真实起飞速度的含义和限制见[飞机与起飞](docs/design/02-飞机与起飞.md)。

字母按键不区分大小写，支持 Shift 与 Caps Lock；尽量采用动作英文名称的首字母，避免重复占用；标点键作为后续观察类操作规划，按物理键位识别，不依赖输入法输出中文还是英文标点。学习方式与标点键初案见[游戏流程与操作](docs/design/01-游戏流程与操作.md#键位学习与标点键规划)。

## 本机开发

需要 Node.js 18 或更高版本。缺少依赖时安装锁定版本：

```bash
npm ci
npm start
```

通过浏览器打开 [http://localhost:5186](http://localhost:5186)，不直接打开 HTML。端口已占用时可用 `PORT=5187 npm start`。无编译或打包步骤，Three.js 从本机依赖目录加载。

启动后显示外部机场场景，可观看四秒开场后进入驾驶舱完成起飞与初始爬升。macOS 也可使用根目录启动脚本，当前没有飞行游戏发布地址。

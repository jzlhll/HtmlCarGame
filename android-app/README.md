# 学习航站 · Android

Kotlin + Android WebView 的离线游戏合集，提供英语空战、四季车途、低空穿越三个入口。首页按平板竖屏设计，横屏沿用可滚动布局；不改变三个网页工程独立开发和启动方式。

## 运行与编译

使用 Android Studio 打开本目录，需要 JDK 17、Android SDK 36 与 Node.js 22 或更新版本。当前使用 AGP 8.13.2、Gradle 8.14.4、Kotlin 2.2.21，最低 Android 9（API 28）；设备还需支持 WebGL 2 和 Android WebView 的受限来源消息接口。

本机安装调试包的入口：

```bash
cd android-app
./gradlew assembleDebug
```

输出为 `app/build/outputs/apk/debug/app-debug.apk`。发布时由使用者配置签名后使用相应 release 任务；仓库不保存签名文件、密码或本机 SDK 路径。

`assemble`／`bundle`／`merge*Assets` 在整理 Android 资源前自动执行 `prepareGames`：

1. 校验三个网页工程的包版本、锁文件、依赖；缺依赖或锁文件不匹配时自动 `npm ci`。
2. 使用低空穿越现有生成器准备固定模型，赛车及英语空战生成资源指纹；源码与本机功能保持，不套用赛车 Pages 的专用裁剪规则。
3. 将运行源码、必要 Three.js 模块、语音源、源图及词库来源整理到 `app/build/generated/gameAssets/games/`，注入 Android 专用桥接。
4. Gradle 将上述目录作为 assets 集成进 APK／AAB。资源输入或输出发生变化时重新整理，未变化时由 Gradle 复用。

首次依赖下载与飞行资源生成需要额外时间；手机运行不需要 Node.js、开发服务器或网络。Android Studio 若未继承 nvm 的 PATH，可传 `-PgameNodeExecutable=/绝对路径/node`。只核对某个工程的整理可使用：

```bash
node scripts/prepare-games.mjs --game=english-air-combat
```

生成的 Android 包、网页副本、模型和缓存不提交 Git。`gradle-wrapper.jar` 是标准构建工具入口，与游戏生成资源无关。

## 每日学习与游戏额度

| 项目 | 规则 |
| --- | --- |
| 英语目标 | 每天有效学习累计15分钟；一天只解锁一次，达标后仍可继续学习 |
| 有效学习 | 英语正式关卡、单词预习、仍处于锁定倒数的错题复习；账号、设置、普通菜单、结果展示不计 |
| 空闲暂停 | 连续30秒没有新的触摸／按键操作，停止计时并暂停；前30秒属于允许的操作间隔，达到30秒后不再累计 |
| 操作来源 | 原生触摸／按键与可信网页操作核对；按住按键自动连发、动画、定时器及状态心跳不算新操作 |
| 工作日奖励 | 赛车、低空穿越各12分钟，独立余额，不共用也不互借 |
| 周末奖励 | 按设备本地日期，周六、周日各18分钟 |
| 每日重置 | 进入新日期清零学习进度与两个已用额度；不把昨天剩余额度带到今天 |
| 暂停与后台 | 不累计学习或消耗额度；空闲／切后台恢复需点击原生继续，不能仅靠网页自行恢复 |
| 额度耗尽 | 原生暂停蒙层立即拦截游戏，返回首页后也不能重新进入该游戏 |
| 记录范围 | 本机整个应用共用每天的管控账本，切换英语账号、重进游戏或旋转重建不重新发额度 |

计时使用 `SystemClock.elapsedRealtime()`，状态连接中断也停止计时。唯一账本及串行原子写入器由 `GameHubApplication` 持有，每个计时片段保存，读取／写入失败停止开放游戏；不以丢失或损坏的记录自动重发额度。日期回拨会阻止继续；这是本应用内的离线管控，不能阻止系统级清除数据、卸载或人为把日期调到未来，也不会限制其他应用。

## WebView 与原生能力

三个游戏使用各自的 `https://<工程名>.appassets.androidplatform.net` 来源，由 `WebViewAssetLoader` 从 APK assets 提供资源，浏览器存档不会自动迁入 App，各游戏存储互相隔离。只允许当前游戏目录的资源和受信主 frame 的消息；不开放任意网页跳转、文件 URL 或外部脚本桥接。发布版关闭 WebView 调试。

英语朗读优先走 Android `TextToSpeech`；初始化超时、服务失败或缺少英语数据时给当前请求返回错误，再由网页原有朗读尝试回退。暂停、切后台、切游戏取消旧请求，迟到回调不能播进新页面。原生朗读是否可离线取决于系统是否已安装相应英语语音数据。

低空穿越的 Android 副本增加竖屏可折叠触屏控制，复用正式游戏命令及按住状态；普通网页仍保留原键盘方式。原生容器同一时间只持有一个 WebView，返回首页释放上个游戏。

## 文件职责与验证边界

- `app/src/main/java/com/allan/gamehub/`：每日规则、持久化、竖屏入口、WebView 及原生朗读。
- `scripts/prepare-games.mjs`：三工程离线整理；`scripts/integrate-game.mjs`：仅向打包副本注入适配。
- `web/`：状态心跳、可信操作、原生暂停与朗读桥接，以及飞行触屏布局。

本次一次性资源整理的三个游戏约54.95 MB，原网页源码保持不变；204个模块及其本地依赖已核对。该字节数是离线游戏文件大小，不是 APK／AAB 压缩大小。英语暂停门控修复后仅核对受影响的副本与时钟，不重复生成飞行资源。

已检查原生 Kotlin 类型与每日计时边界，已修复 Activity 重建并发持久化及原生暂停后复习时钟恢复的问题。当前没有 APK 安装、平板真机触控、系统 TTS、WebView GPU／内存或完整 Gradle 资源合并验收；静态资源整理与纯逻辑结论不能替代这些结果。
